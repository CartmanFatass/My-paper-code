# Spec 颗粒度与范例复用

目标是找到适合重复 RL 工程任务的交接方式：减少遗漏、澄清和返工，同时保持最终质量。
先固定角色模型研究说明策略；后续才扩展模型。当前实现每轮只执行两题，不自动发起
整个比较矩阵。[一句话入口](QUICKSTART.md)直接把新打开的 session 作为 CM。

## 可复用内容与每题事实

| 可复用 | 每题必须查明或写出的差异 |
| --- | --- |
| 五项交接和精准引用方式 | 目标、所属路径、交付对象、预算与停止条件 |
| 某类任务的接口和边界检查方法 | 实际 shape、类型、单位、错误/突变约定 |
| loss、状态、随机流等常见处理骨架 | 本题已选定的 reward、时钟、mask、分母与梯度 |
| 局部代码例子及适用前提 | 例子在本题是否适用，哪些假设需要替换 |

必要科学事实在所有组完整可得。不能故意从 L0 隐去条件来制造高档优势，
也不能用范例默认值填补未知语义。同一事实只写或引用一次，避免模板与差异冲突。

五类模式覆盖 [loss/credit](patterns/01_loss_and_credit.md)、
[时间/状态](patterns/02_time_and_state.md)、[RNG/evaluation](patterns/03_rng_evaluation.md)、
[runner/publication](patterns/04_runner_publication.md)和
[集成/受限性能](patterns/05_integration_performance.md)。
它们来自当前项目工程边界的人工选择，不能当成工作频率统计。
三个可执行微例子提供局部参考，不是整题答案或新 RL 框架。

## 当前可执行比较

直接实现基线使用当前项目 Astra/medium CM + Astra/high reviewer。
委派场景固定 Astra/medium CM、Terra/high implementer、Astra/high reviewer，
对四档内容 × 两种方式进行可选比较：

- L0：当前五项交接。
- L1：加本题接口、数据形状与代码约定。
- L2：再加状态/数据流、关键分支和具体逻辑。
- L3：再加适用局部骨架或代码例子。
- fresh：CM 本次实际撰写；生成、澄清与纠错属于本轮成本。
- reuse：只分发该档允许的固定材料，CM 选择适用部分并补本题差异。L0 只有结构。

八个策略与一个直接实现基线是配置目录，不是一次运行九遍的指令。
每轮从五个经典任务中抽一题，从三个非范例中抽一题，默认预估难度不同。
同 CM 连续处理两题、真实子代理和杂务；同配置比较可重复 seed 并另开新 session。
第一题是常见模式，第二题明确改变某种适用假设，检验不加判断地复用的风险。

任务是基于当前 HMASD 源码边界重新构造的 bounded synthetic repairs。
当前题库/参考解/典型错误已做离线检查；easy/medium/hard 尚无经验难度校准，
也不能把两题等同于完整生产工程负担。仅不同题型和难度标签不能证明泛化。

原设计的 S1/H1/H2 和最多 21 次主研究属于实现前的大批次设想，已被本轮
“随机经典一题 + 非范例一题”的执行规模替代。未授权或自动启动该旧批次。
若后续比较更多策略，先选择有限配置和 seed，保留重复依赖，再独立选新题验证；
不从单次结果直接选生产赢家。配置见 [_host/MATRIX.json](_host/MATRIX.json)。

## Spec 本身也是结果

独立裁判检查事实完整性、引用可达性、说明准确性、模板适用性和档位遵循。
区分“缺少事实”和“事实存在但执行者忽略”。不合规运行仍保留原分配组，
另报遵循情况；不能事后换标签。真实 native 调用/返回用于核验实际子代理和首次上下文，
手写审查文件不能替代真实审查证据。首次实现快照用于判断 reviewer 的发现是否成立。

观察 implementer 追问、CM 澄清与编码接管、有效/无依据 review、前题回归和未完成事项。
详尽但错误的 spec 应是可见失败。先比较完整质量与严重缺陷，再看成本；
不为篇幅、更多检查或框架加分。当前零候选运行，不给最优档位或模型排序。

## 首次投入和实际复用成本

库制作/维护单列，当前为 unmeasured。每轮查阅、选择、写差异、解释和返工仍计团队成本。
fresh 的详细 spec/例子由 CM 真写并计入本轮，不能作为免费主持材料。
报告未摊销投入和实际已观察复用次数，只有数据齐全才计算摊销。
未来复用次数是情景估计；不能把历史 CM 数量当成未来复用次数。

成本由既有工具读取新 CM 根与全部实际子代理，独立裁判另列。
不能把 tree cost 再加一遍 child self cost，不能按字数估美元。
先前历史提取仅用于可行性与选材，不是此次模型比较结果。
只有后续独立比较支持的条目才可提议生产改动；benchmark 不自动修改生产工作流。
