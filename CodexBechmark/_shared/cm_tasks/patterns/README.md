# 可复用 spec 候选库

这是面向 RL 工程的第一版任务模式，供 CM 选用一个相关文件并填本次差异。
是待评测的工作流候选，不是新的强制规范、审批步骤或生产框架。
所有内容均须服从任务已选科学含义；范例里的约定不覆盖原卡。

每份模式沿用五项交接，并给 L1 工程约定、L2 逻辑与 L3 范例的增量。
不相关项目可省略，不要求读完整个目录。新测试时按档位分发，不能让低档候选浏览全库。
命名相似不保证语义相同；遇到例外，CM 应指出差异而不是强套范例。
