# RCLE CPC revision 04

This isolated package binds exact object `RCLE-CPC-SCIENCE-20260815-04`.
It does not import checkpoints, stochastic coordinates, seeds, or results from
earlier RCLE objects. `certificate` performs deterministic hand-written and
static conformance checks only. Every stochastic initializer, host object,
training object, and evaluation object requires both the hash-bound exact
certificate and an active Root direction-scoped production lease.

The production frontier is one complete three-arm seed directory. A directory
is installed only after its update-1000 checkpoints, all ordinary cells, both
held-out cuts, and registered diagnostics are complete. Analysis requires all
16 exact seed packets and never reads temporary seed state.

The frozen run uses one CPU worker and no GPU. The active lease's `memory_mib`
limits the current process working set. The registered 45-minute value is a
lease-planning envelope, not a cumulative scientific termination rule: current
lease expiry is enforced at each activity boundary, while cumulative runtime
and sampled peak RSS remain descriptive telemetry. It contains 3,727,360
episodes and 46,301,184 agent-phase decisions. Partial-result interpretation
and seed replacement are forbidden.
