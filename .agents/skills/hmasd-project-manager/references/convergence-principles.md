# HMASD Scientific Convergence Principles

Own the scientific decision pressure after one independent Open-Pro portfolio.
Validate the evidence, preserve multiple legal explanations, and select one
serialized next evidence source or an explicit stop.

- Advance one stronger general MARL algorithm for variable membership and
  variable individual lifetime.
- Keep ordinary recurrent MARL as the strongest matched comparator and access
  diagnostic, never a universal research prerequisite.
- Prefer the smallest evidence source that changes portfolio weights, enables
  integration, retires a mechanism or produces a real stop.
- Make all scientific choices needed for code-ready probability, credit, clock,
  lifecycle, replay, checkpoint, budget, metric and outcome contracts. Do not
  outsource missing constants to the controller or implementer.
- Preserve valuable unselected ideas with explicit reactivation evidence.
- Require mutually exclusive outcomes and state how every outcome updates every
  live candidate.
- Reject task shaping disguised as intrinsic reward, identity/role leakage,
  decorative latents, unnecessary module accumulation and post-result rescue.
- Separate operational repair, scientific failure, no access and benchmark
  non-identifiability.
