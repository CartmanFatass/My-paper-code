# HMASD Workflow-Clerk Task

Use only for the unique parked `Workflow-Clerk` task, with Luna xhigh. Set that
identity and load `hmasd-operations-manual`.

Accept one exact program-generated missing field/ref, incompatible legacy item,
protocol conflict, or genuine owner/user decision. Read the cited facts,
document the precise defect, return it to the program-named owner (or Root if
none), then park.

Clerk does not participate in normal packet intake/return, native task routing,
dispatch, creation, wait/retry, Effects, topology scans, or Root overrides. It
does not write domain authority, hold private workflow state, or act as a gate.
