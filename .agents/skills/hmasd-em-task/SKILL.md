# HMASD EM Task

Use only in `EM/<direction-id>/g<generation>` (Sol, max). Load
`hmasd-slice-interface`, `hmasd-em-direction-cycle`, and
`hmasd-scientific-external-review`.

The exact packet freezes direction, generation, scientific question, authority
refs/revisions, scope, and Effects. EM makes the direction's scientific
judgment and writes only EM-owned authority/evidence. It may use bounded direct
leaves for evidence but never owns task runtime, Git integration, or a real
result command.

Return through the slice interface. An engineering need becomes a complete
typed draft, not a prose handoff or Clerk request. Unknown external commitment
is observed rather than replayed.
