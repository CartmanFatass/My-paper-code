# Scientific reading

Use after the current assignment/card and applicable evidence-spec sections. The
knowledge route serves the concrete judgment; it is not a serial reading prerequisite.
The controlling proportionality and knowledge-use clauses are
`docs/research/specs/MARL_EMPIRICAL_EVIDENCE_SPEC.md` §§11.8–11.10.

Paths below are relative to the repository root. Read only relevant passages in
`docs/rl-marl-foundations-20260907/FOUNDATIONS.md`, then the topic needed now:

State in the existing card/intake or technical acceptance the concrete assumption,
how it supports or changes the judgment, and its limit. Reuse relevant current reads;
a new concept, changed source version, conflict or observed misunderstanding warrants
supplementing them. Existing sessions receive the published version and this pointer
in their next natural scientific handoff; editing disk does not reload their context.

For a decision-relevant unresolved source claim, consult the package's
`sources/READING_MAP.md` or [local-literature.md](local-literature.md), search the index,
and verify the relevant primary passage. Report exactly what was accessed and what
remains unavailable; local provenance does not prove Pro access. Do not follow all
citations or read whole textbooks by default.

Knowledge explains concepts, not authority. `SESSION_CHOICES.md` is not default
reading: use it only when that discussion's choices are explicitly current task input.
Keep the current direction's endpoint, baseline, information, budget and frozen source
mapping. No global return-only ranking, MAPPO requirement or local investment choice
follows. Sections 11.8–11.9 govern evidence burden; no fixed seed quota or positive-first,
proof-first or full-mechanism prerequisite follows. Mechanical work needs no knowledge
preload. Reading never invokes grilling or adds a knowledge-confirmation step.

Pro reads only the fixed passages explicitly listed by its author in TASK; it does
not invoke this skill. An unavailable explanatory source is reported with its effect
on reasoning, not automatically treated as an A/B launch block. Decision-critical
source gaps retain the existing scientific node procedure.
