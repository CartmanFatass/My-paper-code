# Portfolio reporting and owner-requested planning

Portfolio is the report the user reads, not a standing decision authority. DM owns the entire
lifecycle of its own direction. Direction Pro Convergence remains the independent scientific Reviewer; DM responds to its
findings and owns the resulting decisions. Portfolio reporting does not replace that review.
Clerk compiles current facts and coordinates accepted work; Root
is the user entry. Owner requests are required for Portfolio Pro consultation and cross-direction
adjustment. A DM result, consumed allocation, lifecycle decision, vacancy or timeout is not such a
request. Do not obtain Portfolio approval for ordinary research, family decisions, recast or C work.

## Current report

Maintain docs/research/portfolio/PORTFOLIO.md from current DM events/intakes. Use concise Chinese
with links: accepted conclusions and contrary evidence; DM's actual lifecycle decision and reason;
actual runs/reviews/consultations with owner/identity; completed results/costs and honest unknowns;
next DM action/revisit condition; and optional cross-direction choices for the user.
Keep recommendations separate from implemented facts. Reuse unchanged evidence rather than
re-reading history or requiring every DM to submit a new packet. Update on material changes.
A DM PARK/CLOSE is recorded directly; report released capacity without automatically filling it.
Do not keep stale pause/approval snapshots in the current report.

## Explicit owner commission only

If the owner asks for advice, prepare advice. If the owner asks to implement an adjustment, apply
only that requested scope; a request for a report/recommendation alone does not authorize changes.
For an explicitly commissioned Pro consultation, record the owner request and exact advisory or
implementation scope, gather relevant current DM facts and preserve competing proposals. Use
scientific-tools only for substantive scientific analysis, not mechanical report assembly.

Use hmasd-pro-research-prompt-author and the registered Portfolio binding only when that consultation
is explicitly requested. Clerk owns the new request's native Transport and full immutable archive.
Existing accepted requests retain their original bindings/parents; observation and archive continue
without a replacement Send. Stop unsent automatic planning and keep its source material as report
input. Do not silently apply a pending old Pro plan under superseded standing-finality rules.

Read the full commissioned answer; Clerk checks binding/completeness and sends the source to the
relevant DMs/user as advice or the exact owner-authorized assignment. DMs retain scientific judgment
and lifecycle ownership. Record actual recommendations/applied actions separately. Global layout,
new directions and new resource commitments require owner-requested adjustment; there is no
automatic grant, vacancy replacement or additional approval tier hidden in a report.
