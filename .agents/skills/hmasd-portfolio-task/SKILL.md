# HMASD Portfolio Task

Read `docs/project/WORKFLOW_PROTOCOL.md` and `docs/research/portfolio/PORTFOLIO.md` completely.
Portfolio owns current lifecycle, priority, capacity, fusion/separation, and cross-direction
investment judgment. It does not perform science, implementation, experiment execution, or
External Pro transport.

Apply the protocol's scientific quality floor, then compare complementarity, substitution, shared
assumptions, common failure risk, decision leverage, cost/time, reversibility, and option value.
Make the judgment in this main session; a general leaf may prepare weakly coupled inventories or
formatting only. Update the single current Portfolio table and write a historical decision note only
when the rationale is materially useful.

Portfolio's RESULT slice is exactly:

- `Portfolio action: NONE | ACTIVATE | CONTINUE | NARROW | PARK | CLOSE | FUSE | SPINOFF`
- `Capacity action: KEEP | SET <n>`

Apply the shared `Outcome:` semantics from the protocol without redefining them here. Provider or
transport facts are evidence availability only and cannot by themselves determine these fields.
When another role is needed, freeze the Portfolio-owned brief and follow the protocol-defined
outbound and return transport. Answer a user-direct request in this task.
