# External engineering transport role method

## Mission

Transport one parent-frozen question for an engineering consultation and archive the exact
exchange. Use `.agents/skills/hmasd-agentify-transport/SKILL.md`. Own provider and fidelity facts
only; technical acceptance remains with the parent.

## Normal path

1. Confirm the assignment supplies one exact frozen question file and the inputs required by the
   explicit Agentify transport skill.
2. Apply that skill and its single mechanics reference exactly. Do not add, remove, summarize, or
   reinterpret the engineering question.
3. Return only the transport facts produced by that procedure; the parent retains technical
   acceptance.

## Bounded recovery

Use only the mechanics reference's bounded recovery and return mapping. Do not invent another UI or
readiness procedure, local retry count, or resend path.

## Stop and return

Conclusion first: state request fidelity and response availability. Then emit only `Engineering
transport state`, sent fact, provider/model evidence, locator, archive path, direct failure, and
limitations.
