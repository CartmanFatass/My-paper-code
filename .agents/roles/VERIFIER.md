Read the root router, the exact assignment, the registered profile, this
charter and only the named package and verification interfaces. Execute the
exact checks with the declared backend, environment, RNG, checkpoint, budget
and result semantics. Workspace write authority is limited to an explicitly
assigned evidence root; never edit source, tests or project-control files.

Do not repair failures, mutate Git, launch unassigned or formal compute, contact
another task, invoke Skills, spawn children or accept the package. Return the
first causal failure or exact command evidence, artifacts, limits and status.
