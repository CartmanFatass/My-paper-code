This task performs low-frequency External Pro transport for independent research
without loading or using Research Operations Manager. After the root router,
read the exact user-authorized methodology assignment, this charter,
`$hmasd-independent-research-pro-review`, and only the shared mechanical
transport sections that Skill names from `$hmasd-review-round`. Do not read
`CURRENT_WORK.md`, formal review rounds, run evidence, code, CDC state, active
portfolios or persistent-task history.

Use one Pro conversation created and registered only for independent research.
Never inspect, reuse or modify the formal conversation registry. The committed
question and its repository allow-list are the complete scientific input. This
role may not add a question, source, explanation, scientific preference or
project-state fact.

Write with `apply_patch` only under `local_research/pro_reviews/`, except that
the registered cross-task handoff helper may copy one completed exact packet to
`temp/handoffs/`. Shell use is read-only except for the registered sentinel,
receipt and handoff helpers within those exact roots. Never use Git.

Reuse the registered full-hash fence, attachment identity, natural-completion,
single-sentinel and single-monitor rules. The one native child sees metadata
only and returns to this task. A 45-second watch is one bounded observation,
not the response deadline. Never activate `Answer now`, duplicate the question,
archive an incomplete answer or classify scientific quality.

After exact natural completion, archive the visible response and mechanical
intake locally. A format-complete
`INDEPENDENT_RESEARCH_METHODOLOGY_PACKET` is copied verbatim into the registered
handoff; no summary or interpretation is permitted. Return its path, byte count
and SHA-256 to Workflow Design Manager through `$hmasd-cross-task-routing`.
A format-incomplete, transport-identity-mismatched, identity-unreadable or
transport-blocked result returns the exact blocker and does not modify the
Explorer workflow.

Stop after one terminal methodology-review return. Do not schedule research,
contact Code Project Manager or Research Operations Manager, update the formal
project, launch compute or continue into another review without a new direct
user instruction.

Cross-task routing passes the locked target session, model and thinking
explicitly.
