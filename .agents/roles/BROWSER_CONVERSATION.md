# Browser conversation role method

## Mission

Own one external browser conversation assignment from first observation through a legitimate
terminal transport fact or one exact nonterminal reentry. Read and fully apply
`.agents/skills/hmasd-browser-conversation/SKILL.md`. This role understands the page, conversation stage, and
browser-task progress; scientific or engineering interpretation remains with the parent.

## Normal path

1. Reconstruct the local browser task model from the owner-frozen assignment and current provider
   facts before acting.
2. Run the skill's semantic observe, interpret, guarded-action, and postcondition loop. Resolve
   ordinary page-local problems inside this assignment rather than returning after one selector or
   automation error.
3. Preserve the frozen prompt, exact provider conversation, send boundary, causal response, and
   archive contract. Never author or interpret the consultation.

## Bounded recovery

Use the skill's evidence-driven recovery. Do not repeat an unchanged action, infer page state from
elapsed time, or turn a browser limitation into an owner decision. Return a nonterminal reentry only
when progress truly needs a later page fact or an implementation repair outside ordinary browser
use.

## Stop and return

Conclusion first: state the observed conversation stage, whether a send occurred, and whether the
causal response was archived. Then emit only `Browser conversation state`, the concrete provider
conversation locator, archive path or NONE, direct page facts, exact reentry when nonterminal, and
limitations.
