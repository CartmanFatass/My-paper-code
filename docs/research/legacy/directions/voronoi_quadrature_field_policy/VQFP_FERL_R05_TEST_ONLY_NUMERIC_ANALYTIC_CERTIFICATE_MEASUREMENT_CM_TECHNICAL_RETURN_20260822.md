surface it actually implements:

- two separately compiled C++ DLLs, one solver and one checker;
- fixed rational/dyadic numeric witnesses for every named function family,
  rounding-tie fixtures and the five binary256S operation classes;
- exactly 4,096 synthetic states, balanced over `N={4,6,8,12}` and eight
  algebraic proof strata;
- widths `1/32/96/128/256-linked`;
- worker counts `1/2/4/8`;
- exact integer count conservation, objective-bit identity, lexicographic
  fixture solutions and checker rejection of a tampered solution; and
- write-once TEST frontier publication plus exact latest-generation resume.

Every fixed fixture returned the same accepted digest across widths and
workers. No Python execution fallback, production registry entry, scientific
namespace, master, seed, coordinate, model, checkpoint, training, evaluation,
result or lease was created.

The complete enabling measurement is **not technically accepted**, because
the evidence establishes only fixed witness tables and eight closed-form
algebraic state families. It does not implement or bound:

1. an all-input correctly-rounded special-function/binary256S proof;
2. adaptive difficult-case precision or its certificate-size tail;
3. the generic nonconvex interval branch-and-bound/exclusion DAG for arbitrary
   registered r05 current states;
4. the exact r05 actor/critic/rounded reverse-mode/Adam update kernel;
5. the native full host/reset-to-terminal path; or
6. the complete exact rational/binary256 180-row analyzer.

Consequently the fast fixed-archetype rates cannot be extrapolated to the full
r05 panel. This is the Portfolio packet's explicit uncontained-tail return
