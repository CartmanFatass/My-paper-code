## Definition-complete prospective finite host

### Finite population and episode clock

- Joint training uses active roster envelopes `M in {4, 8}`. Evaluation with no further updates uses
  held-out `M=12`.
- Each episode has six ordered boundary windows. A physical member leaves after window 2 and rejoins
  with the same physical key but a fresh presentation index before window 5. The intervention and
  event log use physical keys; presentation indices are nuisance permutations.
- A boundary transaction is one selector read followed by one service action. Each active member has
  at most one read and one service action in a window.
- Exact balancing is over the joint tuple `(M, window, physical member, required publisher, relevant
  record slot, payload presentation, lane presentation, churn state, cue value)`. Paired arms share
  this tuple and all exogenous randomness except the named association intervention.

### Auditable event order and physical truth

For every service opportunity `j`, the host commits an append-only event row in this order:

1. Sample the physical service need and its required publisher `P*_j` independently of record slot,
   carrier identity, cue value, arm, action labels, and initialization seed.
2. Two distinct publishers issue immutable records `R*_j` and `D_j`, with unique record IDs,
   publisher IDs, payload commands, and issuance sequence numbers. `R*_j` is correct only because its
   publisher ID equals `P*_j`; `D_j` is a decoy. No carrier exists yet.
3. An independent balanced permutation places the two records in physical read slots, defining
   `T_j in {0,1}` as the slot containing `R*_j`. Another independent balanced permutation maps the
   two payload commands to physical service lanes.
4. The registry issues unique carrier objects and an immutable association table from carrier ID to
   record ID. Authentic carrier issuance occurs only after the truth and slot events are committed.
   A carrier is valid when its issuer, record ID, and issuance order agree with the registry; validity
   does not assert that its record is currently relevant.
5. A treatment-blind arm router exposes exactly one normalized hint field, one successful validity
   result, and the same read/service interface. The router cannot change records, payloads, physical
   truth, controller state, or event order.
6. The selector chooses a physical record slot; the frozen controller consumes the selected payload
   and chooses a physical service lane. The shared native reward is then computed from the committed
   publisher truth and physical lane truth, never from cue agreement, carrier ancestry, arm label, or
   action index.

Correct-record selection is therefore the same physical relation in every arm:
`publisher(selected_record) == P*_j`. The event log directly records every precursor and association;
ancestry is never reconstructed from a downstream label.

### Association arms and containing null

All learner-visible fields are normalized to `(local physical state, payload summaries, hint,
validity)`; no arm label or source-type token is visible.

1. **AUTHENTIC.** The valid carrier is bound to `R*_j`. Its normalized hint is the associated
   record's physical slot, so `H^A_j = T_j`.
2. **REASSOCIATED.** A whole valid carrier is drawn without replacement from another opportunity in
   the same exact balancing stratum and remains bound to its donor record. The donor construction
   makes `H^R_j` balanced and conditionally independent of `T_j`, while carrier validity, support,
   cue marginal, event count, lookup success, and work remain matched. No field inside a carrier is
   edited.
3. **PREDICTIVE_INDEX.** An ordinary treatment-blind index service emits the physical record index
   `Q_j = T_j` after the independently committed truth and placement events. It carries no carrier
   ID or record-binding semantics. The response is wrapped in the same-size envelope, traverses the
   same successful validation and lookup path, and is normalized into the same `hint` input. Thus
   the contextual-bandit null receives the same decision-relevant predictive bit, access, work, and
   validation geometry as AUTHENTIC without authentic carrier-to-record association.

AUTHENTIC versus matched REASSOCIATED is the association intervention. PREDICTIVE_INDEX is the
competent same-information containing null. A positive AUTHENTIC-minus-REASSOCIATED contrast is not
carrier-specific if PREDICTIVE_INDEX matches AUTHENTIC.

### Exact neutral initialization and held-fixed controller

- Every trainable action head begins with all Q values exactly zero. Before any reward update, an
  explicit neutral branch ignores every feature and chooses action 0. It is the same branch for all
  arms and all seeds; no tie order, hint, lane map, record index, feature layout, initialization seed,
  or arm label can change it.
- Exact balance makes the pre-update selector accuracy and pre-update service success `1/2`. The
  initial evaluator must report these values before any learning result is admissible.
- The anonymous shared service controller is learned first on a treatment-blind forced-record
  calibration population. It also starts from the exact neutral branch, learns only from the common
  reward, and never receives arm or roster identity. One resulting checkpoint is frozen and cloned
  byte-for-byte into every selector arm.
- Before selector training, that one checkpoint must pass forced-relevant and forced-decoy tests in
  every training envelope and held-out `M=12`, under both hint values and both churn states. Required
  competence is at least `0.90` correct service conditional on the forced relevant record in every
  cell. Forced relevant versus forced decoy must also show nonzero two-sided native-return headroom
  in every arm.
- Selector heads are then trained from the same zero state with the same contextual-bandit update,
  optimizer, learning rate, minibatch order, transaction clock, paired RNG roots, and frozen
  controller. No controller update occurs inside an association comparison.

The fixed controller makes record choice the only learned causal route to return. Anonymous shared
heads and physical-key evaluation prevent roster or presentation identity from acting as shortcuts.
