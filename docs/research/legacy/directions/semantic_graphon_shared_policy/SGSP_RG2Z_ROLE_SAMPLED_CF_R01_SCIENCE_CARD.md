## 3. One exact prospective origin-selection law

For each future seed block, update, arm-independent factual episode coordinate
and public role, select exactly one origin `(t_r,i_r)` from that role's
`12*(N/3)` agent-slot positions. Selection is fixed before the episode and is
independent of simulator state, buffer contents, event/report presence,
factual or alternative action, policy probability, gradient and outcome.

The 32 factual episodes for a given roster in each update are grouped into 16
fixed episode pairs. For each pair and role, one fresh arm-independent base-
slot selector address
`(namespace,seed,phase,update,roster,pair,role,base_slot)` draws
`b_{pair,role}` uniformly from `{0,...,11}` and omits episode side. Side 0 uses
slot `b_{pair,role}` and side 1 deterministically uses slot
`11-b_{pair,role}`. Separate side-specific arm-independent addresses
`(namespace,seed,phase,update,roster,pair,side,role,local_index)` choose the
role-local agent index uniformly from `{0,...,N/3-1}`. The two arms use the
same selected role, slot and local index at the matching factual episode
coordinate.

This antithetic time pairing is prospective workload balance, not outcome
stratification. Each selected slot is marginally uniform, each pair has exactly
13 current-through-terminal transitions and 11 future-only policy rounds, and
each episode still has exactly one selected origin per role. There is no
retry, replacement or extra selection when an origin is empty, locally
ineffective, low-probability, saturated or scientifically inconvenient.

The base-slot selector address omits side; only the local-index address includes
side. Both omit arm, state, action, buffer, report, branch and outcome. Numeric
seed labels and the namespace master word remain unbound until a separately

## 4. Full-suffix unilateral counterfactual target

At a selected origin, retain the complete branch origin after all agents have
computed their current observations, messages, role summaries, post-GRU hidden
states and legal distributions and after the factual joint actions have been
sampled, but before the simulator transition mutates state.

For the focal selected agent `i` at slot `t`, construct one complete vector

\[
\widehat Q_{i,t}(a),\qquad a\in\mathcal A_{i,t},
\]

over every currently legal action:

- for the factual label `a*`, reuse the factual episode's terminal return
  `J_base` under a required factual-branch identity;
- for each nonfactual label, restore the same branch origin, replace only the
  focal current action, hold every teammate current action equal to its
  factual value, apply the ordinary current simulator transition, and then
  recompute every agent's observation, message, recurrent state, legal
  distribution and action closed-loop from slot `t+1` through slot 11;
- every branch uses the immutable pre-update parameter snapshot and the same
  complete future environment/action-uniform potential tape; and
- the branch label, forced action and execution order never enter stochastic
  addresses.

The factual-action intervention must reproduce the factual suffix and
`J_base`. Open-loop factual future actions, factual future hidden-state replay,
shortened horizons, one-step bootstraps, branch-specific resampling and
probability/effect/outcome pruning are forbidden. Each Q entry is one full-
horizon Monte Carlo potential outcome on a shared tape, conditional on factual
teammate current actions; it is not exact expected `Q^pi`, joint-action credit,
Shapley credit or an inferential replicate.

The branch engine may stream, batch or exactly cache only if it preserves every
logical Q entry, complete state, remaining tape address, recurrence, horizon
and factual identity. Apparently empty or ineffective legal actions remain in
the vector. No branch state, private future value, Q vector or branch history
may enter execution inputs, the critic, replay, checkpoints, evaluation or

## 5. Actor estimator, retained critic and one update

At each selected role origin define

\[
\widehat B_r=\sum_{a\in\mathcal A_r}
 \operatorname{sg}[\pi_r(a)]\operatorname{sg}[\widehat Q_r(a)],
\qquad
\widehat A_r=\operatorname{sg}[J_{base}-\widehat B_r].
\]

The score part of the per-episode actor loss is

\[
L_{score}=-\frac13\sum_{r\in\{W,E,R\}}
 \log\pi_r(a_r^*)\widehat A_r.
\]

Equal role weighting is mandatory. Each role owns exactly one third of the
original factual agent-slot mean in every balanced roster, so uniform origin
selection makes this an unbiased estimator of that all-origin score term
before nonlinear global clipping and Adam. Averaging over ten Q entries would
incorrectly overweight the four-action relay role. The sampled trainer is a
distinct finite-budget parameter trajectory, not a semantics-preserving
subsample of CCA and not an estimator of CCA's final policy.

Retain the inherited factual entropy average over all agents and all 12 slots,
and retain the inherited critic, terminal-`J` critic target, coefficient,
parameters, initialization, optimizer grouping and contribution to the one
concatenated global gradient clip. The critic never appears in
`widehat A_r`. The complete per-episode loss is

\[
L=L_{score}-0.01\operatorname{mean}_{i,t}H(\pi_{i,t})
 +0.5\operatorname{mean}_{t}(V(g_t)-J_{base})^2.
\]

Average episode losses equally over the 64 factual episodes. Complete every
base episode and its three selected-origin Q vectors before the single
full-batch backward call. Then apply the inherited global clip, Adam update and
arm projection. There is no auxiliary target, replay, importance weighting,
extra actor sample, branch-policy log probability, second backward call,
minibatch, epoch, validation or checkpoint search.

Origin sampling is unbiased only for the preclip score term. Global clipping,
critic-gradient interaction and Adam make the realized optimization path part
of this exact package. No result may claim unbiased post-clip updates, CCA
equivalence, or isolation of the counterfactual baseline from the retained
critic-and-clip system.
