Select `RETAIN_PHYSICAL_PRIOR_COLDSTART` only if every condition holds:

- direct `PHY-TRUST - EDGE-FLEX` held-out lower endpoints exceed `0.04` at

  held-out sizes;

This supports only the science card's exact finite-budget, exact-task,
adaptation-free held-out-roster package claim.
