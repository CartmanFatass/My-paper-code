## 二、为什么值得买一次，而不是把保留候选误当授权

所要改变的仍是既有可选理想公共分配器的开发选择：是否把这一 learned correction 留在已可用 greedy／nearest 服务规则旁，作为有进一步开发价值的选项。没有新的接收项目、场景需求或 field application 被发现。四个角色各自有不可替代的用途：新自身初始化显示 q 提供的起点；final256 显示真实学习后的 sampled policy；固定 greedy 防止把规则能力记为 learned increment；nearest 保留另一已取得成绩的合法参照。这比只测 q 或再看旧 checkpoint 更直接回答已选的增量服务问题。[投资问题，Why buying an observation][question]；[提案，One fresh identity and four comparison roles][proposal]。

A 的经验动机不是抽象的“仍有可能”。B08 已经真实学习并从自身初始化改善，当前又有一个明确的强参照、唯一的行动概率改动及一套能够否定其用途的完整比较。新方案直接向实际行为分布提供 greedy 的当前偏好，而不是再次要求原均匀起点配方自行发现它；但是改变起点和每步偏好是否带来有用服务，仍完全是待测问题。这个区别足以支持一次有界 B，不足以证明初始化就是旧失败的原因。[B08 E0，Binding / Native service / Exposure][e0]；[候选答复，第一、三、六节][selection]。

B 的反对理由必须保留：现有规则已经解决了相当多的服务结构，值得学习的偏离可能很少；随机偏离会改变后续位置和下一次 greedy 输入，甚至破坏其服务；较强偏好也可能减少有益替代动作的采样。先前 nearest-prior 配方的失败提醒我们，导入好规则并不保证学到增量。新 fit 还可能只是撤销 q 随机偏离造成的损失，而没有胜过 deterministic greedy。缺乏新起点结果与完整费用预测，使此次选择不能写成“已经证明便宜而有效”。[候选 intake，Retained question / Evidence, claim ceiling][selection-intake]；[当前 DIRECTION，Current position][direction]。

我仍选择 A，是因为这次支出严格换取一个具体、能改变开发建议的完整观察，并且预先保留最有力的否定性比较；不是因为参数少、native 曾经很快、候选被保留、机器可能空闲或旧投资已经发生。600 秒支持与 180 秒 native 是明确愿意承担的有限风险；材料没有提供成功概率或定量收益模型，我没有补造。若现在选择 B，保持未拨款也完全不需要证明方法不可能；只是本次权衡中，我更重视取得这一个增量服务观察。[投资问题，Portfolio principles / Complete work][question]；[证据规范 §8.1、§§11.8–11.9][spec]。

## 四、绑定的策略、学习与合法信息

### 唯一行动法则

每个实际公共 snapshot 上，以已有精确 greedy phase g(x) 构造

`q(s|x) = 0.9 * 1[s = g(x)] + 0.1/N`

`pi_theta(s|x) = softmax_s(log q(s|x) + z_theta(s,x))`。

epsilon=.1 固定不调。g(x) 最小化同一 N 个循环分配的总绝对环形距离，signed distance 在半圈按 clockwise +60，精确平局取最小 phase。z 保留 shared 8→32→32 tanh assignment encoder、实体 mean pooling、四个公共 context 标量及 36→32→1 scorer，共 2,561 个 FP64 参数；其他 affine 层 fresh fan-in uniform，末 scalar 层为零。[B09 提案，Exact proposed learner][proposal]；[policy.py，PhasePolicy / quota_arrays / greedy_phase][policy]。

每队每机会从实际组合分布抽一次 phase，并只累计同一次 draw 的 log pi。q 不含可学习参数，不等于可以从归一化与评分中删掉；不得从 q 采样却只评分 softmax(z)，也不得为 N 个实体复制同一个 team likelihood。保留现有 native action-selection 数值与语义，greedy argmin 不被替换成可微或浮点重建的近似。[提案，同节][proposal]；[完整候选答复，第三节][selection]。

新初始化是 pi=q，不是 B08 均匀相位，也不是 deterministic greedy。N8/N12 的 greedy 概率 .9125/.9083333333 是单次动作概率，不是 native competence 或 return 混合比例。16 次机会及各自闭环轨迹使 `.9*greedy-return+.1*uniform-return` 不成立；学习后 logits 可以压过偏好，.1/N 不是最终概率下界，.9 不是保留率或安全保证。不增加 teacher、critic、reward shaping、entropy/KL penalty、clipping、温度、gate、annealing 或 fallback。[提案，Exact proposed learner][proposal]；[候选 intake，Retained question][selection-intake]。

### 原生路径及一个完整 fit

保持 120-sector／六 beacon／H64 native roster host。t=0,4,...,60 重算实际实体 rank 和公开 demand；t24 的 membership／epoch 先于选择、运动及服务。survivor 保留自己的物理状态，departure 不再占行动行，newcomer 取得原生状态与脉冲；rank 不是持久身份。行动为当前 demand-list 中 `b[(rank_i+s) mod N]`，走原 MOVE-TO-CLAIM。公开物理状态、membership、demand 与事件是已有理想 dispatcher 的合法信息，不添加未来／私有信息。greedy 共享该调度设施，nearest 不需要 phase 消息，因此不声称等通信或等计算比较。[提案，Exact proposed learner / Four comparison roles][proposal]；[B08 card，Question, learner, comparator][card]。

**选择所供未筛选 seed29 的一个新 fit**，由 DM 在实际准入后绑定 `RCLE-TBCFV-B09-GREEDY-ANCHORED-PHASE/seed/29` 的既定 SHA256 master 和 run_block0，沿原 semantic HMAC/address law 生成。不是恢复 seed28、挑选 seed，或重用旧 root/tape/checkpoint。训练 update1..256、cells0..7、rows0..7；评价 update0、held-out cells8..15、rows0..63。本次审查未构造这些 master、随机流或模型。[提案，One fresh identity][proposal]。

一个模型、一个 Adam(lr=3e-4, betas=.9/.999, eps=1e-8, weight_decay=0)，256 个 64-episode block，八个 6/10 training cell 各八个 episode，native batch32。每个 episode 直接取得 `Y=1-sum64(u)/64` 与 `score=sum16(log pi)`；loss 为 `-mean64(stop(Y-cell_baseline)*score)`。每 block 一次 backward／Adam；finite loss/gradient 检查在参数与 baseline mutation 前，随后按既定 .95 衰减更新八个初始为零的 cell baseline。仅 final256，无早停择优或训练延长。[提案，Exact proposed learner][proposal]；[policy.py，adam_update][policy]。

## 五、四个面板、主量和实际后果

四角色各完整 512 episodes：本次 q 的 own initialization、sampled final256、GREEDY-QUOTA-PHASE、INDEPENDENT-NEAREST；每角色八个 held-out 8/12 cell×64 scenarios。init/final 共享声明的外生语义坐标与 phase uniforms，固定规则只共享外生地址，每个角色保留自己的行动、占位与轨迹。newcomer 位置按各角色自己的占位和共同 ranked keys 生成，相同 keys 不保证相同物理事件结果。旧面板或历史平均值不能替代任何新角色。[提案，One fresh identity and four comparison roles][proposal]。

两条 ACTIVE_CONTINUATION churn 路径 P={8→12,12→8} 等权。分别报告 `D_g = mean_P(U_greedy-U_final)`、`D_n = mean_P(U_nearest-U_final)`，及 `G_U = mean_P(U_new_init-U_final)`。D_g/D_n 的本地 MEI 各为 **.025 U**，表示 40 个 post-event ticks 中一个归一化 unmet-demand tick；此尺度不是 G_U 的阈值、等价界或跨方向统一门槛。每路径、全八格 U/F/failure-coded tau/40U/full-Y、曲线、实际曝光、参数位移及所有 adverse observations 都保留。[提案，Primaries / Interest scale][proposal]。
