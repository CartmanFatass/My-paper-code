## 1. 本轮要解决的问题

把后续工作集中到三个证据缺口：**目标任务上的基线能力、独立训练复现、机制归因**。
K 轴研究技能何时结束，N 轴研究成员变化后如何保持协调。双轴是研究组织方式；具体方向的融合、归档和席位变化，依照最新证据分别形成决定。

历史覆盖率不是当前 cluster 宿主的可比 J 标尺。Scenario 1 reward 还含质量项和高度惩罚；跨宿主、配方、预算的数值不能直接建立已达能力或可达下界。

### 对 2 SD 判据的校正

按五个已归档 FSD 配对差值做事后描述性复算，均值为 **0.0674370791 J**，差值的样本 SD 为 **0.0848818879 J**，均值 SE 为 **0.0379603343 J**，2 SD 为 **0.1697637758 J**。四个差值为正。

若把规则具体化为“配对差值均值 > 2 × 配对差值样本 SD”，这五次观察不满足该规则。这是对一种明确解释的描述性核对，不改变五个原对象的读数或判定。原计划 B5 使用 IQM 差值，且没有定义所用 SD 是各臂 SD、合并 SD 还是配对差值 SD；五个配对差值也不能确定“两臂 IQM 的差”。不能凭本次均值复算直接重判 B5 或其 FSD 推荐，更不能把上述统计量互换后形成新的成功判定。

## 3. 修订后的推断原则

1. **效应价值与估计精度分别定义。** MEI 描述研究上值得关心的差异，事先结合任务效用或成本说明理由；seed 波动用于判断精度和设计重复规模。保留有理由的 MEI，取消统一 2 SD/±1 SD 判据，不另设统一 0.01 J。
2. **先确定所估计的量。** 学习曲线、固定训练终点、样本效率和经验证集选择的 checkpoint 是不同问题；主要量及选择暴露在运行前写明。
3. **独立训练是学习结果推断的基本单位。** 评价回合嵌套于训练实例；重复 checkpoint 也不增加训练样本数。配对须由设计支持，不能只看 seed 编号。
4. **报告效应和匹配该单位的区间。** 区间依赖的方法、模型及少样本限制必须明确。区间宽时报告“不确定”；支持实际等效需要对预先定义的等效区间有足够精度，点估计落在 ±SD 内不能证明 null。
5. **聚合工具服务于问题。** 单任务保留每个训练实例和曲线；跨任务聚合明确任务权重、尺度、归一化与抽样层级，适用时用 IQM/bootstrap。bootstrap 不能创造独立训练信息。
6. **重复规模与主张匹配。** 少量 seed 仍可做开发探索；更强的性能结论需要相应重复与精度。五个或十个 seed 是可能的规划数，不自动保证充分性，也不成为所有探索的启动条件。需要追加样本时事先规定边界，避免看到理想结果才停止。

两项外部 addendum 数值只保留为待校正的原始建议。若 `J` 的变化只来自权重为 0.7 的 coverage 项，`0.05 J` 对应约 `0.05 / 0.7 = 0.0714`，即 **7.14 个百分点**，不是五个百分点。K 轴 2×2 设计若报告标准的等权边际中断效应，其尺度为 `[(I-128 − D0-128) + (I-1280 − D0-1280)] / 2`；不除以二的表达式是两个 simple effects 的和，MEI 必须先声明采用哪一种尺度。

方法依据：[Gorsane 等，2022，§§2.2、3](https://papers.nips.cc/paper_files/paper/2022/file/249f73e01f0a2bb6c8d971b565f159a7-Paper-Conference.pdf)、[Agarwal 等，2021](https://proceedings.neurips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)。本文的投入顺序是所有者本次选择，不宣称是文献的通用门槛。

### Scenario 1 首项比较的具体边界

- 起点：`envs/pettingzoo/scenario1.py`、`configs/config_1.py`、`hmasd/baselines.py`、`experiments/baselines/scenario_1/baseline_set.json` 及已有 E0 证据。算法开关存在不代表已接入同一宿主。
- 核心候选是 flat MAPPO 与固定 k HMASD；固定 k 的选择及双方调参暴露要可比较。MAT 可在确有比较价值和预算时加入，不固定为第三必选臂。
- 评估每臂信息、动作、reward、终止和归一化的一致性。记录梯度更新与实际开销；完整方法比较可声明不同更新安排，归因比较则针对具体混杂因素设计控制。
- 若采用每臂 n 个独立训练实例、每次 B 个环境步，两个核心臂的正式训练量为 `2 × n × B` team-environment steps；调参、评价另计。并行 lane 与 agent 数的乘数须按具体 runner 计入，不能由参考 episode 数猜算。
- HMASD 胜出支持该完整方法在此任务/预算下的价值；持平需要用精度区分等效和不确定；落后可以反映方法不适配、调参或实现问题，不能直接断言代码错误。隔离层次结构本身的因果作用仍需合适消融。
- 下一次卡片准备必须给出明确的 n、B、调参搜索范围、评价日程、实际源版本、执行负责人及现有或新申请的额度；本方案不虚构这些已获批准。

### N 轴必须区分的三种设定

| 设定 | 训练与执行条件 | 需要证明的能力 |
| --- | --- | --- |
| 共同训练团队的回合内成员变化 | 训练哪些策略、加入者来源、观测/通信和缺失掩码均明确 | 在成员进入/离开后保持或恢复团队回报；状态连续性可作具名消融。 |
| train-N / test-N′ | 测试人数/组成超出或不同于训练分布 | 人数或组成迁移，不能替代回合内 churn 证据。 |
| 开放式 ad hoc teamwork | 单个学习者与不能共同训练的队友合作 | 适应未知队友策略与队伍变化；GPL 属于此类。 |

## 5. 宿主、方向与自动化

受控小环境用于解释机制，外部基准用于可比较的性能验证；两者均保留明确版本、任务分布和比较条件。检查固定方法的能力和缺口很有价值，但没有显著缺口不自动禁止探索；拥有特权信息的 oracle 也不能单独证明灵活时长或成员机制是缺失能力。

方向收敛依据问题、比较器、估计目标和现有证据。可以成为同一问题消融的内容准备合并方案；偏离目标的方向准备历史保留方案。逐项刷新当前 DIRECTION、最新 intake 和负责人事实后，再形成具体生命周期/投资决定，不按名称执行“归档 22 个”。

每项研究应能回答：本次结果将改变哪个判断？下一比较将排除哪个解释？共享结果摘要可从既有记录提炼，不新增重复台账。预测、原始证据、反例与必要追溯继续保留。

代理在已经确定的范围内自主完成工程、实验、收集和解读；独立审阅提供可质疑的意见。本次未采纳逐卡人工审批、取消既有委托或把 Pro 权限整体改成仅评论的建议。
外部 addendum 所写“每个 rung 入口和转换都需所有者批准”及“停止无人值守的新对象选择”也未获采纳；现行 AGENTS §§2、4、5 的分层权限和无人值守委托继续控制。
