# Full-direction MARL evidence-standard reaudit candidate

Date: 2026-09-01

Status: `PREDECISION_EVIDENCE_PACKET`

This document does not mutate Portfolio lifecycle. It records Root's candidate synthesis for the
`portfolio:cross_direction` decision after a read-only review of all 35 registered direction
authorities under `docs/research/specs/MARL_EMPIRICAL_EVIDENCE_SPEC.md`.

## Decision question

Which directions should be ACTIVE, PARKED, or moved to legacy after correcting the previous
over-application of conclusion-bearing/formal requirements to exploratory MARL work?

The audit applies four rules:

1. A/B work is adaptive and has no one-shot consumption state.
2. Missing telemetry, invalid implementation, absent runtime observation, or another incomplete
   assignment produces no scientific polarity.
3. A valid C result consumes its exact frozen object, not its direction.
4. A direction is closed only for structural impossibility/equivalence, genuine absorption,
   sufficient independent bounded evidence, or absence of a valuable executable question at every
   appropriate evidence class.

Capacity is unbounded. ACTIVE therefore means that a concrete, valuable, tier-appropriate next
object exists; it does not assert that all ACTIVE objects have equal priority or should claim more
than bounded toy/benchmark evidence.

## Cross-direction fusion boundaries

Fusion does not transfer result polarity. Each accepted direction inherits only the named question,
control, implementation primitive, or invalid-attempt replacement obligation.

1. **Temporal programme — SCDMP**: event-order value is the main policy question; RISP supplies
   Bayesian duration-memory evidence; ONLGR supplies rate/link controls; EBCR supplies coordinated
   renewal and one unchanged incomplete-C replacement; APFI supplies only prospective host ancestry.
2. **Relational/variable-roster programme — FRRIE**: tight-versus-containing relational package is
   the main comparison; SGSP supplies treatment ancestry; CCIC supplies covariance/motif controls;
   Field-slot supplies a variable-`N` compression B object; Roster-SMF supplies the exact-census
   control.
3. **Handover programme — DISH**: DISH asks which state source to transfer; VSP-05 asks whether the
   proposal should be accepted. Their comparators and endpoints remain separately identifiable.
4. **Roster-memory programme — RCLE**: RCLE asks about finite-budget persistent latent value;
   VSP-06 supplies the selective authenticated partner-memory branch. Information-necessity claims
   remain closed.

## Priority and execution implication

Unbounded capacity removes an arbitrary WIP cap but does not remove scientific or resource
dependencies. All 19 ACTIVE programmes may prepare or execute independent A/B work in parallel.
The first investment wave should favor `SCDMP`, `UCOPE`, `FRRIE`, `VNFC`, and CBSC because they have
the clearest existing mechanism, implementation path, and result-bearing bounded question. Every
result-bearing invocation still requires fresh 4 GiB physical/effective memory admission.

No claim in this packet promotes toy evidence to general MARL, UAV transfer, safety, or deployment.
No old valid C result is rewritten. No incomplete artifact is interpreted.
