# Incomplete assignment does not consume a scientific object

Date: `2026-08-31`

Owner: Root

## Decision

A scientific object and an evidence attempt are distinct. If a launch or artifact omits a required
prospective instrument, resource observation, or another element of the frozen assignment, the
attempt is invalid evidence because the assignment was not completely implemented. Quarantine the
artifact and give it no scientific polarity, but do not mark the scientific object consumed.

The invalid artifact cannot be resumed, repaired in place, salvaged, or used to tune its replacement.
After the defect is repaired, an outcome-blind fresh evidence instance may implement the unchanged
scientific object under a complete prospectively frozen contract. It must use a new result root and
fresh stochastic realization where the object calls for one, while preserving the frozen treatment,
comparators, population law, estimand, inference, thresholds and stopping rule. If observed outcomes
influence any of those choices, the work is a new scientific object rather than a replacement.

This rule applies independently to every incomplete attempt. A replacement that again omits a
required prospective or run-time element is quarantined in the same way and still does not consume
the object. References to “one” replacement describe the next planned complete evidence instance,
not a lifetime failure budget. Only a valid completed scientific assignment consumes the object.
