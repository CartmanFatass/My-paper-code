## Common gate order

All surviving learned work follows the same scientific order:

1. authentic support and causal ownership;
2. native action/return headroom;
3. competent same-information containing null;
4. matched information, environment interaction, optimizer exposure, and useful work;
5. held-out condition that tests the claimed generalization;
6. only then a structured learned comparison.

A transport failure, engineering failure, weak comparator, representation response, or proximal
metric does not establish scientific polarity.
