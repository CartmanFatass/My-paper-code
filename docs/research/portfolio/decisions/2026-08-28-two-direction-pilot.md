# Historical Portfolio decision — two-direction pilot (2026-08-28)

This note is historical rationale, not current lifecycle state. The current
table remains `docs/research/portfolio/PORTFOLIO.md`.

## Considered set and quality floor

The native task list showed no current EM/CM participant for any direction;
archived pre-cutover tasks were treated as historical evidence only. The
reviewed candidates were the registered directions with retained science
cards and prospective continuation language. ONLGR and EGRCR were the only
pair with explicit, bounded answer-changing discriminators and traceable
source material at the current quality floor: each states a clear question
and non-goals, matched controls, an interpretable discriminator, distinct
scientific versus execution failure handling, and a claim ceiling.

APFI was not selected because its censored-flow object is still an unreviewed
constructive draft. UCOPE was not selected because its accepted R03 result is
a terminal fixed-budget support failure with same-question rerun and successor
prohibited. Other retained directions were either closed/non-identifying,
covered by a cleaner route, or lacked a currently authorized answer-changing
object.

## Decision

The exact pilot capacity is two concurrently advancing directions:

1. `expressibility_gated_renewal_credit_relay` (EGRCR), an enabling
   waiter/joiner interaction and association discriminator; and
2. `opportunity_normalized_lease_gated_rebinding` (ONLGR), a direct marked
   lease-censored physical-time variable-`k` policy discriminator.

They are complementary rather than duplicate: EGRCR tests whether correctly
associated delayed interaction credit changes selective renewal, whereas ONLGR
tests whether a physical-time probability link changes cadence robustness.
They share ordinary-GAE, finite-renewal-host, matched-tape, finite-budget and
support risks, so the pilot is deliberately limited to two. EGRCR is cheaper
and reversible as an enabling test; ONLGR has the more direct project-facing
algorithm leverage. No numeric score, vote, or VOI is inferred.
