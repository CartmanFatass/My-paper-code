# 问题

收到搭档快照时，保留一半旧状态能否提高训练后的服务？

# 机制与比较器

固定一半旧状态加一半完整桥接，比较完整替换；各训练16轮，评价同一组四种条件。

# 结果一句话

半保留平均434.5，替换441，差−6.5；四项差值−15、0、−8、−3，未达24的关注尺度。半保留多4次无效提交。

# 预测核对

事前“弱正向”猜错符号；你的预测未作答。

# 排除了什么

本配对不支持固定半保留的服务优势。没有普通换主，不能判断状态来源价值；一个训练配对不证明普遍无效。

# 下一步与需要你做的

按既定规则保留替换，不延伸此候选，不自动加种子。观察命令耗时未测，完整成本上限不能确认；服务结果仍可读。无需回复。
