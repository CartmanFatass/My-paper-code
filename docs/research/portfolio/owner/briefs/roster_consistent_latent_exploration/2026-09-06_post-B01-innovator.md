# RCLE B01 后 Innovator 决定简报 — 2026-09-06

**一句话**：Pro（PRO_FINAL）不接受 DM 的“先单臂学到会”阶梯，直接开一个改步长的配对 B：**RCLE-TBCFV-B02-NORM-0p02**——两臂（C1P1 持久共同计划、FLEX 重键）都把每次非零联合更新的全参数欧氏步长从 0.0005 改为 **0.02**，新配对种子 18，每臂 200 次更新 × 64 episode，最终八个留出格各 256 episode；主量改为两条成员变化路径（8→12、12→8）的 **U 差**，并加一次共享的初始化评估和一次同面板最近信标参考。不停车，不冻结 C，不改定义卡，不动 Portfolio。

## 理由

B01 是真实、完整、但几乎没有改善的学习观察，已经足以支持一次具名的学习器改动。在近似原有交互规模上改一个明确的更新量，比先做到单臂 4,000 次（训练 episode 是本对象的十倍）再把“出现完美恢复”当作比较资格更直接、更省。

## Pro 对 DM 的更正

- “τ 离开 40”不能当有用学习的通用资格线：最近信标参考在两条路径上需求明显更少，却也几乎从不连续四 tick 全服务；U 可以先于首次完美恢复改善。
- 1.4e-8 是两个位移范数之差，不是两臂参数轨迹的距离；共享抽样不能保证换种子仍相同；`parameter_delta_norm` 打印的是常数 0.0005，不是实测位移；200×0.0005=0.1 只是路径上界。B01 让更新法则值得改，没有证明归一化 SGD 错误。
- 不选普通 0.01 学习率（按已记录梯度范数算出的步长约 0.000439，与旧值相近）；不选非零 FLEX 头初始化（合法但多加一个起点因素）；不先买 0.0005 下的第二个种子（seed 18 在新步长下**不是** B01 的重复，B01 的种子不确定性仍未解）。
- 对本选择最强的反对：0.02 是旧步长的四十倍，可能主要放大梯度噪声、让策略更差，或仍无实质函数变化；没有量级扫描证明它恰好合适。

## 对象要点

- 唯一改动：g≠0 时 θ ← θ − 0.02·g/‖g‖₂，g=0 不更新；每 64 episode 一次 backward 一次联合更新；两臂同法则、全向量归一化。其余宿主、信息、初始化、回报、baseline 全同。
- 种子 18：master = sha256("RCLE-TBCFV-B02-NORM-0p02/seed/18")，再按现有 `_derive_block_digest`、block 0 派生。
- 共享 update-0 评估（C1P1 初始化策略，八格各 256）作为两臂共同起点；伴随量 G_U = 两路径 (U_init − U_final) 均值；主量 ΔU = 两路径 (U_FLEX − U_C1P1) 均值，正值利于 C1P1；MEI U 0.05、τ 伴随 4 tick；六行读法。
- 成本：每臂完整调用 ≤ 600 s，整对象累计 ≤ 1,500 s（含构建、聚焦检查、参考、发布）；B01 的 62/69.8 s 只是同规模的量级参考。
- 发布的 `parameter_delta_norm` 不得再打印 0.0005 冒充新量；CM 只做最小适配，不改全局常数，不动 B01 代码。
