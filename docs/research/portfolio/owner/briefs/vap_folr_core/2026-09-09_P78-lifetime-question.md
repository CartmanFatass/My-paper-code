# 问题
是否值得在明确公开车辆生命周期事件的新版本上，比较保留与清空幸存车记忆？

# 机制与比较器
两边都知道发生了车辆进出及自己是否新生；新车都从空状态开始。通用循环策略保留幸存车历史，另一边在事件后清空它。

# 结果一句话
Root恢复发送后，原节点选择这个有限问题；它认为价值接近“不再计算”的备选，尚无性能结果。
