# HMASD Research Map

This is the human navigation map for the repository's 33 research directions.
It records a concise position and links to stable research and code
directories. It is documentation, not an authorization, scheduling, lease, or
workflow surface. Historical CM, EM, gate, and lease wording inside linked
artifacts remains provenance only.

Status snapshot: 2026-08-24. A direction can be reopened whenever new evidence
or an explicit research decision makes it worthwhile.

## Portfolio summary

| State | Meaning |
| --- | --- |
| `ACTIVE_ENGINEERING` | A concrete implementation step is the current next work. |
| `DORMANT_REVISIT` | Retained but intentionally inactive until a named reason to revisit. |
| `RESOURCE_WAIT` | Scientific value remains, but the current implementation cost or substrate is unsuitable. |
| `RETAINED_RESULT` | The completed result remains useful; no immediate follow-up is selected. |
| `SCIENTIFIC_NO_CURRENT` | No answer-changing current object is identified; this is not a permission failure. |

## How to use this map

Start with the direction row, then read its science cards, result/disposition
documents, and `CODE_SCIENCE_INDEX.md` where present. Candidate code is
isolated until deliberately integrated into a production route. Update this
map when the concise scientific position or stable directory mapping changes;
do not add runtime status, leases, process IDs, reviewers, or handoff receipts.
