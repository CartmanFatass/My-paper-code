# Root Problem-Family Research Portfolio

## Purpose

This document preserves Root's live multi-direction research map after the
session's control-plane correction. It prevents two recurring errors:

1. treating missing code or a missing native host as scientific evidence; and
2. treating single-direction development and multi-direction discovery as
   separate queues.

They are one research graph at different resolutions. Root discovers shared
unknowns across directions. A promising node may immediately become a
direction-scoped question: EM makes its scientific meaning complete, and CM
constructs or runs it. There is no fixed direction count or WIP slot. Concrete
compute conflicts may sequence commands, but do not control scientific
eligibility.

The historical words `FILTERED`, `ABSENT`, `PARKED`, `FAILED`, and `READY` do
not decide anything here. Each entry states the observed fact, the scientific
unknown, and the next discriminator in ordinary language.

## Project-level scientific destination

The portfolio is navigating toward one or more HMASD/MARL algorithms with this
minimum value contract:

1. the algorithm supports **variable agent count `N`** or **variable skill period
   `k`**; and
2. under at least one supported variation it improves **robustness** or **task
   performance** against a matched baseline.

Both clauses are inclusive alternatives. A useful algorithm may address only
variable `N`, only variable `k`, or both; it may improve only robustness, only
performance, or both.

Operationally, variable `N` means one shared algorithm and parameterization can
run at multiple roster sizes and at least one held-out size; an in-sortie churn
claim additionally requires join, exit, or failure during an episode. Variable
`k` means one algorithm adapts to externally varied skill periods or chooses its
own duration/termination; training a separate policy for every fixed `k` does not
qualify.

Toy environments may be designed for the algorithm. They are not required to
pre-exist in the repository. A toy is valuable when it isolates a causal failure
that also exists in a UAV setting and makes the transfer path explicit:

- what UAV change corresponds to `N` or `k` variation;
- which observations, actions, communication/coordination or credit mechanism
  are preserved;
- which churn, timing, partial-observation, assignment, or control failure is
  isolated;
- which robustness or performance metric will later be checked in a UAV
  simulator and, if warranted, on real UAVs.

The evidence ladder is: identifiable mechanism toy, a second toy with the same
causal structure but different surface realization, UAV simulator, and controlled
real UAV. Comparisons match physical time, training samples, model capacity,
communication and inference cost. At least one held-out `N` or `k` schedule is
required. Robustness is measured by degradation, worst case, CVaR or failure
rate; performance by return, success, task time, energy or safety. Ordinary
floating-point tolerances and uncertainty estimates are used; bit-level equality
is not an experimental criterion.

Root distinguishes three kinds of work:

- **direct algorithm candidate:** implements an adaptive policy/training or
  coordination mechanism for variable `N` or `k` and can progress from toy to
  UAV simulation;
- **answer-changing enabling experiment:** isolates a mechanism whose outcome
  selects, deletes, or materially changes such an algorithm family;
- **weakly aligned work:** has no credible path to either variation axis and no
  result that would change a better-aligned direction.

Mechanism novelty alone is not the destination. It earns investment only through
its decision value for the variable-`N`/variable-`k` algorithm program.

## Root routing rule

For every promising node:

- if the scientific question, comparator, observable, host dynamics, activity
  boundary, or claim ceiling is incomplete, use its EM;
- if those meanings are complete but code, host, adapter, runner, environment,
  launcher, or resource observer is missing, use its CM;
- if a real run yields no question-relevant data, return the unchanged science to
  CM or ask the same EM whether replication remains valuable;
- if the run yields valid data, return it to the same EM for interpretation and
  then use one science-minimal External-Pro convergence request;
- add or deepen directions by expected decision information, not by slot
  availability or repository presence.

For pure-theory and science-definition closure, the direction's ChatGPT
External Pro now owns the exact-revision mathematical/causal disposition. Before
production, EM freezes the complete object and asks the same Pro conversation
for `CLOSED|REVISION_REQUIRED`; any accepted science-bearing correction returns
as a new complete composite to that conversation. Local Principles/Critic calls
are optional advisory tools only, not prerequisites, co-signers, substitutes,
or vetoes. EM retains science authorship and interpretation, CM retains
technical acceptance, and Root retains portfolio and production sequencing. An
already active treatment is not retrofitted; its bounded interpretation receives
closure during same-conversation result convergence.

Every active promising algorithm direction also receives one independent
External Gemini innovator conversation by default. Gemini is used for divergent
world/domain-informed search—mechanisms, analogies, overlooked regimes,
counterexamples, scenario families, controls, and toy-to-UAV bridges—not for
convergence, formal causal closure, result acceptance, technical acceptance, or
portfolio selection. Those serious uses remain with local EM/Root, CM for
technical facts, and the direction's dedicated ChatGPT External Pro. The two
external conversations and intakes remain separate; transport serialization
does not make either one a substitute for the other.

## How Root coordinates EM and CM

Root does not ask every EM to rank ideas, and does not treat a completed science
card as an automatic experiment queue entry. For each problem family Root keeps
three research objects:

1. the shared causal unknown;
2. the strongest alternative that can explain the current evidence; and
3. the smallest discriminator whose possible outcomes lead to different next
   actions.

The concrete coordination cycle is:

1. **Family synthesis.** Root combines direction-local questions and warnings,
   without importing their results, and identifies a causal edge worth cutting.
2. **Direction formation.** If that edge is nonredundant and identifiable, Root
   assigns one direction EM. EM owns the exact host semantics, treatment,
   comparators, observables, activity boundary, interpretation map, budget, and
   claim ceiling.
3. **Root portfolio check.** Root asks only whether the completed card would
   divide the family, whether a stronger existing experiment dominates it, and
   which other directions each possible result would change. Root does not redo
   the EM's science or inspect implementation details.
4. **Immediate construction.** A meaning-complete, answer-changing card goes to
   CM immediately. CM owns all missing code and the real run. It does not wait
   for another direction to close.
5. **Conditional preparation.** While CM works, Root records how positive,
   negative, nonseparating, inactive, and no-data outcomes would alter the family
   graph. EM is re-consulted only for a real science ambiguity or result, not for
   engineering checkpoints.
6. **Result intake.** CM returns question-relevant observations and anomalies to
   the same EM. EM interprets only that direction. Root then updates the
   cross-direction graph: retain or delete mechanism edges, select the next
   discriminator, and decide where new single-direction depth is warranted.
7. **External convergence.** A valid result plus same-EM interpretation receives
   one science-minimal External-Pro request. Pro challenges the conclusion,
   strongest alternative, claim ceiling, and next discriminator; it does not
   validate files or code.

This makes EM and CM active research instruments inside Root's multi-direction
loop. EM supplies direction-local scientific depth; CM converts a scientifically
defined missing object into evidence; Root supplies cross-direction choice and
mechanism synthesis.
