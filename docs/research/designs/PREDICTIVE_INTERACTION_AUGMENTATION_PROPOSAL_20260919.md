# 科研提案：从历史有效性原型到预测式交互增强

日期：2026-09-19。性质：owner 请求的研究设计提案，供本 PR 审阅；不是冻结实验、
新方向登记或运行授权。合并只保留提案，不自动采用任一模型、修改基线、启动拟合或占用席位。
后续由实际方向负责人依据当时证据选择一个问题，使用现有 NOTES / CLAIM / runs，
保持原额度与暂停规则。本文件不成为第四种常规实验记录。

## 1. 问题与本次建议

外层研究循环负责从证据修正解释；内层 MARL 负责从交互更新参数。二者不能互相替代。
本提案优先考虑 N 轴：**在共同训练团队的回合内成员变化中，合法历史的预测性组织，
能否改善有限训练下的任务效用，而不仅是提高预测准确率或增加容量？**
不同时承诺未见 N 迁移、未知队友 ad hoc teamwork 或 UAV 部署。

建议首先把“历史是否包含有用信息”“怎样表示”“能否学会利用”“净收益是否值得”
分成可被不同证据改变的判断。以已有通用循环策略为起点，而不是保护旧增强架构。
开放小模型是一个可能的表示来源，不是先验必选组件；Jev 是结构化接口的参照，不是本地可复现权重。

## 2. 哪些判断要承担预测风险

| 判断 | 与替代解释不同的预测 | 哪类结果削弱它 |
| --- | --- | --- |
| H-need：合法历史含有当前线索不能替代的决策信息 | 在有独立依据的遮蔽/成员变化条件下，历史影响任务相关预测或行动后果；当前-only 不完全解释 | 在所测条件与足够敏感测量下，当前线索解释了相关差异；仍不推出所有环境都不需要历史 |
| H-aux：任务相关预测能帮助有限学习 | 预测改善伴随预定恢复/完整回报改善，而非仅训练拟合变好 | 预测更准但行动或 native return 不改善，或主要收益来自另一未预测变化 |
| H-pre：预训练提供额外先验 | 相同结构、输入/目标/微调权限下，预训练初始化比非预训练参照更有效 | 两者相近或非预训练更好；不能把辅助任务收益归于预训练 |
| H-use：完整方案值得投入 | 在声明预算、信息权利下有可重复的任务增量，成本可接受 | 只有额外算力/信息带来收益，或损害正常阶段、延迟与训练成本抵消价值 |

这些不是需要依次全部通过的门槛，也不假定 H-need 是所有表示收益的必要条件：
有限资源下，组织已经可得的信息仍可能有用。每次只选择真正影响下一步的判断。
某些实验可能没有区分力；允许明确写“未更新”，不要编造新的洞见或精确后验概率。

## 3. 简单原型与 MARL 的对应关系

### 3.1 实体老虎机：身份、槽位与漂移

构造独立实体 e 的 Bernoulli 收益，未知参数 theta_e；以 Beta(alpha0,beta0) 为先验，
成功/失败计数为 s_e/f_e，则后验为 Beta(alpha0+s_e,beta0+f_e)。
这是提议的分析模型，不是项目已有实验或对实际神经网络的定理。

分别处理：原实体暂时不可见；同槽位换了新实体；同一身份的收益规律改变。
身份索引统计、槽位保留、全部重置、带遗忘的更新在这些条件下有不同预测。
[BOCPD][2] 提供变化点/距变化点时间的不确定性原型，不提供共同学习队友的正确后验。

映射到 N 轴时须保留可观察的身份与生命周期权利；不能把模拟器真值暗中授予候选。
被简化掉的关键因素是队友的策略更新、联合信用、动作影响后续可见性和共同适应。
只有恢复这些因素后的学习比较，才能形成对应 MARL 主张。

### 3.2 切换代价原型：给 K 轴的独立问题

在声明的后续执行规则下，定义
`Delta(h) = Q(h, switch) - Q(h, hold) - c`，两项 Q 不重复包含本次切换成本。
[Option-Critic][1] 是价值相关终止的来源。若另外假设
`pi(a|h) proportional to exp(Q(h,a)/tau)`，则 log-policy gap 等于 Q gap / tau。
这是条件恒等式，不断言当前 coordinator 满足它。

它启发检查：gap 变化是替换价值改变，还是温度/熵/技能表征漂移？
回到 MARL 后还需研究同步与异步承诺、局部更换对队友的影响和团队信用。
这不是本提案同时启动 K+N 实验的理由，也不是重开任何已停止的固定对象。

### 3.3 干扰实体 contextual bandit：表示问题不等于协调问题

让奖励依赖集合中的少数关系，其余实体是干扰；改变排列、干扰数量和关系组合。
这能分析稀疏表示的有限样本作用；小型联合动作博弈则补回 bandit 没有的协调。
OPT [3] 提供稀疏、多样交互原型及重组的设计来源。不能因为图可视化清楚就称之为因果结构，
也不能把交互原型等同于可主动执行的技能。

原型可以仅是推导、反例或现有数据分析。没有强制先跑 toy 的阶段，没有正结果准入线。
失败只约束两者确实共享的假设；成功不外推到 UAV。

## 4. 可实现的预测式增强接口

### 4.1 先固定一个能观察的目标

优先使用轨迹已有的 native outcome，避免不可核查的“历史有效性标签”。
一个具体候选是：对窗口 W，预测本条轨迹接下来 W 个 primitive ticks 的平均团队奖励：

`y_t = (r_t + ... + r_(t+W-1)) / W`。

W=3 可作为 H20 宿主上的初始设计候选，非已冻结选择。训练前固定窗口、时刻约定、
终止/截断处理与归一化；不足 W 的窗口不当成零收益。若采用丢弃或截短目标，明确其
选择分布/含义，不把死亡或离开导致的缺失视为随机。成员变化后的恢复窗口与整回合
native return 都保留，避免局部改善掩盖全程损失。

该标签是行为策略下的事实未来结果，不是 switch/hold 或其他未执行行动的反事实价值。
对其预测好也不意味着学到了可控性。预训练模型输出是估计或软目标，不是观察真值。

### 4.2 小型辅助头与开放模型是可分开的实现

第一种低成本候选：在现有 Generic 循环表征上接训练专用预测头，用事实 y_t 做 Huber
或另一预先选定的预测损失，与原 TD 学习联合训练。预测头不参与执行动作，不修改
actor 的合法输入，不改变原环境奖励：
`L = L_native + lambda_pred * L_prediction`。
[UNREAL][4] 支持的是辅助任务可用于学习共享表示的研究先例，不能保证此目标在当前任务有用。

另一种候选：把合法历史编码到冻结的开放小模型，输出固定长度 z_t，作为训练侧
value / mixer 的附加表示；从共享任务损失学习适配器与读出。对 FOLR 必须按实际
utility/mixer、target network 与 replay 所有权实现，不能套用 PPO 术语改变更新规则。
在 UAV actor-critic 上选择 critic 路径则是另一项对象，不与 FOLR 的数值混合。

[LLaRP][5] 的先例是冻结预训练模型、学习输入和行动/价值适配；不是证明 0.8B 模型
能直接处理当前数值任务。语言模型可以贡献语义先验或序列表征先验，两者需由对照区分。
没有真实语义时不强行把数值状态改写为叙事，也不把任意 skill ID 解释成自然语言技能。

首个设计不同时加入蒸馏、奖励塑形、执行门控与可学习终止。输出先是预测表征，
不是替代原 actor 的高层规划器。模型容量、token 顺序与额外历史窗口都是潜在混杂因素。

### 4.3 信息、数据与成本边界

- 输入只含该模块在对应训练/执行角色下有权获得的历史。central critic 的训练权限
  不是 actor 的执行权限；额外历史权利须给主对照同等访问或标明为跨信息包比较。
- 未来结果仅作训练标签，不能进入当前输入或评估策略。replay 中目标策略/行为策略
  改变会改变预测分布；固定预测窗口不消除非平稳性或离策略问题。
- 训练/开发/评估按完整 world、episode、实体生命周期和拟合实例分组；
  不随机拆相邻窗口制造泄漏。在线预处理/归一化只用训练数据，评估不回写模型。
- 需要置换一致性时对实体排列、无关实体和槽位复用做相称检查；模型生成的文字说明
  不替代 native action/return 证据。局部观测切割造成的分布偏移也应说明。
- 准入、线程、设备和资源上限沿用现有工程方法。模型准备/辅助拟合/调参不能藏在
  “零 RL fit”中；在选择下一对象时声明其真实训练和非拟合工作。
- 计算分别报告环境交互、优化/推理量、完整 wall、峰值内存、训练准备与实际基站通信。
  冻结权重不等于无需反向传播：训练输入适配器时仍可能保存大规模激活。

## 5. 最小可选择比较，而非必跑矩阵

| 当前需要改变的判断 | 有针对性的比较 | 能与不能说明什么 |
| --- | --- | --- |
| 是否值得加入这个预测任务 | 同一 Generic 主干与原学习法；两臂都有相同预测头，lambda=0 对固定非零 lambda；所有额外准备计入 | 测预测训练包的增量，不证明 LLM 或历史语义必要；优化额外量仍报告 |
| 预训练是否提供增量 | 同一小模型结构/输入/读出/目标，预训练权重对固定非预训练初始化参照，微调权限一致 | 测预训练初始化包，不是语言语义因果证据，也不单独证明优于 Generic |
| 候选是否值得实际使用 | 已确定候选对有能力的同信息 Generic，原始 reward/终止和评价一致 | 测完整方法的任务与成本收益；参数量或表示不等时明确包级范围 |
| 收益是否依赖正确历史对应 | 针对明确假设的历史对应干预，保持其余输入/预算尽量一致 | 检查对应关系敏感性；打乱会引起分布偏移，不自动提供完整因果归因 |

这些是备选问题，不是四轮自动流水线。建议 N 轴负责人先读现有输出能否定位
成员变化后的损失；已有数据无对应字段时，明确缺测，不假装已诊断。
若低成本预测头的中间目标已经足够明确，可直接选择学习比较，不先做模型尺寸搜索。

一个可供选择的探索规模是两臂各三个新训练实例，共六次拟合，所有调参/辅助准备
须在同一前瞻额度中计入；若额外拟合使总数超出，缩小/改变问题或按现有规则申请，
不能把监督训练从科研成本中删除。单对两次拟合也可用作明确的探索性 screen，
但不能把其128个评估回合称为128次独立训练重复。

在复用 FOLR 当前学习法时，5000训练回合、4969更新、128最终评估/臂是一个已有曝光
参照，不是此提案已发布的命令或适用于所有小模型的预算保证。
具体 chosen arm、源版本、窗口、loss尺度、训练/调参权限、随机性与评价分布
应由所选问题在现有 NOTES 中前瞻确定。这里没有选 seed、模型 checkpoint、启动脚本或额度。
确认仍用新的 CLAIM 与独立训练批次；不得把此处探索或旧 A/G/Z 混成确认样本。

## 6. 每类结果如何改变下一判断

| 观察 | 应更新什么 | 不应自动做什么 |
| --- | --- | --- |
| 预测改善，native return 无改善或变差 | 弱化当前代理目标到控制价值的连接，检查任务相关性/训练干扰/成本 | 不将“预测更准”宣布为 MARL 成功，不立即换更大模型 |
| return 改善，但预期中间变化没有出现 | 保留完整包收益，修改机制解释 | 不把任何阳性记到原先的历史有效性机制名下 |
| 预训练与非预训练参照都改善 | 更支持结构/预测任务，也可能仍有未分开的优化因素 | 不宣称预训练知识是原因 |
| 只有预训练参照在独立条件下有稳定增量 | 增强预训练有用的判断，继续核对额外数据与成本 | 不直接外推语言常识、任意 N 或 UAV 安全 |
| 只在变化后恢复改善，正常阶段受损 | 描述真实权衡，按用途判断净价值 | 不只报告有利窗口 |
| 处理未触发、标签泄漏或技术失败 | 保留具体失败及已完成曝光，修正相关环节 | 不计为活跃机制负结果或偷偷退款 |
| 差值小且不确定性大 | 说明未有效区分；按复现/诊断的实际价值选择或闲置 | 不宣称等效，也不强制写新洞见 |
| 针对性修正连续未兑现其预测 | 削弱支撑希望的具体理由，可停止这条包/机制投入 | 不凭固定失败次数宣告全方向不可能，也不以无限优化借口保护它 |

不必先完全解释每次失败才能继续；便宜的直接比较可能比复杂诊断更有价值。
停止投入可以出于下一条信息不值得成本，必须与科学否证分开。

## 7. 模型与 Jev 的研究边界

[Jev 官方接口][6] 将 state 与 typed questions 映射到结构化决策/概率，而非长文字解析。
借鉴其输入输出形式，不假定其概率在本任务已校准；schema 正确不等于事实正确。
本次没有获得可复现 Jev 内部训练与权重的材料，因此不把它作为核心白盒方法。
此处的 Jev 模型讨论与仓库同名 Pro transport 路由是两回事；不修改传输工具或供应商设置。

[Qwen3.5-0.8B 官方模型卡][7] 提供一种开放权重起点，但没有当前 MARL 的功效证明。
0.8B、2B到4B只表示可考虑的资源范围，不自动排程规模扫描。
选择时固定实际 checkpoint revision、license、tokenizer、精度及适配权限；
只冻结模型权重也要说明是否经其反传。4B个FP16参数仅权重就约8GB（十进制），
量化不消除激活、上下文缓存、优化器、并行RL与其他进程成本，不能据此保证本机可训练。
无须引入 API key、下载模型或安装依赖来合并本提案。

可选的基站部署必须另外声明刷新周期、信息来源、丢包/延迟和算力分摊。
低延时是要测量的条件，不是由“小模型”这个称谓保证的收益。

## 8. 如何进入实际研究，以及如何退出

合并后，方向负责人可以在未来已授权工作中采纳、修改或拒绝本提案的具体问题，
理由留在原 NOTES；不要求每个方向都回复，不建立 adoption registry。
源码更新不证明运行中会话已加载；沿既有安全边界交接，绝不重发、重启或重算冻结对象。

优先建议是一项 N 轴问题，而不是 N+k+LLM 大组合。若所选目标没有可用标签或信息
对应关系不成立，可以换成更合适的预测量、使用小型专用网络、直接测试或闲置；
不要为了复现 OPT/Jev 外观而保护这套实现。真正的交付是被证据约束的下一判断，
而不只是一个新的模型名称。
