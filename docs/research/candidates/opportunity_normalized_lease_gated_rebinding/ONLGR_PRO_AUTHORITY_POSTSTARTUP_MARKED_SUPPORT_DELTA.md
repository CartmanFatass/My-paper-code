## Accepted authoritative defect

Every native and IID cell has 32 episodes and two agents, so tick zero supplies
exactly `32*2=64` rows. The virtual anchor makes `e_policy=8` and both marks
legal. The old predicate could therefore pass entirely on startup actions even
if no voluntary marked action occurred at a post-startup callback. Reporting
virtual versus observed exposure did not remove those rows from the claim-
activating denominator.

This is a support/interpretation-activation defect, not a defect in scientific
activity start. It leaves `P`, `W`, `R_IID`, `MPI`, `HPI`, and other coherent
finite-budget return contrasts mathematically defined.
