# MGTAP 方向裁决：CONTINUE，检验固定选中配置的重复性

**决定：MGTAP CONTINUE，继续现有可选 COND 开发范围，保持既有优先级；下一项具体目标是将双方学习率固定为本轮各自选中的 \(10^{-4}\)，进行一对全新训练比较。DENSE 仍是通用开发默认。不 RECAST、不 PARK/CLOSE，不自动重做八拟合选择程序，也不向更低学习率扩展网格。**

理由不是“出现了正结果，所以应当再跑一次”，而是：**公平的有限选择程序已经产生一个有实际开发意义的留出收益，现在有一套明确配置值得判断是否继续维护；新拟合能检验其表现是否再次出现，而无需重新购买六个选择拟合。** 这是一项有限、可逆的研究投入，不是对稳定优势、调参收益或几何机制的认定。

本次只处理 MGTAP 自己的方向问题。当前三席仍由 MGTAP、RCLE、FOLR 占用，零预留、零空缺；本决定不改变其他方向，不应用旧 DISH 补位建议，也不产生第四方向。Portfolio 作本次方向级判断，原 MGTAP DM 负责后续普通设计、实现、技术接受、执行和科学回应，无需另一次 Root ratification 或仅用于批准启动的咨询。

## 一、完成的程序提供了什么新知识

### 公平选择已经实际执行，不能再只当作调参可能性

本轮不是把 COND 调好、同时让 DENSE 停留在不利设置。选择阶段在同一 master8251 下，为每个方法完整运行三个学习率候选，并分别按**该方法自己的验证回报**选择：

| 学习率                |        COND 验证均值 J |       DENSE 验证均值 J |
| ------------------ | -----------------: | -----------------: |
| \(3\times10^{-4}\) |     0.141122999879 |     0.026265496601 |
| \(10^{-4}\)        | **0.164929589016** | **0.168706516564** |
| \(10^{-3}\)        |     0.130317161828 |     0.149452263124 |

双方均选中 \(10^{-4}\)，没有平局。DENSE 没有被固定在明显较弱的 base 候选，选择器也没有最大化 COND−DENSE 的差。选定记录保存后，才构造全新的 master8252 配对；没有将候选权重、优化器状态转入留出训练，也没有依据留出结果改选学习率。完整结果记录与独立审查支持这条实际执行链，而不是仅有协议、哈希或时间戳上的承诺。

全新留出配对的最终均值为 COND **0.15031149414404593**、DENSE **0.12660659643095226**；原主量是按固定世界顺序计算的差值均值：

$$
\widehat{\Delta}
=\frac1{32}\sum_{e=0}^{31}
\left(J_{\mathrm{COND},e}-J_{\mathrm{DENSE},e}\right)
=\mathbf{+0.023704897713093642\ J}.
$$

条件配对世界 SE 为 **0.004197354694630503**；29 个世界有利、3 个不利，全部保留。按原严格 \(>0.01\) 的规则，结果为 **COND_ABOVE_MEI**。这项局部结果不需要改判或追加检验才能保留。

**一个重要反例是：在选中学习率的验证面板上，DENSE 均值高于 COND；在新的留出配对上，方向反转。** 两阶段使用不同拟合策略和面板，这并非完整性矛盾，却直接阻止把它们写成“两次独立正向重复”。三项不利最终世界也不能因总体均值有利而被淡化。

### 假说得到加强，但没有被归因或普遍化

原问题是：在相同合法信息、真实原生奖励与有限学习条件下，条件汇聚处理是否值得作为 intact-DENSE 之外的可选实现继续发展。本轮保持五 UAV、五十均匀用户、H256、无阴影自由空间、合法 raw108 actor 信息、私有 GRU64、训练专用 critic 信息及原生速度行动；改变的是双方获得的有限学习率选择机会。

因此，支持的更新有两层：

**其一，原生设置敏感性不再只有 toy 动机。** 在8251这次实际选择中，不同学习率对应不同原生学习结果，尤其 DENSE 在 slow 下远好于 base。这是当前实例中的设置敏感性，不是旧原生失败已被解释，也不是总体学习率响应曲线。

**其二，公平选定后的 COND 完整程序取得了有用的局部留出收益。** 这加强了可选分支的开发依据，但没有识别“调参导致了多少收益”：8252 没有未调参控制，8251 的 base 候选不能冒充它。双方恰好选中同一学习率，也没有隔离条件处理、表示结构、优化和联合轨迹变化各自的贡献。

这里仍然只有**一个选择阶段随机实例、一对最终训练**。32 个世界给出的是条件于这对拟合策略的评价变异，六个选择候选不是六次程序重复；训练与选择总体的不确定性仍未估计。完整更新和参数移动说明学习路径实际被执行，不说明循环状态已经充分、伙伴意图被识别，或条件模块是收益的独立原因。

## 三、为什么现在继续固定配置，而不是 PARK 或继续搜索

### 最强 PARK 论据

立即 PARK 仍有实质理由：历史结果混合，本轮只有一次自适应选择和一对最终拟合，选中验证面板本身不 favor COND；两个赢家还都位于网格下边界。一次有利结果可能不足以抵偿继续维护分支的完整成本。若每次不利后都改变问题、设置或终点，直到再找到一个正结果，就可能成为持续追逐不稳定收益。

我接受这一风险。**本次没有量化未来收益概率，也没有证明 MGTAP 的预期价值高于所有其他方向。** 选择继续意味着愿意承担新配对再次不利、最终仍决定停止这套配置的可能性，而不是忽略它。

但固定配置的新学习比较在此边界更值得做，原因如下。

**它会改变一个明确的下一步开发选择。** 当前不是要决定将 COND 升为全局默认，而是决定是否继续维护和发展双方 \(10^{-4}\) 条件下的可选 COND 程序。新结果再次有用，会加强有限分支投入的依据；尺度内或不利结果，会削弱仅凭8252继续推进的理由。若这些结果无论怎样都不改变实际开发工作，就不值得再买；本次所选目标明确允许它们改变工作方向。

**它针对主要剩余不确定性，而不是再寻找一个候选赢家。** 现有配置已经由双方各自验证表现选定。固定配置、重新拟合，可以观察另一个完整学习实现的后果；给8252增加评价世界无法替代这项信息。新随机实例同时涉及学习与最终评价变化时，也不能把结果差异完全归因于训练方差。

**它比重复完整选择程序少做与当前问题无关的工作。** 下一配对只需两次拟合，而重新选择需要六次候选拟合加两次留出拟合。两者回答不同问题；前者的拟合、tick 和 Adam 数是后者的四分之一，但这不是总墙时或完整研究成本必然降低四倍的承诺。

**不优先重做八拟合**，因为当前开发取舍是已选配置是否值得保留，并非整个选择器在新 master 上会选什么、又表现如何。以后若实际要采用并评估“每次先选率再训练”的完整程序，选择阶段变异才是对应问题，不能由这次固定配置比较代替。

**不自动扩展低端网格**，因为边界赢家只说明它在当前三个候选中最好，不说明更低一定更好，也不证明必须先找到最优学习率才能研究配置的有限价值。下探学习率是合法但不同的优化问题；现在优先固定而非继续优化，正是为了减少结果不利时不断移动目标的空间。

**不增加机制、headroom 或全量诊断项目作为前提。** 本次要的是有限完整程序的开发信息，不是调参因果、几何机制或全局最优证明。取得更强归因当然需要相应设计，但不能把那些证据负担强加给当前 B。
