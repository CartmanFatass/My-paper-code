## 5. Assessing the proposed sum-plus-count change

### Changing the fixed mean to a sum alone does not add a representation

The frozen REL context is

\[
c_U=\frac{1}{20}\sum_j\tanh(Uu_j),\qquad
c_V=\frac{1}{10}\sum_k\tanh(Vv_k),
\]

followed by a learned linear context projection and the full raw residual. These denominators are the fixed slot limits, **not the number of present entities**. A zero-padded row contributes zero because the row maps are bias-free. This is not active-count mean pooling that automatically normalizes away the number of observed records. [E8, “Treatment and comparator”][E8].

An algebraic reading of that definition separates a rescaling from a new structural operation. Write the learned projection as two blocks, \(P_U,P_V\), and define \(S_U=\sum_j\tanh(Uu_j)\), \(S_V=\sum_k\tanh(Vv_k)\). Then

\[
P_Uc_U+P_Vc_V=(P_U/20)S_U+(P_V/10)S_V.
\]

For unchanged row maps, a sum-based branch can therefore reproduce the same encoding by rescaling its learned projection blocks. This is a deduction about the stated representation, not a numerical replay, support census or new formal study. It does **not** show identical gradients, Adam trajectories or finite-budget returns. Scaling can matter to learning. It does show why merely replacing the two fixed divisors cannot be described as recovering previously unavailable cardinality or introducing a new physical ground binding.

This distinction matters after the old B03 experience: fixed-coordinate optimization differences can be highly sensitive to generic scale choices. That historical observation is not a proof that sum scaling cannot help P75; it is a reason not to relabel scale sensitivity as a distinctive native geometry result. [E10, “Rule applied verbatim and direct result”][E10]; [E11, “Direct measurements and ordered rule”][E11].

### Explicit counts could change processing, but their proposed role needs to be substantive

Adding the numbers of present user and other-UAV records is not mathematically the same operation as the rescaling above. Those counts can distinguish some aggregates with different occupancies, and an explicit count input may make a useful response easier to learn. A learned nonlinear count-conditioned response could therefore be a legitimate B package even though its information was already derivable from the original input. Redundancy of information does not imply redundancy of finite-training computation.

The count must have the right meaning: it is a count of currently observed, SINR-eligible records after truncation, not the total fifty-user population, globally served users, an independently known demand, or a persistent neighbor roster. At most twenty user records and four actual other UAVs can be visible in the available slots. Count extraction must use the existing row/padding convention, not privileged indices, new membership information or hidden masks. Both packages already retain all original raw rows. The proposal cannot be justified by claiming that DENSE or the original REL has no access to the information from which these counts are derived. [E8, information boundary][E8]; [E9, §§2–4][E9].

The strongest favorable hypothesis is that a count-conditioned operation could distinguish sparse evidence from cancellation among multiple current relations, or adjust how strongly a local context affects velocity in crowded versus sparse observations. But local occupancy is also an outcome of SINR and interference; simply increasing the influence of a larger count has no monotone native-service guarantee. The offered description does not yet make clear whether the intervention is just larger context amplitude, an additive count feature, or a genuinely count-conditioned geometry response. Those mechanisms have different interpretations and different parameter-matching consequences.

**I do not select the changed comparison.** The proposed scale component has the limited meaning established above. The additional-count component remains a possible representational convenience, but currently lacks a sufficiently specific reason to expect a consequential advantage over the valid full-information dense alternative, rather than another generic feature/conditioning trial. P75's adverse endpoints do not favor that particular explanation over the live alternatives. This is a comparative judgment about the present proposal's value, not a rule that a future B must first diagnose P75, prove count insufficiency, or produce a positive result.
