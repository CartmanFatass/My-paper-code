legal integral assignment that maximizes the same immediate reward. It knows

### 3.2 Strongest competent same-information generic comparator

The only admissible generic baseline for this census is
`FREE-EDGE-FEASIBLE`. Its accepted design has the same runtime observations,

optimization-validity gate and reached final fitting and the matched held-out

failed gate is not a competent final baseline result.

oracle gap can certify panel headroom but cannot substitute for

## 4. Direction-local MARL structure trace

This census records, but does not elevate to Portfolio policy, the direction's
local trace:

```text
public roster and task-demand event
  -> centralized allocator owns N coupled entity actions
  -> common public role/capability/task/load information
  -> autoregressive legal integral coupling and one team reward
  -> shared actor parameters receive exposure through that joint return
  -> residual demand/capacity, idle, unmet demand, and native Y
```

The frozen host therefore contains a coupled allocation and team-credit path:
one entity's action changes residual capacity and the legal consequences of
later entity actions. It does not contain decentralized execution, hidden
identity, temporal credit from epoch 2 to epoch 1, partner co-adaptation, or
other-agent learning nonstationarity. Whether coupled allocation is the
*binding* difficulty against a competent generic learner is unresolved and is
not answerable by this census.
