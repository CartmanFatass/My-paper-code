## Candidate reuse examined

`envs/relay_corridor/host.py` is a real vectorized NumPy host. Its `step` scores
`(delta / N) * sum_i serve_i`, with each agent's service determined by its own freshness, role and
regional target. `config.py` fixes `e5_coupling_enabled=false` and raises `NotImplementedError` if
it is enabled. Region events can be shared, but no partner action enters another agent's service
test in this implementation. Its exact reference machinery and `rows_per_rollout` are useful
examples of finite return calculation and the cost law; they do not supply the proposed crossed
identity-period-partner population. Changing this shared host to manufacture such a population
would be a new scientific intervention and would touch another direction's frozen surface.

`envs/probe_environments.py` also does not supply the missing host. `PolicyProbe._compute_reward`
uses only the first agent's action. `DiscriminatorProbe._compute_reward` always returns `1.0`;
`set_skill` directly sets the observed state. Those probes cannot demonstrate a partner-dependent
native consequence or useful identity selection merely by setting `n_agents=2`.

Thus the smallest honest construction, if selected, is disposable research-tier code under a new
VSP-C1 attempt directory. No production contract, core import, capability registry or host clone
certificate needs to be added. There is no accepted new implementation at this boundary.
