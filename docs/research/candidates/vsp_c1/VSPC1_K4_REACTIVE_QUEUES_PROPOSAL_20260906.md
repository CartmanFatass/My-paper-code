## 2. One host, with actual event and information timing

The proposed disposable host has two service queues, capacity 4 each, two persistent workers, and exactly 48 primitive ticks. There are no membership changes, replacement, rejoin or hidden worker identities. The focal worker is the **only learning role**. Its partner is **fixed, reactive and non-learning**; it has no public future action plan, hidden policy state or adaptive optimizer. This is consequently a stationary control problem with a reactive teammate, not evidence about partner co-adaptation or strategic MARL learning.

At episode reset, both queues contain 2 jobs; a fair bit supplies the previous focal assignment `h`. The focal holding period `d` is exogenous and fixed for the episode, equally weighted over {2,6}. At each tick `t`:

1. At a focal renewal (`t mod d = 0`), the learner observes `(q0,q1,h,t,d)` and chooses queue 0 or 1. It must keep that assignment for the next `d` ticks. Between renewals it receives no new policy input and takes no new policy decision.
2. The partner observes current queues and `h` every primitive tick. It selects the larger queue; an exact queue tie selects `1−h`. The choice uses the previous focal assignment, not the focal's new simultaneous choice. The focal is told this policy; both learning arms have exactly the same information and can in principle infer it at renewals.
3. Different assignments can serve one existing job from each chosen queue. If both workers choose the same queue, the shared station serves at most one job in total. Empty stations serve zero. Let `s_i` be jobs actually served from queue `i`; this makes `s_i ∈ {0,1}` and `s_i ≤ q_i`.
4. After service, each queue receives an independent Bernoulli(0.7) job. Set `q_i' = min(4, q_i − s_i + arrival_i)` and count overflow as dropped work. Set `h'` to the focal's held assignment. New queues and the changed `h` affect the partner's next action.

The complete native return is `J = total jobs served / (2 × 48)`, in [0,1]. All 48 ticks count, including idling and collisions. Dropped arrivals and unserved ending backlog are retained as descriptive consequences; they are not extra shaped rewards. New arrivals after the final service tick cannot be served in the episode. No stop on success, selected subwindow, successful-episode filter or rescaling by observed arrivals is proposed.

The scientific chain is: **job arrival / queue imbalance → persistent focal and reactive service roles → renewal-only focal observation versus primitive partner observation → held focal assignment and current joint station occupancy → actual semi-Markov TD update → completed work, idling and overflow across the full episode**. Longer commitment changes the queue state and partner response encountered before the next decision. This is a hypothesis about learning usefulness, not a claim that an optimal-action reversal or a performance gap has already been established.

## 3. Two real learners and the strongest proposed control

The primary comparison holds host, observations, action set, primitive interaction, period weights, update count, optimizer and evaluation fixed. State features are `[q0/4,q1/4,t/48,one_hot(h)]` (5 values). Candidate action contributes a two-coordinate one-hot encoding. Period is legal input to both arms.

| Arm | Proposed action value | Trainable parameter count |
| --- | --- | --- |
| FACTOR | One tanh hidden layer of width 24 maps state/action (7 inputs) to four features; dot with a learned four-coordinate embedding for `d` | 300 |
| GENERIC | One tanh hidden layer of width 28 takes state/action plus period one-hot (9 inputs), then a scalar linear output | 309 |

GENERIC is a fully conditioned nonlinear control, can learn queue/partner/duration interactions, and already shares hidden features across periods. FACTOR's four coordinates and two period columns impose **no strict rank bottleneck**. The question is therefore this multiplicative-conditioning choice's finite-budget return, not identification of sharing versus no sharing, low-rank savings, or a unique causal factorization effect. The 9-parameter difference is explicit. A tabular semi-Markov learner is a credible alternative on this discrete host, but table containment does not establish its finite-budget competence; the proposal does not execute a comparator search. Convergence should replace the proposed control now if it sees a materially stronger reasonable same-information choice and explain the comparison that replacement answers.

Use matched semi-Markov Q-learning in both arms: for each actual renewal transition, normalized reward is the sum of actual primitive service rewards in that segment divided by 96. The target is that reward plus the next-renewal continuation, with terminal continuation zero. `γ=1` is deliberate for this finite undiscounted task; equivalently `γ^d=1`, with tick supplied to the learner. The period never changes inside an episode. No transitions for unexecuted durations, counterfactual rollouts, padding decisions or skip-transition augmentation are included.

To avoid adding a recurrent-state explanation, both arms use the complete declared renewal state above. A target copy initialized from the online model and updated every 16 optimizer steps supplies continuation; select the next action with the online values and evaluate that action with the target copy (Double-Q target). Targets are detached. This is a proposed common trainer change for the new stateful host, not a repair or rerun of B01/B02. Adam is fixed at learning rate 0.01, betas (0.9,0.999), epsilon 1e−8, no weight decay, gradient norm clipping at 5. Initialize dense layers with Xavier uniform and zero biases; FACTOR embeddings use Normal(0,0.5), as in the earlier accepted learner. A target copy is learner state, not a separately trained arm.

Each update collects 16 complete episodes (8 per period), then performs one optimizer step over their actual renewal transitions. Give each episode equal total loss weight, and each of its renewal rows equal weight within that episode. This prevents the threefold short-period opportunity count from becoming threefold period weight. Short- and long-period decision counts remain separately reported. Exploration falls linearly from 1.0 to 0.1 across 256 collection/update cycles; evaluation is greedy with a fixed action-0 tie rule. No replay/tuning sweep is proposed.

Use one fresh training seed, 401, with named separate initialization, arrival, initial-memory and exploration streams. The two arms share exogenous initial-memory/arrival tapes and exploration uniforms indexed by episode and primitive tick; policy-dependent branching cannot shift those slots. Evaluation uses separate held tapes, reused across arms and checkpoints, and never supplies policy inputs or training targets. Pairing reduces exogenous comparison noise, not training-seed uncertainty. No empirical claims from the prior host are pooled with this instance.

## 4. Measurement, budget and what the next observation decides

Primary observable: FACTOR minus GENERIC mean complete-episode `J` at the fixed 256-update endpoint, with equal period weights. Report each period's difference, both initial values and every checkpoint; a mean gain must not hide a period's loss. The initial and every-32-update evaluations give 9 checkpoints, each with 256 episodes (128 per period). Full-curve AUC is descriptive and cannot replace the endpoint after seeing its sign. Evaluation episodes are Monte Carlo observations of one training instance, never independent learner seeds.

Proposed minimum effect of interest: **0.025 absolute mean J**, equivalent to 2.4 completed jobs per 48-tick episode in expectation. This makes an improvement matter on the native count scale without demanding a large percentage against a possibly poor initialization. It is this proposal's value judgment, not a repository threshold or a measured effect.

How the result would be interpreted: a trustworthy endpoint gain above the MEI supports considering one or two new training seeds with the same comparison; all period losses and curve reversals remain visible. A difference inside ±MEI supplies little support for paying for this conditioning choice on this setup; record equality/uncertainty descriptively, without claiming equivalence. An adverse effect at or beyond the negative MEI favors the generic choice on this observed instance and challenges carrying this factorization forward, without closing K4. A mean benefit coupled with a material period loss is a mixed tradeoff requiring its own next decision. Missing primary return or broken reward/information/update semantics limits the dependent claim; trustworthy counts or surviving direct measurements remain reportable. These are proposal-level readings for the node to select or amend, not a retrospectively frozen card rule.

One paired training instance cannot establish stability, mechanism identification, transfer, an optimum, or population uncertainty. DM's tentative prediction is a small or mixed difference (inside the MEI more likely than a large uniform gain), because the generic controller has full state and period input and the factor form is not a restrictive compression. A clear adverse endpoint is credible, not an outcome to screen away. No owner prediction is solicited until a ladder card is actually frozen; current prediction slot: not taken.
