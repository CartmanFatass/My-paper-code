**决定：继续现有原生持有价值家族，但只选择一个改变比较含义的 B/EXPLORE：两臂均保留完整的 136→128→133→1 普通价值网络，只在处理臂添加现有 640 参数的剩余持有门；一个全新的配对训练实例，各训练 768 个完整回合，只评价最终 768 终点，并保留同一新布局组上的零速度 H。** 不选择第四个不变的双面板比较，不追加旧检查点评价，不展开其他宿主、演员、时长或结构搜索。这是方向层的后继对象选择，**不是 RECAST**，也不是源码接受、进程启动、正式 UAV 进入、C 晋级或 Portfolio 生命周期与优先级决定。[本轮问题 §§1、3–4][question]；[当前准备接收 §§1、3–4][preparation]

我不采纳“本轮无后继、结束实例化比较”的建议。最窄理由不是尚有未测变体，而是已有比较把两种用途的参数作了替换：处理用 640 个门参数，普通对照则用 650 个额外普通体参数；新问题改为**保留已经实际取得较好终点的普通体，再问加门是否值得**。此前较早终点的真实正向实例使这项增量用途不只来自源码想象；新对照又不牺牲普通体来保护门。一次完整训练对可以改变下一项具体选择——继续保留这个附加门包，或保留不带门的完整普通体——而不必先证明 650 个参数造成了旧差异。[本轮问题 §§2–3][question]；[当前门工厂][gated]；[普通宽体][wide]

**停止是有力的备选，不是被排除的答案。** 三个相对差下降、8503 的大幅最终缺口、混合的较早终点以及稀疏的门输入，都反对自动继续现有近等参数配置。完整体加门仍可能只是多花实现和训练成本、再得到一个有限优化实例；我对它超过所选收益刻度并不乐观。此次取舍在于：它不削弱最强已达普通结构，直接检验尚未被现有比较回答的附加包用途，且只安排一个终点明确的真实 B。新增容量和优化的解释未被排除，但性能 B 本来就不要求先隔离唯一机制。这个理由不授权持续加宽、不断换种子或“试到正号”。[B12 接收 §6][b12]；[证据规范 §§5.2、11.8.2、11.9][spec]

## 二、为何选附加包，而不选第四个原比较或直接停止

继续的最强依据不是“门一定学到了持有信用”。它是两项较窄事实的组合：8501/8502 的固定 512 正差及 GATED 高于 H 的原生均值真实存在，较早 8301/8303 的正观察也保持；而当前源码确实把“门参数”和“额外普通单元”配置在不同臂上。因此，当前结果回答的是这两个近等总量训练包的相对表现，**不是在一个完整普通体上添加门的边际用途**。[B12 接收 §6][b12]；[门工厂 models][gated]；[WideCritic][wide]

这不把原对照称为有缺陷，也不宣称旧 GATED 被人为压弱。近等参数比较是一个有意义且已经得到结果的设计；追加普通体是另一个明确标注的性能选择。新设计若有收益，只能支持“该完整体加门包在本实例值得考虑”，不能反推旧晚期差异由普通体的 650 参数造成。若没有实用收益或出现损害，就没有理由沿这次附加包自动推进。结果知情的设计适应在 B 中合法，但不是对旧结果的修复，也不是结果盲确认。[本轮问题 §§3–4][question]；[证据规范 §§4、5.2、11.8][spec]

停止的实质理由是：已观察的 768 优势不稳且没有 UP 点，当前最强晚期实例显著偏向普通结构，门直接参与的训练行仅约 1.13%，而 MLP 已有同信息非线性共享。以上确实降低附加门成功的预期。我的取舍与 DM 不同之处仅在下一次有限投入：保留普通体后测试附加门，比再测一次“以门换普通单元”的变化更能决定未来是否保留门；这一次观测不以另增比较器、解释所有旧失败或搜索正向宿主为条件。它仍可能不成功，且全部实现、检查和运行成本都计入判断。[本轮问题 §§3–5][question]

第四个不变 B 仍然合规，主要增加当前两包和双终点变化的一个实现样本。它不是因为已有三对就被禁止，而是本轮更有用途的问题已经转为“完整普通体上是否值得附加门”。旧检查点的更多评价则主要改善条件面板精度，不新增独立训练，也不能直接回答这个新包问题。本次选择既不要求先做精确最优、全支持或因果普查，也不把这些工作移到 A 类作为前置。[证据规范 §§11.8.2–3、11.9][spec]

## 三、所选比较的确切含义与需要保护的源码边界

两臂共同普通体均为 **136→128→133→1**，第一层与第二层后仍用原 tanh。令 r 为已有五个 remaining/4 输入，零基列号是 119、123、127、131、135；x 为其他 131 个原有状态及旧命令输入，`z=W_x x+b`，B 为原第一层的五个持有输入列。唯一结构差为：

`MLP-V: h1=tanh(z+B r)`；`GATED-V: h1=tanh(z⊙(1+A r)+B r)`。

后续两臂均为 `Vhat=W3 tanh(W2 h1+b2)+b3`，第二隐层同为 133。A 为无偏置 128×5 参数矩阵，直接全零构造。保留原 `B r`、所有 x 信息、原始偏置与完整后续层，不缩窄或移除普通对照的信息。[GatedCritic，L14–27][gated]；[WideCritic，L9–25][wide]

共同普通体先按当前初始化规则形成，然后复制给两臂，包括五个私有随机初始化的额外第二层行、五个偏置及初始为零的五个新增输出权重；两臂的可变参数、优化器和价值矩存储独立。处理额外添加零门，不额外消耗行为随机流。普通体参数 34,827，附加门后 35,467，增加 640，即 1.83765%；相对于旧 GATED，新增的是它此前没有的 650 个普通体参数。**这不是容量匹配实验。** 数学上的 A=0 包含普通初始函数，不保证有限训练不劣；分拆第一层计算还可能带来普通 FP32 舍入差。必要的是同字段、同共同参数及零门的普通数值检查，不是逐位相等或函数类精确证明的启动门。[机器事实 candidate_parameters][facts]；[两种 critic 源码][gated]；[WideCritic][wide]

当前 `models()` 先在 GATED 分支包门，仅在另一分支且 width=133 时构造 WideCritic，所以现有 width=133 选项**不会**生成所选的宽体 GATED；现有 checkpoint 元数据也把它记为 34,817。后续实现必须让两臂都先获得相同完整普通体，并正确保存新实际结构/数量，不能仅改标签、以旧工厂运行后称为新包。按已读 `GatedCritic` 对 source.network 的复制和后续层调用，这个组合有清楚的源码实现路径；尚未构造或测试，不能把可行推断写成代码已经接受。[models，L30–37][gated]；[study.py，checkpoint_identity、run_pair][study]；[当前 B12 runner][runner]

科学路径不扩大：五个持续成员各保留 108 维局部输入与独立 GRU 历史，共享演员权重；两臂均有相同的 t0 时长 1/4 选择及合法速度动作，持有中观测和循环状态继续更新，t4 起普通反馈。中央价值仍只读 136 维已有信息，输入在当前决策之前组装。t0 的 remaining 为零，不能把刚选择的时长送入当次价值；非零门输入只可能在 t1–3。价值不用于选择动作，没有 duration-Q、反事实轨迹或额外续约干预。[本轮问题 §3][question]；[原形成决定 §§一–二][opening]；[B12 卡 §2][card]

共同训练继续使用累计 FP32 价值矩：每个两回合 rollout 的 512 个真实 return-to-go 目标合并一次，归一化目标用于价值平方损失，收集的解码原生价值用于 gamma=1 全回合优势；优势 detach 并在该 rollout 归一化，四个 epoch 不因中途 critic 更新而重算。评价和 H 不更新价值矩。两臂均保留复合 agent PPO、实际决策 mask、共同原生奖励、原有联合梯度裁剪和熵系数；不把归一化价值损失换成原生单位 MSE，也不把回报 J 的时间平均误用为训练 return-to-go。[B12 卡 §2][card]；[ValueMoments][moments]；[study.py，run_pair][study]

门的稀疏直接作用不是回报效应上界：共享普通权重、价值矩、优势归一化及联合优化可以影响更长的政策轨迹；反过来，这些也是正负差的替代解释。尤其不能把所有 t≥4 的差都解释为当前持有信息的直接作用。既不强制长持有来制造曝光，也不把门移动或 critic 拟合改善设为收益替代物。[本轮问题 §3][question]；[原形成决定 §一][opening]

## 四、唯一后继 B 的训练、测量与独立单位

可写卡问题是：**在相同信息、时长可选演员、归一化价值训练与有限 768 回合预算下，给完整普通 critic 附加现有门，是否改善最终采样政策的全回合原生回报？** 该 B 只产生一个新配对训练实例。准备材料没有选定新数字主种子；由 DM 在本次选择后的对象卡中一次事前指定并保留，用明确新初始化/训练/评价域，不按结果换号。这是既有对象定义职责，不是再询问本节点的许可条件；本答复不声称已完成该数字的命名空间查重。[本轮问题 §4][question]；[准备事实 current_new_exposure][facts]；[AGENTS §§2、4][agents]

沿用当前分流结构：对新主种子 s，b=100000s，共同初始化 b+11、额外普通宽体初始化 b+12；各臂私有训练速度/时长流 b+21/b+22；768 个训练 reset 使用 b+1000+e；最终 32 个评价 reset 使用 b+2000+e，并为各臂每个评价回合新建 b+3000+e、b+4000+e 的私有速度/时长生成器。构造与首个 reset 按现有规则使用对应键。配对共同初始参数和外生 reset；不共享可变 RNG 对象、优化器、循环历史、价值矩或训练数据，不承诺两臂分支变化之后仍逐 tick 使用相同动作噪声。[B12 卡 §3][card]；[study.py，run_pair][study]

每臂连续训练 768×256 个原生团队步，每两完整回合一个 rollout，四次 full-rollout epoch，各一次 Adam。保留当前学习率、损失权重、归一化、32 步循环梯度分块和 PPO/联合裁剪设置，不新增调参维度。正常结果终点是第 768 回合训练及其最后更新完成后的政策；不做 512 面板、初始政策评价、最佳检查点选择或追加旧模型复测。H 只在新 32 个布局上评价一次，发送原有零速度命令，不建学习器、不调参，在第二臂的评价环境中完成。[本轮问题 §§3–4][question]；[B12 卡 §§2、5][card]

**删除 512 面板不等于将 `fixed_endpoints` 简单设为 False。** 已读 study 只在 fixed_endpoints 路径上创建独立 eval_env；旧 False 路径令 eval_env 与训练 env 是同一对象。所选新对象必须将“评价时点”与“训练/评价环境隔离”分开：每臂训练、评价各一个环境，共四个；只在最终 768 评价，沿用冻结评价矩和私有评价随机流。相应主输出是最终单面板 Delta，而不是旧 `paired_change_from_rows` 的 C。训练连续性、隔离、真实终点计数和发布标识是此次实际变化需要保护的边界；不额外重放历史训练来证明它们。[study.py，run_pair 中 eval_env、evaluate_endpoint 与主量分支][study]

对三个控制器的最终回合使用相同的 32 个 `(episode, reset_seed)` 身份。`J=原生 reward_sum/256`，主量为 `Delta_new=mean_i(J_GATED,i−J_MLP,i)`。同时保留两臂各自的 J、H 的 J、GATED−H 和 MLP−H 的全部 32 个差及每个负身份。各对比的条件 SE 为该 32 个配对差的样本 SD/sqrt(32)；三个对比满足 `(GATED−H)−(MLP−H)=Delta_new`，并非三次独立成功。只缺 H 时，完整可信的学习器主对仍可报告；损坏哪个依赖，就限定哪个结论。[study.py，primary_from_rows][study]；[证据规范 §§4、11.8.3、11.8.7][spec]

**MEI 保持绝对 0.01 的完整时间平均原生团队回报。** 它与已达均值约 0.14–0.23 相比是可理解的有限性能刻度；按原覆盖项，一个持续多服务用户贡献 0.7/50=0.014，但质量项也可能变化，不能把 0.01 解成保证服务某个固定人数。它不是精度、显著性、等价或 headroom 门槛。严格大于 +0.01 为 UP，严格小于 −0.01 为 DOWN，其余包括两边界为 WITHIN；不会为新包降低刻度。[本轮问题 §4][question]；[B12 卡 §4][card]

n=1 是一个配对训练实例，两个 fit、五个 agent、768 个回合、多个梯度 epoch、32 个评价身份均不增加训练独立单位。此对象不测 C，也不产生任何关于旧 512→768 变化的新复现；不与任何旧协议合并成总体均值或胜率。保留所有新训练记录、实际更新数、终点参数/价值矩、非零 r 行数与门绝对移动，不能把归一化或门初始零范数的相对位移异常当作机制结果。[本轮问题 §4][question]；[机器事实 exposure_line][facts]
