**决定：开放反应式双队列这一新家族，选择一个有限的“反应式队列持有时长条件价值 B01”：仅比较所提 FACTOR 与 GENERIC，两臂各用一个新训练实例 seed 401、256 次更新，在固定 48 步任务上读取完整本征回报。保留 GENERIC，不改成表格比较器，不增加第三臂、伙伴学习、周期扫描或预算延长。** 这是方向层的新家族与下一对象选择，足以据此写 B/EXPLORE 卡；不是源码接受、实验启动、C 冻结或 Portfolio 状态变更。已结束的公开固定计划、六步、八情境家族保持结束。

最强理由不是新任务更长、可运行或可能很便宜，而是它使尚未回答的问题落到一个实际选择上：同样看到续约状态的两个价值学习器，如何给“现在占用哪条队列、随后保持多久”赋值，才会在后续队列和伙伴响应中完成更多工作？一次可信的固定终点比较，能够决定是否值得为乘性时长条件结构再选一两个独立训练实例，或在这个组合上停止追求它、保留普通完整条件模型。旧任务的伙伴未来动作不受学习者影响；这里服务会改变队列，队列及上一分配又改变伙伴下一步的动作。这个差别不是旧家族换名，也不需要先证明最优动作必然反转或存在某个幅度的优势。[提案§§1–4、6][proposal]；[已接收的上一决定§2][intake]

最强反对意见仍成立：伙伴完全已知且不学习，所以这仍是平稳的单学习角色控制问题；FACTOR 没有已建立的队列归纳优势，两周期上的四维因子也不是严格低秩约束。结果可能主要反映两种小网络及共同优化器的有限预算差异，而不是独立的“跨周期共享机制”。我接受这一反对意见所限定的主张，仍选择一次真实 B，因为这次比较能暴露持有行动的后继状态代价，而不只是重复已触及参考值的公开计划匹配。**新状态转移提供一次探索的理由，不提供继续换宿主直到出现正号的许可证。**[提案§§2–3、6][proposal]；[证据规范§§5.2、11.8–11.9][spec]

## 二、选中的问题与实际作用链

保留提案的单一宿主，不同时改变伙伴、周期数或参数化菜单：两条容量各为 4 的队列、两个持续存在的工人、48 个原始 tick；初始队长各为 2，初始上一分配 h 为公平随机位；外生 d∈{2,6} 在整个情节内固定，两种 d 等权。只有焦点工人学习，伙伴是无内部隐藏状态、无更新的固定响应程序。[提案§2][proposal]

每个 tick 的顺序必须保持以下含义。续约时，焦点先读取该 tick 开始时的 (q0,q1,h,t,d)，选择队列 0 或 1，并保持 d 步。伙伴在同一个决策时点读取当前队列和旧 h：选较长队列，相等时选 1−h；它不能偷看焦点这次同时选择的新动作。不同站可各服务一个已有工作；同站总共最多服务一个，空站服务零。服务之后，两队列分别获得独立 Bernoulli(0.7) 到达，截到容量 4，超出量记为丢弃；随后 h 更新成焦点当前持有的分配。下一 tick 的伙伴因此可能改变动作。焦点在持有期间没有新策略输入或重新选择。[提案§2][proposal]

这一链条已经在定义上区别于公开切换表。例如从合法初态 q=(2,2)、h=0 出发，伙伴当前选 1：焦点选 0 时该步可完成两件，选 1 时只能完成一件。若随后两条到达均为零，两个选择分别产生 (q′,h′)=((1,1),0) 与 ((2,1),1)，伙伴下一步也分别选 1 与 0。这只是依据规则的局部推论，不是已运行轨迹、最优策略证明、全支持见证或额外实验。它说明选择会同时改变当步服务、后继状态及响应，而不是只改变一个标签。[提案§2][proposal]

完整问题因此是：**随机工作到达与不平衡 → 持续的焦点/响应伙伴角色 → 焦点仅在续约看状态、伙伴逐步看状态 → 焦点持有分配及联合占站 → 真实持有段奖励和后继价值更新 → 全情节完成工作、空转、溢出与剩余积压。** d=6 比 d=2 更久不能根据新到达重新分配；这种后果进入两个模型的 Q 目标，而不是靠加一个“协调奖励”引入。[提案§§2–3][proposal]

绑定结构是时间抽象：不同外生持有时长下的行动后果和价值条件化。角色数固定；没有终止学习、伙伴共适应或多学习者信用分解。伙伴规则虽已告知，但未来到达及伙伴实际响应轨迹没有交给焦点。续约状态足以描述所定义的平稳控制问题；不因间歇观察就另加循环网络解释维度。

## 三、为什么保留这一个同信息 GENERIC

两臂的状态特征统一为 [q0/4,q1/4,t/48,one_hot(h)]，候选动作另给二坐标 one-hot；时长对两臂都是合法输入。选择如下，具体网络输出形式也在此明确：

| 学习臂 | 值函数与参数 |
| --- | --- |
| FACTOR | 7 维状态—动作输入，经宽度 24 的 tanh 隐层，再经带偏置线性层输出四维 φ(s,a)，与 d 的可学习四维嵌入做内积；300 个可训练参数。 |
| GENERIC | 同一 7 维输入再拼接二坐标时长 one-hot，经宽度 28 的 tanh 隐层及带偏置标量线性输出；309 个可训练参数。 |

参数数目来自 [准备计数 parameter_counts][counts]，结构来自 [提案§3][proposal]。两臂各有一个同尺寸、非优化的目标副本。GENERIC 的 9 参数差额明确保留，不靠删掉周期或状态信息制造弱对照；参数接近不等于函数类相同、初始化相同或优化难度相同。

GENERIC 可以用时长参与隐层非线性交互，也跨周期共享隐藏特征。FACTOR 则将时长作用放到输出内积，可能改变跨周期梯度耦合、尺度和优化路径。**比较的是这两种完整参数化在共同训练方案下的本征表现，不是共享对不共享，不是严格低秩对满秩，也不是唯一因果结构消融。**[提案§3][proposal]

表格半马尔可夫 Q 学习是合理备选，但此时替换它会同时改变表示泛化和更新行为。它可能有利，也可能把同样有限样本分散到许多时间、队列和周期条目；当前没有这些访问或学习结果，不能预定它更强。当前选择 GENERIC 的理由是它保留全部反馈和完整时长条件表达，以相近参数量及共同真实训练器，直接针对被提名的乘性结构。它是合理且未被故意削弱的比较器，**不是已经证明达到某种 competence 的比较器**。实际初值、训练与评价曲线将成为首份同宿主基线观测；不先做比较器筛选或全面调参包。[提案§§3–4、6][proposal]；[证据规范§§5.2、11.7–11.9][spec]

因此不加表格第三臂，不把手写调度策略当作已测上界，也不复用旧宿主结果冒充新基线。若本次结果以后暴露一个具体比较器缺陷或新的表示选择，那是下一项有独立理由的 B，不是本次保证 FACTOR 获胜的补救空间。

## 四、可直接写卡的真实学习和数据时点

采用提案的共同半马尔可夫训练器，补全均方 TD 损失、同步顺序与探索端点这些必要细节，不改变臂数、预算或研究维度。[提案§3][proposal]

令一次真实续约行为从 t 到 t+d，实际段奖励为 R=Σ(s0+s1)/96。非终局目标为 y=R+Q_target(s′,a*,d)，其中 a*=argmax_a Q_online(s′,a,d)，并列固定取动作 0；t+d=48 时 y=R，不调用终局下一动作。γ=1，对应有限、未折扣的完整本征回报。目标 detached，不能反向更新目标副本。s′ 是该段末尾服务、到达和 h 更新之后、下一续约真正可得的状态；不能使用段内中途队列作为焦点的新输入。

每轮用当前在线模型收集 16 个完整新情节，d=2、6 各 8 个；收集期间不更新参数。随后对这一批所有真实续约行做一次 Adam 更新，之后清空该批，不设 replay 或反事实补样本。若情节 e 有 n_e=48/d_e 行，损失固定为 L=(1/16)Σ_e[(1/n_e)Σ_j(Q_online(s_ej,a_ej,d_e)−y_ej)^2]。即每情节等权、情节内真实行等权；两个周期各占半个总权重，而非因为短周期有三倍决策就有三倍损失权重。段奖励不再除以 d；不能以每原始步平均奖励替代原定全情节目标。

每轮各周期的均方 TD 损失分开保留，作为训练描述而非服务表现的替代指标。短周期每轮 192 行、长周期 64 行，总共 256 行；240 行有非终局备份。除已经实际执行的转移外，不产生别的时长、跳步、未来轨迹或模拟伙伴的训练样本。这些行数与 [准备计数 algorithm_work_law、per_arm][counts] 一致。

在线/目标模型初始相同；每完成第 16、32、…、256 次优化更新后，将在线参数复制到目标副本，在下一轮收集与备份前生效。评价读取该更新完成后的在线模型。普通两动作评分不是额外政策搜索；为与所列评分计数一致，行为选择对两候选都评分，即使该决策最终走探索分支。

Adam 固定学习率 0.01、betas=(0.9,0.999)、epsilon=1e−8、无权重衰减、全局梯度范数裁剪 5。所有 dense 权重 Xavier uniform、偏置零；FACTOR 时长嵌入 Normal(0,0.5)。第 u 轮（u=1,…,256）使用 epsilon_u=1−0.9(u−1)/255 的 epsilon-greedy；探索时均匀选两个动作，非探索及评价并列取 0。没有循环内学习率选择、提前停止、最佳 checkpoint 或评价反馈调参。[提案§3][proposal]

只使用新根 seed 401。初始化按臂分离；到达、初始 h、探索判定和探索动作使用分离的命名随机流。两臂共享同情节/同原始 tick 索引的外生到达与初始 h，探索随机量也按这些预定槽位索引，而不是按策略实际消耗顺序推进。参数尺寸和抽样不同，不能声称两臂拥有相同初始参数或政策。评价另用独立 held tapes，在两臂和九个 checkpoint 间复用；两个时长的评价 tapes 分开生成，均不供训练或政策观察。记录映射即可，不需要新的随机数管理服务。

一次配对是每臂各一个实际训练模型，不是两个独立的训练重复。共同随机数降低环境比较噪声，不消除初始化、探索和优化路径不确定性。新的初始参数范数与最终实际位移应由本次真实调用保留；现在它们未知，不能用旧位移、名义学习率或任意位移比值门槛替代。这不要求另跑一个移动能力实验。[准备计数 exposure_line、historical_movement][counts]；[证据规范§11.4及§11.8.3][spec]

## 五、主测量以及它改变什么选择

每个情节的 J=48 个 tick 实际完成工作总数/96，所有碰撞、空站和无服务 tick 都在分母里。最后一次服务后的新到达不能在该情节服务。溢出、空转和结束积压作为解释完整后果的量保留，不加奖励项，不按实际到达量重新归一化，不只评价成功段。[提案§2][proposal]

评价网格固定为 u=0,32,64,96,128,160,192,224,256；每点 256 个完整情节，两个时长各 128。主量是更新 256 的等权差 Δ=(Δ_2+Δ_6)/2，其中 Δ_d 为该时长 FACTOR 减 GENERIC 的平均完整 J。必须同时报告两个原始终点均值、两个时长的差及损失、两臂初值、每一固定点和全曲线，而不是只交出 Δ。[提案§4][proposal]

**MEI 选择绝对 J 的 0.025，等于每个 48 步情节平均 2.4 件工作的差。** 这是本次探索对实际工作数量的价值判断，不是部署最低要求、统计显著线、等价界或跨方向门槛。描述分支的“达到”包括恰等于该值；每时长的实质损失也按同一绝对刻度 −0.025 展示，不用正均值掩盖它。[准备计数 MEI][counts]

全曲线 AUC 只用这九点按更新轴做梯形积分，再除以 256；等价于 [0.5J_0+J_32+…+J_224+0.5J_256]/8。两个周期及其等权平均用同一范围。它用于呈现学习路径，不因终点不利而升格为获胜指标；也不与旧任务任何 AUC 合并。初值差不能通过事后只报“从初值增加量”消除。

采样误差与训练实例误差分开。可直接从固定终点评价的逐情节配对差 X_{d,e}=J_F−J_G，用现有数组统计均值与标准误，不增加任何 rollout。两个时长的评价 tapes 独立时，等权 Δ 的条件标准误为 0.5√(s_2²/128+s_6²/128)，s_d² 是该时长配对差样本方差。这只是对本对训练模型的评价噪声描述；跨 checkpoint 重复 tapes 有相关性，不能把九点当九个 seed，也不能据此给训练人群置信区间。接近 MEI 且评价误差足以影响读法时，明确记录分辨力不足，不靠追加评价自动改变预算。[证据规范§§5.2、11.8.3][spec]

下一观测改变的研究选择非常具体：在有状态反馈及响应伙伴的这一固定任务上，乘性时长条件结构是否值得承担一次有限独立重复的机会成本，还是此处继续保留完整条件 GENERIC、停止追求该 FACTOR 组合。它不会选择一个可部署策略，不会回答未见时长，也不把两臂都学得很差时的一点相对差说成完整 competence。

## 七、结果如何改变决定，以及一条可证伪预测

涉及周期损失的行是对均值分支的限定，不取消其真实均值。两臂绝对回报及从初始的变化也必须一并读：有利相对差可以是一个局部 B 信号，却不因对照较差自动成为“队列任务已解决”；双方共同不动或共同低回报，可以提出一个具体的训练器问题，但不要求先补一整套最优参照才能承认现有观测。

**工作预测：在这次固定 seed 401、256 更新及预定评价样本上，|Δ|<0.025 比达到任一方向 MEI 更可能；不预期 FACTOR 产生明确的双周期共同增益。** 原因是 GENERIC 已拥有完整状态、时长非线性交互与共享特征，FACTOR 没有已知队列结构优势；它改变的主要是条件化和优化几何。这是可错的推测，不是观测。若固定终点 |Δ|≥0.025，第一项预测在描述性读数上不吻合；尤其两个 Δ_d 都≥0.025 将强烈反对“没有明确共同增益”的预期。评价误差较大时同时报告该限制，不把不吻合重写成命中。正负两侧都允许反驳，不筛去不利输出。
