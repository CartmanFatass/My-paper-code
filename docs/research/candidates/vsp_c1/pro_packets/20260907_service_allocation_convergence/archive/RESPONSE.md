## 二、所选新问题的范围与反对意见

本次选择的是一个固定三队列分配实例，而非关于“增加队列是否导致 FACTOR 有效”的干预研究。相对旧宿主，队列数、每队列到达概率、初始工作总量、网络输入与参数数目、新种子和评价网格都改变。即使新结果与旧结果不同，也不能把跨宿主差值唯一归因于覆盖稀缺，更不能合并成跨任务优势。所有这些选择均在已知双队列结果之后提出，属于探索性适应。[提案，§§1–4][proposal]；[证据规范，§§4、5.2][spec]

保持三个容量为 4 的队列、两个持续存在的工人、48 个原始 tick；初始队长为 (2,2,2)，上一焦点分配 h 在 {0,1,2} 均匀取值。每条队列每 tick 服务后独立获得 Bernoulli(0.5) 到达。每情节的外生 d 固定为 2 或 6，两周期等权。均值到达 1.5 件/tick 小于瞬时总服务上限 2，仅说明没有故意设置总量过载；它不保证有限容量、持有约束下的可服务比例，不是稳定性或性能余量证明。[提案，§2][proposal]

值得回答的动作选择是：在续约时沿用当前队长的贪婪分配，还是选择一个对整个持有段及后续队列更有利的站点。长持有期间，焦点不能根据新增工作重新分配，伙伴却继续响应；一条当前较长的队列未必是整个段都最值得占用的队列。这是问题动机，不是已经观察到的最优动作反转或收益。只有真实原生比较才能说明这个动机在所定预算中有没有实际分量。

保持 K4 开放但不选择该宿主，是最接近的备选，其理由是研究用途仍局限于小型、已知伙伴的表示选择。我不选择它，因为这次可以直接区分“无需学习的规则已足够”“一般价值学习有额外用途”“乘性条件结构值得进一步验证”三种不同的后续选择。表格 Q 学习也是合理备选，但此时替换或追加它会同时改变泛化与更新行为；表格可表达不等于在同预算下已更强。保留完整信息的 GENERIC 加这个固定规则足以回答当前 B 问题，不先筛选比较器、不增加伙伴学习或可学习终止。[提案，§§1–3、5–6][proposal]

## 三、可写卡的宿主、合法信息与学习

### 事件、时点及真实信用

在 tick t 的焦点续约处，先读取当前 (q0,q1,q2,h,t,d)，选择 a∈{0,1,2} 并持有 d 步；段内不再给焦点政策新输入或新选择。伙伴每个原始 tick 读取当时队列和旧 h，选最长队列，并按 [(h+1) mod 3,(h+2) mod 3,h] 的顺序解并列。它不能读取焦点这次同时选出的新动作。不同站各最多服务一件已有工作；同站总共最多一件，空站零服务。服务后才到达、容量截断并记录溢出，随后 h 更新为当前持有动作。[提案，§2][proposal]

事件到后果的链条是：三路随机到达与排队竞争，作用于持续的焦点/响应伙伴角色；续约时的有限行动机会决定焦点占哪一站，联合占站改变已完成工作及后继队长，后继队长与旧分配改变伙伴响应；这些实际段回报和下一续约状态进入值更新，最终作用于全部 48 tick 的完成工作。伙伴没有学习参数、梯度或隐藏策略状态。续约状态是完整的平稳控制状态，不把这种时间抽象包装成伙伴共适应或多学习者信用分解。[提案，§2][proposal]

主回报固定为 J=全情节实际完成工作/96。碰撞、空站和无服务 tick 不从分母删除；最后一次服务后的到达不能在本情节完成。溢出、结束积压及未用服务能力只作描述，不加奖励项，不按实际供给量重新归一化。学习器的动作集合不因固定策略的排除规则而被删减。[提案，§§2–3][proposal]

### 两个学习臂与固定策略

| 对象 | 确定的形式与信息 |
| --- | --- |
| FACTOR | [q0/4,q1/4,q2/4,t/48,one_hot(h),one_hot(a)] 共 10 维，经 24 宽 tanh 隐层和带偏置四维线性输出，与可学习的 2×4 时长嵌入内积；372 个在线参数。 |
| GENERIC | 同一输入再拼接 [1[d=2],1[d=6]]，12→28 tanh→1 带偏置标量输出；393 个在线参数。 |
| LQ-EXCLUDE | 每次续约用自己的当前状态算出伙伴此刻的动作，选另外两队列中最长者，队长并列取最低编号，然后同样持有 d 步。无训练、调参、前视到达或段内再分配。 |

保留 GENERIC 的 21 参数差额和原隐层宽度，不通过调宽度筛选结果。两网络都共享特征，四维因子对应两个时长列没有严格低秩限制；相近参数量不等于函数类、初始化或优化几何相同。GENERIC 有完整时长非线性交互，是本次合理的同信息学习比较器，但不是已经在新宿主验证过 competence 的基线。[提案，§2][proposal]；[准备计数，candidate][counts]

LQ-EXCLUDE 是透明、合法的贪婪参照，不是最优控制器或保证强于学习器的臂。它在同一结果里暴露明显的调度不足，而不能证明任何政策已解决任务。**共享评价 tapes 仅指共享外生到达、初始 h 与周期：三个控制器必须各自演化队列、h 和伙伴动作。** 不能把任一学习臂的内生队列或伙伴轨迹重放给参照，也不能让参照每 tick 重选焦点动作。这是对“同样情节”的必要含义澄清，未增加工作量。参照既不产生训练数据，也不提供动作掩码、奖励、目标或 checkpoint 选择信息。

### 共同真实训练器

继承已读原卡 §§3–4 的实际段 Double-Q/Adam 方案，只把动作集合及输入维数改成上述三队列定义。每轮 u=1,…,256，在在线参数不变时收集 16 个完整新情节，两个 d 各 8 个，随后对全部实际续约行做一次 Adam 更新并清空该批。epsilon_u=1−0.9(u−1)/255，探索均匀选三动作，贪婪及评价并列取最低编号；即使走探索分支也对三动作评分。不用 replay、未执行时长转移、跳步增广或未来政策搜索。[提案，§2][proposal]；[原卡，§§3–4][card]

实际段 t→t+d 的 R 为段内已服务件数/96；s′ 是该段最后一次服务、到达及 h 更新之后真正可见的下一续约状态。非终局目标 y=R+Q_target(s′,argmax_a Q_online(s′,a,d),d)，终局 t+d=48 时 y=R 且不评分下一动作。gamma=1，目标 detached，目标网络不被优化。每情节 n_e=48/d_e 行，损失为 L=(1/16)Σ_e[(1/n_e)Σ_j(Q_online−y)²]。每情节等权，两个周期各占一半；短周期三倍续约行数不能变成三倍周期权重，R 也不再除以 d。

Adam 固定 lr=0.01、betas=(0.9,0.999)、eps=1e−8、无权重衰减，梯度总范数裁剪 5。dense 权重 Xavier uniform、偏置零，FACTOR 嵌入 Normal(0,0.5)。目标副本初始复制在线参数，之后在第 16、32、…、256 次更新完成后复制；评价用更新后的在线模型。分别保留各周期每轮均方 TD 损失，但不把损失下降视为服务增益。[原卡，§3][card]

只用新根种子 402；初始化按臂分流，训练到达、初始 h、探索判定和探索动作分别命名，跨臂的外生及探索随机量按预定情节/原始 tick 槽位配对，而非按政策分支消耗顺序推进。两个时长的评价 tapes 彼此独立、独立于训练，在两学习臂的五点及固定策略终点评价间复用。具体确定性映射在结果产生前记录，不再挑 seed。一个配对实例是独立学习单位，两个在线模型及其两个非优化目标副本不是四次独立训练。[提案，§2][proposal]；[原卡，§4][card]

## 四、主测量、参照与学习增益分开

每个学习 checkpoint 用 256 个完整评价情节，d=2、6 各 128。固定策略只在最终同一批 256 个 tapes 上评价一次，不做初始或中途参照调用。主量仍是更新 256 的 Δ_d=J_F,d−J_G,d 和 Δ=(Δ_2+Δ_6)/2；完整记录三个控制器的原始均值、逐周期结果，以及两个学习臂的全部五点、初值和周期损失。[提案，§3][proposal]

同时定义 E_F,d=J_F,d−J_R,d、E_G,d=J_G,d−J_R,d，并分别等权平均；R 表示固定策略。这些是事先指定的参照对比，不是看过结果后从三者中挑一个较弱对照。因为 E_F−E_G=Δ，它们不是三条独立成功证据。若 FACTOR 只比 GENERIC 好而仍明显低于参照，保留 Δ 的局部事实，却不称其为有用调度能力；若两学习臂均优于参照但 Δ 很小，支持的是价值学习在该任务上的用途，而不是乘性结构的用途。

MEI 采用绝对 J 的 0.025，即每个 48 步情节平均 2.4 件工作；逐周期实质损失用 −0.025 描述。参照对比使用同一工作量刻度解释，不另设为启动门或必须通过的 competence 证书。该数值既不是显著性线、等价界，也不是现实部署数据上限；256 更新只是一项固定探索预算，没有因旧结果很小而降低 MEI。[提案，§3][proposal]；[证据规范，§11.7][spec]

五点 AUC 为更新轴 0:256 上的梯形积分除以 256，即 [0.5J_0+J_64+J_128+J_192+0.5J_256]/4；总回报及两个周期使用相同范围。它只能描述这张较疏网格上的路径，不能声称解析所有暂态、代替终点或与旧九点 AUC 合并。保留从初始到终点的变化，但不改成只比较初值增量；若终点对参照的优势在初始化已存在，就不能把整项优势归于后续学习。

从已有最终逐情节配对数组报告每一对比的条件标准误即可：SE=(1/2)√(s_2²/128+s_6²/128)，其中 s_d² 是相应配对回报差的样本方差。这不增加 rollout，可由现有数组统计完成。共享参照、共享 tapes 和跨 checkpoint 相关性保留；这些标准误仅描述固定政策的评价噪声，不能构造训练种群的稳定性结论。边界附近不确定就原样记录，不追加评价去跨过阈值。[原卡，§5][card]；[证据规范，§5.2、§11.8.3][spec]

## 六、各结果改变的选择与工作预测

以下是本次 B 的描述性分支，不是统计裁决、B 消费规则或一般性的后续研究门槛。Δ 始终是主终点；参照关系限定其实用解释，逐周期损失限定等权均值，二者都不抹去主量。[证据规范，§§11.7–11.9][spec]

| 观测 | 最小解释及下一选择 |
| --- | --- |
| 主回报、信息或真实更新损坏，或没有可比终点 | 不形成受损依赖的性能结论；保存可信独立事实，指出具体缺口，不称负实验。若只是参照缺失而两学习臂可比，保留 Δ，仅将相对规则的价值列为未确认；不自动补第三调用。 |
| Δ≥0.025、没有实质周期损失，且 FACTOR 对参照也有同刻度收益、没有被均值掩盖的实质损失 | 是最直接支持继续研究该表示的局部信号；下一项值得考虑的是同设置的一到两个独立训练实例，而非换负载、伙伴或参照。本次不分配这些调用，也不称稳定胜出。 |
| FACTOR 对 GENERIC 有意义的收益，但两学习臂仍落后固定规则 | 保留学习器间收益及其所有曲线；不称已获得有用调度优势。不因正 Δ 自动重复，当前更倾向保留无需训练规则、停止推进这个 FACTOR 组合；有具体训练问题才另提有范围修订。 |
| 至少一个学习器相对参照有明确收益，但 FACTOR 相对 GENERIC 在 MEI 内或不利 | 支持的是该实例中的学习政策用途，而不是乘性结构。若 GENERIC 取得收益，后续实际选择倾向 GENERIC 与固定规则的局部比较，不为挽救 FACTOR 增臂或改主量；任何新对象仍须另行选择。 |
| Δ≤−0.025，或等权均值掩盖某周期≤−0.025 的损失 | 前者在该实例倾向 GENERIC；后者是周期权衡。结合二者对参照的实际水平作保留政策的判断，不改周期权重、不删损失，不宣称负迁移机制或关闭 K4。 |
| Δ 在 MEI 内且没有学习器相对规则的有用收益，或抽样误差使边界未分辨 | 此次没有给继续这项参数化比较提供实用理由，保持符号和不确定性，停止在该对象边界；不自动延长、增加评价或转向另一个相似宿主。没有证明等价或最优。 |
| AUC、初值增量与固定终点的排序不一致 | 原样同时报告，仍用固定完整终点作主要选择；不选最佳 checkpoint、seed 或较有利指标宣布胜者。 |

这些分支会重叠，按“依赖是否可信—主量—参照用途—周期代价”共同解释，不把参照失败倒推成 Δ 无效。一个正 B 不自动获配更多预算；一个负 B 也不禁止以后提出真正不同且有决策用途的比较。若两学习器都不及规则，未知原因仍可能是共同训练器、初始化、有限优化或这个任务本身，不能从一次比较选择其中一个作为唯一解释。

**工作预测：固定策略的等权终点将至少不低于一个学习臂，即 J_R≥min(J_F,J_G)。** 理由是它直接使用可见队列与伙伴即时动作，而两网络没有已知的队列结构优势，共同有限训练也未必学到持有段内的有效前瞻。若最终两学习臂的等权 J 都高于 J_R，这一预测在预定读数上不吻合；若它们均有 MEI 量级增益，反驳更有实用分量。尤其 FACTOR 在两个周期同时对 GENERIC 和参照均领先至少 0.025，会强烈反对上述谨慎预期。评价噪声须同时呈现，不能用它把错预测重写成命中；所有者预测未取得，不代写。

需要的新性能证据只有这里所选的两次完整学习调用及第二次内的固定参照评价。没有选择精确最优、全支持普查、调优 headroom、全面因果诊断或搜索之前置。所放弃的是最优性、唯一归因与训练人口结论，不是回报、信息、真实学习或比较的完整性。一次局部结果至多支持这个固定任务与预算中的信号或反例，不能证明稳定优越、等价、严格低秩收益、未见周期迁移、伙伴共适应、去中心化多学习者信用或部署能力。[证据规范，§§4、5.2、11.4、11.8–11.9][spec]
