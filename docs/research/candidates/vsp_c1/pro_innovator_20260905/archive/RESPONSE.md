**我的最终选择是：采用这个两角色服务 toy，补全学习器与测量口径，直接进入一次 seed 0、两个学习臂的有界 B 比较；不先安排零学习 A，也不把强制首动作表或穷举上参考设为前置。首轮训练全部身份—周期单元，并让两个伙伴行为层都出现在训练中。**

所选问题是：**在同信息、同原生回报、同环境曝光与优化更新预算下，显式因子化的跨周期动作价值参数化，能否比完全条件化的通用动作价值模型更快学会正确选择，或反而损害学习？**这比再做一次宿主测量更能改变下一步研究决策：公共计划下的最优控制可以直接分析，但两种真实学习器在有限预算下的表现仍然未知。当前材料没有支持任何一方获胜；选择 B 是选择一次可证伪的探索，不是认可已有性能结果。提案与已生效的证据规范允许这种直接小 B，不要求先完成上参考普查、完整调优或机制归因。

## 一、现有证据支持什么，仍缺什么

以下仓库观察均来自 `CartmanFatass/My-paper-code` 的固定版本 `f87ceedc42dde8f49d178b79f3a5e860948f4bc9`。记录内部提到的历史提交只用于理解溯源，没有跟随读取其他版本。

**已读取的事实是：目前没有可用于本题的真实 VSP-C1 learner，也没有已经测得的原生回报或数值 headroom。**旧 A01 完成的是资产可用性核查；其 `R_upper`、`R_generic` 和二者之差都缺失，不是零。保留的旧结果只有一次注册审计，环境交互、模型构造、学习、优化和回报评价均为零。

源码复用的边界也很明确：

| 已有表面                          | 可借鉴之处               | 不能当作本题已有资产的原因                                                                       |
| ----------------------------- | ------------------- | ----------------------------------------------------------------------------------- |
| 旧 VSP-C1 实现及 CLI              | 历史对象的含义与活动计数        | CLI 进入的是四角动作核审计，不是环境—policy—learner—trainer—evaluator 链；解除旧检查不会自动得到新学习对象            |

因此，真正仍需实现的是一个独立的小型研究宿主、两种动作价值模型、共同训练器和共同评价器。实现时间、实际运行速度、峰值内存、通用学习器能力及候选效果都没有实测依据。准备曝光文件明确记录“未初始化模型、零位移”，不能作为未来 B 已有非零学习曝光的证明。

## 二、保留的宿主：周期确实改变合法行动，而不是只改变标签

我保留提案的以下定义，不增加成员变化、学习伙伴或终止策略：

| 项目    | 本轮选择                                                       |
| ----- | ---------------------------------------------------------- |
| 固定成员  | \(N=2\)：一个学习型焦点控制者、一个固定伙伴程序                                |
| 原生时间  | 六个计分步，\(t=0,\ldots,5\)                                     |
| 身份动作  | \(i\in\{0,1\}\)，表示选择并保持的服务模式；不是实体 ID 或伙伴 ID                |
| 外生周期  | \(p\in\{2,6\}\)，一条 episode 内不变；合法重选时刻为 \(0,p,2p,\ldots<6\) |
| 伙伴行为层 | \(\tau\in\{2,4\}\)，表示伙伴自行执行频道切换的时刻                         |
| 镜像上下文 | \(c\in\{0,1\}\)，伙伴执行 \(b_t=c\) 当 \(t<\tau\)，之后执行 \(1-c\)   |
| 决策信息  | 重置时公开 \(c,\tau,p\)；以后公开原生时钟与上一实际伙伴动作，两臂完全相同                |
| 动作执行  | 在合法边界先选择模式，再计该步 reward；边界之间保持模式                            |
| 原生回报  | \(r_t=\mathbf1[a_t=b_t]\)，\(R=\frac16\sum_{t=0}^{5}r_t\)   |
| 学习对象  | 焦点控制者的动作价值与合法动作选择；不学习周期、不学习伙伴、不学习低层执行器                     |

实际因果路径是：

**公开伙伴计划 → 伙伴实际执行频道行动 → 焦点动作在外生边界间保持 → 两者联合完成服务 → 段回报进入动作价值更新。**

这里的时间抽象是实质约束；但伙伴既不反应也不学习，而且未来计划完全公开，**整个任务可以还原为完全可观测的单控制器有限时域问题**。本轮不能据此证明战略性 MARL、多智能体非平稳性或协同适应的价值。

### 为什么这个小问题尚未平凡到不值得一次 B

下面是根据定义作出的推导，**不是执行结果**：

| 周期与伙伴层         |   最优首动作 | 同信息最优六步回报 |
| -------------- | ------: | --------: |
| \(p=2,\tau=2\) |   \(c\) |     \(1\) |
| \(p=2,\tau=4\) |   \(c\) |     \(1\) |
| \(p=6,\tau=2\) | \(1-c\) |   \(2/3\) |
| \(p=6,\tau=4\) |   \(c\) |   \(2/3\) |

特别是 \(\tau=2\) 时，短周期应先跟随当前频道，长周期应选择之后占多数的频道。**同一公开初态的最优首动作随周期翻转。**因此不能把周期删去，也不能用只改变折扣的设计代替这个宿主。

但其有限性同样重要：两个周期共有的决策时刻只有 \(t=0\)，\(t=2,4\) 只属于短周期。本轮是一个很小的共享与学习干扰诊断，不是普遍跨时长组合的验证。

历史 `RLPA-VSP-01` 的“比所有周期都短的共同微时域”适合局部身份诊断，却可能完全不触及持有边界。本轮明确选择完整六步原生回报，而不是声称旧微时域对象已经回答了这个问题。历史 AIP/RLPA/CAP 仍只作为设计来源及替代解释记录。

## 三、人口、上参考与主指标

### 自由选择策略回报是唯一主性能量

外生人口为

$$
x=(p,\tau,c)\in\{2,6\}\times\{2,4\}\times\{0,1\},
$$

八个上下文各占 \(1/8\)。每个学习器在首边界和全部后续合法边界自由选择：

$$
J(\pi)=\frac18\sum_x R(\pi;x).
$$

每次评价记录八个实际 episode 的服务总数，并以总计四十八个计分机会归一化。主比较为固定第 128 次更新后的

$$
\Delta J=J(\pi_{\mathrm{factor}})-J(\pi_{\mathrm{generic}}).
$$

按 \(p\) 和 \(\tau\) 分层的回报直接从这八条 episode 汇总，不另加评价曝光。

### 强制首动作回报不是自由策略回报

可选诊断中的

$$
Q^\pi_0(i;x)=R(\operatorname{do}(a_0=i),\text{之后按 }\pi;x)
$$

是干预后的条件回报。其身份—周期—伙伴八单元各占 \(1/8\)，单元内两个 \(c\) 各占 \(1/2\)，但**对两个强制身份均匀平均，不等于让策略利用上下文自由选择身份**。

这个区别在本宿主尤其明显：按最优续接计算，均匀强制首动作的总体均值是 \(2/3\)，自由选择最优值则是 \(5/6\)。镜像 \(c\) 的等权聚合还会抵消固定身份的标签差异。因此，我不选择把强制八单元均值作为首轮学习效果的主指标。以上仍是定义推导，不是已生成的动作表。

### 同信息上参考必须按当前持有段决策

参考规则在每个合法边界 \(t\)，选择

$$
a^*(t)=\arg\max_{a\in\{0,1\}}
\sum_{u=t}^{\min(t+p,6)-1}\mathbf1[a=b_u],
$$

平局取动作 0。

这里必须是**下一合法边界之前的持有段**，不能把整个剩余 episode 都当成这次动作的不可撤销持有期。由于本任务没有跨段切换成本，且当前动作不改变伙伴计划，该规则给出同信息合法最优控制。其八上下文均值由定义得到 \(5/6\)。

这个规则获得的观察、合法动作、人口和权重与学习器相同，没有特权信息；但它利用已知任务模型，不支付学习成本，所以是**解析上参考，不是同工作量的已训练比较器**。本轮无需执行它的穷举普查，也不能据此补写旧 A01 的实测 headroom。

## 四、最小完整 B 设计

以下是本次选择所补全的设计参数，而不是仓库中已经运行的设置。

### 两个实际学习臂

在合法边界使用共同状态特征

$$
s=(2c-1,\ \tau-3,\ t/6,\ \ell_t),
$$

其中 \(t=0\) 时 \(\ell_t=0\) 是“没有前一伙伴动作”的哨兵；以后 \(\ell_t=2b_{t-1}-1\)。动作与周期均使用普通二元 one-hot 编码，不提供“正确动作”、参考值或从评价产生的标签。

| 学习臂  | 实际参数路径                                                                                                                                                     |              参数数 |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------: |
| 因子化臂 | \([s,\operatorname{onehot}(i)]\in\mathbb R^6\rightarrow16\) 个 tanh 单元 \(\rightarrow u(s,i)\in\mathbb R^4\)；学习两行周期嵌入 \(v(p)\in\mathbb R^4\)，输出 \(u^\top v\) | \(112+68+8=188\) |
| 通用臂  | \([s,\operatorname{onehot}(i),\operatorname{onehot}(p)]\in\mathbb R^8\rightarrow19\) 个 tanh 单元 \(\rightarrow\) 无约束标量动作价值                                   |   \(171+20=191\) |

因子化臂的共享位置是同一个状态—动作编码器及价值特征；两个周期的样本都更新它，周期通过可学习嵌入改变动作评分。**选择器不是周期盲的。**其梯度来自真实段回报与下一边界价值，不来自旧加性 logit 补角公式。

还有一个必须保留的限制：**两个周期配四维嵌入，并没有形成有约束力的“秩四瓶颈”**；周期轴只有两列。这个比较检验的是共享参数化与优化偏置，不是证明低秩必要性。通用臂也共享隐藏层，因此负结果首先表示这套因子化参数化相对该通用模型的代价，不能单凭符号就完成“负迁移”的因果归因。

通用臂拥有全部状态、动作和周期信息，没有删除公开计划、限制动作排序或故意缩小容量。它是本轮采用的强通用学习对照，**不是已经验证为穷尽调优意义上的最强学习器**。现有证据无法作出后一个保证；首轮探索也不需要先为此开展调参普查。公共计划解析控制仍作为更强的非学习反解释保留。

### 训练支持与实际 policy

**不遗漏第四角，不留出伙伴。**每轮 32 条真实 episode：每个周期 16 条，每个 \((p,\tau,c)\) 上下文 4 条；128 轮后，每个外生上下文有 512 条训练 episode。

两个身份动作在所有这些上下文都合法、都接受训练。这里的“训练全部单元”表示不屏蔽任何动作条件经验，**不表示事后把两种动作采样数强行补齐**。记录实际身份—周期—伙伴—上下文动作计数，不补种子、不替换轨迹。

两臂使用相同的 epsilon-greedy 规则：

$$
\epsilon_j=1-0.9\frac{j-1}{127},\qquad j=1,\ldots,128.
$$

探索动作均匀选择，贪婪评分相等时取动作 0。只在合法边界调用选择器，其他步使用已保持的模式。

采用 seed 0。上下文顺序和探索随机数按 episode、原生边界配对；不同形状模型使用独立、具名初始化随机流。各臂实际执行自己的动作轨迹，不用一臂结果决定另一臂的数据。评价不消耗训练随机流。

### 真实 learner 与 trainer

两臂使用 CPU FP32；稠密层 Xavier-uniform 初始化、偏置为零，周期嵌入独立零均值正态初始化，标准差 \(1/2\)。不导入预训练参数或教师标签。

一条学习 transition 横跨一个真实持有段：

$$
(s,i,p,g,s',d),\qquad
g=\frac16\sum_{\text{该段}}r_t.
$$

每轮完整 rollout 后，使用该轮更新前参数计算并停止梯度的目标：

$$
y=g+(1-d)\max_{i'}Q_{\theta_{\mathrm{old}}}(s',i',p).
$$

终局续接严格为零，\(\gamma=1\)，不按周期另乘折扣，也不把段 reward 再除以段长。

每轮执行一次全批量 Adam 更新：学习率 \(10^{-2}\)，betas 为 \((0.9,0.999)\)，epsilon 为 \(10^{-8}\)，weight decay 为零，梯度全局范数裁剪为 5。无 replay、无额外 epoch、无调参扫描、无隐藏辅助损失。

每批产生短周期 48 行、长周期 16 行，共 64 行。为了不让“短周期多三倍行数”悄悄变成三倍人口权重，选择共同损失：

$$
L=\frac1{32}\sum_{e=1}^{32}
\frac1{m_e}\sum_{k=1}^{m_e}(Q_{e,k}-y_{e,k})^2,
\qquad m_e=6/p_e.
$$

这使两个周期在损失中的总权重各为一半；**它不抹掉实际续约样本数、bootstrap 深度和学习难度的差异**，这些仍须如实报告。

### 真正的 evaluator 与最低充分检查

在更新 \(0,16,\ldots,128\) 的九个固定时点，用同一个真实宿主，对全部八个外生上下文各执行一次无探索自由策略评价。评价数据不进入训练，不用于改超参数或选择“最佳 checkpoint”。

报告全部九点曲线、初始化回报、最终 \(\Delta J\)，以及事前定义的等间隔梯形曲线面积。初始化领先与训练产生的增益分开解释；仅初始化领先不能被命名为更快学习。一个训练种子不能估计训练种子总体不确定性，也不能把八个上下文或九次评价当成九个独立训练样本。

最低充分检查限于实际依赖：动作保持、伙伴切换时序、六步 reward、终局 bootstrap、人口权重、两臂信息一致，以及主结果写出和读回。检查复核本次已计入预算的实际轨迹与结果，不另选一轮环境 smoke，不增加训练更新。未来曝光报告应来自各臂真正的 \(\theta_0,\theta_{128}\)，记录初始化范数、实际位移、位移比、真实 transition/update/evaluation 计数；不能复制准备文件中的零曝光。

本轮不增加 dummy、shuffle、persistent-noise、递归或独立周期学习等额外学习臂。它们对应更强归因问题；没有这些控制，本轮就不作那些归因主张。

## 六、预测、反证与会改变下一决策的观察

**我的预测不是因子化必胜。**这个完全公开、状态很小的宿主有利于通用模型很快追平；因子化臂可能在早期借共享特征获益，也可能因双线性优化、初始化或跨周期梯度干扰更慢。\(\tau=4\) 的首动作偏好一致，\(\tau=2\) 的首动作偏好冲突，主评价的已有分层结果可以初步观察这种差别，但不能单凭分层差异完成机制归因。

我保留提案的 \(1/12\) 作为**描述性**最小关注幅度：它相当于平均每条六步任务半个服务步。它不是 follow-up 的必要门槛。

| 实际观察                                    | 下一步判断                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------- |
| 因子化臂有可信最终回报改善，或事前定义的学习曲线改善，两臂都完成真实学习与评价 | 优先建议同一比较追加 seed 1、seed 2 两个独立训练种子，保留所有正负和失败结果；小于 \(1/12\) 的真实改善也可支持这次有限跟进 |
| 两臂很早达到相同最优自由回报，曲线也没有有用差别                | 本宿主在该预算下缺少进一步分辨力；不追加相同穷举 A 或无目的重复 B，不据此关闭 K4                              |
| 通用臂明显更好，尤其差异集中在首动作偏好冲突的层                | 反驳“这套因子化参数化在本预算下有利”的预期；先用已有分层曲线和行动记录区分初始差异、学习迟缓与周期冲突，不直接声称已定位普遍负迁移        |
| 两臂都完整学习但改善很小                            | 仍是有效探索观察。可据实际曲线提出具名的新 B；没有正结果不是全面停止规则                                     |
| 一臂未更新、输入不匹配、reward/目标错误或主评价缺失           | 该依赖上的学习比较不能成立；报告确切缺口，不把技术失败当作机制负面或候选胜利                                    |

对于“通用网络是否只是学得太弱”的反解释，一个便宜而具体的后续候选是**同信息、完全条件化的表格 Q 学习比较**；这里公开状态很小，它可以直接挑战神经表示学习困难。但这是由实际结果决定是否值得另选的后续对象，**不是现在追加的第三臂**。

还应区分：通用臂没有达到 \(5/6\)，并不自动意味着它是“失败学习器”。完整执行但尚未收敛，可以成为有限预算比较；已证实不更新或测量损坏，则不能。一次可信改善先支持有限独立种子跟进，不要求先证明语义机制、稳定优势或全调优最优性，符合已应用的 §11.8 校准。

## 七、主张上限与不改变的边界

即使结果为正，第一轮最多支持：

> 在这个固定 \(N=2\)、两个已见周期、两个已见固定伙伴计划、八个等权外生上下文及指定训练预算上，一套因子化动作价值参数化相对具名通用学习器出现了初步原生回报或学习曲线改善。
