## Direct observations

### Fiber criterion

Let `X` be a complete conforming R06 result record, `B(X)` the registered
branch map and `C(X)` a proposed prospective certificate. `C` is sufficient
only if `B` is constant on every conforming fiber
`{X : C(X)=c}`. Every audited proper preactivity reduction leaves at least one
gate-bearing value free, and the frozen object supplies no equivariance,
monotonicity or trained-policy identity that makes the branch constant.

### One omitted slot flips WITNESS

For one claim cell, let a proposed certificate retain fifteen of sixteen tape
opportunity indicators in every block and infer the omitted member from
geometry balance or reflection. In one block, set the retained indicators to
seven `O=1` and eight `O=0`; set each other block's complete opportunity
fraction to `8/16`.

- Completion `Y+` gives the omitted indicator `O=1`. All 24 block values are
  exactly `q=0.5`, so the simultaneous interval is the point `[0.5,0.5]` and
  the registered lower-bound part of WITNESS passes.
- Completion `Y-` gives it `O=0`. One block is `7/16` and 23 are `0.5`, so the
  point estimate is `0.4973958`; any nonnegative common critical value leaves
  the lower bound below `0.5`, and WITNESS fails.

The local distinction can arise from one thresholded service event, for
example a `drop` value of `0.100` versus `0.095`, while the static coordinate
map and every retained observation remain identical. Slot-specific physical
noise addresses, rotated geometry and the absence of exact learned-policy
reflection equivariance make both completions conforming. Later gates can be
placed with slack, so the same proposed certificate admits different
first-match branches.
