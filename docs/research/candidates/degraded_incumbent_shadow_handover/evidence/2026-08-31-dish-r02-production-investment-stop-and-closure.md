## Exact current blockers to the binomial interpretation

### Duplicate-root and storage-index leakage

The TEST reducer verifies that COPY and SHADOW rows at one storage index carry equal root bytes, but
does not verify equality across two storage indices that contain the same root. The existing test
helper deliberately gives indices `0` and `1` the same `00...00` root while allowing different
qualifying witnesses. A stronger synthetic construction can assign different indicators to those
two records and the preview accepts them. Because the preview is explicitly
`TEST_ONLY_NOT_READY`, this is a validity counterexample, not a contaminated result.

The legacy R06 population cannot repair this: its deterministic geometry, turn choices, and RNG
addresses use `block`. R02 requires the global record index to be storage metadata only across RNG,
geometry, minibatch order, checkpoint selection, numerical reduction, timeouts, and every other
scientific computation.

### Branch consumption drift

Equal initial frontiers and equal caller-provided address strings do not prove a common future tape.
If one branch skips a sequential draw, later semantic events can receive different random values
without any branch label appearing in the address. A conforming future map would require direct
semantic-coordinate addressing, with the root as a separate 32-byte key and a root-free local
address. No production generator currently proves this.

### Panel-adaptive repair

“Outcome-blind” is weaker than “panel-independent.” A repair can avoid endpoints yet inspect root
bytes or root-dependent failure patterns before selecting among candidate maps. For example, let
two fixed null maps use the first bit and its complement, then choose the map with more successes
on the sealed panel. If `S~Binomial(24,0.5)`, the selected count is `max(S,24-S)` and

```text
P(max(S,24-S) >= 18) = 2 * 0.011327922344207764
                       = 0.022655844688415527 > 0.0125.
```

Therefore same-panel repair is valid only when every scientific request/map/source/native/config/
numeric/RNG/endpoint/reducer raw byte is fixed before entropy and is directly byte-equal on retry,
or when a repair is physically firewalled from the scientific process. Hashes, digests, identities,
or authentication values are not scientific or runtime substitutes for direct raw-byte and direct
behaviour equality. A changed scientific byte needs a direct all-domain scientific bit-equivalence
proof; otherwise changing `F` is a new object with a new prospectively sampled panel.

### The current map is not total

The typed terminal record covers application-policy-forward and future-tick failures, but not every
legal algorithmic failure during initialization, training, checkpoint creation, or prefix
generation. Treating root-dependent algorithm failure as “incomplete until it succeeds” conditions
on completion. A future object must prospectively distinguish algorithmic failures that become
root-level zero/harm from external filesystem, transport, or missing-instrumentation failures that
invalidate the assignment and permit an exact same-panel retry.

`NO_MATERIAL`; the latter can be misread as a zero-effect or equivalence conclusion. The freeze
also makes replay a SHADOW-only modifier that cannot erase COPY, while the preview withholds the
