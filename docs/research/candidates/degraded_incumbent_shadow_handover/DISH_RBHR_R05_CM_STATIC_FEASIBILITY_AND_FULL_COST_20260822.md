## Technical conclusion

The complete seven-file r05 object is statically single-valued and can be
constructed without choosing a new treatment, comparator, observable, RNG
coordinate, threshold, population or branch rule. Every policy-visible value,
deterministic-arbiter value, evaluator-only value and branch-authoritative
reducer has a causal source and a result-blind audit seam. Literal
STRUCTURED-in-FLEX equality, NEVER's live nontransfer action, both separately
trained simple-rule arms, and the first-trigger REAL/SHAM isolation are all
implementable as written. No exact science-bearing ambiguity was found.

This is a static feasibility conclusion, not technical acceptance. No DISH r05
source package, native host, loader, registry declaration, runner, analyzer,
checkpoint/resume schema or benchmark exists in the repository. The shared
source-keyed loader/cache and fail-closed production registry are reusable
engineering substrate, but `pettingzoo.uav_relay.full_environment` is explicitly
unsupported because its lifecycle remains Python-owned. Its geometry slice
cannot be promoted or described as the r05 full host. R05 therefore requires a
new candidate-local C++ batched reset/interactive-step/terminal host and a new
component declaration after a separate construction decision.

Actor, eighteen-field snapshot and critic Welford states are separate per arm.
Rollout-start statistics are frozen; updates occur only after collection in the
registered lane-major/tick-major/UAV/copy order. Present bits suppress sentinels,
statistics freeze after update 1,024, and evaluation cannot update them. The
audit stores counts/means/M2 identities and exclusion counts, not scientific

### Critic, protocol and evaluator authority

- The centralized critic can receive current responder truth, physical state,
  camera values, link margins, SOURCE headers, base-buffer error/margins, token,
  current renewal state and terminal. These are causal-current training-only
  values. The critic has separate weights and no deployment or message/CAS
  authority. It receives no package/stratum, future clock/noise, remaining
  horizon, counterfactual, RNG identity or future outcome.
- SOURCE payload coordinates/velocity are opaque at both actor and learned
  message boundaries. Only the base evaluator decrypts them to score the fixed
  service recurrence. Arbiter access to owner/epoch/sequence/lineage fields is
  deterministic protocol authority, not a learned input.
- Every one-tick delivery follows the fixed order: control headers arm locks;
  SOURCE replacement; SERVICE_RELAY/base; STATE; READINESS; COMMIT_RESULT.
  Application then precedes camera/filter/controller update and the next
  reservation. Native before/after snapshots can audit this without exposing a
  future value to policy.
- Advantage assignment and the recovery witness use evaluator-only current
  ground truth. Their actor ABI is physically separate and they cannot call a
  learned model. The winning candidate attempt, requested stratum and package
  stay in the sealed population manifest and are never actor/critic fields.
- Branch-authoritative logs are keyed by immutable logical tape coordinates and
  contain endpoint/cost/support/hard-event reducers plus causal audit digests.
  Partial blocks remain non-evaluable. All accepted and calibration tapes are
  retained by their complete address plus winning attempt; completion order
  cannot select or replace one.

The audit therefore finds no outcome, future-tape, package, stratum, block,
address or counterfactual leakage into a deployed policy.

## Literal treatment and comparator feasibility

### STRUCTURED inside FLEX

One implementation must instantiate shared weights and identical arithmetic for
both arms. A TEST-only containment call copies any STRUCTURED parameter state
into FLEX, supplies the same causal state and the same action uniforms, and
forces the four residual outputs to exact constants:

```text
DeltaI=0
alpha=1
r=0
beta=0
```

The call compares, tick by tick, all four recurrent states, normalized actor and
snapshot inputs, messages and float32 wire payloads, origin/application
predicates, `y/b/a`, eligibility, owner/token/sequence/buffers, promotion and
future actions. Constants should be installed directly at the mask boundary so
containment does not depend on a library's approximation of `tanh(0)`. FLEX's
unmasked production residuals still act only at first snapshot initialization,
promotion blend, readiness/commit score and first boundary mean before the
common hard projection and CAS predicates. None can bypass terminal, one-owner,
version, lineage, epoch, separation or slew checks.

This proves literal function-class containment. It does not claim that the
separately initialized/trained finite-budget FLEX optimizer follows the
STRUCTURED path; finite-budget regularization/learnability remains the frozen
strongest alternative.

### NEVER and simple rules

NEVER executes the identical recurrent/prediction/message graph, shadow motion,
preparation and live learned commit Bernoulli. A true commit produces the same
32-byte costed NOOP but never enters CAS or invalid-commit accounting. The
initial owner remains sole service authority. This is a separate message enum
and hard authority mask, not a zeroed action probability.

IMMEDIATE and HYSTERESIS are independently initialized and trained full-graph
arms. Their sole substitution is deterministic prepare/commit timing using G1
or G5 and repeat-until-one-success under the common certificate. No checkpoint,
normalizer or model state is shared with another arm.

### REAL/SHAM isolation

The fork boundary is after application-tick arrivals/buffer replacement and
before CAS. The clone includes physical/filter/recurrent/normalization states,
all buffers and locks, token/versions, held actions, battery, terminal state,
address identity and the complete remaining tape. REAL and SHAM both increment
epoch, set handover-used, complete preparation, invalidate old versions, reset
warmup, cease later transaction messages and charge the same byte/energy shell.
They emit the byte-identical nominal-promoted-sender COMMIT_RESULT under the
same margin. Only REAL changes owner, promotes the prepared state and remaps
actuators. SHAM's telemetry is ignored by controllers and is not an invalid
commit. A clone-diff allow-list can therefore prove exact isolation.

The arm-independent advantage assay, recovery witness, support/headroom gates,
24-block family and exhaustive result map each have all required implementation
facts. No comparator approximation or result-selected fallback is necessary.
