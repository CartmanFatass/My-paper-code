## 一、决定：CONTINUE／MEDIUM，但调整下一项比较目标

**FOLR 继续，保持 MEDIUM 和现有一个席位。不 PARK、不 CLOSE，不作方向级 RECAST。**

我选择的下一项具体目标，**不同于报告推荐的“persistent 对 current-only”两臂消融**：

> **共同保留原 Generic64 融合循环能力，在处理组增加合法的持久实体历史分支；将这一增强完整学习程序，与同期全新训练、未增强的 Generic64 直接比较，判断增强方案是否提供值得继续开发的原生回报增量。**

这是**两个新拟合**，不是在原提案上强制增加第三臂。暂不选择 current-only 增强臂，不自动重复第三个旧 BANK16 block，也不延长旧实验或改变宿主。

我接受 DM 和独立审查关于附加实体历史的科学动机，但在本次机会成本判断上，优先回答“**是否值得在 Generic 之外维护这个增强方案**”，而不是先回答“**在两个增强方案内部，持久状态是否更好**”。后者有真实研究价值，却可能在两臂都不如 Generic 时仍给出阳性结果；前者更直接影响当前开发选择，同时少训练一条实体分支。这个取舍不是因果消融的普遍优先级规则，也不是对缺少第三臂的完整性指控。

**本次归类为现有实体历史研究族内的前瞻重设计。** 原实体历史开放范围明确采用 BANK 替代 pooled recurrence、没有额外 pooled GRU；不能把现在的双流方案称为原实现不变。本决定前瞻扩展该具体架构范围，但继续研究同一物理成员变化、合法观察者历史和有限协调回报问题，保持宿主与信息接口，不重置 recast 历史，也不恢复已经停止的 scalar `LEARNED_EVENT` 套件。旧卡、旧源码和旧结果保持原义。

当前容量为 **ACVC、MGTAP、FOLR 三占用，零预留、零空缺**。RCLE 的 PARK 和已经完成的 ACVC 补位不撤回；本次不修改其他方向、不重新分配其资源、不创建第四方向。原 FOLR DM 负责应用本决定和普通研究执行，无需另一轮仅用于批准启动的 Portfolio 或 Root 确认。

## 三、科学假说的调整：从替代通用循环，到检验附加价值

我读取了原 `Actor` 和 `ObserverAttention` 源码。结构差异明确：

**Generic** 先对当前可见实体作 attention，与公共及本地元数据融合，再进入自身存续期的 GRU64。**BANK** 则先逐观察者—主体更新 GRU16，再投影、attention 和当前读出，没有那条后融合的通用 GRU。当前物理特征旁路保留了当前信息，却没有使两种时间组织等价。

因此，两个 BANK 损失没有直接回答以下问题：

> 保留 Generic 对融合关系历史的处理能力后，附加的实体索引历史能否带来净的有限学习收益？

这是从源码提出的可检验假说，**不是已诊断“丢掉 Generic 循环导致 BANK 输”**。同样，保留 Generic 的架构也不保证保留其已学策略、初始 Q 函数或最终成绩；新增分支会改变优化、探索和队友共同适应。Generic 已有合法历史，不证明它已经形成充分状态；新增结构可以帮助学习，也可以增加冗余、陈旧信息和优化负担。

**我选择继续的对象是这套新完整程序的有限性能，不是一个必须先证明的纯记忆机制。** 因而可以优先用未增强 Generic 作直接参照，而不要求先完成持久性消融、精确上界或同容量证明。

## 四、最强反方案与成本：为什么不 PARK，也不先做候选内部消融

### 最强反方案是可逆 PARK

PARK 的理由很强：短 H20 行程、重复可见的当前线索、完整公共生命周期信息以及 Generic 自身的历史处理能力，可能使额外实体状态没有足够回报空间。旧替代程序两次明显落后；增加一条分支还可能使原本可用的循环学习更难。即使代码正确、参数有移动，新方案也可能再次没有开发优势。

我不认为这些反面证据已经被“附加而非替代”这个名称化解，也没有估计新方案的成功概率。继续确实意味着支付新增实现、双流训练、观察、分析和审查工作，承担再次得到不利结果的风险。

仍选择继续，基于三个相互关联的理由。

**第一，新方案保留了旧比较中被交换掉的能力，而不是任意再增加一个参数。** 当前反证针对“主体局部循环替代融合循环”的完整程序。让增强策略仍能使用融合历史，再评价附加实体路径，是一个明确、与旧反证有关但未被其覆盖的开发变化。它没有增加特权信息或更换任务来寻找有利结果。

**第二，直接对未增强 Generic 的结果会改变实际开发动作。** 一个有用的净增量支持保留增强路径；尺度内或不利结果则使支付这条附加路径的理由减弱。相比之下，persistent 对 current-only 的正差只能在增强候选内部作选择，尚不能说明应当在 Generic 之外维护其中任何一个。**我愿意购买直接程序增量的信息，但本次不优先购买这一条件性内部选择。**

**第三，可以在同样两个拟合的范围内回答直接问题。** 不需要给原两臂消融再加第三个 Generic。将 current-only 增强臂换成完整未增强 Generic 后，仍保留两套真实学习程序及相同训练/评价曝光，却不再训练第二条 BANK 分支。这是工作结构上的减少，不是已测的墙时或总成本优势。它也少提出一套新的 current-only 行为语义，降低当前改变路径的范围。

这是一项**定性、可逆的投入判断**，并非测得的正期望信息价值。即使直接比较再次不利，也不会使本次选择事后变得无效；但不能因此自动再换结构或抽取新 seed。

### 对 DM／Reviewer 推荐方案的实质分歧

我同意独立审查：原两臂消融在定义清楚后是合法、有用的 B 问题，未增强 Generic **不是它那个较窄主量的必需第三臂**。我的调整不是提高其证据门槛，而是**改选当前更值得回答的问题**。

代价也明确：直接增强对 Generic 的比较，不能告诉我们潜在增量究竟来自持久状态、额外当前特征处理、参数化、融合或共同适应。对此我选择收窄归因，而不是为纯机制解释增加成本。未来若“保留持久状态还是逐步清空”本身成为值得解决的开发选择，DM 已澄清的 current-only 对照仍可使用；它不是被否定，更不是本次的隐含下一关。

### 对三项审查发现的处理

**P1：保留持久流的合法生命周期；本次不实施未选 current-only 臂。** 对观察者 \(i\)、主体 \(j\)，增强流先按两者的存续指示截断旧状态，可见时更新，不可见时只携带仍合法的历史：

$$
\bar m_{ij,t}=c_{i,t}c_{j,t}m_{ij,t-1},\qquad
m_{ij,t}=
\begin{cases}
\operatorname{GRU}_{16}(e_{ij,t},\bar m_{ij,t}),&\text{当前可见且存活},\\
\bar m_{ij,t},&\text{否则}.
\end{cases}
$$

不在不可见时合成物理观察；观察者/主体更替时清除对应历史和时间梯度。若以后采用 current-only，它必须是可见时 `GRU(e,0)`、不可见时零状态；仅 detach 或仅清 GRU 输入都不足。但本次不为未选臂增加训练、运行或检查任务。

**P2：Generic 路径在增强组中不能被实体路径偷偷改写。** 实体特征进入后端 Q 融合，不仅在处理组反馈到 Generic 输入；Generic 自身状态仅按自己的存续期边界处理，不因同伴更替整段清零。每臂拥有自己的参数、隐状态、replay、优化器和随机状态；online 与 target 分别用自身参数重建相应状态流。保留通用架构不保证历史 Generic 成绩。

**P3：完整程序主张取代同容量或纯持久性主张。** 本次不再利用“相同名义张量”来描述比较。增强比 Generic 多出实际模块、历史依赖和学习工作；这是待评价程序的一部分，不能填充无用计算来伪造等成本，也不能把净回报差独立归给历史内容。

### 剩余工程是实际工作，不是已验收能力

目前新增强程序尚未实现或技术接受。原 DM 可直接实现或委托有界批次；新 recurrence、fusion、RNG和replay路径需要已有规范要求的独立高风险审查。聚焦检查应覆盖可见—不可见—重现、观察者/主体替换、acting/replay与online/target各自状态、融合到 Q/损失的真实连接，以及旧 Generic 路径未被改变。复用未变检查，不为进入启动边界重复整套历史测试。

### 1. 明确两种实体状态法则

令 \(v_{ij,t}\) 表示当前可见且观察者、主体均存活，\(c_{i,t},c_{j,t}\) 表示同一存续期继续，\(e_{ij,t}\) 为清洗后的合法当前输入。两臂各自使用自己的 GRU16 参数：

$$
\bar m^{P}_{ij,t}=c_{i,t}c_{j,t}m^{P}_{ij,t-1},
$$

$$
m^{P}_{ij,t}=
\begin{cases}
\operatorname{GRU16}_{P}(e_{ij,t},\bar m^{P}_{ij,t}),&v_{ij,t}=1,\\
\bar m^{P}_{ij,t},&v_{ij,t}=0,
\end{cases}
$$

$$
m^{Z}_{ij,t}=
\begin{cases}
\operatorname{GRU16}_{Z}(e_{ij,t},0),&v_{ij,t}=1,\\
0,&v_{ij,t}=0.
\end{cases}
$$

两臂均按 episode、观察者与主体的实际存续期边界清除实体状态，inactive状态保持零。对照不能在不可见分支回退到旧 \(m\)，也不能用 detach 代替清空。**同一套 seen／age、visibility、public lifecycle、readout mask 和当前特征旁路仍然合法地存在于两臂**；不可见 token 可以含有这些 bookkeeping，但不能偷偷带入旧 learned entity state。P1修正的是尚未实现的提案歧义，不是 B03 的追溯 bug。

### 2. 通用路径、融合与学习必须真实相连

两臂都采用当前可见实体 attention 加 public/local metadata，进入自己的 Generic64；其状态按自身行程、出生和inactive边界处理，不能因任意 peer 替换就整体清空。实体分支在通用循环之后的 Q 读出端加入，不能只在一臂反馈到 Generic 输入。

采用报告中的64维通用流、64维实体读出、拼接后共同的 linear128→5 Q读出。对应模块初始构造、共享模块的选择、初始化顺序和 RNG 消费前瞻说明；各臂仍拥有独立的参数、优化器、replay和可变状态。online及target分别以自身参数重建两个状态流，不复用另一网络的缓存。分支必须实际连接到 Q值和训练损失，而非仅在模型树中存在。

相同参数形状并不要求所有参数具有相同有效更新。清空实体 hidden input 会改变跨步梯度，部分 hidden-to-hidden 矩阵可能没有该路径的输入信号；这是干预的一部分，不需要补虚假计算或要求每个参数都移动。所得对比包含 persistence、优化和共同适应的后果，不是孤立的“有用记忆内容”效应。

循环状态、replay、RNG及读出改动适用独立高风险工程审查。一次聚焦于可见→不可见→重新可见、观察者/主体替换、acting/replay及online/target状态归属的验证，应覆盖具体改变；不因到达启动边界而重复整套历史检查。旧审查已经完成，无需再发同一个问题取得启动许可。
