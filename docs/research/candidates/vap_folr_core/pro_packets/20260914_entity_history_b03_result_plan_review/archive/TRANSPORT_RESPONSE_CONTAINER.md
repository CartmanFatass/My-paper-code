## 3. The source asymmetry is real, but is not a diagnosed bug

In `Actor.forward`, Generic attends current visible tokens, combines the result with public/local metadata through `fc2`, and recurrently processes that fused input in GRU64. BANK instead advances observer–subject GRU16 entries before token projection, attention and final current fusion; its Q head receives no additional fused GRU state. Thus the old comparison replaces post-fusion recurrence with subject-local recurrence. The direct physical-feature bypass does not make these temporal organizations equivalent. [model.py, Actor.__init__/forward][model].

The same source sanitizes unseen physical values before embedding, uses each observer's self query, and separates visible-update masks from live/seen readout masks. Public lifecycle metadata reaches the policy outside masked physical tokens. These are meaningful protections of the legal comparator, not proof of sufficient state. Neither the width difference nor the ordering identifies which feature caused either loss. Both implementations match their declared packages; calling the replacement a discovered integrity defect would rewrite the experiment. [Model, ObserverAttention and Actor.forward][model]; [card, Mechanism/comparator][card].

The additive hypothesis is therefore plausible: entity-indexed persistence might help when it does not displace generic recurrent processing of fused relations. It remains compatible with redundancy, stale information, difficult optimization, or no useful additional history on this host. Source structure supplies a testable alternative, not evidence of expected gain. [Intake, proposed hypothesis and alternatives][intake]; [FOUNDATIONS sections2,4][foundations].

## 4. Material prospective findings: define the intervention, not merely its label

**P1 — Zeroing the GRU argument alone need not produce a current-only branch.** The existing BANK code computes a candidate, then uses `torch.where(visible, candidate, h)`. Substituting zero only for the candidate's incoming hidden argument would still carry old `h` through an unseen step. That would violate the proposed current-only interpretation. No such faulty successor has been implemented; this is a concrete risk exposed by the reused source. [Model, BANK update/readout][model]; [intake, control description][intake].

A sufficient definition uses visibility `v`, observer/subject continuation `c_i,c_j`, and sanitized permitted input embedding `e`. Persistent state first becomes `m_bar = c_i*c_j*m_previous`, then uses `GRU16(e,m_bar)` when visible and carries `m_bar` otherwise. Current-only branch state is **`GRU16(e,0)` when visible and zero when unseen**, irrespective of its previous output. Both reset at episode/observer/subject boundaries. Detaching old state would remove gradients but not history and is not this control. No fabricated unseen observations or retained last-visible learned value should enter the control.

Keep live/seen readout masks, labels, visibility/seen/age metadata and current-feature bypass identical across arms. An unseen control token can still encode legal metadata, but not carried learned state. Keep Generic64's own-trip recurrence in both arms; peer turnover must not trigger blanket clearing of that state. This is not a memory-free comparison: Generic recurrence and historical bookkeeping remain available to the control. These specifics resolve the proposed estimand without requiring a separate diagnostic study. [Model, metadata/continuation/allowed masks][model]; [intake, common-information proposal][intake].

**P2 — Retaining a generic path means retaining its architecture, not its realized policy or guaranteed performance.** Define the common Generic input as current attention plus legal metadata, advance its own-trip GRU, and fuse that output with the bank readout for Q values. Do not inadvertently feed bank features into only one arm's generic recurrence or share a mutable hidden cache between arms. Each complete learner trains its own common path and partners; their learned parameters, states and trajectories can diverge. Neither augmented learner is guaranteed to match the historical Generic score. [Intake, common Generic64 path and Q fusion][intake]; [model, Generic branch][model].

Prospective construction should match both arms' module initialization and specify the shared fusion initialization, optimizer inclusion and RNG consumers. Avoid an unintentionally disconnected bank branch; faithfully reconstruct both state streams separately under online and target parameters. One focused changed-path check covering visible→unseen→reappearance, replacement, and acting/replay/reset behavior is proportionate. Existing unchanged checks need not be rerun wholesale. This is ordinary semantic acceptance, not a positive-result or full-reconstruction gate. [Engineering sections7.1–7.3][engineering]; [specification11.4,11.8.6][spec].

**P3 — Equal parameter counts do not match temporal capacity or optimization.** Resetting hidden input removes the branch's across-step dependency and gradients; in the conventional GRU, hidden-input weight matrices receive no hidden-state signal when that argument is identically zero. Persistence therefore changes effective computation and credit assignment even with identical tensors. These are intended consequences of the intervention, not reasons to abandon it or add dummy computation. A resulting difference is a finite trained-program contrast involving persistence and co-adaptation, not isolated useful-memory content or proof that losing fused recurrence caused B02/B03. [Proposal's capacity limitation][intake]; [model, GRUCell use][model]; [empirical note, whole-method versus component cause][empirical].

## 5. A useful narrow question does not require a third arm by default

The two-arm primary can be **persistent-minus-current-only final native return**, after fresh training of both augmented policies. Its concrete decision is whether persistent entity-indexed state deserves continued development *within this augmented candidate*, rather than using its step-reset branch or declining this line. That is an actionable preliminary question, not merely prediction of a memory statistic. [Intake, proposed question and endpoint][intake].

A gain beyond a prospectively stated MEI1 supports interest in persistence relative to that control; an inside-margin observation supplies no practical separation on that fit, without equivalence; an adverse contrast favors the current-only augmented program on that fit. Missing endpoints support no dependent contrast. One fit per arm gives no stable learning-population conclusion. More panels on B03 checkpoints would not answer this new training-law question. [Specification11.7–11.8][spec]; [empirical note][empirical].

**A contemporaneous unaugmented Generic is not necessary for that narrower primary. It is necessary evidence for a claim that the augmentation beats Generic alone.** Persistent could outperform current-only while both underperform unaugmented Generic. A positive ablation cannot establish net augmentation value, and the historical B03 mean cannot fill that missing comparator. This limits what the pair can decide; it does not automatically require purchasing a third fit. If the actual intended decision is immediate replacement of Generic, the primary comparison must instead address that decision. The DM should explicitly respond that conditional persistence development—not adoption—is worth the narrower experiment. [Intake, omitted-unaugmented-arm limitation][intake]; [specification11.8.4,11.9][spec].

## 6. Substantive alternatives and proportional work

I favor the additive-control question for further consideration because it retains the relevant generic capability in both arms, changes one declared persistent-state law, and measures native consequences with two real learners. It addresses an exposed design alternative that an unchanged third block leaves intact.
