# Select the public-lifecycle extension for a bounded trained comparison

Select the explicitly public-lifecycle easy Traffic Junction extension for a later class-B comparison of trained RETAIN and RESET. Continue this newly scoped question, narrowly: does indiscriminate erasure of a genuinely continuing car's recurrent state at real roster events have a native-return cost or benefit after both learners can adapt? The proposed information change resolves the particular identity and undisclosed-event problems identified by P77, while the multi-step action/reward path makes the question different from repeating B04's terminal private-bit readout. This is a scope selection, not a finding that retention improves traffic performance, an execution allocation, or a Portfolio disposition. [Proposal, §§2–4][proposal]; [P77, §§2–3][p77].

The selection is a close call on question value. Ordinary generic RETAIN remains the strong zero-work alternative and already supplies the history capacity under consideration. The marginal purchase is therefore an empirical limit on blanket survivor resetting, not a new typed-state algorithm. That limited purchase is worth one bounded real learning comparison, but not an intervening source-identification project, policy search, exhaustive diagnostic, or open-ended attempt to obtain a favorable sign. Class B is sufficient for this purpose; a stronger claim is neither selected nor needed. [Empirical specification, §§5.2, 11.8–11.9][empirical].

## What the proposed interface changes—and what it does not

The accepted source observations are specific. Easy Traffic Junction has five slots and twenty primitive steps, actual goal/collision removals followed by possible same-step refill, locally masked entity observations, native movement choices, and native progress/waiting/collision reward. Boundary active masks do not identify every physical trip: active before and active after can conceal replacement. The source GRU and previous-action path follow slots rather than explicitly fresh trip lifetimes. These observations are retained source findings, not measured event frequencies or learning effects. [P77, §2][p77]; [Source record, `source_reading_ranges` and `direct_facts`][facts].

The proposed adapter changes the information protocol openly. During the actual native transition it records real departures and activations; only after reward, removal and spawn does it emit metadata for the next actor input. A repeated removal call on an already inactive slot contributes no second departure to the event record, but this bookkeeping must not suppress or alter native simulator calls or their side effects. In particular, preserving the source includes its waiting behavior and random-number consumption, not silently replacing either with a cleaner trip-age or event-tape model. This is an assessment of the declared design, not verification of an implemented adapter. [Proposal, §2][proposal]; [P77, §2][p77].

The continuing-trip predicate is appropriately stronger than a mask difference: `C[j] = A_before[j] and A_after[j] and not D[j] and not B[j]`. A slot removed and refilled within the step has a birth and is not a survivor. The global cue `E = any(D or B)` describes a completed real roster event, not an anticipated arrival. Episode, slot and activation occurrence define ownership for bookkeeping; no numeric generation identifier becomes an actor feature. Entrants and inactive slots have fresh/zero hidden state in both arms, and previous-action features retain the preceding action only for a continuing trip. These common rules remove predecessor-state transfer from the intended contrast. [Proposal, §2][proposal].

Information parity requires the proposed separation between recipients. Both fixed state managers receive the active mask, B, C and E. Both learned per-car actors receive the same native local attention representation plus global E and their own B scalar, appended before the existing GRU input projection. Both replay paths receive the corresponding recorded next-observation metadata. Neither actor receives a departure reason, hidden position or goal, another car's memory, the full event list, a numeric epoch, or a future event through this extension. [Proposal, §2][proposal].

Giving E to both learned actors matters even though both state managers could already inspect callbacks. A RESET-only discontinuity can convey event information through the policy's internal state and subsequent action. Common public E makes that event information explicitly available to RETAIN as well. This addresses the disclosure objection; it does not preserve the original CAMA information set. A locally observing survivor can now know that something changed elsewhere. Local physical traffic remains partially observed, but all resulting claims belong to the declared lifecycle-visible variant. P77's no-ready conclusion for unchanged permitted information remains correct. [P77, §3][p77]; [Proposal, §2][proposal].

At the next actor update, RESET clears a true survivor's full incoming GRU state when E is one, before processing the current observation and metadata. RETAIN carries that state. Clearing after processing the observation would be a different intervention. RESET is also not a completely memoryless or information-free policy: it still receives current observations, the public cue, continuing-trip previous-action features, and can accumulate new recurrent history between events. Episode reset clears all state, marks the initial car's birth, and uses E=0. Events in the final native transition have no subsequent native control opportunity; terminal computational passes and target handling must remain distinguished from actual post-event actions. [Proposal, §§2–3][proposal]; [P77, §§3–4][p77].

## Decision value and the strongest contrary case

The strongest support is the concrete sequence now available for study: another physical car arrives or leaves; an existing car truly continues; its retained local observation history may contain information about traffic no longer in view; and it has later movement choices with native consequences. The same public event cue can help either learner adapt to changed traffic without dictating whether all prior context should be discarded. This connects roster change with multi-agent partial observability and partner adaptation rather than merely relabeling a generic reset operation. The source establishes the opportunity for this chain, not its frequency or payoff. [P77, §2][p77]; [P68, §§3–4][p68].

My inference is that the comparison has modest but genuine discriminating value because both directions of effect are intelligible. RETAIN may preserve useful recent traffic context. RESET may reduce obsolete context or make finite-budget learning easier. Both may perform similarly because current inputs and rapid rebuilding suffice. Separately training the rules tests these adaptive responses; damaging an already RETAIN-trained policy at evaluation would not answer that question. No sign is asserted in advance.

The strongest contradiction to buying the comparison is that RETAIN is already the competent generic history path. A RESET loss could confirm a familiar consequence of discarding useful information without producing a better method. In addition, twenty steps provide a short horizon, each car reobserves its own position and goal, lifecycle cues themselves may facilitate adaptation, and the useful post-event survivor exposure has not been sampled. Full recurrent state may carry irrelevant as well as useful teammate context. None of this establishes memory necessity, and none makes a RETAIN gain inevitable. [P77, §§2–5][p77].

I therefore do not accept two possible overstatements of the recommendation. First, an actual roster event does not make all survivor memory obsolete: the physical owner continues, and past observations of teammates can remain relevant. Second, a plausible source-to-effect story does not establish a useful performance margin or an affordable wall time. What makes the limited observation worth selecting is the now-explicit comparison meaning on a real multi-step host, not novelty by renaming, demonstrated headroom, or presumed low cost. The no-work alternative would remain scientifically respectable; it is narrowly not selected for this question.

## Relation to the existing family and smallest meaningful comparison

This is a new exploratory question within the roster-change state-continuation agenda, with an explicit extension of information and state semantics. It is not an unchanged B3/B04 continuation and not evidence for the old strictly-self-ancestry definition. A car's full causal GRU contains its own observation history, which can include other cars. Ownership of the recurrent record does not make its informational ancestry self-only. Neither a separate self-only network branch nor an ancestry census is selected to recover that stronger interpretation. [P68, §§2–4][p68]; [P77, §3][p77]; [Direction, “Accepted N3 B04 science”][direction].

The smallest useful prospective comparison has the two stated retention rules and the same source generic entity-attention GRU/QMIX base, not a CAMA-coach treatment against a different generic architecture. Each arm learns under its own rule, with matched architecture and model size, initial parameter pairing, optimizer configuration, native objective, nominal collection/update exposure, and final evaluation selection. Both online and target recurrent replay unrolls must reproduce their arm's acting rule using metadata aligned to the completed transition. Common entrant/inactive handling and trip-consistent previous actions are shared design changes, not additional treatment differences. [Proposal, §§2–3][proposal]; [P77, §§3–4][p77].

The source architecture is a credible generic comparator, but its competence at the eventual small exposure is unmeasured. That distinction belongs in the interpretation, not in a new tuned-baseline prerequisite. Equal optimizer counts also do not imply equal gradients, effective optimization, or parameter movement. Shared-parameter teammates co-adapt differently in the two arms, and trajectories can diverge after different actions. The source's branch-dependent global NumPy draws make equal seed labels insufficient to guarantee equal realized traffic events. Pair initialization and declared randomness where appropriate, but do not force identical event tapes by altering the simulator or condition away the policies' different event exposure. [P77, §§3–4][p77]; [Source record, `direct_facts`][facts].

The primary observation should remain the difference in mean full-episode native team return at final frozen greedy evaluation, with RETAIN minus RESET as the stated sign. Each final policy is evaluated under the rule it learned. Report both arm means as well as their difference. Do not substitute an event-conditioned subset, event-normalized reward, selected transient, or evaluation-only RESET ablation for that primary observation. A measured difference would be the total trained-system effect of the two state-management rules at the declared exposure, including optimization and co-adaptation—not a uniquely localized causal effect of one stored teammate feature. [Proposal, §3][proposal].

One matched training pair can provide the initial class-B observation; this is not a mandated seed count or allocation here. The independent learning unit is the matched pair of training instances, not a car, GRU row, replay episode, or evaluation rollout. More evaluation episodes can describe conditional rollout noise but cannot estimate training-seed population uncertainty from one pair. Independent training seeds would address repeatability in any subsequently justified follow-up; neither significance nor all-positive outcomes is a prerequisite for a bounded B observation. [Empirical specification, §§5.2, 11.8.2–11.8.4][empirical].

## The next discriminator and how much it could establish

The selected next scientific discriminator is ordinary real training and sampled native return under those two rules, after a later separately allocated configuration and implementation. No preceding policy search, exact maximum, support census, diagnostic experiment, or source re-identification is selected. Forgoing those analyses relinquishes optimality, exact equivalence, information necessity and complete mechanism attribution; it does not relinquish reward integrity, correct trip ownership, shared declared information, faithful online/target training, or a trustworthy primary return. [Empirical specification, §§11.4, 11.8.1, 11.8.5–11.9][empirical].

A later card would name the four requested within-run exposure totals for each arm: births, departures, true-survivor event opportunities, and actual survivor resets. A true-survivor control opportunity requires C and E together with a subsequent native action. Episode initialization is not an earlier survivor event, and final-step arrivals/departures do not manufacture such opportunities. Native event totals can retain terminal events while the opportunity/reset totals distinguish control-relevant handling. Replayed rows are computational reuse, not new physical arrivals or independent opportunities. RETAIN's survivor erasures are absent by its rule; its common entrant and episode clears must not be relabeled as survivor resets. [Proposal, §2 and additional caller constraints][proposal].

These are interpretive counts from the selected run, not a demanded population census or event-frequency pilot. There are no additional episodes or telemetry framework for them. Scarce exposure limits an erasure interpretation; a run with no true survivor followed by another native action cannot establish post-event survivor-control cost merely because its episode returns are readable. Conversely, different exposure totals across arms can be consequences of different learned behavior, not automatically a pairing defect. They must remain visible without changing the full-episode primary comparison after seeing them.

A RETAIN advantage would be a preliminary native cost of GRU survivor-memory erasure on this lifecycle-visible configuration after training adaptation. It would not establish typed-state innovation. A RESET advantage would be retained as an opposite-sign trained-system result, consistent with—but not uniquely proving—a benefit from discarding context or a different learning path. An unresolved difference would limit what this configuration, exposure and evaluation can tell us; it would establish neither exact equality nor memory uselessness. The magnitude and uncertainty would be reported against the later card's own interpretation, without importing B04's MEI. No sign gives an automatic entitlement to more runs. [Empirical specification, §§11.7–11.8.4][empirical].

No complete causal diagnosis, publication-grade superiority test, transfer study, or extra approval layer is introduced. A future implementation needs only proportionate verification of its changed behavior and primary output through the ordinary existing process; this response commissions no separate check or engineering task. No nested candidate search, joint-action enumeration, hypothetical trajectory tree, or diagnostic sweep is part of this minimum comparison. [Source record, `unselected_future_b_work`][facts].
