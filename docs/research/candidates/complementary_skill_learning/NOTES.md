### Concrete candidate for criticism, not a frozen batch

Use native **S1, N=6, 50 users, k=10, six team and six individual labels**, fixed episode
length 500. Full HMASD training from scratch, 16 lanes x 500 x 45 rollouts = 360,000 team
transitions per fit. The retained FSD native collector/config constructors can supply this
path without restoring the entire archived duration adapter. Its low actor is local
observation -> base -> individual-skill FiLM -> GRU -> Gaussian action head; team skill is
used elsewhere, including critic/coordinator/discriminators, and must not be described as a
new actor input. The high level has the existing global state and all observations; no
actor gains another member's hidden state, a future label, a predictor value or planner.

Commonly correct the actual environment action boundary to clip raw actions to [-1,1],
while PPO stores and scores raw Gaussian samples; retain reward, normalizers, entropy and
recurrent entry semantics. This is a new common baseline condition, not a retroactive
repair of historical results. No N changes, duration choices, new service reward or S7
mechanism are introduced. S1 native service is coverage, link quality and height penalty;
the last component is not battery energy or return-to-base safety.

All three arms use the same ordinary AR combination-exposure law: at each individual
factor, after legal support/masking, mu_i = .9*pi_i + .1/|A_i|; keep the team factor as
ordinary AR. Store actual prefixes and old log mu, score new log mu under the same law in
PPO. Never overwrite sampled labels after logging pi. All labels are allowed in this smaller
proposal; omit the design draft's 16 forbidden joint combinations and do not claim unseen
combination or cross-play generalization. Same exposure law/opportunities are controlled,
not the realized state/label distribution, which changes endogenously with learning.

Let e_i be the low actor's post-FiLM/post-GRU feature recomputed from the real boundary
observation, actually executed individual skill and stored entering hidden state/mask.
The stored entering hidden state is detached. Let x contain the current pre-action global
state, all observations, pre-decision hidden states and time, with these stored inputs
detached; Z is the actual team skill. Both training-only heads see the same x/Z/e_1..e_6.
No gradient enters the coordinator. Two possible auxiliary predictors are:

- **P head:** b(x,Z) + mean_i u(x,Z,e_i) + mean_(i<j) g(x,Z,e_i,e_j), with an initially
  proposed rank-32 bilinear pair term. The decomposition is a parameterization, not unique
  causal credit. All e-dependent terms backpropagate to the same actor trunk.
- **G head:** a competent ordinary two-layer MLP on exactly the same concatenated inputs,
  with width chosen prospectively for a similar trainable parameter count. It can represent
  interactions; it is deliberately not made additive or denied partner information just to
  favor P. Matching parameter count does not establish equal optimization difficulty.

Both heads are present, initialized and trained in every arm. All heads target the same
factual native discounted return Y_t = sum_(l=0..49) .99^l R_(t+l), at actual k10 boundaries
t<=450, with no bootstrap and no window crossing a reset. The first 10 steps use that
combination, later steps follow the actually executed behavior of the current rollout.
Record native R at collection explicitly, distinct from mixed intrinsic/learner rewards.
All targets and their normalization use training data only. MSE, initially lambda=.05,
one pass per rollout, minibatch 128 retaining the short final batch. Auxiliary follows the
normal PPO/discriminator update on the same rollout; exact order is shared across arms.
Prediction errors are diagnostics, never synthetic counterfactual truth or selection scores
for unexecuted training actions. The 50-step target is provisional: a 10-step realized
commitment target is a plausible smaller alternative, with a different estimand and count.

### Proposed readings and the difficult identifying boundary

1. Primary endpoint: deterministic own-team native J = 6*mean episode learner return/500,
   plus absolute coverage, quality, height penalty and every world's signed differences.
   Evaluate initialization and final45 on distinct predeclared 32-world panels; no best
   checkpoint, post-score extension or final-world tuning. Training curves are retained.
2. At final45, delete auxiliary heads from execution and evaluate all low-level banks with
   the same independent uniform team/individual skill rule every 10 steps, on 32 new worlds,
   zero parameter/normalizer updates. This directly tests bank service under a common
   high-level rule. A gain cannot require the arm's learned coordinator at deployment, but
   can still be generic navigation/representation improvement. A loss under uniform may
   reflect a changed visitation distribution, not absence of useful learned combinations.
   Cross-arm controller swaps are not assumed valid: label identities/semantics can drift.
3. A possible finite real-combination diagnostic: for each final bank, 16 new worlds with
   a 200-step common-uniform prefix, freeze/copy full environment, recurrent and RNG state;
   execute four predeclared two-member/two-label rectangles (other labels fixed), all four
   cells each, 50 steps per branch. First10 changes only the selected combination. Report
   Y_ab−Y_a'b−Y_ab'+Y_a'b' and absolute native service in all cells. These are interventions
   on executed skills, not predictor extrapolations; there is no exhaustive label search.
   Choosing the following40 continuation matters: own mu matches the training label's
   on-policy meaning but retains the learned coordinator; common uniform removes it but
   changes the predictor's target distribution. Neither large |Delta| nor a better pair
   MSE establishes positive useful complementarity. A chosen-cell comparison must be
   predicted before its true branch outcomes, never selected by test maxima. An additional
   additive readout would incur more fitting and is not silently included here.
