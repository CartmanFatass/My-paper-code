## 5. Strongest competent baseline required by this census

The baseline slot is `TUNED-GENERIC-RAW`: a treatment-blind generic recurrent learner that receives
the same B1 raw observation sequence and legal action support, is explicitly tuned through a
reported development comparison rather than fixed as one unexplored configuration, and is
evaluated in a technically valid result under the same population and evaluation exposure as the
upper.

At minimum, retained evidence must state the candidate configurations or tuning choices, selection
rule, selected configuration, seeds, episodes, transitions, optimizer updates, model-selection
exposure, evaluation population, and native return. A single fixed learner, an incomplete result,
a post-hoc best seed, or a mechanically proposed repair of an invalid artifact does not fill the
slot.

This object does not create that learner evidence. If the slot is absent, it records
`tuned_generic_baseline_status = ABSENT` and leaves the gap null.
