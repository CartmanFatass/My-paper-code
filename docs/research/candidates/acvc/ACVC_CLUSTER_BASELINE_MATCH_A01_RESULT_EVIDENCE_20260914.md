## Direct HMASD, D2 and the smallest correction

The `hmasd`/`hmasd_original` switch leaves the direct high/low/discriminator method. `mappo` fixes n_Z=n_z=1 and disables high-level/discriminator training and rewards; its constant skill has no variable privileged payload, although unused coordinator construction/work remains. D2 is a separate branch selected by `policy_interruption_mode=d2`, with decision masks, segment records and a different coordinator update function. Setting an infinite interruption cost or fixed D2 clock does not identify it with direct HMASD. Neither kind of fixed skill boundary means that primitive motion, recurrent observation or optimizer updates are held for k ticks.

A plain adapter cannot simultaneously preserve (i) direct HMASD's periodic centralized execution, (ii) ACVC's current private-actor information boundary and (iii) the proposed assertion of equal execution rights. Removing only global state is insufficient because the joint-observation Transformer still communicates other agents' information. Setting every skill to one constant removes the hierarchical method. Moving all execution to common global inputs changes ACVC's intended use; a new decentralized high-level coordinator would be a new mechanism, not a repair of this comparison.

**Smallest recommended scientific correction:** retain the private-information cluster use case, defer direct HMASD for this comparison, and propose one fresh **ACVC C/F package versus flat recurrent MAPPO-style** B block with explicit bounded-action adaptation. This preserves the retained asset, task and information question, but **changes the originally proposed HMASD-versus-MAPPO contrast**. It therefore goes back to Portfolio as a concrete new investment choice, with the unchanged fresh-reference B and consolidation still real alternatives. [Prospective proposal](ACVC_CLUSTER_MAPPO_COMPARISON_B01_PROSPECTIVE_20260914.md) is not a frozen card, implementation authorization or grant. Direct HMASD remains a legitimate future periodically centralized task comparator if that information regime is deliberately selected elsewhere; this A does not declare HMASD invalid or close its family.
