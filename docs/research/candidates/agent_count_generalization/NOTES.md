### Proposed bounded design, pending the focused advice below

N deliberately avoids building heterogeneous-N replay. N=4/8 are prespecified count
extrapolations, not churn, cross-play, heterogeneous actuators or variable duration.

500-step episodes, fixed k=10. The N=4 capacity constraint is a property of that test;

Candidate H6: full HMASD configuration with six team and six individual skills,
FiLM/GRU, coordinator, discriminators and low-level learning; ordinary fixed clock.
Comparator SET: ordinary parameter-shared recurrent PPO actor and centralized critic,
one constant skill, no skill-discovery reward or coordinator/discriminator learning.
SET gets the same legal global state and joint observations every ten steps as H6's
coordinator, held between refreshes, plus its current local observation every step.
Its central input is an ordinary shared entity/set encoding, not the old N=6 flattened
CF input; current native-scale correctness repairs apply to both arms.

The minimal proposed transfer implementation lives in this direction's experimental
package. The environment itself is unchanged. A wrapper makes a fixed-capacity state
layout (up to eight real UAV positions, explicit actual-roster validity mask, all user
positions and time), physically scales coordinates, and does not fabricate local
visibility masks. A shared-weight masked set encoder for UAV positions (with count)
removes untrained per-slot state weights. It supplies state features to both arms'
central critics and H6's coordinator/team discriminator. Users retain their full
fixed 50-position information; no environment-outcome field is added to policy inputs.
SET's central snapshot additionally uses a nonlinear shared encoding plus mean/max
aggregation of the actual joint observation rows, with count and ego observation;
its parameters do not depend on N. An attention form is an alternative only if advice
identifies a material competence defect in this ordinary set construction.

H6 retains its ordinary ordered autoregressive skill assignment; its agent value head
becomes shared across positions so N=8 does not add untrained heads. Its low-level actor
retains local observation and assigned skill rather than receiving SET's continuous
central features. Thus lawful source information/cadence match, but representation,
bandwidth, hierarchy, intrinsic reward, parameter count and optimization differ. This
is a package comparison, not identification of hierarchy or a novel N-invariant theorem.

record exact capacity and every optimizer's work rather than artificially equalize them.
The actual learned state/set encoders have separate weights per role and per fitted arm;
"common" means the same architecture/feature contract, not parameters shared across fits.

The fixed-N runtime and buffer can be reused for training; test runtimes allocate their
own real N rows and reset all per-episode recurrent/skill state. There are no absent
policy/action rows and hence no loss on padded agents. Only the explicit state storage
