## Frozen host and controls

The treatment is
`EGRCR-T3-DIRECTED-CYCLE-SUPPORT-ORACLE-HEADROOM-v1`. Agents are fixed to
`{0,1,2}`. For each joiner one directed predecessor waiter is favorable and
the other waiter unfavorable, while each identity is favorable once and
unfavorable once across joiners. Generic cue/sign, lag, propensity, readiness,
ages, budget, clock, and action support are fixed. Compatibility is derived
from deployed output/input port occupancy, not from a reward label.

Both arms use the same generic intercept plus six ordered-pair one-hot head and
the same action-time IDs. `GAE-DP` uses an exact pair-aware finite-state value,
no critic learning, and lambda selected prospectively on disjoint calibration
roots. `PAIR-Q-ORACLE` replaces only the eligible source advantage with the
pre-enumerated expected pair action value. The frozen selection chose
`lambda=0.5`. The evaluator allocates exactly one token inside each of 96
favorable/unfavorable dyads per root using an interior logistic choice and
common uniforms. A source-localized panel severs the waiter transition while
retaining pair context, expected Q, sampled total-service tapes, head, data,
optimizer, and evaluator.

## Observed scientific surface

### Identity support

All support gates passed.

- For every joiner, favorable-minus-unfavorable natural effect `C = 0.8` and
  ordered interaction contrast `K = 0.8`, above the frozen `0.50` minima.
- Favorable pairs had `Delta = kappa = 0.4`; unfavorable pairs had
  `Delta = kappa = -0.4`.
- All waiter and joiner marginal sums were exactly zero.
- Joiner-only and waiter-only effects were exactly zero and invariant to
  identity.
- Every true-waiter first stage was present.
- When the immediate waiter transition was replaced by a no-op, every `C` and
  `K` collapsed exactly to zero.
- Each root contained 16 observations in every pair/action cell, exactly 192
  source records, 96 actions of each value, and complete three-agent traces.

These facts establish a balanced, consequence-distinct, path-dependent
ordered identity object. They do not establish algorithmic or oracle utility.

### Representation and competent GAE

Representation and the noiseless competence gate passed.

- The shared head ranked every favorable pair over its matched unfavorable
  pair; a pair-masked control remained exactly at chance 0.5.
- All six GAE gradient signs matched the prospective oracle.
- GAE/oracle noiseless gradient cosine was `1.0000000000000002`.
- Their maximum favorable allocation-probability difference was exactly zero.
- Maximum Bellman residual was `5.551115123125783e-17`.
- Both one-step parameter displacements were
  `0.28378645758317145`; mean Bernoulli KL was approximately
  `0.00167687`, beneath the frozen functional-class bound.

The sampled native GAE was not incompetent: its favorable-token fraction mean
was `0.5633680555555555`, with root-level 95% interval
`[0.5220399615353473, 0.6046961495757637]`, strictly above chance.

## Competing readings for independent review

1. **Both prerequisites pass.** This would require treating the small positive
   allocation-probability contrast as headroom despite exact actual allocation
   and utility equality and a prespecified `0.10` decision threshold.
2. **Support passes, competent GAE exhausts decision-relevant headroom.** The
   host contains a real balanced path-specific pair consequence, but oracle and
   GAE are essentially the same update direction and make the same scarce
   choices and utility at this budget.
3. **Evaluator sampling hides a real oracle advantage.** Common-uniform token
   discretization can suppress a very small probability difference. Against
   this reading, the expected difference itself is only about `2.22e-5`, far
   below the registered material threshold; enlarging tokens after observing
   the result is forbidden.
4. **The exact-value baseline is unrealistically strong.** A practical learned
   critic might leave more room. Against this reading, the frozen question asks
   for headroom over a competent same-information GAE; manufacturing a gap from
   critic underfit would not isolate ordered association credit and would
   import a learned-estimator question.
5. **The host is an identity lookup by construction.** The directed cycle is a
   six-cell persistent-identity object with no transfer. This limits any
   positive claim but does not erase its exact balanced support and path-sever
   facts.
6. **Generic denoising remains sufficient.** If a later design produces a gap,
   the source-localized panel must not reproduce it. This observation supplies
   no positive native excess over that control.

## Decision branches and unresolved alternatives

- If actual allocation and bounded utility are indispensable, the headroom
  prerequisite is absent and no relay comparison is authorized in this host.
- If a probability-only effect below the frozen material threshold is accepted,
  the cycle's estimand and claim ceiling have changed after observation.
- A different future host is scientifically distinct only if it prospectively
  demonstrates native source-path oracle allocation/utility headroom over a
  competent same-information GAE and a source-localized control before any
  relay arm. Adding seeds, tokens, an approximate critic, or a relay to repair
  this result is not such evidence.
- Remaining explanations include a different stochastic transition geometry,
  a materially larger but prospectively justified pair effect under the same
  competent baseline, and limitations of this single constructed one-update
  host. None is observed here.

Shared finite-host risks include one-step optimization, constructed bounded
service, finite fixed-token evaluation, and ordinary-GAE/value-function
semantics. EGRCR's association question remains distinct from ONLGR's
physical-time policy-link question, but both can fail through saturated
finite evaluators or generic probability movement without downstream utility.

## Claim ceiling

At most, the evidence can support a statement about one prospectively frozen,
fixed-population, exactly three-agent, finite-horizon, bounded, single-update
microhost: balanced ordered waiter identity support existed, but the
same-information prospective pair-Q oracle produced no actual fixed-token
allocation or bounded-utility gain over competent pair-aware GAE. It does not
establish relay value or impossibility, learned-estimator behavior, multiple
updates, variable populations, fixed-`k` superiority, transfer, UAV or
continuous-control relevance, safety, deployment, or general credit.
