## Frozen cycle question

Does a correctly associated ordered waiter effect, attached only to the later
joiner's stored request record, provide answer-changing bounded utility and
scarce renewal-allocation improvement over both ordinary GAE and an
equal-marginal wrong-waiter binding cut? Or are generic dense/lower-variance
shaping, request-rate/update geometry, the prior cut's generic-cue
anti-supervision, missing downstream identity-specific waiter exposure, or a
host with no remaining allocation headroom sufficient to explain every
observed effect?

The first decision is whether the existing traceable B1 observation already
answers this bounded question. A new executable observation is justified only
if it can change the Portfolio recommendation and tests a scientific contrast
not already exposed by B1.

## Competing explanations and distinct predictions

1. **Association-specific incremental credit.** With generic cue/sign,
   marginal label distribution, work, update norm, request count, and
   information held fixed, correct waiter identity changes later-record update
   direction, scarce allocation, and bounded utility relative to both GAE and
   a wrong-identity cut. Prediction: the intact arm exceeds both controls on
   allocation and utility, and the identity-specific advantage disappears
   when only the waiter identity/consequence link is broken.
2. **Dense or lower-variance duplicate shaping.** The relay encodes the same
   favorable-context information already present in ordinary return.
   Prediction: probabilities or score-credit covariance can move, but intact
   does not improve scarce allocation or bounded utility over GAE; an
   information-equivalent generic target performs similarly.
3. **Wrong-cut anti-supervision.** The registered opposite-type cut changes
   generic cue-to-outcome sign as well as waiter identity. Prediction: intact
   beats that cut even if waiter identity is irrelevant; a cut that preserves
   generic cue/sign and changes only the waiter key removes or sharply reduces
   the contrast.
4. **Update/request-rate geometry.** Arm-local normalization, fixed displacement,
   discretization, or common-uniform request changes create proximal
   selectivity without changing the binding allocation boundary. Prediction:
   probability/selectivity separates while fixed-token allocation and utility
   remain equal; matched common normalization and equal-count evaluation do not
   reveal an intact-over-GAE task effect.
5. **Missing downstream identity exposure.** The host has only one effective
   waiter consequence per generic cue stratum, or ordinary return immediately
   exposes the same consequence. Prediction: no legal cue-preserving
   wrong-waiter derangement with different bounded consequences exists, or an
   oracle association label has no utility headroom over GAE.
6. **Non-informative host or allocation ceiling.** GAE and intact rank the same
   scarce choice at every root because the host's decision surface is already
   saturated. Prediction: exact allocation/utility equality persists even when
   proximal probabilities differ; a scientifically useful follow-up first
   needs prospective headroom and multiple same-generic-signal waiter targets,
   rather than more seeds or a repeat.

## Frozen outcome-to-claim and Portfolio branches

- If existing B1 evidence directly exposes the ordered edge, bounded waiter
  consequence, later-record expression, and actual scarce allocation/utility,
  and no untested contrast could change investment, complete this cycle from
  static evidence. Preserve the bounded negative claim and recommend
  `PARK` or `CLOSE` according to remaining option value; do not create CM work.
- If a smallest new test exists that preserves generic cue/sign and marginal
  information while changing only waiter identity, and it has prospective
  oracle utility/allocation headroom over GAE, freeze one executable
  discriminator and use exactly one EM-to-CM-to-EM observation round.
- A positive executable result requires intact to improve both scarce
  allocation and bounded utility over GAE and the cue-preserving wrong-identity
  cut, with equal information, counts, work, update scale, and consequence
  exposure. It supports only a bounded constructed-host continuation.
- If correct binding beats only a corrupted cut, changes only probabilities,
  ties GAE on allocation/utility, lacks identity-specific consequence, or the
  purported neutral cut cannot be constructed, the association mechanism is
  not decision-changing. Recommend `PARK`, `CLOSE`, or at most `NARROW` to an
  explicit prerequisite host-discovery question.
- If the useful object is a different mechanism rather than ordered relay
  credit, identify it as a possible `SPINOFF` question without importing its
  claim into EGRCR.

No branch supports end-to-end variable-`k`, superiority to fixed `k`,
multi-update stability, a learned counterfactual estimator or gate, UAV value,
continuous control, safety, or general source-to-target credit.

## Early stop and scope-invalidated conditions

Stop without CM when the retained evidence already distinguishes the material
branches, no legal identity-only control plus oracle headroom exists, or the
only proposal is a repeat, extra seeds, threshold repair, broader learner, or
more favorable host without a prospective falsifier. Stop after the single
round if its contract completes without decision information or any resource
bound is exhausted.

The scope is invalidated if a proposed test changes the credit destination,
adds reverse/debit credit, changes scientific/numerical/RNG/checkpoint or bit
identity semantics silently, lacks same-information consequences, requires
shared core, adds multi-update/learned-estimator/UAV claims, exceeds the frozen
round/resource bound, or new evidence changes the scientific question enough
to require a distinct material cycle. A transport/provider fact never
invalidates scientific scope; it changes only the corresponding Pro state and
keeps this same WORK waiting under the protocol.
