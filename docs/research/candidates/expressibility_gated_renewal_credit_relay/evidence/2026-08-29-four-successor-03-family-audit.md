## The comparator-closure test

For action record `r`, let `H_r` be the complete permitted action-time history,
`A_r` the sampled action, and

`S_r = grad_theta log pi_theta(A_r | H_r)`

its policy score. Let `C_r` be the scalar actually fed to the association arm
after its admitted event binding, causal decomposition, centering, scaling,
clipping, panel normalization, or routing. The full finite tape and every
downstream object used to form `C_r` are available during learning to both
arms under the frozen equal-information and useful-work contract.

The competent generic Rao-Blackwellized target is

`Cbar_r = E[C_r | H_r, A_r, permitted conditioning objects]`.

Because the score is measurable at the action record, the tower property gives

`E[sum_r S_r C_r] = E[sum_r S_r Cbar_r]`.

This equality holds record by record before parameter sharing, common
preconditioning, or summation over later actions. It therefore survives
overlapping paths, serial hops, censoring, substitution, and shared policy
parameters.

Two admissible cases must be distinguished.

1. If `C_r` is valid credit for the same external bounded utility `U`, its
   exact action-dependent population contrast is conditional action value up
   to score-null baselines. Competent exact conditional-Q has the same
   population update.
2. If `C_r` deliberately changes the source target to exploit finite-step
   curvature, normalization, or a surrogate game, it can be noncollinear with
   `Q(U)`. But the frozen generic arm receives the same edge locator,
   decomposition, transformation, and work and may Rao-Blackwellize that
   transformed target. Its update again matches `C_r` exactly. Prohibiting
   this would create a representation, target-access, or optimizer restriction
   that the frozen comparison expressly disallows.

This does not assert that every biased surrogate equals external-return Q. It
asserts the narrower decision fact required here: no exact finite candidate
earns an irreducible association advantage over the competent same-object and
same-work generic comparator. A finite-step anti-coordination surrogate may be
scientifically interesting, but in this cycle it is either generic optimizer
geometry or task-specific shaping, not evidence for association-aware relay.

With the same preconditioner `P`, matching updates imply

`P g_assoc = P g_generic`.

The normalized orthogonal residual is therefore exactly zero, a common trust
map receives identical inputs, and a common evaluator makes identical scarce
decisions. This fails the prospective `0.10` noncollinearity gate before the
allocation, utility, and `0.05` localization gates can pass.

## Common balanced panel

The smallest panel has persistent agents `{0,1,2}` and all six ordered
source-waiter assignments equally represented. The third agent supplies the
competing, downstream, or substitute role. Each identity is equally often
source, waiter, and third party. At the source boundary the two eligible
waiters share readiness, age, budget, action time, and generic features. A
public edge key records the current source-waiter relation and is available to
both candidate and generic arms.

The source action is binary with behavior probability `1/2`; a content sign
`c in {-1,+1}` is balanced; external service utility lies in `[0,1]`; and
identity never directly pays reward. Using the minimal source feature vector
`phi(c)=(1,c)`, a value contrast `Delta(c)=kappa*c` yields the exact logit
gradient `(0,kappa/4)`. Adding balanced identity one-hots does not alter the
candidate-versus-generic equality.

## Family 1: overlapping many-to-one contention

### Canonical strongest construction

A background record for the third agent is already live. Activating the tested
source record writes a pending job into its true waiter's physical state; one
later queue slot then admits either that waiter or the background competitor;
the admitted record attempts service on the following transition. For
`c=+1`, the true waiter's job matches demand and the competitor does not. For
`c=-1`, the compatibility is reversed.

| Content | `U(a=0)` | `U(a=1)` | ordered path contrast |
| --- | ---: | ---: | ---: |
| `c=+1` | 0 | 1 | +1 |
| `c=-1` | 1 | 0 | -1 |

The physical association has the full favorable/unfavorable span. A pathwise
target `K=c` and exact conditional-Q contrast `Delta(c)=c` nevertheless give
the same population gradient `(0,1/4)`. Exact full-return GAE has the same
expectation.

### Disposition

Reject at comparator equality and noncollinearity. The orthogonal fraction,
difference in scarce decisions, association-minus-generic allocation gain,
and normalized-utility gain are all exactly zero. On the matched severed
panel, candidate and generic remain equal, so native-minus-severed excess is
also zero. The failure is not weak contention: the tested action flips
external utility by a full unit, while exact conditional value already
contains displacement of the competing live record.

## Family 2: serial two-hop complementarity

### Canonical strongest construction

The source action first writes a mark into the true waiter. The waiter's later
action opens or blocks a route and the third agent then either completes or
cannot complete the second hop. No reward is paid merely for the mark; utility
requires the ordered source-waiter-downstream path.

| Content | `U(a=0)` | `U(a=1)` | two-hop path contrast |
| --- | ---: | ---: | ---: |
| `c=+1` | 0 | 1 | +1 |
| `c=-1` | 1 | 0 | -1 |

The association path label and external conditional-Q contrast are again both
`c`, so candidate, generic Q, and population GAE all give `(0,1/4)`. Any
shared contribution from later action records is added identically to both
arms and cannot break the equality.

### Disposition

Reject at comparator equality and noncollinearity. Multiplicative path
completion changes the Q table but does not create information outside Q:
`Q(H,a)` is the conditional expectation of the ordered-hop product. A
different first-hop/second-hop reweighting is a transformed target that the
same-object generic arm may condition and Rao-Blackwellize. All decision,
allocation, utility, and localization advantages over that arm are zero.

This is the strongest mechanistic countercase because the externally useful
event exists only after two ordered physical transitions. Its failure rules
out path length and complementarity alone as reentry.

## Family 3: censored substitution chain

### Canonical strongest construction

After activation the original waiter either persists, the record expires, or
the third agent substitutes as holder, with the three lifetime modes equally
weighted and unknown at action time. The full event history becomes public as
it occurs. Physical substitution preserves the source-created job; expiration
removes it.

| Content | Mode | `U(a=0)` | `U(a=1)` | pathwise effect |
| --- | --- | ---: | ---: | ---: |
| `c=+1` | persist | 0 | 1 | +1 |
| `c=+1` | replace | 0 | 1 | +1 |
| `c=+1` | expire | 0 | 0 | 0 |
| `c=-1` | persist | 1 | 0 | -1 |
| `c=-1` | replace | 1 | 0 | -1 |
| `c=-1` | expire | 1 | 1 | 0 |

The realized association target is
`K(c,M)=c*1{M is persist or replace}`. Its action-time conditional mean is
`(2/3)c`, exactly the conditional-Q contrast. Both updates are `(0,1/6)`.
The pathwise target retains lifetime-mode noise that the Rao-Blackwellized
target removes.

### Disposition

Reject at conditional-Q/Rao-Blackwell equality. The actual carrier changes
identity and expiry censors the effect, but neither creates an exact decision
advantage. Candidate and generic use the same trust step and token choice;
their allocation and utility differences are zero natively and after
severing, and native-minus-severed excess is zero.

This is the strongest statistical countercase. It shows that heterogeneous
realized carriers and correct censoring remain conditional-value objects when
the complete event history and relation key are shared.

## Strongest objection and its disposition

The strongest objection is that allowing the generic arm to Rao-Blackwellize
the candidate's transformed target makes the comparator broad enough to absorb
any exact association operator. That objection is factually correct and is the
point of this prospectively frozen cycle: it asks whether association contains
decision-relevant content irreducible to a competent generic estimator under
equal information and useful work. In a fully enumerated finite host there is
no approximation or compute bottleneck to prevent absorption.

Restricting the generic arm after seeing that equality would change the
estimand from association-specific information to representation or optimizer
efficiency. A future finite-data, finite-compute factorization comparison could
be valid if both critic classes, parameters, data, optimizer state, FLOPs, and
memory are frozen prospectively and the generic critic can represent the
factorized solution. That is a materially different discriminator and cannot
repair this cycle.
