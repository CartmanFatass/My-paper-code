## 1. Question and claim ceiling

On the exact outcome-informed `48` TRAIN / `16` EVAL CRTO B01 population, what native G16 gap
remains between the stated row-wise legal-action oracle and the strongest TRAIN-tuned member of a
frozen generic no-learner action-rule family?

For EVAL row `i`, define

```text
U_i = max over legal printed actions a of G16(a; i)
B_i = G16(a_GENERIC(i); i)
H_i = U_i - B_i.
```

`U_i` is a privileged evaluation reference and never an available action rule. `a_GENERIC` is
chosen without EVAL G16 values. The result reports `H_i` in native G16 units. It applies no
relative percentage and no minimum effect of interest.

**Claim ceiling.** A direct measurement fact about the exact selected B01 rows, the current
four-agent K8 service-relay host semantics, the frozen generic family below, and one deterministic
TRAIN/EVAL split. It is not a result for a trained generic learner, residual information,
representation value, natural K8 prevalence, policy return, variable populations, transfer,
safety, deployment, or lifecycle. A nonzero `H` says only that this declared no-learner family
leaves oracle gap on these rows; it cannot turn B01 comparator weakness into a mechanism negative.

## 4. Stated upper reference and tuned generic baseline

### Upper reference: `LEGAL-G16-ORACLE`

For every row, replay every legal printed action through the unchanged common-future evaluator and
take the maximum finite G16 value. Ties use the existing printed-action order. This is exactly the
reference underlying native regret in B01 and is privileged evaluation information.

### Generic no-learner family

Every candidate is given the same pre-decision information interface as RAW and receives no future
G16 value. A candidate may ignore fields; ignoring available information does not grant it
privileged information.

1. `LOGGED-SCRIPT`: the unchanged deterministic script action at that boundary, already described
   by the common-history freeze as a simple same-information behavioral diagnostic.
2. `MASK-ORDER(pi)`: for each of the `8! = 40,320` permutations `pi` of the existing printed action
   order, choose the first currently legal action in `pi`. This family uses only the legal mask and
   adds no CRTO label, event, onset, future, entity identity, residual, or oracle input.

Score every candidate on TRAIN using mean native regret. TRAIN contains exactly `24` KEEP and `24`
REPLAN rows, so its unweighted mean equals the equal-side mean. Choose the unique candidate with
minimum TRAIN mean regret; ties use lexicographic candidate ID. Freeze that one candidate before
any EVAL action or G16 value is inspected, then apply it unchanged to all `16` EVAL rows.

This is finite comparator-arm tuning, not model fitting: there is no predictor, neural gate,
parameter initialization, gradient, optimizer, checkpoint, adaptive search, or EVAL-driven arm
choice. It is the strongest candidate only within this declared no-learner generic family, not a
claim about every generic learner.
