**Question (Pro's first choice, adopted).** Can the existing ordinary deployment capability (the frozen planner operating on the lawful team map) be turned into a decentralised multi-UAV policy that needs no online planner, keeps full closed-loop service and lowers online compute — so that a competent initialisation exists for a bounded MARL continuation? Stage 1 (this cell, b01) is a supervised capability study; it claims no MARL gain. The continuation (team-return fine-tuning from S) is a separate later declaration, not approved here.
**Information contract (fixed; same for teacher and student).** Team map = the union of the six UAVs' lawful sightings pooled instantly (B0's rule), users placed at their latest sighted xy, unseen users absent; known UAV positions (all six, true xyz — the team's own state); ego index. Neither teacher nor student ever reads hidden user coordinates (truth guard as in b04; F's global map is a reading-side reference only). Students output one 3-D target per UAV from (team map, UAV positions, ego); no communication beyond the shared map is modelled; the pure-local no-sharing variant is out of scope.
**Teacher T_10 (interface-matched ordinary reference; zero fit).** B0's procedure expressed at the macro interface: at every macro decision (every 10 host steps, 50 per episode) each UAV's target is the current B0 plan site assigned to it (B0's trigger, cap, planner and `assign_targets` unchanged; trigger checks happen at macro decisions; before the first plan the target is the spawn position). T_10's closed-loop all-500 C̄_bh on the 32 dev worlds is its competence reading; it must be reported beside B0's .7375 and may not be replaced by it. The student is evaluated without any teacher call, menu or search result at decision time.
**Student.** A shared-weight per-UAV MLP over the fixed feature encoding (50 × [known flag, x/5000, y/5000] + 6 × UAV xyz normalised + ego one-hot; 174 floats) → 3-D target (tanh-scaled to the box as the macro adapter decodes). Initialisation S0 = the untrained network (seed 932201); one architecture, one seed, fixed before any run.
**Exposure (fixed; two accounted segments).** Segment A: teacher closed-loop trajectories on 64 fixed training worlds 3000–3063 (disjoint from dev/hold-out/probe sets); labels = T_10's targets at each macro decision (64 × 50 × 6 samples); supervised regression (MSE on the tanh pre-image or the box coordinates — fixed in the L0 note before the run), fixed epochs and batch. S_bc = the result. Segment B (one DAgger round, declared once): roll in S_bc on the same 64 training worlds, relabel every visited macro state with T_10's decision on the student's own lawful map at that state (same information; the label planner runs on the visited state), continue the supervised fit on A ∪ B from S_bc with the same optimiser settings; S = the result. No extra rounds, seeds, capacity changes or epoch extensions after any score; dev worlds never enter the label set.
**Evaluation (common, fixed).** S, S_bc, S0 and T_10 run 500 host steps on the 32 dev worlds 1000–1031 under the same information contract and executor; primary reading all-500 C̄_bh per world, paired; also final-100, far-cluster share, per-world negatives, online CPU per episode (student forward passes vs T_10's planner calls). F (gate) and the random-target floor .365 are scale references only.
**Purchase line and bands (Pro's practical tolerances, adopted; not non-inferiority proofs).** "A useful planner-reuse instance" requires all of: S ≥ .71; S − T_10 ≥ −.03; S − S0 ≥ +.10; student online CPU ≤ ½ of T_10's; and T_10 itself competent on the panel (T_10 ≥ .70). **S ≥ .64 but not all conditions** → partial capability / cost trade-off recorded; no RL continuation bought. **S < .64, T_10 not competent, or cost over cap** → this distillation stops; positive worlds kept, no rescue; a technical failure is listed separately from "not learnable". If S ≈ T_10 but S0 already had the same capability, no learning gain is claimed. Only after S meets the line is a bounded team-return continuation from S declared separately (comparators: frozen S, same-budget supervised continuation, the same-information ordinary planner).
**Price (estimates and caps).** Teacher trajectories + roll-in relabelling ≈ .5–1.5 CPU-h; two supervised segments ≈ .5–1.0; regression and full evaluation ≈ .2–.5; **CPU cap 3 CPU-h**, engineering cap 6 h (probe and data handling included).
