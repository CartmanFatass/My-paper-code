# EOCIV-A8 exact dyadic ledger identifiability — code/science index

## Claim boundary

`EOCIV-A8-EXACT-DYADIC-LEDGER-IDENTIFIABILITY-PROOF` is a source-only
constructibility audit. A positive terminal branch can establish only that the
accepted source exposes the exact ledger and causal-panel interfaces frozen by
the public A8 contract. It establishes no algorithm effect, value, learning,
generalization, deployment claim, component attribution, B8 authorization, or
portfolio disposition.

## Source entry and state ownership

- `scripts/run_eociv_a8_exact_dyadic_ledger_identifiability.py` is the one-shot
  command boundary. It binds the actual working directory, accepted Git commit,
  runner, audit core, and two registered EOCIV host-source files before any
  certificate inspection. The output uses exclusive creation, so an existing
  result cannot be overwritten or treated as a retry.
- `experiments/candidates/eociv_lite/exact_dyadic_ledger_identifiability.py`
  owns the frozen roster, exact dyadic decoder, static source observer, eight
  certificates, six-branch precedence, result validator, and zero-activity
  ledger. It parses source text/AST only and never imports an EOCIV runtime
  module.
- The accepted host source must itself contain exactly one literal
  `A8_EXACT_DYADIC_INTERFACE_MANIFEST`. Absence, duplication, a nonliteral
  manifest, or a stale line-hash witness fails closed. The audit does not create
  or repair that scientific interface.

1. Reward-interface manifest: the primary key is exactly
   `(episode_key,timestep,reward_slot)` and dtype/value encoding remain payload.
2. Capture census: every reachable emitted scalar has one unique capture site
   after the final claim-bearing wrapper and before cast or reduction, with raw
   bits available and native control flow unmodified.
3. Exact decoder: binary16, bfloat16, binary32, binary64, and integer inputs map
   to integer `N` at scale `2^-1074`; nonfinite/unsupported inputs, float
   aggregation, and tolerance fail.
4. Fork/tape dependency: all eleven frozen state families are deeply
   non-aliased and every tape lookup uses the nine-field coordinate address;
   cursor/global/unkeyed randomness fails.
5. MASK identity: CORRECT/SWAPPED traces match in raw bits for the complete
   frozen channel census from fork through termination, including signed zero.
6. Phase/count oracle: the exact H8A/H8B roster, 18 training roots, 12 held-out
   roots, 4 shocks, derived tape seeds, and the prospective 144/192/336 episode
   counts are checked without executing an episode.
7. Endpoint/firewall: native/complementary ownership, history-local endpoints
   and accumulators, finite context, retained no-target episodes, and the
   held-out freeze firewall are exact literals.
8. Freshness: A8 identities and dependencies are checked for forbidden B6/B7
   source/artifact import or reconstruction.
