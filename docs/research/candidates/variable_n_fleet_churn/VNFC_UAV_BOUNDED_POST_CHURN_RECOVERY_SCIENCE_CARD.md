## Treatment: MAPR-4

`MAPR-4` is one feed-forward shared-parameter masked autoregressive recovery
policy across every agent and roster.

- The shared agent encoder is `38 -> 64 -> 64` with SiLU activations.
- The shared zone encoder is `15 -> 32 -> 32`; labeled outputs are concatenated.
- The global encoder is `4 -> 16 -> 16`.
- Roster context is the elementwise mean and maximum of agent encodings. Each
  mean coordinate uses an order-independent exact accumulator followed by one
  correctly rounded division by `N`; maximum uses exact binary64 comparison.
  Presentation order therefore cannot change a pooled bit pattern.
- The learned token table has exactly four 16-dimensional rows keyed by the
  failure-relative serialized roles
  `[EXEC_failed,RELAY_failed,EXEC_intact,RELAY_intact]`, not by absolute zone,
  physical identity or roster size. The same table is shared at every `N` and
  failed zone.
- Each legal candidate score uses candidate encoding, roster mean/max, both zone
  encodings, global encoding and token embedding in an
  `288 -> 128 -> 64 -> 1` SiLU MLP. Null uses the same state/token input with a
  single learned 64-dimensional null-candidate embedding shared across all four
  roles, rosters and failed zones.
- The base score of a still-available candidate does not depend on which earlier
  candidate was selected, except through removal from the legal set.

The joint-command log probability is the sum of the four masked categorical log
probabilities. Deterministic evaluation chooses the highest score at each token
with the common tie law. The actor work is at most four score/selection passes

## Training law and exact bounded work

MAPR and DIRECT train only at post-event `N=3,5`. Within each replicate and arm:

- 256 fixed updates, no early stop or checkpoint selection;
- 16 complete episodes per update, exactly four per
  `(N in {3,5}, failed zone in {1,2})` cell;
- six joint decisions per episode at `t=0,20,40,60,80,100`;
- terminal training objective
  `J_train = 0.5*R_fail_60 + 0.5*U_total`, with zero intermediate shaping;
- PPO with the exact recursion and losses below, four epochs and four equal
  minibatches per update; and
- one AdamW optimizer per arm over its actor and critic together, with learning
  rate `3e-4`, betas `(0.9,0.999)`, epsilon `1e-8`, and global gradient-norm cap
  `0.5` before each step.

Index the six decisions by `j=0,...,5`, set `V_old(s_6)=0`, use reward `r_j=0`
for `j<5` and `r_5=J_train`, and compute backward

```text
delta_j = r_j + V_old(s_{j+1}) - V_old(s_j)
A_5 = delta_5
A_j = delta_j + 0.95*A_{j+1}
Rlambda_j = A_j + V_old(s_j).
```

Across the 96 joint-decision records in the complete 16-episode arm batch, set
`Ahat=(A-mean(A))/sqrt(mean((A-mean(A))^2))`. If that denominator is exactly
zero, every `Ahat` is zero. No epsilon is added. The old joint log probabilities,
old values, `Ahat` and `Rlambda` are stopped.
