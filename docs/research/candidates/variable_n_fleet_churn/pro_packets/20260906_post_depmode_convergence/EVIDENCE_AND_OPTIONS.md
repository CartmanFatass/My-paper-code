## DM 看到的选项

1. **在最小有据单元上暂停 N7 直接回报探索族的投入**（DM 推荐，供质疑）。保留两次训练、部署方式评估和
   所有原始行；不改写任何已测正号；方向回到研究队列（生命周期、优先级由 Portfolio 掌握，本节点不改）。
   理由：两个独立种子都在四个指标上低于固定 BCRH，执行方式已被排除为解释，继续同配置只增加对一个
   0.01 量级分离的精度；没有 headroom 记录说明学习者还有多少可得空间；方向排序已最低。
2. **一个改变学习者信息或信用的具名新 B**（例如向 actor 暴露 BCRH 同信息的候选评分、或把恢复动作的
   信用从终点回报改为分区服务差），一对新种子，每臂沿用 B01 的完整调用上限。只有当它有比"再训一次"
   更强的决策价值时才值得；DM 目前不能给出一个已经写清的候选，请节点只在能具体命名时选择它。
3. **一个便宜的既有记录分析**，仅当它改变上面两项之间的决定且输入已存在（例如按世界配对的
   BCRH−学习者差与失败区、初始拓扑的关系）。DM 不推荐把它作为诊断门槛。
4. **明确的第三次 recast**。将触发再一次 `second-recast` 类标记；除非能写出具体的新事件→角色→信息→
   动作/信用→学习曝光→原生后果路径，否则不推荐。
