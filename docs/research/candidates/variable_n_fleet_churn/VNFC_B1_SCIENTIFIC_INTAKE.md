seeds and every registered conclusion panel, with no material or permutation
anomaly. The contrasts are scientifically interpretable without changing B1.

`B-REBIND` satisfies the registered project-facing variable-`N` value condition as
an **end-to-end package**: one shared parameterization improves both held-out-even-
size performance and post-churn robustness relative to `G-MEAN`, and it satisfies

for a structured variable-`N` allocation package.

The result does **not** support the named mass-calibration or learned-persistence
mechanisms. `A-MASS` is practically equivalent to `G-MEAN`. The large increment is
introduced by `A-JOINT`, the exact coverage-aware joint decoder. `B-REBIND` does not
separate positively from `A-JOINT`. Under the accepted Pro correction,
`keep(a)=1-switch(a)`, so at a post-reset event

`score_B(a) = bid(a) + coverage(a) + 0.04*keep(a)`  
`             = bid(a) + reward(a) + 0.04`.

The constant cancels from sampling and argmax. Consequently the B-specific contrast
tests insertion of the known switch-cost part of the immediate reward into an
already coverage-aware decoder; it cannot identify learned persistent rebinding.

The scientific selection from B1 is therefore the **structured joint-allocation
family**, not `A-MASS` as a standalone mass mechanism and not `B-REBIND` as a learned
temporal-persistence mechanism. Exact reward-aware enumeration is a diagnostic
mechanism, not the UAV endpoint.

## Algebra-guided simple-null diagnostic

With B's learned logits set to zero, its score maximizes the exact current reward,
up to an assignment-independent constant. The registered `GREEDY-ORACLE` realizes
that same one-step decision rule along its own trajectory, modulo reward-equivalent
tie histories. It is therefore the relevant simple-null reference exposed by the
Pro correction, although its comparison was not a registered project support
condition.

Using the retained eight paired seed summaries as a post-result diagnostic:

- `B-REBIND - GREEDY-ORACLE` on `P` is `-0.2174020`, 95% CI
  `[-0.3437202,-0.0910837]`.
- `B-REBIND - GREEDY-ORACLE` on `H` is `-0.1920236`, 95% CI
  `[-0.3046002,-0.0794469]`.
- Mean absolute `Ogap` is `0.1805204` for B and `0.1714670` for A-JOINT.

This diagnostic is not used to redefine a prespecified support threshold. It does
show that learned bids have not demonstrated additional utility over the simple
reward-complete greedy rule on this nearly myopic host; the nonlearned reference is
materially better on both primary outcomes. The B-versus-G result is therefore
fully explained by known structured action scoring without invoking learned mass
calibration or learned persistence.

## Strongest alternative explanation

The strongest explanation is now supported rather than merely hypothetical: exact
enumeration injects the known coverage and waste objective, and B additionally
injects the known switch penalty, so the action mechanism performs most of the
coordination. The factorized G/A policies must discover a combinatorial feasible
assignment through independent categorical decisions, while A-JOINT/B receive an
explicit optimizer over all `4^N` assignments. A zero-bid reward-complete rule is
already sufficient to outperform the learned B package on the primary panels.

The host further favors this explanation: churn is exogenous, the only temporal
coupling is the next switch cost, every roster contains all specialties, demands
and task identities persist, a dummy action safely absorbs surplus, and held-out
sizes preserve familiar capability geometry. These facts do not invalidate the
package result, but they prevent interpreting it as learned population-
compositional coordination or general MARL competence.

### UAV path and next discriminator

Do not promote the current B package directly to a UAV simulator. Its useful
component is an exponential, reward-aware exact enumerator, the learned bids remain
below the simple greedy reference, static held-out sizes are interpolation, and the
host lacks travel, battery, topology, service duration, delayed information, and
relay feasibility.

The single highest-information successor is a **scalable reward-source and
allocation cut**, not more B1 seeds or tuning. Use a common reward-blind
residual-demand auction or primal-dual allocator and a strong generic sum-capable or
task-attention set policy. Cross:

- fixed total mass versus genuine expansion/contraction;
- equal task-wise mass with separable specialists versus coupled multi-capable
  rosters; and
- keep-optimal versus switch-required churn.

Include the existing reward-complete zero-bid/greedy rule only as a diagnostic
ceiling, not as the candidate. Compare analytic pressure against ordinary sum
aggregation under the same scalable allocator. If persistence remains in scope,
use an adaptive lease or release decision and require service noninferiority in
switch-required cells; a fixed keep coefficient is only a reward-coded control.
Include at least one roster size above the training maximum.

Decisive branches are:

1. If the scalable generic allocator matches the exact/greedy ceiling, retain the
   structured allocator and delete learned mass and persistence claims.
2. If learned bids add no value beyond a nonlearned residual auction, treat the
   useful object as operations-research control rather than a learned MARL
   mechanism.
3. If analytic pressure beats the sum-capable comparator only when real mass
   changes and survives equal-mass capability-geometry controls, retain the mass
   hypothesis.
4. If an adaptive lease reduces unnecessary switching while preserving service in
   switch-required cases, retain a persistence hypothesis; otherwise delete it.
5. If the advantage exists only under exhaustive reward scoring or disappears for
   an above-range `N`, do not advance this family to the kinematic UAV surface.
6. Only a scalable survivor should move to 2-D fleet service with reachable
   capacity, travel, battery, relay constraints, recovery time, energy/safety, and
   event-decision latency.
