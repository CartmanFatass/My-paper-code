## 四、为什么不选择 B：承认增量，但不再购买这一次重复

一个新的 authentic H/D0 k5 pair 是合法的最小 B，能够回答“这个局部 package gain 是否在另一个初始化和外生随机性下再出现”，并记录新的 G shortfall。**单个训练对不足以估计种子总体，不等于单个训练对不足以支持有用的 B。** 我不因为 n=1、G 领先或不同梯度工作而拒绝这个备选；也不声称再测只有零信息。（[证据规范，§11.8.2–3][spec]。）

但本次要选择的是下一项值得实际执行的研究，不是罗列所有仍未知的量。上轮更换比较器的读数曾能改变“支持是否仅相对弱 C 成立”这一判断，B03 已经使答案成为“在这一个真实五轮 D0 上，不仅如此”。备选 B 不再推进这个证据边界，而是增加同一实现、同一预算下的变异覆盖。B03 新出现的较大 G shortfall 确实给重复提供了理由，但新的训练 pair 同时改变 learner 与评价 keys；它提供另一组表现，不能单独诊断这个短缺。诊断并非其义务，只是不能把这个未识别收益额外算作 B 的信息价值。

| 备选 B 可能产生的完整读数 | 它会新增的有限认识 | 对本次取舍的影响 |
| --- | --- | --- |
| H−D0 > .01 | 再有一个独立 pair 支持同一预算下的局部优势；同时保留其 G gaps | 会加强重复出现的事实，但我仍不据此选择继续发展这一已给规则的包 |

| H−D0 < −.01 | 取得相反的独立 pair，进一步显示表现变异 | 会增加对继续取样的反证；不会撤销 B03 的已观察局部优势 |

这不是把假设结果赋予经验极性；以上只用于判断新增信息可能改变什么。对当前扩展，我愿意保留的结论已经是有限的“可实现 package 差异”，没有选择把它发展为一个需要持续比较、调参或建立发生频率的候选程序。因此，这一次重复虽能改变证据记录的厚度，却不足以改变我对这轮扩展继续投入的选择。**我接受对重复性与表现变异尚不知道更多的代价，而不是要求先补够种子才准停止，或先获得理想结果才准继续。**

停止的理由也不是“给定规则没有学出来，所以所有混合控制器都不值得研究”。给定规则、非最优方法和有限性能比较都是合法对象；这里的判断只针对已测试 host、控制包与这一轮目标。§11.8 允许一个可信正结果支持有限后继，同时没有让正结果自动产生持续投入的义务。A 与 B 在这里是下一条观察价值的取舍，不是由一个未请求的 C 标准裁决 B 不合格。（[证据规范，§11.3、§11.8.1–3、§11.9][spec]。）

## 六、不用未成形的 C 为这轮延续另开出口

P44 §4 的既有源码读取区分了两条实际路径：corridor 的公开 region-change flag 作用于 physical lease-renewal mask；scenario1 的 UAV 接口接收连续 movement actions，改变位置、连接／干扰及 native reward，在已检查的接口上没有同一个 lease-mask 输入。因此不能直接把 H 的面板收益称为 UAV intervention 或 transfer。改变 HMASDAgent 的真实 internal skill boundary 进而改变 actor movement 是一个不同的可能问题，而不是 H 已迁移。（[P44，§4][p44]。）

这个接口区别不是停止 B 的理由，更不是“UAV 还没证明，所以 toy B 无效”。我不选择 C，是因为这里没有从已接受证据中确定一个比同构重复更值得购买的具体新 native-action 比较，并同时给出其所需 family 决定与相称预算。源码路径可能存在，不自动选择某个 treatment；长期 UAV 目标也不能替代实际问题、比较器和工作边界。本次不凭一般算法印象填入新触发条件、私有信息、Q-head、team-credit 或新的 host。

本节点复用的是 P44 已记录的接口和文献边界，没有另行展开四个条件源码面，也没有读取其引用的论文原文。P44 所记 ACAC/MARL-0449 的选定段落仅帮助区分 intra-option control、termination 与 decision-time information；它不为 FSD 增加训练种子、唯一诊断或新颖性结论。省去新的源码／文献普查，放弃的是声称“已审查并选定另一个 C 实现”的权利，不是声称不存在任何有价值的未来 C。（[P44，§4–5][p44]。）

故 C 的当前局限准确地说是：**本次没有形成可据当前证据明确优选并限定工作的具体新动作问题。** 这不是 GitHub 访问缺口、工程不可能性或 UAV 经验阴性；它不妨碍在已有完整证据支持的 A/B 选项中作出 A。以后一个真正有决策用途、动作与信息路径清楚的具体 B 可以另行提出，不需要先赢 G、补齐 tuned headroom、完成因果诊断或重复本面板。本次不把这样的未来提案安排成另一个 source census、准备任务或自动后继。
