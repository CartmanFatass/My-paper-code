## One proposed next question

**After one predeclared policy change by an action-owning teammate, does resetting the continuing
learner's complete Adam state improve or worsen sampled native team return over a fixed
adaptation budget, compared with ordinary Adam-state carry from the same learned policy?**

The proposed population is one fixed cooperative task with partial local information, fixed N,
and a teammate whose legal actions influence the learner's useful response and native reward.
Choose one task and one old/new teammate-policy pair for their stated coordination semantics
before new outcomes. This preparation selects neither a benchmark nor a policy pair. It does
not authorize a search for a host on which RESET or CARRY wins.

The proposed event-to-consequence path is:

1. At one fixed completed-episode boundary, the same teammate changes from a declared policy
   to another declared policy. Membership, entity identity, slot assignment, reward and physical
   transition law remain fixed. The teammate acts in both regimes; it is not a no-op label.
2. The continuing learner owns its actor, critic and optimizer. Both arms retain the same
   learned parameters and other learner state at the fork. CARRY preserves Adam's complete
   state; RESET clears only that state, including its step counter. Global learning schedule,
   update budget and information are matched.
3. Both arms have the same local observations, available action history and boundary notice.
   Neither receives the teammate's weights, hidden state, future actions or a correct-action
   label. Episode-level recurrent state follows the same reset convention in both arms.
4. Real on-policy interaction and learning continue under the changed teammate. Primary
   evidence is sampled native-return AUC across the same fixed post-change interaction window;
   terminal return and both full curves remain visible. Later arm trajectories may diverge.

No join, leave, rejoin, censoring, replacement or survivor transfer occurs in this proposed
population. The teammate is fixed within each regime, so this also excludes claims about
simultaneous partner co-adaptation. Episode boundaries avoid an undeclared lifetime or
semi-Markov discount change. Any future variable-roster question remains separately unresolved.

This is independently useful as a decision about a practical optimizer-state choice when the
learning target changes because of another agent. It cannot, by itself, establish a specifically
multi-agent optimizer mechanism, a novel algorithm, roster recovery, or stable superiority.
It deliberately exposes a change from the roster-age agenda for Convergence to accept or reject.
