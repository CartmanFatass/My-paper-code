## 3. Scientific choices now accepted, not yet implemented

The full response is the precise scientific source; the following identifies the choices that
changed from P11's unselected proposal.

| Quantity | Accepted direction choice |
| --- | --- |
| Population | One new toy two-station short-horizon handoff task; fixed receiver A and courier B on positions -2 through 2; no member or role changes. |
| Service law | Sixteen three-step rounds per episode, H=48 joint steps. Each round resets positions and one package, not entities. A moves/waits/receives; B moves/waits/delivers. Simultaneous actions, one action per step; successful joint receive/deliver at one endpoint earns one shared reward. Native episode return is 0–16 deliveries, without shaping. |
| Active teammate event | B follows the public midpoint light for two moves, then delivers; after the fixed boundary B follows the opposite endpoint rule. Both scripts act legally and are fixed within their regimes. Neither needs training or policy selection. |
| Information | The same local observations, visibility/missing markers, observable past actions and rewards, full permitted episode history and one change-notification bit for both arms. No script target/internal state, future teammate action or correct-action label. Actor and critic have the same information. |
| Learner | Recurrent PPO: 64-unit tanh encoder, 64-unit GRU, categorical actor and scalar critic; FP32; shared Adam with the fixed hyperparameters in the response's learner section. No imported oracle-sign learner or deprived-history baseline. |
| State fork | After P=4,096 complete prefix episodes and their final update, discard consumed on-policy data and copy identical actor/critic, global progress and all other learner state. CARRY retains full Adam state; RESET clears moments and per-parameter step counts only. Constant schedules and parameter groups remain identical. |
| Exposure and RNG | Master seed 1103, one independent prefix, two paired descendants with Q=1,024 adaptation episodes each. Pair exogenous light sequences and comparable action-sampling streams; allow actual trajectories to diverge. Evaluation uses separate RNG. GRU resets only at whole-episode boundaries. |
| Primary | Actual adaptation-service AUC = sum of the Q undiscounted training-episode returns divided by Q; Delta = RESET minus CARRY. All 48-step episodes have equal weight. Preserve every raw return and both complete curves. |
| Secondary evaluation | E=64 sampled episodes at the prefix endpoint; one shared post-switch q=0 evaluation; 64 per arm at q=16,32,64,128,256,512,768,1024. Frozen stochastic policies; no greedy substitution, extra updates or selection of the best checkpoint. |
| Future stop/device | A single logical prefix-plus-pair invocation, at most 1,800 seconds including initialization, training, evaluation and output; alternate matched adaptation batches. One process, one CPU compute thread, FP32, configured remote-first route. No automatic extra arm, seed, retry or budget. |

Event-to-consequence reading: an action-owning courier changes where it actually brings a package;
the receiver must use legal observations/history to choose an endpoint early enough to arrive and
receive within the three-action deadline. A late reaction cannot recover two moves plus receipt
for that round. Subsequent observed actions and actual service feedback can change later competent
actions and actor/critic learning signals. Adam state may then alter parameter updates and native
service within the fixed adaptation budget. This is a proposed causal path, not an observed effect.

The per-round resets are task resets, not join/leave/rejoin, replacement, survivor-state transfer,
entity/slot reassignment or censoring. Both agents persist, complete episodes have fixed length,
and the teammate does not co-adapt within a regime. No variable-lifetime or semi-Markov claim is
made; the selected learner uses gamma=1, GAE lambda=0.95 and terminal bootstrap zero.
