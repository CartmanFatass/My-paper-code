## Controlling order

Read a later complete panel in this order:

1. exact task/revision/one-budget binding and complete atomic evidence;
2. reward independence, no leakage, implicit permutation-safe execution and
   physical/task support;
3. literal `PHY-TRUST` subset of `EDGE-FLEX` plus all information, parameter,
   communication, useful-work and optimizer matching;
4. two-sided return answerability and exact legal-action support;
5. `EDGE_TRAIN_COMPETENT` at both seen sizes;
6. held-out direct return, cold-start interaction and worst-zone relations;
7. semantic-column-cut action TV, return loss and advantage attenuation; and
8. the first matching branch below.

No later mechanism fact can rescue a failed direct relation, answerability gate
or competent-comparator gate.

## First-match branches

### 1. Invalid, incomplete or contaminated

Any missing required seed/panel, nonfinite output, reward/held-out leakage,
unmatched input/action/support/work/optimizer, failed nesting, row-order defect,
new-role or roster-specific adaptation, or treatment-specific physical support
returns no scientific relation. Unchanged-science repair belongs to a future
CM only if empirical work is separately authorized.

### 2. Non-answerable or incompetent comparator

If two-sided return headroom or exact legal-action support fails at either
held-out size, or `EDGE_TRAIN_COMPETENT` fails at either training size, return
`NONIDENTIFIED`. Do not call the arms equivalent or delete/retain the fixed
prior from this panel. Legal-action TV itself remains a registered cut
quantity, not a separate answerability quantity.

### 3. Retain bounded physical-prior cold-start value

Select `RETAIN_PHYSICAL_PRIOR_COLDSTART` only if every condition holds:

- simultaneous lower bounds for `PHY-TRUST - EDGE-FLEX` exceed `0.04` at both
  held-out sizes;
- lower bounds for each held-out-minus-seen interaction exceed `0.03`;
- lower bounds for worst-zone timely-delivery differences exceed `0.02` at both
  held-out sizes;
- semantic-column-rotate return-drop lower bounds exceed `0.05` at both sizes;
- intact-versus-rotate legal-action-TV lower bounds exceed `0.08` at both;
- advantage-attenuation lower bounds exceed `0.03` at both; and
- all earlier validity, answerability and competence gates pass.

This supports only the science card's exact finite-budget, exact-task,
adaptation-free held-out-roster package claim.

### 4. Do not retain the fixed prior as default

Every other complete, valid, answerable panel with a competent `EDGE-FLEX`
selects `DO_NOT_RETAIN_FIXED_PRIOR_AS_DEFAULT` for this task and budget. Record
one descriptive subreason without changing the decision:

- `EDGE_PRACTICALLY_EQUIVALENT` when both held-out direct intervals lie wholly
  inside `[-0.04,+0.04]`;
- `EDGE_MATERIALLY_BETTER` when both held-out intervals lie below `-0.04`;
- `FIXED_EFFECT_NOT_ROBUST_ACROSS_N` for mixed/partial direct or interaction
  evidence;
- `ZONE_BALANCE_NOT_PRESERVED` when the worst-zone gate fails; or
- `SEMANTIC_ACTION_USE_NOT_ESTABLISHED` when any cut gate fails.

This branch does not claim universal EDGE superiority, mathematical identity,
or absence of value at another prospectively defined task. It says the fixed
restriction has not earned default retention against its containing learner on
the one registered object.
