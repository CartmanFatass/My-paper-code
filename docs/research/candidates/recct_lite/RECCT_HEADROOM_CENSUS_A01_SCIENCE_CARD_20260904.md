## 2. Why this remains a MARL direction-local question

The host presents an orientation-paired relay task with source and receiver roles, changing active
membership, survivor state, and rejoining instances. A phase-0 source message and a phase-3
receiver prediction affect native reward. The candidate credit path uses authenticated directed
`LR` and `RL` source-to-receiver learning ports to select a target update.

The binding structure is **multi-agent credit assignment**: which source-to-receiver relation
receives learning credit, under actor-visible role and roster information, may change the target
update and ultimately the receiver action. Roster change and partial observation are host context;
the present mechanism question is not reduced to a storage, receipt, or transport property merely
because the immediate intervention is an information-flow cut.

  definition, information boundary, and evaluation support;
- any existing raw intervention gap, kept under its original estimand and never substituted for
  `H`; and
- the exact evidence deficit when `H` is not identifiable.

Apply the following rule verbatim after the single evidence pass:

1. **HC-X / EVIDENCE_PATH_INCOHERENT.** A cited result cannot be read, its validity is
   contradictory, or the host/population/information boundary cannot be recovered. Report no gap

2. **HC-A / RAW_HEADROOM_IDENTIFIED.** Both `J_upper` and `J_generic` are valid, explicitly
   designated, and matched. Report both raw values and `H`, with no threshold or disposition.
