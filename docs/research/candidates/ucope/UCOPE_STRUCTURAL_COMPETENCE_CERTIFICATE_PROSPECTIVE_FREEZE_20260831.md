## Exact fit and policy pairing

For posterior SHORT belief `b`, action period `k`, probe indicator `a`, total
cost `C`, linkage indicator `L`, and reliability `p`, the frozen bases are:

```text
z_T = (1, b, k/9, b*k/9, (k/9)^2)
z_R = (1, (1-a)k/9, (1-a)(k/9)^2, a, aC, aL, aLp)
```

Only odd `K={1,3,5,7,9}` retained rows enter fitting. A JSON integer token is
an exact integer. Every historical floating-point JSON number token is first
converted to the nearest finite IEEE-754 binary64 value under
round-to-nearest, ties-to-even, and that bit pattern is then converted to its
exact dyadic rational. Both signed zero representations become exact zero;
nonfinite or overflowing tokens are invalid. The original token and row bytes
remain unchanged for direct equality. There is no later FP32 quantization.

Sufficient statistics are accumulated as unweighted exact normal equations.
Rank and the unique solution use deterministic Gaussian elimination with the
first nonzero pivot in row order. Tail rank must be exactly `5`; root rank must
be exactly `7`. Every matrix, right-hand side and coefficient in the sealed
artifact must use canonical reduced rational strings. JSON numeric values,
nonreduced rational strings, negative denominators, tolerances, approximate
pivots, or implicit tie breakers are invalid in those sealed exact fields.

For seed `s` and half `g`, let `T[s,g]` be the tail fit on PROBE rows in half
`g`. For a root row in half `f`:

- IMMEDIATE uses its retained `tail_return`, matching the historical frozen
  root-target contract;
- PROBE uses its retained realized probe primitive plus
  `max_{k in K_train} T[s,1-f](b,k)`.

All such targets are fixed before solving `R[s,f]`, the root fit on half `f`.

