## Advice not adopted

Several response details are stronger than, or conflict with, the reviewed
prospective object and are not adopted:

- **Process separation.** The accepted claim is auditable data-dependency
  isolation, not an operating-system process barrier. Before fitting, a
  training-limited replay path must validate every captured row without
  importing oracle, evaluation, `K_TEST`, competence results or the historical
  result. Fit code and APIs receive only the accepted captured training bytes.
  Postfit oracle sources are opened only after the exact coefficient artifact
  is sealed.
- **Rational representation.** Normal matrices, right-hand sides and
  coefficients use canonical reduced rational strings. A second rational
  object representation would create two encodings for the same sealed
  algebra and is rejected.
- **Separate decoded copies.** The create-once bundle retains the complete raw
  members and exact source dependencies. Direct raw equality plus canonical
  line comparison and full deterministic replay from those bundled bytes is
  sufficient; a second durable decoded copy is redundant. The strict validator
  repeats the full fit and competence computation from the raw bundle.
- **Complementary target ties.** A PROBE root target consumes only the exact
  scalar `max` over odd-`K` continuation scores. Equal maximizing periods share
  that same scalar, so no action or tie breaker enters the target. This is not
  a fit stop. Equal postfit action scores are different: they make the policy
  nonunique and remain a strict stop.
- **Automatic admission.** The response's admission-style disposition names
  are superseded by `STRUCTURAL_PREREQUISITE_PASS`, `admit=false`, and
  `ROOT_NEW_OBJECT_DECISION_REQUIRED`. Only Root can register a later object.

The response's more expansive bundle/result schemas are useful design ideas,
but fields that do not change direct equality, exact recomputation or the
claim ceiling are not required for this cheapest discriminator. No summary or
cryptographic metadata is added as a scientific gate.
