```text
f_theta(u_v,u_y,u_phi)
```

### Cross-fitting retains one useful lemma

For the historical two-action Bernoulli witness, let `K12` and `K34` be the two independent
two-tape counts. Under the exact lexicographic selectors,

```text
Q_pair = 0
D_pair = (K12-1)*(K34-1)/4
S_pair = (K12-1)*(K34-1)/2.
```

Therefore `E[Q_pair]=E[D_pair]=E[S_pair]=0`. More generally, conditional on public state, if every
action has the same true expected value within each graph, evaluation-fold independence forces
population `D=S=0` even with arbitrary common-random-number dependence among action/graph potential
outcomes inside a tape. The proposed split therefore removes the old same-tape plug-in bias in
population `D/S` for that strong null.

This does not save the object. `S` is no longer an oracle nonnegative max-minus-min range and can be
negative; `Q` can be positive under equal action means; and the joint functional can be positive
under the scientifically relevant common-optimum null.

### Exact common-optimum counterexample

Use three distinguished actions `a0,a1,a2`; set the other 15 catalogue actions to `0.5` on every
tape and graph. Each complete future tape is independently type `R` with probability `1/5` or type
`C` with probability `4/5`. Direct full-mission values are:

| graph | tape | `a0` | `a1` | `a2` |
| --- | --- | ---: | ---: | ---: |
| `q=0` | `R` | 0 | 0.9 | 1 |
| `q=0` | `C` | 0.8 | 0.3 | 0.1 |
| `q=1` | `R` | 0.3 | 0.9 | 0.6 |
| `q=1` | `C` | 1 | 0 | 0.6 |

All values lie in the registered `[0,1]` endpoint range. Their true graph-conditioned means are

```text
mu_0=(0.64,0.42,0.28)
mu_1=(0.86,0.18,0.60).
```

Action `a0` is uniquely optimal in both graphs and uniquely maximizes the graph-average value
`0.75`. Hence the intended oracle opportunity has `Q*=0` and `D*=0`.

A two-tape selection fold is mixed `R/C` with probability `8/25`. Then the graph-specific selectors
choose `a1` for `q=0` and `a0` for `q=1`, while the pooled selector uniquely chooses `a2`. A held-out
fold verifies both strict `Q` comparisons unless it is `R/R`, so

```text
Q_cf = (8/25)*(24/25) = 192/625 = 0.3072.
```

The mixed selection fold has true held-out `D=0.20`; an `R/R` selection fold has `D=-0.07`; a
`C/C` fold has `D=0`. Therefore

```text
D_cf = (8/25)*0.20 + (1/25)*(-0.07)
     = 153/2500 = 0.0612.
```

The true held-out selected-max-minus-selected-min contrasts are `-0.52` for `R/R`, `0.23` for a
mixed fold and `0.52` for `C/C`, giving

```text
S_cf = (1/25)*(-0.52) + (8/25)*0.23 + (16/25)*0.52
     = 241/625 = 0.3856.
```

Thus the complete proposed population gate is positive although one common action is uniquely
optimal. This is differential selector error: graph-specific two-tape selectors and the pooled
two-tape selector have different regret. It is not selection/evaluation leakage, same-sample
maximization bias, a rare interval event, or a tie-rule defect.

### The estimands are distinct

After integrating out the held-out fold, the corrected `D` is

```text
D_2 = E_selection[
        0.5*sum_q { mu_q(Aplus_q(selection))
                    - mu_q(Acommon(selection)) }
      ].
```

The protected oracle opportunity is

```text
D_star = 0.5*sum_q max_A mu_q(A)
         - max_A 0.5*sum_q mu_q(A).
```

Fold swapping changes neither equality nor selection regret. The direct distinguishing prediction
is exact in the counterexample: the oracle selects common `a0` and reports zero opportunity, while
the cross-fit reports graph separation and `D=0.0612`. The cross-fit therefore measures held-out
performance of a finite noisy selector, a different scientific object.

A second deterministic witness exposes the revised `Q` meaning in the opposite direction. If
`a0` has values `(1,0)` across graphs and `a1` has `(0,1)`, the oracle optima are disjoint and
`D*=0.5`, but the common selector equals one graph-specific selector; the frozen bilateral-strict
`Q` is therefore zero and the simultaneous gate rejects a maximally clear opportunity. `Q` is not
the original disjoint-optimum prevalence in either direction.
