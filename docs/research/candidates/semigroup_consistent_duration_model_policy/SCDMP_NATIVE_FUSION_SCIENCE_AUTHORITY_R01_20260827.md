## Stage 1 — one treatment-independent order-erased foundation

### Foundation actor and critic

For each fresh replicate `s in {0,...,23}`, train exactly one
`NATIVE-ORDER-ERASED-DELIVERY-FOUNDATION`. The actor is

```text
F_theta:R^14 -> R^27
```

with two SiLU hidden layers of width `80`; the critic has the same input and
hidden widths and emits one scalar. Affine maps include biases. The actor has
`9,867` parameters, the critic `7,761`, and the foundation `17,628` trainable
parameters. Neither actor nor critic receives `q`, `d`, event position or an
ordered token trace.

All arithmetic and optimizer state are float32. New affine weights use
row-major Xavier-uniform initialization with gain one and all biases are zero.
There is one architecture, one update budget, one final checkpoint and no
checkpoint, seed, threshold, reward or stopping menu.

### Foundation training law

Each foundation receives `192` PPO updates. Every update allocates 16 complete
horizon slots: eight at `k=4` and eight at `k=10`, with four `RG` and four `GR`
episodes inside each `k`. Initial state and disturbance addresses are paired
prospectively; the foundation never receives chronology.

At each real renewal, sample one categorical action by inverse CDF in the fixed
27-action order from one fresh address-stable `Uniform[0,1)` variate. Exact
cumulative-boundary contact selects the first action whose cumulative
probability is strictly greater than the variate. There is no other action
noise, temperature, epsilon exploration or argmax during training.

For each renewal record `j` with realized duration `h_j<=k_j`, snapshot
`logp_old,j`, `V_old,j` and the complete old actor/critic. With

```text
gamma=0.996
lambda=0.94
rbar_j=sum_(ell=0)^(h_j-1) gamma^ell*r_(tau_j+ell)
delta_j=rbar_j+1[nonterminal_j]*gamma^h_j*V_old,j+1-V_old,j
A_raw,j=delta_j+1[nonterminal_j]*(gamma*lambda)^h_j*A_raw,j+1
Y_j=stop_gradient(A_raw,j+V_old,j),
```

normalize all valid `A_raw` once per arm/update with population variance and
`1e-8`. The normalized advantage, old values, log probabilities and targets
remain immutable for the update.

For minibatch `M`, the only loss is

```text
ratio_j=exp(log pi(a_j|o_j)-logp_old,j)
L_policy=-mean min(ratio_j*Ahat_j,
                   clip(ratio_j,0.82,1.18)*Ahat_j)
L_value=0.5*mean(V(o_j)-Y_j)^2
L_entropy=mean H(pi(.|o_j))
L_total=L_policy+0.55*L_value-0.012*L_entropy.
```

One backward pass differentiates all foundation tensors. Clip the combined
gradient once to global L2 norm `0.9`. One persistent AdamW optimizer uses
`beta_1=0.9`, `beta_2=0.999`, `epsilon=1e-8`, learning rate `2.5e-4` and
decoupled weight decay `2e-5` on every matrix and bias. Moments start at zero;
the globally one-based optimizer index never resets.

Each update uses four epochs. An epoch-keyed Fisher-Yates permutation of all
valid records is split by quotient/remainder into four nonempty minibatches
whose sizes differ by at most one. Every valid record occurs exactly once per
epoch. This gives 16 AdamW steps per update and `3,072` steps per foundation.
Only the update-192 checkpoint is eligible; all 24 checkpoints must be
technically accepted before competence evaluation.

## Stage 2 — ordered-hold viability adapter and controls

### Task-native ordered-hold score

At a renewal, for supplied chronology `q`, reconstruct only the task-defined
latent reserve value `d_q=0.55*q`. For each legal action, simulate the exact

```text

         -2*1[predicted physical failure]
         -0.5*(z_end/0.55)
         -0.25*(|phi_end|/0.48)
         -0.25*(f_end/0.42)
c_q(o,u)=clip(j_q(o,u),-3,1)
J_q(o,u)=c_q(o,u)-mean_(a in actions)c_q(o,a).
```

This is a prospective, current-state, one-hold physics score. It is not an
outcome fit, future-tape oracle, full-mission value, safety certificate or
claim-bearing endpoint. Centering removes softmax-constant ambiguity.

### Treatment: `ORDERED-HOLD-VIABILITY-ADAPTER`

Clone and freeze the exact foundation actor. A one-hidden-layer SiLU scale
network `g:R^14->R`, width 32, gives `alpha(o)=softplus(g(o))`. Treatment logits
are

```text
logit_T(u|o,q)=F_frozen(o)_u+alpha(o)*J_q(o,u).
```

The scale network has 513 trainable parameters. Its output weight is initialized
to zero and its output bias to `-4.600166`, so the initial scale is approximately
`0.01`; all other new weights use the global Xavier rule and biases are zero.
Because `alpha>=0`, the adapter can only increase preference along the ordered
one-hold viability score relative to the frozen foundation. Arbitrary foundation
logit differences still control the total ordering. No unique mechanism claim
is implied.

The treatment critic receives `(o,q) in R^15`, uses two SiLU width-64 layers and
emits one scalar; it has 5,249 parameters. Treatment therefore has 5,762 new
trainable parameters while the 9,867 foundation actor parameters remain frozen.

### Strictly containing `FREE-DIRECT`

The residual has 6,939 parameters. Its output matrix and bias start exactly at

### Tied `REVERSED`, invariant `SET-FREE` and `FOUNDATION-ONLY`
