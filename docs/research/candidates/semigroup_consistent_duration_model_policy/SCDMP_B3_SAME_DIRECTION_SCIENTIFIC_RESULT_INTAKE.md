## Preliminary scientific conclusion

The exact fixed-scale calibrated B3 package completed competently and stably,
but did not establish the registered wrong-relation manipulation needed to
interpret CORRECT-versus-SHUFFLE as a relation-specific contrast. It therefore
did not establish calibrated-package action-relevant inductive bias,
representation specificity, a FREE-control endpoint result, exact-treatment
deletion, adverse effect, non-harm, null, equivalence or family failure.

The strongest bounded explanation is **a directionally correct but scientifically
too-small wrong-relation first stage under the complete finite optimizer
packages**. Because every general competence and support condition passed, this
is more specific than generic model incompetence. It still leaves unresolved
whether CORRECT and SHUFFLE converged to effectively similar mappings, the
wrong-order objective exerted insufficient distinctive pressure, or the
arm-specific exposure/alignment/clipping/Adam geometry masked or created the
small difference. The experiment cannot tell whether an actually active wrong-
relation package would reveal value for correct semigroup order.
