# Independent scientific audit of a prospective same-target foundation-first order object

Please act as an adversarial scientific innovator. The question is whether one coherent prospective
research object can establish task identity, ordinary-controller competence, and direct order
opportunity on the same native target in that order, before any order-aware adapter is even
instantiated. This is a result-blind definition audit, not a request to implement, run, estimate,
review code, choose a portfolio action, or infer a historical result.

The initial candidate is a planar fixed-four-carrier simulator in which four quadrotors carry a
rigid cable-suspended pallet through an offset gantry and dock at 24.5 m. During fixture-supported
setup, the same two equal-duration events occur in opposite order. `HOOK-HANDOFF` swaps the first two
hook assignments, while `FORMATION-ROTATE` maps `(p1,p2,p3,p4)` to `(p4,p1,p2,p3)`. From the common
initial assignment `(1,2,3,4)`, the two orders yield `(4,2,1,3)` and `(1,4,2,3)`. A common
`LEVEL-RELEASE` then zeros public cable tensions and exposes the same public release pose while
leaving the different hook assignments latent. The assignment determines which pair of cable loads
is affected by the available zero-sum load-share actions, so graph-matched and graph-mismatched
first actions have different prospective overload consequences. The public plant observation and
announced command-hold period are exactly aliased at the first actionable renewal; order-aware
objects may retain the two raw setup tokens, while the foundation receives only their unordered
multiset. Later public physics is shared and may reveal consequences.

Do not accept those statements merely because they are named in a prior card. Audit whether they
jointly define a task-native physical noncommutation, genuine first-renewal public aliasing, and
direct action relevance. If they do not, identify the exact contradiction. You may propose at most
one correction, and only if it preserves the plant, mission, causal event relation, public
information law, action opportunity, and sequential gate meanings. Do not manufacture a more
convenient target.

The prospective authority must be meaning-complete in one place: plant, fixed roster, mission,
clocks, noncommuting same-multiset event, public aliasing, latent physical distinction, observation,
complete action catalogue, external command-hold registry, foundation, opportunity estimand,
controls, endpoints, thresholds, first-true map, workload, and a fresh stochastic namespace. Every
historical SCDMP task, prompt, conversation, operation, checkpoint, coordinate, identity, gate and
result is provenance only. Similar controller roles or a binary order variable do not transfer
identity or evidence.

The first empirical prerequisite would train exactly one treatment-independent order-erased
foundation in each of 24 fresh replicates, before any order-aware parameter exists. Competence would
require simultaneous adjusted safe-docking lower bounds above 0.72 in all 12 order-by-six-regime
cells, a pooled lower bound above 0.84, and four worst-regime physical-failure upper bounds below
0.10. Every replicate is retained. `FREE`, `SET-FREE`, any suspended-payload comparator, and any
historical checkpoint are ineligible substitutes.

Only after that complete gate passes and those exact foundation actors are frozen would the same
object run a disjoint full-mission forced-first-action assay. For each paired public state and each
of two latent graph modes, every legal first action is forced for the announced first hold under
shared future-disturbance tapes; the same frozen order-erased foundation controls the rest of the
mission. The direct value is safe docking multiplied by remaining completion-time fraction. The
assay compares graph-specific action maxima with the best action common to both graphs, preserves
complete argmax ties, and also measures within-graph action sensitivity. Its three simultaneous
adjusted lower bounds must exceed 0.20 for disjoint optimal-action sets, 0.025 for graph-conditioned
value gain over a common action, and 0.060 for action sensitivity. At this point there is still no
adapter, order-aware model, later-stage identity, or final treatment comparison.

The fail-closed interpretation is fixed. An incomplete or contradictory authority is invalid
evidence. A valid foundation nonpass ends before the opportunity assay. A valid opportunity nonpass
ends before any adapter. Only a complete native identity plus a passing same-object foundation gate
plus a passing same-foundation opportunity gate can make a later adapter package scientifically
eligible. None of these branches is a general claim about order, semigroups, arbitrary sequence
length, arbitrary hold duration, variable team size, UAV transfer, deployment, or flight.
