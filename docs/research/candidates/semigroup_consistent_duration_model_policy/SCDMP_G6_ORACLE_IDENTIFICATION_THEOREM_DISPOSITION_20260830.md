## Finite-horizon g-formula and proof

Write `pi_f` for the deterministic renewal action induced by checkpoint `f`, distinguishing it from
the plant's formation-error coordinate. For fixed `(f,q,k,s,a,W)`, define
`Phi_(f,q,k,a)(s,W)` by installing `a` at tick zero, applying the exact `q`-indexed primitive update
for the first fixed hold unless absorption occurs, and, if still live at each later renewal, applying
`pi_f` for the next fixed hold. Failure dominates same-tick docking; a terminal update stops before
any further policy query; timeout stops at tick `T`.

### Lemma 1: pathwise single-valuedness

At tick zero, `(q,k,s,a)` and the first disturbance triple determine exactly one successor. If the
successor is terminal, the endpoint is fixed. Otherwise the remaining hold count uniquely determines
whether the same action continues or a renewal query is due. At a due renewal, `pi_f` returns exactly
one action. Induction repeats at a strictly larger tick and therefore stops after at most 364 updates.
Thus every `(f,q,k,s,a,W)` has one terminal outcome and terminal time. Absorption during the first
hold simply means `pi_f` is never queried; unused tape coordinates have no effect.

### Lemma 2: boundedness, measurability and uniqueness

By the assumption map, every one-step map, policy action and terminal predicate is Borel. Finite
composition and a finite first-hit rule make

```text
U_(f,q,k,s,a)(W) = U(Phi_(f,q,k,a)(s,W))
```

Borel in `(s,W)` and bounded in `[0,1]`. Hence

```text
V_f(q,k,s,a)
  = sum_(W in Xi^T) 8^(-T) U(Phi_(f,q,k,a)(s,W))
```

exists, is unique and is Borel in `s`. Equivalently, backward recursion assigns the frozen endpoint
at an absorbed state, zero at a live timeout, and at every earlier live tick averages the eight exact
next-tick values while the hold counter and each renewal action are deterministic. Every recursive
call uses a later tick, so the recursion is acyclic. This proves finite-horizon structural
identification; it does not claim that enumerating `8^364` tapes is computationally cheap.

### Lemma 3: finite maxima and complete argmax sets

A finite maximum of the 18 Borel value functions is Borel and attained. Define, for a cell
`z=(k,s)`,

```text
M_q(z) = max_(a in A) V_f(q,z,a)
G_q(z) = Argmax_(a in A) V_f(q,z,a)
C(z)   = max_(a in A) 0.5*(V_f(0,z,a)+V_f(1,z,a)).
```

Every `G_q(z)` is nonempty and retains all exact ties. Membership in an argmax is a finite set of
Borel comparisons, so the least indexed member of an argmax or intersection is a measurable
selector wherever that set is nonempty.

### Lemma 4: cell nonnegativity and bound

For every action `a`,

```text
0.5*(M_0(z)+M_1(z))
  >= 0.5*(V_f(0,z,a)+V_f(1,z,a)).
```

Maximizing the right side gives

```text
Delta_f(z) = 0.5*(M_0(z)+M_1(z))-C(z) >= 0.
```

Because values are nonnegative, choosing a graph-0 maximizer in the common objective shows
`C(z)>=M_0(z)/2`, and symmetrically `C(z)>=M_1(z)/2`. Therefore

```text
Delta_f(z) <= 0.5*min(M_0(z),M_1(z)) <= 1/2.
```

This is a universal range, not an evaluated plant value.

### Lemma 5: exact cell null

If `a_star in G_0(z) intersect G_1(z)`, then its common objective is
`0.5*(M_0(z)+M_1(z))`, so `Delta_f(z)=0`.

Conversely, suppose `Delta_f(z)=0` and choose any action `a_c` attaining `C(z)`. Then

```text
0
  = 2*Delta_f(z)
  = (M_0(z)-V_f(0,z,a_c)) + (M_1(z)-V_f(1,z,a_c)).
```

Both deficits are nonnegative, so both are zero. Thus `a_c` is optimal in both worlds and
`G_0(z) intersect G_1(z)` is nonempty. This proof neither assumes unique optima nor requires the two
argmax sets to be equal.

### Lemma 6: population null

Let

```text
nu = 0.5*(delta_7 x mu_7) + 0.5*(delta_13 x mu_13).
```

Then `Delta_f=integral Delta_f(z) d nu(z)`. Its integrand is measurable, bounded and nonnegative.
The integral is zero if and only if the integrand is zero `nu`-almost everywhere. Since both `k`
weights are positive, this is equivalent to cell zero for `mu_k`-almost every state separately at
each `k`; Lemma 5 gives the common-optimum characterization. Choosing the least indexed member of
the intersection yields a measurable shared action `a_c(k,s)` on that full-measure set, with an
arbitrary default on its null complement.

The quantifier is pointwise in the paired `(k,s)` cell. One globally fixed action is not required.
For example, two state regions may respectively share only `a_1` and only `a_2` and still have zero
oracle advantage everywhere.

### Lemma 7: coupling and expectation order

Every `V_f` uses only the registered marginal product law of `W`. Sharing the same tape across
potential graph/action worlds changes paired covariance and therefore may change an estimator's
variance, but it cannot change any marginal expectation, exact maximum or `Delta_f`. Neither oracle
observes `W`.

The frozen order is `max_a E_W[U]`, not `E_W[max_a U]`. A tape-revealed action would add future
information and define a different, generally larger object. No finite sample chooses an action in
the displayed g-functional, so finite-selector regret is **excluded by definition**, not estimated
and not canceled.

## Boundary and circularity checks

- **Ties:** complete argmax sets control the null. Unequal sets with a shared tied optimum give zero;
  disjoint sets give a strictly positive cell gap. Lexicographic action choice is used by `f` and may
  select a measurable representative, but arbitrary oracle tie-breaking cannot replace the complete
  sets.
- **Absorption inside the first hold:** the first terminal update fixes `U`, suppresses the return to
  `f`, and ignores the unused tape suffix.
- **Absorption at a renewal boundary:** the terminal test precedes the next policy query, so no
  post-absorption action exists.
- **Timeout:** a live path reaching tick 364 receives zero and needs no later hold or policy query.
- **Common random numbers:** coupling is allowed; tape access is not. Marginal values remain fixed.
- **Graph information:** the treated action may depend on `q`; the common action may depend on
  `(f,k,s)` but not `q`. Later public graph consequences enter the same order-erased `f` in both
  worlds and do not create an additional first-action information asymmetry.
- **Fixed duration:** `k=7` and `k=13` are the source card's target fixed regimes. A switched or
  unspecified future schedule would require a schedule argument or law and is outside the theorem.
- **No admitted foundation:** the theorem remains conditional. With no accepted competence-passing
  `f`, opportunity is `NOT_OBSERVED`, not refuted and not zero.
- **Measurable discontinuities:** thresholds, float quantization and tie surfaces can make values
  discontinuous without making them non-Borel. Null surfaces have their ordinary measure-theoretic
  meaning; positive-measure tie regions remain inside the full-set null.
- **Circularity:** `mu`, `f`, the transition, endpoint and disturbance law are fixed first; pathwise
  `U` is constructed next; `V` integrates `U`; only then are maxima, `Delta` and the null formed.
  The continuation foundation maximizes its own frozen logits, not `V_f`. Competence is not inferred
