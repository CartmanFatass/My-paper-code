- **Zero-fit family (full information, deterministic given the world).** KEEP (pre-event targets held); cold SET-now (`search_placement` re-run at t_e on the new users, `assign_targets` from current positions); warm SET (four unaffected sites held; only the UAV(s) serving the relocated cluster — server and, if chain-served, its relay — re-placed by the planner's static evaluator at the same budget; the cold search seeded with the current layout via `extra_candidates` is run as a second warm candidate and the better of the two is the warm rule); departure-subset oracle (under warm SET's new targets, every subset of the six UAVs allowed to depart at t_e, others holding, × departure delay {0, 20, 50} steps for the departing set; the best rollout per world).
