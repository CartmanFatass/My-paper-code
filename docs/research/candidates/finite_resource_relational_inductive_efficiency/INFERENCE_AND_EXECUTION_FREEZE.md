## Exact addressed FP32 uniform law

All detection, uplink, base-link, and inverse-CDF action uniforms are defined directly on an
FP32-representable lattice. For one semantic address `a`, let `B(a)` be the existing
`AddressedRNG.block(a, 0)` PRF output and define

\[
K(a)=\operatorname{uint24}_{BE}(B(a)[0:3]),\qquad
U_{32}(a)=\operatorname{binary32}\!\left(K(a)2^{-24}\right).
\]

Thus `K` ranges over the integers `0,...,2^24-1` and the exact support is

\[
\left\{0,2^{-24},\ldots,1-2^{-24}\right\}.
\]

Every support value is exactly representable in IEEE-754 binary32. There is one PRF block and one
addressed draw per random variable, with no 53-bit binary64 entropy, inexact binary64-to-FP32
rounding, clamp, retry, or endpoint repair. An implementation may carry the exact dyadic value in
a wider register before storing it, because conversion of these support values to binary32 is
exact and must produce the formula's literal bits. Under the declared addressed-PRF seed law, the
`2^24` lattice points have equal mass. This is the maximum-cardinality equally spaced dyadic grid
anchored at zero and contained wholly in binary32 `[0,1)`: a finer uniform grid would require more
than binary32's 24 significant bits near one. It therefore binds the law to the precision actually
consumed by both the native host and actor rather than to an implementation convenience.

The manifest and every tape receipt carry this direct root-free structure literally:

```text
schema=FRRIE_ADDRESSED_FP32_UNIFORM_V1
prf=SHA-256
prf_word_bits=256
selected_bits=24
selection=MOST_SIGNIFICANT_BITS
numerator_min=0
numerator_max=16777215
```

This is a PRF/numeric mapping declaration only. It is never a digest, authentication, freshness,
or admission credential.

For a frozen binary32 threshold `p`, the native coin is successful exactly when `U32 < p`, so its
literal probability under this discrete law is

\[
q(p)=2^{-24}\#\{k:0\leq k<2^{24},\;k2^{-24}<p\}
    =2^{-24}\left\lceil 2^{24}p\right\rceil
\]

for `0 < p <= 1`, with the evident zero case at `p=0`. Hence `0 <= q(p)-p < 2^-24`, and equality
holds whenever `p` is on the lattice, including the `0.75` detection probability. Action sampling

## Inference re-audit and decisive blocker

There is no active confidence-bound method or critical value. The previously considered paired
Student-`t` construction is rejected, including its zero-variance point-interval rule. Every block
statistic is a deterministic function of a finite 256-bit root. Independence of fresh roots does
not make those functions Gaussian, and a discrete law can produce zero observed variance with
material probability while its population mean lies outside a claimed point interval.

The smallest assumption-free candidate is a paired bounded-mean Hoeffding--Bonferroni family. For
member `q` with known support `[a_q,b_q]`, `B=24`, family size `K=28`, and family alpha `0.05`, it
would give

\[
L_q=\max\{a_q,\bar q-r_q\},\qquad
U_q=\min\{b_q,\bar q+r_q\},
\]

\[
r_q=(b_q-a_q)\sqrt{\frac{\log(2K/0.05)}{2B}}.
\]

The common multiplier is

```text
sqrt(log(56/0.05)/(2*24)) = 0.3824559877807603
```

so the two-sided radius is:

```text
0.7649119755615206  for d, e, z, and C with range width 2
1.5298239511230411  for c and I with range width 4
0.3824559877807603  for V with range width 1
0.1912279938903802  for an h-based support slack with range width 0.5
```

`A_TV` has the safe range `[-0.08,0.88]` and radius
`0.3671577482695299`. These radii make the closed `[-0.04,+0.04]` seen-
equivalence band impossible for every observation vector. Because seen equivalence precedes
treatment interpretation, this valid method would make every positive, equality, superiority, and
cut branch unreachable.

This is not merely Hoeffding conservatism. For an exact finite-sample counterexample, let direct
contrast `X` have either

```text
P0(X=0)=1
Pq(X=1)=q, Pq(X=0)=1-q, with q>0.04.
```

The all-zero sample has probability `(1-q)^24`, approaching
`0.96^24 = 0.3754132467271021` as `q` decreases to `0.04`. Any 95% procedure
that excludes means above `0.04` on that sample miscovers `Pq` with probability far above `0.05`;
under the proposed 56-tail allocation the tail error would be only `0.05/56`. Yet `P0` produces
only the all-zero sample. Therefore even the most favorable equality law cannot certify the
registered band with 24 blocks under arbitrary bounded distributions.

The same argument applies to cut-insensitive action TV. Under
`P(V=1)=q>0.08`, an all-zero 24-block sample has probability approaching
`0.92^24 = 0.1351785726111903`, so a valid upper bound cannot certify
`mu_V <= 0.08` on ordinary zero-TV data.
