## Frozen scientific question

Can a genuinely new make-before-break public handover host establish, in both
roster expansion and contraction, all three of the following before any
learned KEEP/FLEX comparison?

1. a public coherent assignment scaffold with prospectively certified recovery
   and service-loss headroom;
2. a physical assay whose fixed disruptive control is worse than coherent
   carry by strictly more than three recovery ticks and 0.03 integrated
   service loss in each churn direction; and
3. direct target-bound continuity opportunity, defined as coherent carry
   outperforming a fresh roster-size-canonical replan by the same two margins
   from a byte-identical public physical event state.

The decision is whether this exact physical opportunity is strong and clean
enough to justify a later, separately frozen finite-budget comparison between a
plan-carry restriction and a competent strictly containing flexible
controller. A negative analytic certificate or physical gate is a complete

## New target-phase handover host

The host is a 96-sector ring with four stationary physical service docks. For
root/scenario global rotation `r`, dock `j` is at

```text
q_j = (r + 24*j) mod 96,  j in {0,1,2,3}.
```

The two active roster sizes are 12 and 20. Demand is uniform and exact:

```text
d_j(12) = 3,
d_j(20) = 5.
```

Episodes last 48 physical ticks. A possible membership event occurs before
movement at tick 16, leaving a 32-tick post-event window. The four cells are
`12->12`, `20->20`, `12->20`, and `20->12`.

Before the event every active entity is co-located with its public claimed
dock and every dock has exact demand. Expansion is make-before-break: exactly
two newcomers per dock are publicly staged at that dock under the existing
plan and become active at the event. Contraction removes exactly two publicly
staged-to-depart entities per dock. Survivors retain current position and
previous public claim. A newcomer has no identity or previous episode history;
its public staged target and current position are available at entry. Within a
dock, a fresh ephemeral public tie mark gives total order and is discarded
after use. No entity key enters a policy or scripted objective.

The public common plan contains one target phase and the exact-demand target
assignment induced by it. The canonical roster-size phases are

```text
c(12) = 0,
c(20) = 1.
```

At episode start the plan phase is `c(N_start)`. The balanced arrival/departure
law preserves exact demand under that old phase. The event packages differ
only in what they do with the phase from the cloned event state.

An entity claims one dock for the complete post-event window. At every
post-event tick it moves at most three sectors along the shortest circular path
toward that claimed dock; an exact 48-sector tie moves clockwise. Service is
measured after movement. An entity serves dock `j` only when it both claims
`j` and is exactly at `q_j`. Thus a target rekey creates a physical transit
loss rather than a claim-count shortfall.

## Frozen public packages

All packages receive byte-identical current roster, positions, previous/staged
claims, dock coordinates, demand, event facts, tie marks, and future physical
law.

- `CARRY-TARGET` retains the old public phase and every survivor/staged-newcomer
  target. It changes no target and remains exact-demand.
- `CANONICAL-REPLAN` sets the phase to `c(N_after)`. In a static cell this is
  identical to carry. In expansion it rotates every target one dock clockwise;
  in contraction it rotates every target one dock counterclockwise. Uniform
  demand makes the fresh plan exact-demand.
- `OPPOSITE-BREAK` is the fixed positive control. In either churn cell it
  changes every target by two docks, using clockwise motion at the exact
  half-ring tie. It is also exact-demand. In static cells it is identical to
  carry.
- `PUBLIC-MIN-SWITCH` chooses among exact-demand assignments by minimizing, in
  order, changed public previous/staged targets, total travel distance, and the
  public lexicographic target vector. On the frozen host it must equal
  `CARRY-TARGET` byte-for-byte.

The positive control therefore tests whether the recovery/service endpoints
detect a deliberately larger target discontinuity. It does not manufacture
claim fragmentation: every package has exact target counts and registered
claim shortfall `F=0`.

## Endpoints and analytic certificate

For post-event offset `h in {0,...,31}`, let `u_h` be normalized unmet dock
demand after movement. Recovery is

```text
tau = min {h in {0,...,29}: u_h=u_(h+1)=u_(h+2)=0},
tau = 32 if no such interval exists.
U = (1/32) * sum_(h=0)^31 u_h.
```

The exact geometry yields the following proposed certificate for every legal
global rotation, reflection, entity ordering, and tie tape.

1. `CARRY-TARGET` and `PUBLIC-MIN-SWITCH` move zero distance, so
   `tau=0`, `U=0`, and `F=0` in every cell.
2. `CANONICAL-REPLAN` is identical to carry in static cells. In either churn
   cell every entity traverses 24 sectors in eight moves. The first seven
   post-event measurements are fully unserved and the eighth is fully served,
   so `tau=7`, `U=7/32=0.21875`, and `F=0`.
3. `OPPOSITE-BREAK` is identical to carry in static cells. In either churn cell
   every entity traverses 48 sectors in sixteen moves. The first fifteen
   post-event measurements are fully unserved and the sixteenth is fully
   served, so `tau=15`, `U=15/32=0.46875`, and `F=0`.

Before any result process, an independent principles audit must verify every
step, including movement/service ordering, the half-ring tie, exact-demand
preservation in both churn directions, and the recovery indexing. The
certificate must then establish these thresholds without sampled evidence:

## Strongest simple nulls and competing explanations

1. **The host bakes in carry.** Arrivals and departures are balanced under the
   old plan, so a roster-size phase reset is deliberately misaligned with the
   make-before-break physical state. A positive would establish this finite
   handover opportunity, not natural prevalence or optimal replanning value.
2. **No plan representation is necessary.** `PUBLIC-MIN-SWITCH`, and likely a
   current-position/previous-claim rule, reproduces carry exactly. The physical
   stage cannot favor a latent over a competent stateful controller.
3. **The phase law is an arbitrary canonicalization.** The direct contrast may
   be better described as avoiding a roster-indexed symmetry reset than as a
   general persistence mechanism.
4. **The assay is tautological.** If the endpoint algebra follows entirely from
   fixed travel distances, execution may test implementation conformance more
   than an uncertain physical effect. A run is justified only if it verifies
   the real host/event/service calls and the analytic certificate is itself
   decision-relevant.
5. **Balanced churn is narrow.** Departures and arrivals preserve exact target
   quotas. Unbalanced or stochastic churn, moving docks, hidden staging, and
   nonuniform demand remain outside the claim.

The alternatives have different consequences. A valid certificate plus
matching physical run establishes a clean existence proof but preserves all
five limitations. Failure of the certificate means no command is needed.
Failure of a valid implementation to match the certificate falsifies this
host or its measurement, not plan continuity generally.
