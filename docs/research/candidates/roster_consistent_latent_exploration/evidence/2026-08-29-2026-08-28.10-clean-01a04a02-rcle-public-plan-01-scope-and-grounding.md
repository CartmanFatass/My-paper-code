## Frozen question, estimand, and decision

On a new four-beacon rotating-service ring, can a public-state common plan
carried unchanged through the held-out physical membership changes `6->10`
and `10->6` produce a simultaneous recovery-time benefit and integrated-
unserved-demand nonharm relative to a competent learned controller whose
policy class strictly contains the keep-plan treatment?

The cycle must first establish, in order:

1. **physical opportunity**: an exogenous two-claim allocation break materially
   worsens recovery and unserved demand relative to a coherent continuation;
2. **common-scaffold controllability**: a public, identity-free coherent
   assignment law directly controls every held-out cell and beats an
   independent-nearest baseline;
3. **containing-comparator competence**: the learned flexible controller itself
   controls every held-out cell and beats that same nearest baseline; and
4. **direct value/nonharm**: the frozen paired rectangle favors either the
   keep-plan restriction, the flexible controller, neither materially, or
   remains unresolved.

Only after all four prerequisites pass may a keep-plan win be checked for a
larger churn contrast than its matched static destination-roster contrast and
for lower treatment-blind claim fragmentation. This cycle contains no

## Physical host and exposure clock

The host is a circular perimeter with sectors `0,...,79` and four moving
service beacons. An episode has `H=56` physical ticks. Claims occur at
`t=0,4,...,52`; a membership event occurs before the claim at `t_c=20`.

For beacon `j in {0,1,2,3}`,

```text
q_j(t) = (20*j + floor(t/4)) mod 80.
```

For roster size `N`, let `b_N=floor(N/4)`, `r_N=N mod 4`, and
`e_t=floor(t/8) mod 4`. The simultaneous service demand is

```text
d_j(N,t) = b_N + 1[j in {(e_t+m) mod 4 : m=0,...,r_N-1}],
sum_j d_j(N,t) = N.
```

Every beacon always has at least one unit of demand. Beacon and demand phases
continue through membership change; there is no new-epoch cell.

Initial physical positions are uniform without replacement on the ring.
Expansion preserves every survivor and places newcomers uniformly without
replacement in unoccupied sectors. Contraction removes a uniformly sampled
subset and preserves survivor positions. Current membership is an unordered
set. There is no persistent roster slot or policy head. All physical and
stochastic host variables are paired across arms within a root and scenario.

At each claim clock every active agent legally claims any beacon. A common
deterministic decoder moves each agent by at most three sectors per physical
tick along the shortest path toward its claimed moving beacon, with clockwise
tie breaking. Co-location is legal. The decoder receives no latent and makes
no allocation decision.

At `t=20`, membership changes first; the public post-event roster, position,
beacon, demand, roster-event pulse, and newcomer pulses are then exposed; all
current agents claim; movement occurs; and physical service is measured. There
is no hidden service interval between event and response.

The policy sees no agent ID. It sees the current public agent-position set,
current public beacon/demand set, current `N`, physical time, event pulse, and,
for the acting agent, own position, public angular rank, previous displacement,
and newcomer pulse. No feature reveals a future arrival, departure, action,
return, or result.

## Endpoints

Let `c_j(t)` be the number of current agents within circular distance two of
beacon `j`, and define normalized unserved demand

```text
u_t = (1/N_t) * sum_j max(d_j(N_t,t) - c_j(t), 0).
```

The primary recovery endpoint is

```text
tau = min {h in {0,...,33}: u_(20+h)=u_(21+h)=u_(22+h)=0},
tau = 36 when no such three-tick interval exists.
```

The direct nonharm endpoint is

```text
U = (1/36) * sum_(t=20)^55 u_t.
```

At each post-event claim clock, let `a_j` be the number of claims for beacon
`j` and

```text
f = (1/N_t) * sum_j max(d_j(N_t,t) - a_j, 0).
F = mean f over t in {20,24,...,52}.
```

`F` is treatment-blind physical allocation fragmentation. It is never a
reward. Every learned arm instead receives the identical dense return

```text
Y = 1 - (1/56) * sum_(t=0)^55 u_t.
```

Every episode is retained intention-to-treat. Censoring, poor return, apparent
latent nonuse, or absence of visible fragmentation never permits exclusion.

## Treatment and strictly containing comparator

`KEEP-COMMON` draws a four-dimensional continuous Normal plan once from a
manager conditioned only on the public episode-start set state. The realization
is broadcast to every current agent, retained at all claim clocks, and carried
unchanged through membership change to survivors and newcomers.

`FLEX-EVENT` uses the identical pre-event common plan and the same manager and
actor backbone. At the membership event it may form

```text
z_i^+ = z + Delta_common(z,g_event)
          + Delta_agent(z,g_event,o_i,eta_i),
```

where `g_event` is the same public event summary available to both arms,
`o_i` is the same identity-free current-agent observation, and `eta_i` is fresh
standard Normal event noise. It may preserve, commonly rewrite, or
individualize the plan. Setting the final weights and biases of both update
heads to zero reproduces `KEEP-COMMON` on every legal history. A pre-result
functional fixture must exhibit both exact containment at zero and one
nonzero, output-connected common/agent update outside the treatment class.

Both arms allocate the same maximum tensor inventory. Event-update outputs are
hard-masked to zero in `KEEP-COMMON`; all other architecture, initialization,
data, action support, public information, plan/noise banks, optimizer,
checkpoint, and decoder are common. The common tensor is copied across arms
within each root. FLEX update-head output layers initialize at zero while live
hidden features give nonzero first-order actor connectivity.

The maximum architecture follows only the scientific interfaces of the public
TBCFV reference: separate mean-pooled agent and beacon encoders, a public-state

## Learning and matched work law

Each arm/root receives exactly 256 complete update blocks. Each block contains
32 complete episodes, eight from every training cell, and produces one joint
plain-SGD update. For episode `b`, the score term is the mean log density over
used plan draws plus the mean log probability over active-agent claims. A
stopped cellwise exponential return baseline is updated only after the joint
parameter update. Plan draws are stopped actor inputs and train the manager
only through their Normal log density. Event noise has no learned density
term; FLEX heads learn only through downstream claim likelihood.

For the complete allocated tensor, a zero raw gradient yields no update;
otherwise the raw gradient is normalized to Euclidean norm `0.05` and applied
with learning rate `0.01`, so every nonzero block update has norm `0.0005`.
There is no critic, entropy term, latent agreement loss, reconstruction,
momentum, weight decay, clipping, replay, curriculum, early stopping, restart,
seed replacement, sweep, or checkpoint selection. The sole learned checkpoint
is block 256.

This matches data, environment steps, update count, maximum tensor inventory,
nonzero whole-update norm, and checkpoint time. It intentionally does not
equalize zero-update incidence, gradient direction, effective stochastic
sample size, curvature, per-parameter allocation, function-space displacement,
state visitation, or basin access. Those are the strongest generic
finite-budget-regularization alternatives.

## Scripted prerequisites

`COHERENT` computes at each claim clock the minimum-total-circular-distance
bijection from current agents to the current demanded service slots. Ties first
minimize changes in survivor beacon claim and then use the public angular-rank
order and beacon/unit order. Newcomers have zero change cost. This public,
identity-free controller carries an allocation convention through churn and
tests direct controllability; it is not a learned comparator.

`FRAGMENTED` is identical through `t=20`. At the first two post-event claims
in a churn cell it starts from `COHERENT` and then moves the first public-order
claimant of beacon 1 to beacon 0 and the first claimant of beacon 3 to beacon
2, creating two shortfalls and two excesses when those claims exist. It then
returns to `COHERENT`. Its paired contrast tests physical opportunity without
changing information, action validity, decoder, or pre-event state.

`NEAREST` independently assigns each agent to the nearest current beacon,
breaking ties by lower beacon index and ignoring demand and other agents. It is
the common noncoordinating baseline.

## Simultaneous inference and gates

or upper Student-t endpoint uses

```text
gamma_global = 1 - 0.05/52.
```

The 52 one-sided tails are four opportunity tails, sixteen coherent-scaffold
tails, sixteen FLEX-competence tails, eight direct-value rectangle tails, and
eight churn-specificity/fragmentation tails. The familywise statement is

For each churn path, opportunity requires positive lower bounds for

```text

```

lower bounds for

```text

```

For every held-out cell, FLEX competence requires positive lower bounds for

```text
16 - T_FLEX
0.12 - U_FLEX
T_NEAREST - T_FLEX - 2
U_NEAREST - U_FLEX - 0.02.
```

For churn path `p`, define paired root-level contrasts

```text
D_TIME(p) = T_FLEX(p) - T_KEEP(p)
D_LOSS(p) = U_FLEX(p) - U_KEEP(p).
```

`KEEP_TARGET_WIN` holds if either path has `L(D_TIME)>2`, the other has
`L(D_TIME)>-1`, and both have `L(D_LOSS)>-0.01`. `FLEX_TARGET_WIN` is the
mirror condition: one path has `U(D_TIME)<-2`, the other has
`U(D_TIME)<1`, and both have `U(D_LOSS)<0.01`. `TARGET_NO_MATERIAL` holds only
when both complete `D_TIME` intervals lie within `[-1,1]` and both complete
`D_LOSS` intervals lie within `[-0.01,0.01]`.

For a churn path, let the matched static cell be its destination roster and

```text
C(p) = D_TIME(p) - D_TIME(destination_static)
G(p) = F_FLEX(p) - F_KEEP(p).
```

A value-winning path has `CHURN_SPECIFICITY` only if `L(C)>1.5`; specificity is
resolved absent if `U(C)<=1.5`. Lower `G` above `0.03` is a concurrent reduction
in treatment-blind fragmentation, not a mediator and not a commonality or
persistence factorial.
