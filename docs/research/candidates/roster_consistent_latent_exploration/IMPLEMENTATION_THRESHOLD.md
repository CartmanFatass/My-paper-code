# RCLE private-state churn-continuity implementation threshold

Status: `HARD_NO_CODE`

This threshold authorizes no source, test, schema, CLI, training, certificate, or result work.

## Single blocker

No current authority defines a reachable pair with identical public history/current physical state,
different causally owned private state that changes the first post-event action and native endpoint,
complete arm-wise equality of local prefix/messages/parameters/clocks/communication/work/randomness,
and failure of exact decentralized recomputation.

Blocker: `NO_REACHABLE_ACTION_RELEVANT_PRIVATE_CROSS_OUTSIDE_EXACT_RECOMPUTE`.

## Containment law

For entity `i`, let carried state be

\[
S_i^e=F_\theta(L_i^e,R_i,R_c),
\]

where `L_i^e` is its complete local observation/action/message/membership prefix and `R_i,R_c` are
matched private/common random tapes. A same-information decentralized controller computes the same
state, post-event action kernel, recovery-time law, and unserved-demand law. A stochastic state is
also absorbed by the conditional behavioral kernel given the same perfect-recall prefix and
correlation device.

Hiding the old draw, history, message, sufficient statistic, or RNG address changes information.
Giving recompute less storage, latency, or work changes resources. A fresh redraw is RESET, not exact
recomputation.

## Required ownership law for any future reopening

State belongs to a persistent physical entity, never a slot, rank, role, or array index. Survivors
may retain only their own state; departed state stops acting and cannot migrate through slot reuse;
newcomers/replacements initialize fresh; only the same physical entity may recover its prior local
prefix on rejoin; slot permutation/crossing cannot transfer state. Explicit handover is a separate
treatment.

## Repository finding

Current TBCFV state transport preserves survivor tensors and initializes newcomers, but its cut is
old addressed draw versus fresh draw; exact reuse/reconstruction of the original draw reproduces
CARRY. CPC uses a centralized full-clue manager without local recurrent prefix/recompute. B2 has no
within-episode churn or physical recovery endpoint. TBCFV lacks equal-cardinality replacement,
leave/rejoin, serialized live per-agent prefixes, and a decentralized recurrent replay controller.

Thus existing surfaces expose old-draw versus fresh-draw interventions, not private continuity
against a competent same-local-information null.

## Parity gate and endpoints

Any future witness must match message payloads/rounds/bytes/latency/delivery; environment and agent
ticks; decisions, transitions, replay/manager calls and updates; capacity/storage/deadline;
checkpoint/initialization; and counter-addressed RNG by physical entity/event/tick/draw/coordinate.
Original private/common randomness must be available to RECOMPUTE.

If TBCFV is retained, use treatment-blind post-churn recovery time and integrated unserved demand:

\[
u_t=N_t^{-1}\sum_j\max(d_j-c_j,0),
\qquad U=40^{-1}\sum_{t=24}^{63}u_t,
\]

with recovery time the first four-consecutive-zero-unserved window after `t=24`, censored at 40.
No margin or empirical branch is frozen while the blocker remains.

## Acceptance and stop

cross; private cross survives. Current authority reaches the two hard-stop branches. Only a
constructive positive-probability witness surviving exact same-information recomputation can create
a new implementation threshold.
