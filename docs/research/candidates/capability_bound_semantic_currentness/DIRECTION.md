## Scientific question

When independently varied OWNER continuity, semantic refresh, carrier capability, and
receiver-addressed payload content are all observable under matched public history, does current
capability-bound content change the unique native `SERVE / REFRESH / SAFE-FALLBACK` decision and net
team return beyond a competent predictive-index or unrestricted raw-history controller?

The direction separates four axes that the source directions previously coupled or left missing:

1. OWNER lineage is live or broken;
2. content is persistent or conditionally refreshed;
3. binding leaves access open or changes authorization, failure, latency, or acquisition cost;
4. payload is correct for the receiver, swapped, or native-neutral.

## Accepted finding — 2026-08-30

The complete registered artifact contains all `6,144` worlds in each of six arms and `36,864` rows.
It selects `VALID_NARROW_PROTOCOL_VALUE`, has no failing witness, and passes all 15 registered
audits. CBSC is rowwise identical to the unrestricted same-primitive RAW optimum and has minimum
selected-action margin `3/8`; the minimum optimized-comparator margin is positive at `1/8`.

Authorized correct current service returns `3/4`; stale or swapped content invokes the reactive
refresh response for `1/8`. Capability difference-in-differences, currentness, and
receiver-correct-minus-swapped content are each `5/8`; OWNER information is `5/16`; retained content
over RESET is `1/2`. Binding has zero action/value effect in `OPEN`, where the predictive index is
pathwise equivalent. Its residual in `BINDING_GATED` is the frozen nonfungible execution-capability
treatment. Neutral payload never opens direct service.

The scientific inference is exact and narrow: current receiver-addressed content plus a current
execution capability has positive one-opportunity protocol value under the frozen access, clock,
and cost law. OWNER history and retained content each add value against their competent registered
controls. RAW containment is equality, not a positive CBSC-over-RAW residual.

### Mechanism and strongest containing null

Repeated public OWNER and semantic changes create a temporally sufficient but nonlocal currentness
state. A relation-aligned recurrent adapter may make the latest target-specific OWNER and epoch
easier for a finite-budget actor-critic to combine with the presented body, receiver content, and
execution capability. Support requires native action and return improvement, not hidden-state
separation or decoder accuracy.

`RAW-GRU` is the containing null. It receives the complete identical primitive stream, the same
common recurrent learner, and a result-blind generic four-byte history adapter. Every structured
adapter output is a deterministic function of that same public history. A competent RAW policy can
therefore implement the same history-dependent rule; no information, representation-necessity,
oracle, asymptotic, or universal structured-over-RAW claim is available.

`PI-GRU` supplies ordinary recency/index structure while retaining the full primitive stream.
`DERANGED-CURRENTNESS-GRU` matches STRUCT's register graph and work but uses the fixed no-fixed-point
lane permutation `O0->E1, O1->E0, E0->O1, E1->O0`.

### Dynamic host and native consequence

Every episode has an eight-token public initialization preamble and 24 opportunities. Each
opportunity has four randomly ordered pre-action positions for OWNER, semantic, capability, and body
events, followed by one decision and one settlement transition, for 152 primitive transitions per
episode. OWNER and semantic state change independently with probability `0.20`, carrier binding
with probability `0.25`, and body issue with probability `0.50`. Body issue is
`CORRECT/SWAPPED/NEUTRAL` with probabilities `0.50/0.25/0.25`; decision access is `OPEN/GATED`
equiprobably; requests are active with probability `0.85`. Event order permits a body to become
stale between issue and the same opportunity's decision.

The learner never receives reduced validity, oracle action/value, reward, success, future facts, or
hidden environment state. At an active decision, exact current receiver-correct content with
current OWNER and epoch and executable capability is valid. `SERVE` returns `+1.00` when valid and
`-0.30` when invalid; `REFRESH` pays `-0.40` at decision and `+1.00` at delayed settlement for an
active request; `SAFE_FALLBACK` returns `+0.20` when active. For inactive requests their respective
values are `-0.10`, `-0.40`, and `0`. The unique immediate oracle is therefore SERVE at `1.00` for
active valid requests, REFRESH at `0.60` for active invalid requests, and fallback at `0` when
inactive. Capability mismatch changes native execution in `GATED` but not `OPEN`; no hidden
authorization label is sampled.

The public token is 16 bytes plus one flag byte, unpacked to 136 binary channels. A deterministic
four-byte adapter adds 32 binary channels. The same persistent Innovator conversation has now bound
the byte codes/masks, family NOOPs, eight-token initialization, RAW FIFO, STRUCT/PI/DERANGED timing,
  counter-addressed PRF, action sampling, recurrent-PPO initialization/order, fixed motif panel, B0,
  artifacts, publication, and resources. `CBSC_OMRC_B01_LITERAL_BINDING_SPEC.md` is the literal
  implementation authority. A third decision fixes lossless raw publication and delegates every
  AUC, diagnostic aggregation, threshold, branch, B2 trigger, and polarity decision to the persistent
  Convergence node; `CBSC_OMRC_B01_METRICS_ONLY_CONVERGENCE_SPEC.md` is authoritative for that
  boundary. No comparator-identity or raw-support ambiguity remains.

### Selected learner and parity

All four learned arms use the same `168 -> Linear(128) -> ReLU -> GRU(128) -> actor(4), value(1)`
FP32 recurrent PPO learner with exactly `121,349` active parameters. Actor outputs are `WAIT`,
`SERVE`, `REFRESH`, and `SAFE_FALLBACK`; `WAIT` is forced off at decisions and is the sole legal
action elsewhere. Adapter input columns start at exact zero so update-zero policies are arm-identical.

PPO uses `gamma=1`, GAE `lambda=0.95`, clip `0.20`, value coefficient `0.50`, entropy coefficient
`0.01`, Adam learning rate `3e-4`, betas `(0.9,0.999)`, epsilon `1e-8`, zero weight decay, and global
gradient cap `0.5`. Actor loss excludes forced-WAIT positions; the critic retains zero-reward event
transitions and delayed settlement. There is no auxiliary semantic loss, imitation, full-Q
supervision, replay, target network, reward normalization, early stop, or arm-specific tuning.

Within a seed, arms must have identical primitive histories, masks, initialization outside the
declared adapter, parameter count and precision, interactions, full-episode BPTT, PPO epochs and
minibatches, Adam exposure, checkpoints, held-out roots, common action-uniform draws, and zero model
selection. STRUCT and DERANGED additionally have exact adapter-work parity. The existing
`online.RecurrentQLearner` and `OnlineQTrainer` are `PILOT_ONLY` Q/replay infrastructure: tape,
FP32, checkpoint, vectorization, and adaptation-free evaluation patterns may be reused, but that
learner/trainer cannot instantiate or be reported as `CBSC-OMRC-B01`.
