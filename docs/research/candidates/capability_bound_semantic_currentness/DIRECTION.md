## Scientific question

When independently varied OWNER continuity, semantic refresh, carrier capability, and
receiver-addressed payload content are all observable under matched public history, does current
capability-bound content change the unique native `SERVE / REFRESH / SAFE-FALLBACK` decision and net
team return beyond a competent predictive-index or unrestricted raw-history controller?

The direction separates four axes that the source directions previously coupled or left missing:

1. OWNER lineage is live or broken;
2. content is persistent or conditionally refreshed;
3. binding leaves access open or changes authorization, failure, latency, or acquisition cost;
4. payload is correct for the receiver, swapped, or native-neutral.

## Smallest discriminator

Before learning, enumerate a finite factorial host with the four axes above. Hold authentication,
visible index, controller, randomness, opportunity support, physical time, and cost accounting
fixed. Compare OWNER-aware currentness, optimized content-retaining OWNER-blind control,
capability-matched predictive index, unrestricted raw-history optimum, reset, and neutral payload.

Continue only if capability/currentness changes a unique action and produces positive net native
headroom that neither the predictive index nor raw-history optimum absorbs. If binding changes no
access/failure/cost edge, payload changes no native action, or the ordinary index is pathwise
equivalent, close the corresponding branch before learning.

## Claim ceiling

A positive result supports only net acquire/use value in the frozen protocol. It does not establish
cryptographic security, a necessary semantic representation, learned abstraction, general
communication value, variable-population MARL, UAV transfer, safety, or deployment. Proactive paid
probing and COUNT-versus-RAW efficiency remain `ucope` questions unless a later prospective object
explicitly crosses those interventions.
