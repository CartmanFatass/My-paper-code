## Inference and strongest contradiction

The selected hypothesis is plausible because repeated public OWNER and epoch changes create a
nonlocal currentness state whose native consequence appears only after combining retained event
history with body, receiver, and capability facts. A typed recurrent adapter may improve
finite-budget conditioning. A one-controller POMDP identifies this question without adding sender,
receiver, coordination, or credit-assignment confounds.

The strongest contradiction is exact information containment: STRUCT adds no exogenous fact that a
competent RAW recurrence cannot reconstruct. The exact factorial therefore supports only protocol
value, not representation necessity, and LR01 supplies no robust codec/optimizer advantage. EOCIV
also shows that a large representation response can coexist with unstable or adverse native return.
Accordingly, a positive B01 result would still leave finite-budget conditioning/optimization as the
strongest alternative explanation.
