The existing Boolean hypothesis is specific. At a positive boundary after an armed interval,

absorbing and safety-handoff scopes bypass persistent confirmation. These are contract semantics,
not observed native-return benefits.

## Meaning a selected host must make explicit

The full trace should be: an actual environment event -> fixed entity and role ownership ->
the decision-time observation/history available equally to treatment and generic control ->
the complete/continue or renewal action and its downstream state -> learner exposure if any ->
native return. N stays fixed; no join/leave/rejoin, replacement, survivor migration or variable-N
claim is introduced. If partner state or joint consequence is absent, say so and keep the
single-controller/information-flow ceiling.

Name the primitive clock, boundary opportunities, tied-event convention, initiation and reset,
completion and censoring, horizon and reward aggregation. If a learner uses semi-Markov targets,
discount by actual elapsed primitive time and account for its segment/update exposure. A long
hold must not manufacture an advantage by hiding censored failures or changing the number of
paid opportunities.

One-hit, dwell, debounce and hysteresis are named simple controls; they do not replace a
competent generic history controller. Give the latter every legal event, age, identity and
history field given to the treatment, with fair state and tuning exposure. A current-only arm
can answer information value but cannot establish same-information efficiency. An exact
same-information finite reference is useful if cheap; a privileged oracle is labelled, and
neither is a tuned generic learner result. Exact optimality is not a launch requirement for B.

Ask whether observed event-conditioned action differences would affect native return beyond
delay cost, rate matching, event frequency, ordinary memory, public greedy, censoring or reward
construction. Do not pay reward for agreement with the proposed certifier. A numerical gap,
predictive latch or Boolean divergence alone is insufficient to claim learning value.
