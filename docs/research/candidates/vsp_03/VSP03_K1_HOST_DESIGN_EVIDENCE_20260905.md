The existing Boolean hypothesis is specific. At a positive boundary after an armed interval,
exact boundary debounce completes, whereas the event-latched rule continues if a target-negative
primitive event occurred strictly inside that interval, including an excursion followed by
re-entry. Boundary evaluation occurs before update. Continuing clears the latch and arms from
the current positivity; completion/reset/identity change clears both bits. First-passage,
absorbing and safety-handoff scopes bypass persistent confirmation. These are contract semantics,
not observed native-return benefits.

The current trace therefore ends before any instantiated entity, legal observation stream,
complete/continue action consumer, learner or native return. It remains possible that the useful
question is a single-controller semi-Markov or information-flow problem. A fixed multi-agent
population alone would not establish an irreducible MARL effect.

## Meaning a selected host must make explicit

The full trace should be: an actual environment event -> fixed entity and role ownership ->
the decision-time observation/history available equally to treatment and generic control ->
the complete/continue or renewal action and its downstream state -> learner exposure if any ->
native return. N stays fixed; no join/leave/rejoin, replacement, survivor migration or variable-N
claim is introduced. If partner state or joint consequence is absent, say so and keep the
single-controller/information-flow ceiling.

Name the primitive clock, boundary opportunities, tied-event convention, initiation and reset,
completion and censoring, horizon and reward aggregation. If a learner uses semi-Markov targets,
discount by actual elapsed primitive time and account for its segment/update exposure. A long
hold must not manufacture an advantage by hiding censored failures or changing the number of
paid opportunities.

One-hit, dwell, debounce and hysteresis are available named simple controls, not a mandatory
full arm grid. Select the smallest set that changes the actual question; do not substitute them
for the strongest competent generic history controller. Give that comparator every legal event,
age, identity and history field given to the treatment, with reasonable matched learning and
selection exposure. A full tuning sweep or oracle-retuned comparator is not a B prerequisite.
A current-only arm
can answer information value but cannot establish same-information efficiency. An exact
same-information finite reference is useful if cheap; a privileged oracle is labelled, and
neither is a tuned generic learner result. Exact optimality is not a launch requirement for B.

Ask whether observed event-conditioned action differences would affect native return beyond
delay cost, rate matching, event frequency, ordinary memory, public greedy, censoring or reward
construction. Do not pay reward for agreement with the proposed certifier. A numerical gap,
predictive latch or Boolean divergence alone is insufficient to claim learning value.

## How an exploratory result should be followed

A single real execution with a trustworthy primary measurement and clear comparison can support
a bounded B signal without prior significance, a multi-seed series or complete causal explanation.
For a positive observation the preferred next step is independent training-seed
replication of the same comparison at the same declared meaning and budget, retaining the first
run and every new positive, null or adverse run. One or two new independent training starts are
an economical initial continuation, not a fixed seed-count gate; the actual next card records
its budget and cost. New evaluation seeds or replaying the same trained checkpoint do not substitute for
independent training starts. Not every seed must be positive.

This follow-up does not wait for exact upper computation, full trajectory/state reconstruction,
bit identity, an exhaustive explanatory census or a new Pro round merely to repeat the same B
comparison. A null or adverse observation can also motivate a specifically justified change
inside the selected B family; positivity is neither a universal prerequisite nor unlimited
compute entitlement. A credible local or proxy improvement can guide narrower follow-up, but
must retain native losses, unchanged complete competence and any selection of a best seed,
checkpoint or metric. It cannot be renamed a native-return gain or stable superiority.

Repair an actual defect on which the intended claim depends. A damaged primary measurement
cannot support that dependent claim; trustworthy narrower observations remain reportable.
An independent comparison or publication path need not reconstruct every historical failure if
its non-dependence is explicit. This does not retrospectively change old quarantine or intake
decisions. Numerical checks use the dtype, scale and action consequence relevant to the claim;
exact replay or bit equality is not the default scientific meaning of reproducibility.
Preserve source/configuration/commands, randomness, counts and outputs sufficient to inspect the
real comparison. A targeted check addressing a real defect is different from routinely imposing
a forensic reconstruction programme on every promising B signal.

Paper-level validation is a later and explicitly higher claim: fair development/final-evaluation
separation, adequate training-seed uncertainty, comparator tuning and any promised transfer or
formal properties follow that claim's class. Exploratory replication can reveal instability
without invalidating the original positive observation, and does not by itself promote to C.

## Minimum experiment and removable burden

This is a prospective design review, not a revised budget for an already selected experiment.
The proposed first measurement is one bounded real training comparison against one competent
same-information control on the minimum executable host. Its actual environment steps, model
updates and native-return evaluation remain the algorithmic work. The resulting card must make
those counts and the relevant termination semantics readable. Do not first add a validation
programme and then report that it cannot fit the cap.

| Output and explanation | Retain every training seed, primary measurements, useful learning curves, exposure and any contrary native consequence | No universal intermediate-array dump, full trajectory replay, complete causal explanation or exhaustive ablation matrix. Removing unrequested work reduces the specified work set; its numerical time saving is
**unmeasured**. No new candidate runner exists from which to price these removals, and the old
census or learner wall times do not estimate that saving. Pro should separate required
algorithm/learner work from optional reference, support, checking and output work before
selecting a feasible comparison. Ordinary array batching and an existing valid native path
can be reused where semantics match; a new acceleration framework is not a prerequisite.
