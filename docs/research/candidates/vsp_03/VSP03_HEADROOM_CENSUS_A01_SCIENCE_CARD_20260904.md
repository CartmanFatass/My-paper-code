  controls but do not replace the strongest competent generic baseline.

  bearing updates, optimizer and model-selection exposure, parameter count and initialization
  scale, final parameter displacement, and evaluation exposure as applicable. The upper reference
  has no learner exposure when it is exact; any computational search exposure must still be
  reported. This census creates no new exposure.

- a same-information generic history controller contains the fixed termination rules and leaves
  little or no headroom;
- one-hit/dwell/debounce/hysteresis performance is driven by event frequency, censoring,
  opportunity-time accounting, or reward calibration rather than a distinctive MARL mechanism;
- the problem is currently a single-controller or systems-interface question because no
  multi-agent role/action/credit consequence is instantiated; and

  not negative algorithm evidence.
