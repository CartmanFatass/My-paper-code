### What history can still matter

The strongest ordinary explanation has four parts.

1. **Membership changes physical opportunity.** Removing a server or relay changes
   service, interference and available actions. The first explanation for an
   event-conditioned score change is this physical effect plus current reallocation.
   A roster mask or a storage permutation by itself does not specify missing information.
2. **Identity indexes the controller's commitments.** G0 remembers which reserve
   it sent, the vacated target and the reserve's home stage. That is legitimate
   history and it can govern action. A competent generic controller must retain
   survivor state, carry its own issued assignments, and process the explicit
   old/new lifecycle mapping. Clearing every survivor at an event or feeding a
   replacement the old occupant's hidden state would create an artificial weak
   comparator. For the toy's genuine same-key return, its existing hidden-state
   preservation is the appropriate ordinary rule. These are different lifetimes.
3. **Event age can predict remaining absence without a private entity trait.**
   In G0, after observing onset O and still being absent at time t, age `a=t-O`
   restricts the unobserved duration D to integers
   `max(80,a+1), ..., 100`, uniformly under its fixed independent duration law.
   A recorded onset therefore contains predictive information beyond an isolated
   active-mask snapshot at some times. Whether that prediction changes the best
   service action is unmeasured. It can be represented by an ordinary public-event
   timer or generic recurrence; it is not evidence for typed memory or a persistent
   private teammate characteristic. Before the first event, its independent owner
   and onset draws cannot be recovered from a teammate's pre-event behavior.
4. **Sensing and teammate behavior are separate candidates.** Ordinary S1 local
   observations may omit users/peers currently out of range, so historical geometry
   or inferred motion could matter. G0's centralized current service/geometry
   interface cannot certify that local information as redundant. Conversely, shared
   actor parameters do not make different agents' recurrent states identical or
   observed. A peer-memory hypothesis would need an actual roster-learning path
   where this hidden policy state persists and changes future actions. R09's joint
   feedforward policy and G0's known ordinary controller do not establish that path.

The revised explanation is therefore not "there is no useful history." There is
explicit lawful assignment/event history. The unsupported step is treating it as
evidence for a new entity-memory learner beyond competent generic recurrence and
ordinary commitment bookkeeping. FOLR's adverse repeat further lowers the value
of importing that old augmentation without a distinct native prediction.
