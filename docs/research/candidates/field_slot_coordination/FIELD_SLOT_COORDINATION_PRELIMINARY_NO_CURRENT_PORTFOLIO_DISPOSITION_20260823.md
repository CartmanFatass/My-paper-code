## Decision

Field-Slot Coordination receives no current research, provider, engineering or
experimental investment. This is an explicit preliminary-concept disposition,
not a negative empirical result and not a hidden resource failure.

The current directory contains a useful representation sketch, but no
registered object/revision, complete transition or probability contract,
frozen train/held-out `N`, thresholds, budget, matched full-set comparator,
learning claim, or UAV bridge. The README itself states that it is an inactive
backup concept and that numerical thresholds and the toy contract are
unregistered. Creating CM or provider activity from that state would convert a
representation idea into an open-ended research program without a finite
discriminator.

## Revisit condition

Reconsider only after one meaning-complete paper object freezes:

1. an anonymous variable-`N` host with multimodality, one-per-target
   anti-coordination and a rare critical member;
2. `full_set_reference` and `hybrid_field_slot` with equal information and
   explicit deterministic-slot probability semantics;
3. train and held-out roster sizes, padding/permutation controls, collision and
   rare-member metrics, runtime/memory slopes and finite thresholds/budget;
4. a claim ceiling limited to representation sufficiency; and
5. a concrete route from a representation pass to a later cooperative-return
   and UAV-relevant decision.

A pass would make later learning investment eligible; it would not itself
establish task performance, cooperation, variable `k`, dynamic membership or
UAV transfer. Until that complete object exists, no owner or placeholder task
is expected.
