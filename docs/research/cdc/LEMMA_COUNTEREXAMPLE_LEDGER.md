# HMASD Lemma and Counterexample Ledger

## Retained lemmas

| ID | Statement | Scope | Does not imply |
|---|---|---|---|
| L-H | The registered noncalendar task is structurally reachable under sufficient control authority. | That task and its oracle/control contract. | A learner has access or hierarchy is necessary. |
| L-C | Registered current-demand/error information is useful to the tested learner. | The tested information intervention. | A particular representation is optimal. |
| L-S | One shared four-step renewal restriction loses capability. | The registered shared-renewal control. | Any learned heterogeneous-lifetime mechanism works. |
| L-D | The ordinary recurrent arm shows partial learning without registered access. | The frozen G0 ordinary arm. | Ordinary recurrence is universally insufficient. |
| L-OBJ | Ordinary no-access cannot be a stronger-MARL research admission gate. | Research-direction logic. | Ordinary baselines can be omitted from superiority claims. |
| L-BAT | Usage, exogenous lifetime variation and logit magnitude can admit trivial passing constructions. | The current EHC behavioral battery. | Event-held state is useless. |

## Counterexamples

### CE-RANDOM-USE

A random KEEP/RENEW policy can satisfy nondegenerate usage rates without
demand-responsive commitment. It refutes usage-as-semantics, not event-held
state as a mechanism.

### CE-EXOGENOUS-LIFETIME

Random opportunity spacing can generate lifetime diversity even when policy
behavior carries no lifetime decision. It refutes realized-duration diversity
as sufficient evidence of learned lifetime.

### CE-LOGIT-WITHOUT-BEHAVIOR

An uninformative latent with a large adapter can perturb logits without useful
sequence behavior. It refutes logit magnitude as sufficient behavioral evidence.

### CE-NO-ACCESS-ADMISSION

Failure of ordinary control on one benchmark limits that comparison but does
not imply a structurally different stronger algorithm should not be studied.
