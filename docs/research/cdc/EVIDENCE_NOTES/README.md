# CDC Evidence Note Template

One completed action creates one short note:

```markdown
# <evidence id>

- Question:
- Implicated conjectures:
- Evidence type: derivation | counterexample | reanalysis | toy | prototype | formal experiment
- Frozen semantics:
- Observation:
- Smallest supported or refuted unit:
- Retained lemma:
- Counterexample:
- Does not imply:
- Portfolio delta:
- Reactivation conditions:
- Provenance:
```

Do not rewrite an old note after theory changes. Add a new note that records the
correction and links the earlier evidence.
