## 完整独立科学审查答复

建议把两个空闲名额分别补为 **DM2：护盾接管下的 PPO 更新用途**，**DM4：合法能量信息能否改善普通规划分配**。两条现在都有独立观察价值；不要求同时启动训练。原 DM2 的路径一致性/饱和诊断和原 DM4 的故障响应时钟，**无需继续购买实验**。

证据支持这一边界：DM2 的 136 回合已确认有限覆盖下的 collector/evaluator 一致；随机动作只增加约 1.22 J，却增加 7.75 return cost，未发现所猜测的均值动作水平饱和。DM4 的事件重规划确实把响应等待从 14.38 降至 0，但 QoS 差为 −.01317，CI [−.04895,+.02261]；改善时钟没有转化为完整收益。以上负面结果应随新研究保留。

同时采用 Claude 最新[独立审查更正](https://github.com/CartmanFatass/My-paper-code/blob/0f5d78903911fc5e6422df621d2ffb18098c30b4/docs/research/candidates/energy_relay_benchmark/NOTES.md#L3377)：开发集 SET c06 在原生 J 已计入风险价格后，仍落后 H_local 约 353/348；风险不同不能使这个差距失去可比性。首次 entry 前缺口较大，但时钟对齐后，后段仍有缺口；这尚未识别因果修复点。

**DM2：在相同继续训练预算下，去掉完全被护盾覆盖动作的直接 PPO surrogate，能否改善完整闭环收益？**

这是有限优化方案比较，不是“修正已证实的错误梯度”。现有代码支持：接管模式由当前 margin 和前一模式决定，接管后四维提交动作被全覆盖。不过，递归状态、熵、优势标准化、ValueNorm 和后续参数更新仍有作用；随机 PPO 的相应梯度也可能只是零均值噪声，不能直接称错。

最小完整比较：

- 从同一公开 c03 **完整 learner checkpoint** 分叉，普通 PPO 对比仅屏蔽接管步直接 surrogate 的 PPO；每臂继续 300k，共 **2 started fits、600k 训练步**。这是一个共享初始化的条件比较，不是两个独立种子复制。
- 保留全部递归步、GAE、critic、entropy、ValueNorm、原优势标准化和更新次数；masked 项置零后仍用原有效样本数作分母，不因筛选自动放大学习率。这样仍可能改变梯度尺度，但这是所比较方案的一部分。
- 两臂结束后，以相同 32 个声明的开发世界、两种动作模式比较：**128 回合、384k 评估步**。同时读取 J、QoS、return cost、失败/低电量尾部及实际受 mask 的曝光量。

不同结果会改变不同判断：若 masked 方案在原生收益上有一致改善，值得后续独立复制；若只改善 loss、确定性单模式或均值而恶化重要尾部，不支持“有效控制学习已改善”；若无完整收益，结束这个具体方案，不自动增加轮数或改奖励。

**值得与 DM3 B02 并行。** DM3 判断的是“监督目标是否把学习容量集中到部署时被覆盖的动作”；这里判断的是“奖励驱动的有限 PPO 更新是否受这些 score 项影响”。BC 的正负结果都不能替代这个判断。DM1 仍拥有从头 SET 种子复制，Claude 仍拥有原 Stage 1 解释和自己的后继选择。

预计训练合计约 **4.7–5.7 小时**，评估约 **40–60 分钟**，工程成本较高：mask 贯穿真实 buffer/sampler、完整状态分叉及数值审查。不得省略检查 proposal 是否通过其他内部路径影响后续输入；若有，应先改正科学前提。c03 应从已报告的节点 artifact 路径核验哈希和载入能力，不能假定旧 run 路径仍在。共享训练代码只允许明确、默认关闭的小改动，不触碰已接受运行。

**DM4：相同合法信息与规划时钟下，考虑目标相关能量代价的任务分配，能否改善 H_local 的服务与原生 J？**

直接根据是：当前 H_local 的分配只使用欧氏距离和固定切换滞回，不读每机 battery/margin；而完整 S4 结果存在明显 return cost 和低电量尾部。它尚不能证明能量分配会成功，但提供了具体、可执行的普通规划缺口。

最小完整比较是保留 S4 原生故障强度、30 步时钟、目标生成、合法观测、护盾与充电机制，只比较原分配和 **一个前瞻冻结的能量分配规则**。每臂 32 个配对开发世界、H=3000：**64 回合、192k 步、0 fit**。

该规则必须明确从当前位置到候选目标、再到合法已知站点的预测公式及服务负载假设。**当前 return margin 只描述当前位置返航，不能冒充目标处服务后仍可返航的保证。** 不调整返航阈值，不额外删除困难目标，也不使用隐藏未来信息。

若能量安排改善后同时提高 J/服务并改善风险，支持修订普通规划基线；若风险下降但服务/J 恶化，就是代价交换；若预测余量改善而原生结果不改善，就停止这一规则，不自动扫参数、提高故障强度或追修选中的极端世界。结果只适用于这个 S4 包，不能直接解释 S7 的学习差距。
