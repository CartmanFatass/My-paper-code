### Root hypotheses about the problem, to be challenged

以下是待批评的工作解释，不是已识别的失败成因。

1. **科学问题与方法增量可能失衡。** 我们较善于完成“这个改动在一个宿主/预算下是否更好”，
   较少收敛出某类信息、耦合或有限学习条件下的可迁移认识。晚进入的强普通基线和反复反号是实据，
   但不证明每次探索都没价值，也不要求每个探索先识别机制或保证新颖性。
2. **确认目标可能替代了贡献目标。** B02的窄正号主张是事前固定且通过，不能撤销；然而确认概率
   与平均收益、教师能力保留、实际成本及方法新颖性不同。B15/B20/C01的小n区间也不能靠“符合3–5
   seeds”保证精度。请评估何时值得确认、何时应继续发现条件或结束，而不是降低统计标准求阳性。
3. **DM可能围绕批次而非问题形成惯性。** 现行宪法和角色已明确要求问题连续性、允许新猜想/转向，
   也允许合理停止；实际最新A/R均认真比较若干后继后停下，不能直接指控违规。要判断其比较是否
   过于泛化为“没有已知机制所以不投”，以及Root是否把问题责任切成了一次次配方交付。
4. **负结果后的反思可能偏于限定措辞。** 限定范围必要，但“不能证明X、也不排除Y”堆积，若不改变
   下一项有价值的选择，就不等于累积科学解释。另一方面，并非每个阴性都必须找出可修机制或继续救援。
5. **执行负担可能有重复，比例尚未测量。** 两方向有作者、工程Reviewer和ResearchCritic的数值/原始
   产物复核，亦有Git/远端控制同步、Pro交付和工作树收尾。源码/信息泄漏、真实更新、独立数值检查、
   同一操作恢复有明确用途；重复核对同一不可变结果是否还值代价要看具体记录。不能由NOTES长度、
   工具调用数或总历时臆造工程/咨询占比，未测成本不是零。
6. **规则已有减负条款，落实方式可能比新增规则重要。** 当前允许小规模完整探索、咨询复用、按风险
   检查、短L0、可选委派；不要求正toy、定理、穷尽反事实或填满三槽。owner刚已改为main方向目录、
   取消整树/重复备份，不得把这些旧负担当作尚未处理的新建议。需要区分现行规则本身与执行习惯。

七、工作流：删掉重复动作，而不是删掉证据

我建议优先简化三类具体动作。

**第一，停止对未改变的不可变材料反复作同一层次的全量核验。**已经绑定来源、完成保全和独立读取的旧结果，应通过现有 Git、runs 元数据和 NOTES 复用。新增 runner、归约器或数据路径变动时，检查受影响依赖；不要因新增一段解释便重新逐个核对全部旧轨迹、权重与历史记录。相同 JSON 被三个人各读一遍，不自动等于三次独立数值验证。

但必须保留一次真正独立的数值读取：从适当的原生紧凑结果或数组重建关键差值、分析单位和冻结判读，并在数值路径发生实质变化时重新核对。删除重复阅读，不等于把作者的汇总当成不可质疑的原始事实。

**第二，不再人工复制工具已经写出的机械事实。**launch manifest 中的节点、命令、SHA、输出和原生身份以引用为主；普通 wait checkpoint 不应变成重抄全部计数、全量重读背景和同步所有方向状态的任务。原生 wait 观察同一已接受句柄；断线或 timeout 不等于终止，不能因此重新启动 worker。方向索引只在实质结果、计划、负责人、暂停或真实依赖变化时更新。现行工程方法已经明确支持这些边界。

**第三，按所改变的决策复用科学意见，按所改变的行为安排工程审查。**既有完整 Pro 已覆盖的结果分支，不需要为读出同一冻结结论再次咨询；科学 Reviewer 已完成的适用重建，不需要再叠一轮同类意见。纯文档修改不自动召集工程 Reviewer；可选 Implementer 也不应成为每次小实现的固定中转层。

三种工作仍各有不可互换的价值：

科学咨询与独立纠偏问“这个问题值得买吗、最强替代是什么、什么证据会改变方向”；工程复核问“实际代码是否实现了声明的比较与合法信息边界”；独立数值读取问“输出是否支持这里的数值与统计结论”。不能让每个角色都重复完整流程，也不能用其中一项替代其他两项。

下一批必须保留的真实性检查，应直接针对新干预：D 的身份与阶段边界；O/S/BC 的共同初始化和匹配批序；教师标签、mask 与时序未被置乱；S 的阶段／标签权重多重集和保存映射；原生参数确实更新；评价没有更新或教师查询；计数包含所有已启动 fit；共同面板匹配；所有不利结果与技术失败保留。完整数据和旧冻结 runner 不被改写。源 SHA、实际节点准入和同一操作恢复也不能因“只有几分钟计算”而省略。

历史检查有明确收益：A 的输出／计时和失败恢复、R 的半队 GAE／ValueNorm／采样，以及咨询交付中把作者 Decision 与真正 Answer 分开的修复，都不是可以整体取消的形式主义。相反，工具事故应优先产生局部修复或明确保留风险，而不是为所有后续研究增加一套永久证明材料。

main 方向目录、取消整树和重复备份已经是当前规则，不应再把它们列成尚未落实的新改革。保留唯一必需证据与冻结合同，复用已有验证副本；不要求“备份一个备份”再退休工作区。成本计量优先使用现有日志可得的范围，完整支持成本未知就保持未知，不先启动一场新台账或测量工程来取得研究许可。
