二、radio 的阳性究竟新增了什么

B01 最重要的结果不是“枚举能在自己的预测目标上优于全开”，而是：在延迟报告、静默导致的发现损失、继续运行的普通运动控制和完整闭环轨迹之中，静默控制仍产生了较大的平均原生收益。

完整世界配对差	平均原生 J 差［描述性 t95］	平均服务人数／tick 差［描述性 t95］
G−A	+0.115009［0.099886, 0.130132］	+7.396606［6.298708, 8.494505］
E−A	+0.119393［0.104491, 0.134296］	+7.781250［6.690212, 8.872288］
E−G	+0.004385［0.001026, 0.007743］	+0.384644［0.038274, 0.731013］

这些是 64 个配对重置世界上的条件性普通控制结果，不是训练程序的复制，也不是物理部署验证。G/E 的非全开选择分别发生于 3,955/4,037 个调度轮次，平均激活发射器约 3.446/3.371 架，说明收益来自实际持续使用的控制能力，不是未激活接口上的偶然读数。

最强建设性解释是：此前每架 UAV 同时承担的“移动平台”和“持续干扰源”两种角色，现在可以部分分开。普通 C 已提供有用的局部运动；G/E 可以暂时减少不合算的发射，让其余成员获得更多有资格的服务连接。即使静默也损失服务资格和发现能力，这个交换在大部分完整世界中仍然合算。它因此提供了一个可以发展的普通控制基础，而不只是又一个需要被学习器击败的分数。

最强简单解释同样有力：相当部分用途可能已经由廉价的干扰削减取得，运动和静默之间未必还留下值得搜索的额外选择。G 已获得主要平均收益；E 的额外收益值得保留，却远小于两者对全开的差距。进一步增加运动搜索、承诺和报告内容，可能主要增加陈旧决策与维护成本，而不是增加服务。

不利证据使这种担心具体化：

在 29305038，G/E 相对 A 均损失 0.055369 J、5.710938 人／tick；但在它们各自已经走出的同一记录几何上，掩码相对全开仍增加 0.081003 J、5.007813 人／tick。因此，“即时无线选择有用”与“由它诱发的整段轨迹更好”不是同一个命题。这个反例没有唯一识别感知损失、C 的评分规则或第四步预测为原因。E−G 还分别有 13 个 J 损失世界和 14 个服务损失世界，质量均差为 −0.003335、区间跨零。没有零服务 tick、最低服务未下降，也不能消除 p10 和持续服务的损失。

原预测的 +5 位置误差显著大于 +2…+4，确实指出了跨越下次运动选择的失配；但把它当成唯一修复目标，会把新能力问题缩成一次预测修补。我建议问得更实质一些：给普通控制器真实的运动—静默共同选择权，它能否创造比“先按自己的局部规则飞，再选择哪些发射器静默”更有用的完整路径？

逻辑上，这个问题以前也可以提出。现在新增的是它的可执行基础和有力参照：不必先训练出一个胜任的全动作学习器，才能测试这个耦合；同时也不能只胜过旧弱学习器，就声称取得了新的控制能力。

本地历史 B02 的全部 96 个 L1−C 配对双降、TRDL B03 的三个 own-tail 差均负，限制的是各自已完成配方。它们既没有否定经验学习，也没有为无线追加 learner 提供理由。B05 三个区组的有界续训正均值则保留了另一种可发展能力，但近常量解释只在一个端点上被检查，不能直接宣布状态依赖已经没有用途。

这一点需要明确：LocalController(history=False) 仍有 _nav_index 等巡视状态，act 也保留自己的建议命令。新控制器必须分开记录 C 建议、已经承诺的命令、实际执行命令，不能把 C 内部保存的建议字段当成环境真实执行动作，更不能沿用“冻结 C 所以冻结轨迹”的解释。

为限制完整首比较的搜索成本，每轮只允许修正一架按固定循环顺序选中的 UAV；其余四架执行各自已上报的 C 建议。被修正成员可以选择全部 27 个原生命令，包括 C 原建议。这是算法的有限搜索范围，不是虚构现实中只有一架飞机能移动，也不是对全队联合最优控制的主张。

四、判别预测、完整读数和停止条件

我的建设性猜想是：某些运动只有与不同静默选择一起考虑才合算，分步搜索会遗漏这些组合。T 应实际改变部分运动—掩码选择，并在完整任务上同时增加平均 J 和服务；它还应相对 R 而不只是相对 S 有用途。

最强的反向预测是：E 已吸收主要干扰机会；C 建议再延迟一块，或短视联合搜索把成员带到不利的后续几何，足以抵消局部增益。共享背景中已有普通规划实际改变动作、却未增加完整净用途的反例，这正是需要强 S 和原 R 两个比较器的理由，而不是“多搜索总会更好”的依据。
