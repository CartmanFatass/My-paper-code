# 迭代 30：首个正式 D7.S 审计结果——有效观测，但材料性尺度不可识别

本轮是一个**完整工作流**的收尾：从上一轮 Pro 的 ALIGNED 裁定开始，经代码决策、

## 结论

正式审计 run `30289161086`（tag `d7s-audit-2`，8/8 分片一次成功）返回**非肯定性
结果**。仪器记录的分支是 `SOURCE_NECESSITY_UNRESOLVED`；Pro 裁定这是**错标**，
按冻结契约的正确处置是 **`PRIMARY_G_DEGENERATE`**（分支 3）。

Pro 的耐久结论，原文引用：

> D7.S R3 produced a valid matched observation but an unidentifiable materiality
> scale. The result closes this measurement route, not the heterogeneous-renewal
> research question.

即：**这条测量路线关闭了，异质续期这个科学问题没有关闭。**

## Pro 纠正了本会话四处

1. `b_m_positive_lcb` 的跨肢聚合应为**析取**而非合取——合取会让一条失败的肢体
   抹掉另一条肢体的有效结果，与冻结分支 7–9 冲突。本轮两肢皆负，两种读法同解，
   所以这个错误在本轮**不可见**，以后才会咬人。
2. **LCB 非正不等于真值 `B_m` 非正**。点估计是正的。可辩护的说法是"未能确立正的
   校准对比"，不是"constructive 被证明不优于 null"。
3. `PRIMARY_G_DEGENERATE` **不**意味着 primary `G` 本身有缺陷，被指涉的是
   目标–比较子–归一化子这个**测量对**。
4. 两个分支标签**从来不是相反的下一步实验**——本会话在提问中自我更正的那一条被
   接受，而它恰是承重的：§9 因两个 `T_m` 点方向皆错而独立禁止扩展。

## 本轮的四项工作流修订（用户裁定）

1. **一次 iteration = 一个完整 Pro→Pro 工作流**。上一会话报"十次迭代"实为单个
   工作流内的 23 次提交、零 Pro 轮次。
2. **Pro 负责一切科学决策**，包括 run 是否有效、缺陷严重度、证据是否收口——旧的
   "是否改变注册量或分支"判据过窄。此前"Pro rounds 只对齐关键算法"仅约束
   **实现前对齐轮**，不是对 Pro 权限的收窄。
3. **一个工作流的 Pro 访问次数固定为三次**：科学决策、代码计划评审、结果提交。
   轮次关闭后出现的新材料进入下一轮计划评审，不得追加回合。
4. **收敛由 Pro 单方作出**。旧定义"双方陈述一致才算收敛"没有终止动作，任一方
   拖住即无限 pingpong。分歧不构成收敛失败；不可执行才是技术阻塞。
