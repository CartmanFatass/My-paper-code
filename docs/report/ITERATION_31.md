## Pro 纠正本会话七处，两处最重要

1. **"归一化子与效应无关"不成立**。这是本会话的推断，被驳回：关联区间同时涵盖
   强正与强负关系，留一拓扑估计不稳定。可支持的说法是**"相关性未被证明"**，
   而不是"无关"。本会话把它标注为 inference，这正是它可被纠正的原因——但本就
   该直接写那句更弱的话。
2. **本会话提交的两个聚合候选并非两个**。"所有配对相等即不变" 与 "任一配对不等
   即可分" 是**严格互补**的同一条规则。把它们并列为备选是逻辑错误。唯一真正不同
   的分数阈值方案被否决，因为它会凭空造出未登记的阈值。

其余：`PRIMARY_G_DEGENERATE` 不等于 primary `G` 有缺陷；N5 的 "raised" 是**假设
状态而非验收检验**；剖析不得自动决定 R4；本会话设置的 fail-closed 默认被明确认可。

## Pro 还查出剖析脚本的三处真实缺陷

**N1 行被整行废弃**：调用处把 stable 与 flex 的逐拓扑向量**拼接**成 16 元向量，
却只用 `U*_stable` 的区间与 stable 的留一点去评估它——混合了两个视界、两个因果类、
两个尺度不同的 `B_m` 分布和两个 `U*` 方向。本会话对照源码复核，确认属实。

**N4 "material" 夸大**：只有 `B_stable` 的调整比非零，其余三个恰为零。
**N2 过于合取**：把"两腿都 resolved 才算 resolved"，而裁定说任一腿即可 raise。

三处均已修复并重跑。**程序化核对**（非目测）：哨兵、Section A 四个标准分布、
留一拓扑、N5 关联块在两次运行间**逐字节相同**，只有那三行判定改变——与裁定
"不影响四个标准分布与 R4 决策"的预判完全一致。
