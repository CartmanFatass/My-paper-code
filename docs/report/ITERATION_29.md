# 迭代 29:最便宜的扫查是那种什么都不读的

日期:2026-07-27 · 分支 `untied-k` · 支撑性工作,不消耗结论性迭代额度
(授权余量维持 17)。

## 方法换了,这轮是它的验证

迭代 28 收尾时点名了自己的成本:确认干净项花掉了大部分读代码时间。定下的削减是
**先拉差集,再只读差集里的项**——生产端的条件/reason 清单对拉测试端的断言清单。

本轮照做,并且往前推了一步:**把"读"整个去掉**。变异一个值再重跑,这件事对意图
完全盲目,所以**没法被一个看起来合理的测试名说服**——而前八例能活这么久,靠的正是
测试名看起来合理。

三次扫查,两次干净,一次不干净。

## 扫查 1 — reason 字符串差集:干净

生产侧每个 `reasons.append(...)` 字面量,对拉测试套件里被断言过的每个字符串。
**每一条 reason 都在某处被断言。** 无缺口。

这次干净的代价是我自己工具里的两个假阴性,值得记,因为它们和我要抓的缺陷是同一形状:

- 抽取模式 `[a-z_]+` 悄悄漏掉了 `displacement_exceeds_X`——大写字母提前截断匹配,
  工具把截断后的名字报成"已覆盖";
- 备选分支写了 `(?:`,那是 PCRE;`grep -E` 是 ERE,整条引号字面量分支什么都没匹配到,
  却报了成功。

两个都是**静默地朝安全方向失败**:扫查报出的覆盖率高于它实际测到的。一个少报缺口的
工具,和一个不能变红的测试是同一种失效,只是高了一层。

## 扫查 2 — 排除原因变异:干净

`mutsweep.py` 逐个删掉八处 `reasons.append(EXCLUDE_*)` 再跑套件。**八之八全红。**
零未守卫。

## 扫查 3 — 常量扰动:16 之 6 未守卫

`constsweep.py` 把每个注册常量挪一步再跑全套件。**十六个里六个不可见:**

```text
REJOIN_BATTERY_RATIO   0.80 -> 1.2          不可能的比值 —— 依然全绿
DELTA                    10 -> 11
H_STABLE                139 -> 140
N_CALIBRATION_EPISODES    8 -> 9
N_AUDIT_EPISODES          8 -> 9
BOOTSTRAP_SEED   2026072601 -> 2026072602
```

分诊确认**六个全部落在活路径上**,没有一个是死配置,所以没有一个能以"无害"打发。

`H_STABLE` 最刺眼,刺眼的原因是结构性的而非数值性的:**`H_FLEX` 被抓到了,
`H_STABLE` 没有。** 对称的一对上出现不对称的守卫,是覆盖"长出来的"而不是"设计出来的"
签名——没有人决定过一个视界要钉住而另一个不用。而 `H_STABLE` 定的是 `T_stable` 的
测量窗口,悄悄改它就是改估计量本身。

`REJOIN_BATTERY_RATIO = 1.2` 最清楚地说明这把扫查测的是**缺席**而不是容差:电量比值
大于 1.0 不是细微漂移,是不可能,而套件没有察觉。

## 修复

`test_every_registered_constant_matches_the_frozen_contract` 钉住**十八个**常量——
扫查覆盖的十六个,加上扫查没够到的两个——期望值取自**冻结合约,不取自代码**。这正是
关键:一张从代码里读出来的表是复述,任何漂移下都绿,那就是本系列第一例的重演。出处为
R2 `:119-120`(视界)、`:63`(Delta)、`:38`(rejoin 比值)、`:227`(自举种子),
其余取 R3/R2 第 8–9 节。

docstring 里带一条给下一个撞上它的人的常设指令:

> If a value here and in the contract disagree, the code is wrong until a round
> says otherwise -- never edit this table to match the code.

`test_the_registered_topology_seed_sets_are_exactly_as_frozen` 同理钉住两组拓扑种子:
任一处的悄悄编辑都会改变审计抽样的总体。

## 配对反例,这次是系统性的

规则要求一个能把守卫推红的扰动。本轮修复的扰动不是一个手写用例,而是**重跑那把找到
缺口的扫查**。修复后 `constsweep.py`:

```text
unguarded: 0 of 16
```

每个常量都被抓到。这是配对反例最强的形态:**量出洞的仪器量出它的闭合**,于是"已修复"
不是一个论证,而是同一次测量返回了不同的数。

244 项测试绿,生产代码未改动。

## 干净项的价值

三次扫查里两次一无所获,本报告用同等篇幅记录它们。**一份只报命中的扫查,不提供任何
关于覆盖面的信息**——没有扫查 1 和 2 在案,下一个读者无法区分"reason 字符串查过且
无恙"和"从来没查过"。否定结果就是覆盖率主张本身。
