# 第一轮来源与概念核查

本次四专题为 RL、MARL、层次/异步技能、实证方法；Luna 负责检索初稿，原对话负责合并与核查。以下错误或含混已发现并在综合稿中修正，不可把初稿直接当权威：

- Stanford 镜像 https://web.stanford.edu/class/psych209/Readings/SuttonBartoRL.pdf 的封面是 Second edition, in progress / Draft / copyright 2014,2015,2016，PDF共455页。它不是2018正式版。第9章从草稿印刷p191，第13章p265；不得把这些页码归到MIT Press 2018正式第二版。2018正式版书目（ISBN9780262039246、552页）单独核实；其正文阅读状态必须如实记录。
- 共享reward只说明完全合作；Dec-POMDP还需明确分散信息/观测历史和决策结构。不能以共享reward一项就完成模型分类。
- 固定动作保持可以是合法固定option；启动集和终止规则可固定或隐含，不要求三个组成部分都可学习或分别是网络。
- option边界上的SMDP表述需要适当Markov条件；history-dependent、部分观测或异步并发情形需看状态/历史结构。
- 正比例reward缩放的策略排序不变性不要求无限时域或精确求出最优策略；在目标、策略集合、折扣、时域和终止语义固定且return存在时，J'=cJ。实际有限优化可受尺度影响。常数平移另须检查是否产生策略相关的累计常数。
- action-independent baseline在适当采样条件下不改变policy-gradient期望；任意baseline不保证降方差，近似critic/bootstrapping的偏差也不能与此恒等式混为一谈。有限样本不自动意味着有偏。
- 非Markov observation仍可定义条件期望E[G|O]；困难是用observation本身作为充分状态作闭合Bellman递推。
- 固定参数策略的条件动作分布会随观测/历史改变。记忆、信念更新、规划重算、参数训练须区分；一般learning概念不能被缩成只有梯度参数更新。
- CTDE不规定某个具体团队变量永远只在训练可见；执行期已允许的团队摘要可以输入actor。
- seed只是随机性标签，独立/配对依据来自实际生成过程；端到端方法比较和单因素机制归因需要不同控制，不形成通用启动清单。
- 通信信息建模允许采用明确的理想化假设，不强制本次新增延迟等机制。
- 参数共享的表达限制取决于输入/身份等设计。
- latent条件策略也可配合固定/隐含持续和终止规则形成option，不能要求独立网络。
