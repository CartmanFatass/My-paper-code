# RL：任务、价值、策略与学习

本稿由 Luna 检索初稿经原对话修订而成。以下用有限或回报存在的 discounted 任务说明概念，不将其自动推广到平均回报或其他设定。

## 任务和策略

MDP 的 state 应足以预测给定动作之后的相关未来分布；reward、转移、折扣、初始分布和终止处理共同定义目标。POMDP 则限制策略能取得的信息。策略可以是 observation 的函数，也可以依赖整个可用历史。关于“最优策略”的说法始终相对于任务、信息和允许的策略集合。

Return 是 reward 沿时间的累计；价值函数是在指定策略及条件下对 return 取期望。例如 \(V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]\)。状态充分时可以使用相应 Bellman 递推。即便 observation 不满足 Markov 性，只要可积，\(\mathbb E[G_t\mid O_t=o]\) 仍有定义；不能据此把 observation-only Bellman 闭合当成已成立。

策略评价估计给定策略的后果，控制寻找更好的策略，模型学习估计转移或 reward，规划使用模型推演。一个系统可以组合这些过程，不能仅凭“使用网络”判断它是哪一种。[教材版本及对应章节](../sources/READING_MAP.md#b1)

## 数据与更新

RL 的数据不是与策略无关的固定样本集：行为会改变下一步能看到哪些状态、动作与后果。探索使学习有机会发现当前策略尚未掌握的行为，利用则依据已有估计取得回报；怎样安排二者取决于任务和学习方法。增加网络容量不能凭空补回从未获得的相关经验，探索噪声或熵奖励也不自动等于有用探索。

Monte Carlo 估计使用实际经历的后续回报；TD 使用 reward 加后续价值估计作更新目标，例如非终止一步目标 \(R_{t+1}+\gamma\hat V(S_{t+1})\)。这种 bootstrapping 可以较早更新，也会把价值估计误差带入目标。多步方法、模型推演和策略梯度可以用不同方式组合数据与估计，不能简单把“更接近真实 return”当成有限训练中总是更好的更新器。

在 on-policy 学习中，数据来自当前或相应更新阶段的行为策略；off-policy 学习则允许目标策略与行为策略不同，需要看估计器如何处理这种差异。数据相关性、探索覆盖、采样分布和函数逼近会影响实际学习，经验池或策略梯度的名称本身不消除这些问题。

Tabular Q-learning 的经典收敛结论带有访问覆盖、学习率等条件。它不能直接成为任意深度网络或同时学习的多智能体系统的收敛保证。[Watkins & Dayan，1992](https://www.ece.uvic.ca/~bctill/papers/learning/Watkins_Dayan_1992.pdf)

策略参数固定时，条件动作分布仍会随观测、历史或内部记忆变化。本文把“参数学习”用于区分训练更新和执行状态递推；这不否认统计学习中也使用贝叶斯更新等更广的 learning 含义。

## 策略梯度、baseline 和 critic

对当前策略条件采样的动作，在可交换微分与求和/积分等正则条件下，动作无关 baseline 满足：

\[
\mathbb E_{A\sim\pi_\theta(\cdot\mid s)}
[b(s)\nabla_\theta\log\pi_\theta(A\mid s)]=0.
\]

因此，它不改变相应策略梯度估计的期望。这里 baseline 在 actor 梯度中作为控制变量使用；若它有参数依赖，不能把额外的 baseline 导数混入这个结论。合适的 baseline 可以降低方差，任意 baseline 不保证降方差。有限样本本身带来估计波动，并不自动造成偏差。

近似 critic、bootstrapping、截断及分布不匹配可能引入其他误差，不能与上述零期望恒等式混同。兼容函数逼近的策略梯度定理同样有明确条件。[Sutton、McAllester、Singh、Mansour，1999](https://proceedings.neurips.cc/paper_files/paper/1999/hash/464d828b85b0bed98e80ade0a5c43b0f-Abstract.html)

PPO 属于策略优化方法，Adam 属于数值参数更新方法，actor–critic 描述策略与价值估计的组织方式。它们处于不同概念层次。实际训练效果可以受到网络、归一化、裁剪和更新安排的实质影响；不能从算法简称推断这些设置都等价。[Engstrom 等，2020](https://arxiv.org/abs/2005.12729)

## reward 变换的边界

若所有其他任务条件和策略集合固定、return 存在，且 \(R'_t=cR_t,\ c>0\)，则每个固定策略满足 \(J'(\pi)=cJ(\pi)\)，策略排序和最优策略集合不变。这不要求无限时域，也不要求实际训练能精确求得最优解。梯度尺度、学习率、正则项、裁剪及数值误差没有同步变换时，训练轨迹和最终学到的策略仍可能不同。

常数平移 \(R'_t=R_t+b\) 要看累计项：

- 固定长度 \(H\)：增加同一个 \(b\sum_{k=0}^{H-1}\gamma^k\)，保持排序。
- 策略影响终止时间：累计常数可能不同，排序可能改变。
- 真正持续、固定 \(\gamma<1\) 且各策略都持续累积的任务：增加 \(b/(1-\gamma)\)。不能忽略终止或吸收状态的具体处理直接套用。

Potential-based shaping \(F(s,a,s')=\gamma\Phi(s')-\Phi(s)\) 在相应假设下保持策略最优性；episodic 边界需要正确处理终止势函数。一般 shaping、reward clipping 或其他非线性变换没有这样的自动保证。[Ng、Harada、Russell，1999](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)

## 对当前讨论的作用

先说清策略获得什么信息、优化什么 return，再判断一个机制改变了表达、数据还是学习。固定参数的执行适应可以是有实质能力的研究对象。是否值得增加记忆或结构，要联系任务中的缺失信息、时间依赖和学习困难；不能从“更复杂”直接推出“更好”。
