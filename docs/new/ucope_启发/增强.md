# UCOPE 启发与增强

## Portfolio 结论

保持 PARKED，不并入 CBSC。R03 独立边界关闭；只保留“共享策略根据可观察 currentness/belief context 决定是否支付诊断成本”的新 acquisition 问题。

## Insight 与数学支撑

R03 解析宿主存在正 acquisition headroom：`Γ=I+D>0`，但第一冻结门即失败——90/90 learned slots 支持不足，三组 competence 全假，所有下游 contrasts unresolved。结论是固定预算非识别，不是 paid probe 失败。

三个 panel 又分别训练独立权重，根 observation 没有 episode-level acquisition-value context；实际学到的是各环境一个常数 PROBE/COMMIT，而非共享策略何时 probe。iid Bernoulli 下 count `N=ΣY` 是充分统计量，RAW 严格包含 COUNT，所以 COUNT 优势只能是 finite-resource invariance/optimization bias。

## 可增强方向

新宿主首先应有一个共享策略覆盖 linked/severed、high/low reliability 与不同 probe cost；exact BELIEF optimum 必须在不同可观察 context 中产生唯一 PROBE/IMMEDIATE flip。运行前由固定 behavior policy 验证 root、tail action 与 count cells 支持，BELIEF competence 先过门。第一阶段只判 net acquisition；COUNT residual 必须另用 fixed dataset 比较 COUNT、RAW 与训练期 permutation-invariant RAW，不使用事后 perm-average。

若 action flip 缺失、probe 直接收益非负、支持/competence 失败或 acquisition LCB 不为正，则停止。CBSC 可提供 currentness/capability host，但 UCOPE 的主动付费干预和支持问题保持独立。
