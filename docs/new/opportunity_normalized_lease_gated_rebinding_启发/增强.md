# ONLGR 启发与增强

## Portfolio 结论

进入过渡 PARK，不再购买 standalone link。完成现有 review disposition 后关闭标签，只向 SCDMP 转移 common physical-rate control 和 service-minus-cost 记账，不转移结果极性。

## Insight 与数学支撑

两种归一化保持不同不变量：

\[
q_\Delta^{EXP}=1-(1-r)^\Delta
\]

保持 survival semigroup；

\[
q_\Delta^{RATE}=\min(1,\Delta h)
\]

在未饱和时保持 executed physical rate。七 tick 精确对象中 `RATE > EXP > RAW`，RATE 接近 unrestricted memoryless ceiling；EXP 虽增加 service，却付出更大 action cost。由此识别的是冻结 service-cost 标量化下的 common-rate operating point，不是 hazard、lease 或 REBIND 机制。

更强的 age/expiry-conditioned 策略显著高于 RATE，说明主要限制是 state-blind memorylessness，而非 link 形状。

## 可增强方向

只把 RATE 当作 SCDMP 的 order-erased/clock competence control。若仍检验 link transfer，必须在 `{1,4}` 拟合后对结果前冻结的第三 spacing 零调参评估，并保留 unrestricted-q、KEEP、charge-matched shell 与 age ceiling。EXP 只有在 held-out cell 明确胜 RATE 且两者有 direct headroom 时，才保留局部 link-transfer；RATE 再次吸收则彻底关闭。
