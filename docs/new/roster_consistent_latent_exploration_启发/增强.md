# RCLE 启发与增强

## Portfolio 结论

关闭 public-plan object，方向 RECAST/PARK 为 private-state churn exploration continuity。若新的 comparator 仍获得完整同一状态和计算能力，则直接关闭。

## Insight 与数学支撑

若 `π_CARRY` 是 competent `Π_REPLAN` 的成员，且信息、动作、动力学、时钟、目标与相关随机性相同，则取 `π_R=π_C` 可逐时得到相同轨迹律，因此

\[
\inf_{\pi\in\Pi_{REPLAN}}L(\pi;h)\le L(\pi_{CARRY};h).
\]

正确结论是 REPLAN attainable set 包含 CARRY endpoint，不是每个任意 REPLAN 实现都不劣，也不是 Pareto frontier 必然嵌套。公开、同信息 persistence 没有独立物理价值；真正反例必须来自 private setup/recurrent state、去中心化信息、有限共同随机性或计算期限。

## 可增强方向

构造 public history/current physical state 完全相同、仅 survivor-private state 或 correlated exploration sample 跨 leave/rejoin/replacement 不同的 cross。比较 carry 与同 local information、communication、capacity、updates 和 work 的 decentralized belief/recompute。主端点为 post-churn recovery time 与 integrated unserved demand。若优势只因 reset 被剥夺信息，则仅支持 information retention；只有 same-private-information comparator 仍不能在期限内吸收时，才支持 continuity inductive value。
