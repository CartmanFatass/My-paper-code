# DEARS 启发与增强

## Portfolio 结论

关闭独立 dual-receipt 标签，将 OWNER-currentness 变量并入新方向 `capability_bound_semantic_currentness`。这不是把 DEARS 的正结果外推到 capability/security，而是把其最小 deterministic lemma 作为 factorial 控制。

## Insight 与数学支撑

R02 固定 authentication 与 SKILL_LEASE 为 live，完整 verifier 退化成一个 OWNER-edge predicate。若

\[
\rho=P(b_{cur}=b_{old}\mid H_{pre}),
\]

即时最优动作值为 `|2ρ-1|`、probe 值为 `1/2`，则 probe 仅在 `1/4<ρ<3/4` 唯一最优。R02 人为设置 live `ρ=1`、broken `ρ=1/2`，所以它证明的是该 stipulated law 下的 serve/probe Bayes rule，而不是 OWNER break 自然导致 semantic refresh。

保留/验证成本为零时，优势只是 gross protocol accounting。必须比较优化后的 content-retaining OWNER-blind 控制，而不是 bit-deleted reset 或固定 stale-use strawman。

## 可增强方向

在 CBSC 中独立交叉 OWNER exact/broken 与 content persistent/refreshed，再交叉 capability open/gated 和 payload correct/swapped。冻结跨格 prior、retention/verification/refresh cost，比较 OWNER-aware、优化 OWNER-blind、capability-matched predictive index、raw optimum 与 reset。只有 currentness/capability 在扣除成本后改变唯一 native action，且普通 index 无法复现，才进入学习。
