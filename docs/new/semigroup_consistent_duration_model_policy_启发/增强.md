## Insight 与数学支撑

当前方向混合三个对象：固定动作的 elapsed-time transition/reward composition、H/R event maps 的非交换性，以及 order 是否改变原生最优动作。前两者不推出第三者。当前 `k` 是环境外生输入，policy 不选择 duration 或 termination hazard，因此不是 learned variable lifetime。

冻结 product-measure/two-fold selector 不能保持 oracle opportunity：存在 common-optimum table 使真实 `Q*=D*=0`，selector-based quantity 却全部过门；也存在 disjoint-optimum table 被旧 `Q` 错判为零。独立估值消除样本复用，却不能消除 differential selector regret。

最重要的新 insight 是：2×3 assay 的真正结论对象不是四个逐图 contrast，而是 matched mapping 相对三个 graph-blind simplex 顶点的价值差：

```text
G_RH     = 0.5*d_1m
G_HR     = 0.5*d_0m
G_COMMON = 0.5*(d_0c+d_1c).
```

三者均为正当且仅当 matched mapping 优于 `{A_RH,A_HR,COMMON}` 上所有 fixed/randomized graph-blind policy。旧规则强制 `d_0c>0` 且 `d_1c>0` 是无关加严，并不是原 claim 的必要条件。

共享 tape 只提供 common-random-number 降方差，不供给 sign symmetry 或 action/graph-label exchangeability，所以 Student-t、sign-flip 与 permutation 均不合法。有界 Bernoulli-KL/Chernoff 只需独立有界 tape blocks，不需对称或分布族。

因为唯一可发布的科学结论是“三项全部为正”的单一 conjunction，可用 all-or-none intersection-union test：每项按 `alpha=0.05` 检验，只有三项全过才整体发布。任一 null 为真时，错误发布概率不超过 `0.05`。这不授权单独引用某个 component；唯一 95% 下界是三个 unit-range-normalized gap 最小值的 `L_theta`，其为正与 `V_A>0` 等价。

## 可增强方向

先定义完整联合初态律和 competent order-erased foundation，再做 `2 graphs × 3 precommitted actions`：两个 graph-matched actions 与共同保守 action。冻结一个可达公共初态、一个 `k`，六格共享 paired future tapes但 tapes 不参与 action selection；首 hold 后交回同一 foundation。直接计算 graph×action interaction 和 candidate-set order value。任何 foundation/alias/action-headroom 门失败都在 adapter 前停止。

最小可实施增强已冻结为 `n=562` independent tapes：23 个 width-144 切片加 1 个 width-60 尾片，共 3,372 cells。三个整数门限是 `21,046 / 21,046 / 42,091`。在每个 gap 的真实均值为其完整 support range 的 `0.1` 时，离散 distribution-free 联合 power 下界为 `0.801021247429385`；`n=561` 只有 `0.799048262648854`，所以 562 是冻结准则下的最小整数样本量。

科学 margin 为 0：通过只支持严格 candidate-set dominance，不支持 material effect。冻结定义中的完整 nonpass 也只能表示“在冻结分辨率下未建立”，不能解释为零效应或负效应。前瞻合同原允许在完成前从 same-master atomic frontier 技术续跑；但现在 canonical object 已完成并消费，不再存在合法 resume。
