# SCDMP 启发与增强

## Portfolio 结论

保持 ACTIVE 并观察现有 operation 到终态；其后 RECAST 为 `foundation_conditioned_event_order_value`。ONLGR 只转入 common-rate/clock control，不转移科学极性。

## Insight 与数学支撑

当前方向混合三个对象：固定动作的 elapsed-time transition/reward composition、H/R event maps 的非交换性，以及 order 是否改变原生最优动作。前两者不推出第三者。当前 `k` 是环境外生输入，policy 不选择 duration 或 termination hazard，因此不是 learned variable lifetime。

冻结 product-measure/two-fold selector 不能保持 oracle opportunity：存在 common-optimum table 使真实 `Q*=D*=0`，selector-based quantity 却全部过门；也存在 disjoint-optimum table 被旧 `Q` 错判为零。独立估值消除样本复用，却不能消除 differential selector regret。

## 可增强方向

先定义完整联合初态律和 competent order-erased foundation，再做 `2 graphs × 3 precommitted actions`：两个 graph-matched actions 与共同保守 action。冻结一个可达公共初态、一个 `k`，六格共享 paired future tapes但 tapes 不参与 action selection；首 hold 后交回同一 foundation。直接计算 graph×action interaction 和 candidate-set order value。任何 foundation/alias/action-headroom 门失败都在 adapter 前停止。

H/R 生成 `S4` 只是 tuple-map 代数事实；当前物理语言只有 `{HR,RH}` 且不闭合。未来 unseen-word representation 若成立，应比较 exact H/R compiler 并归 FRRIE，而非扩大 SCDMP claim。
