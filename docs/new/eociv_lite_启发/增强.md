# EOCIV-lite 启发与增强

## Portfolio 结论

关闭旧 standalone gate。把“真实 receiver opportunity 中 receiver-correct payload 是否改变原生动作”作为 CBSC 的一条轴；不再续跑旧 PPO、valve、credit、retention 或 clipping 修补。

## Insight 与数学支撑

旧方向混合了两个问题：payload 是否有原生价值，以及 learned selective gate 是否优于 universal actor。若 universal actor 获得相同 payload、历史与成本，则

\[
\Pi_{gate}\subseteq\Pi_{raw},\qquad \sup J_{raw}\ge\sup J_{gate}.
\]

所以 gate 优势最多是有限容量、样本、计算或真实通信成本优势，不能证明 payload 独有信息。现有原型虽在表示层区分内容，但没有绑定 fidelity-valid active opportunity population，也没有稳定 native-return headroom。

## 可增强方向

先做零学习 exact gate：冻结真实 membership/opportunity law、source/receiver receipt、native-neutral、物理时间回报和 ingestion cost；枚举 correct/swapped/neutral twins。必须同时有非零 opportunity prevalence、payload twin 导致不同唯一最优动作、正净 headroom 与一个不应开启的 neutral cell。RAW-EXACT 和 hard-open 是 competent controls。若只剩 reliability `ρ` 的 serve/invert/probe frontier，则由 CBSC/DEARS currentness 轴吸收，不再保留 EOCIV 名称。
