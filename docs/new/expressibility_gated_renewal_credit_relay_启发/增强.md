# EGRCR 启发与增强

## Portfolio 结论

关闭 exact-population relay 对象。唯一存活问题进入 FRRIE，作为 finite-data/finite-compute relational inductive efficiency；不得重跑旧 relay families。

## Insight 与数学支撑

EGRCR 的主要贡献是强否证门：真实、正确绑定、可 sever 的延迟关联不自动构成 generic conditional-Q 之外的决策信息。若候选标量为 `C_r`、score 为 `S_r`，generic arm 可用相同历史与 edge key 构造

\[
\bar C_r=E[C_r\mid H_r,A_r,Z_r],
\]

则塔式性质给出 `E[S_r C_r]=E[S_r \bar C_r]`。在精确总体、共同预条件器和 trust map 下，总体一阶更新、稀缺决策与 utility 相同。严格结论是条件单元/总体一阶更新相等，不是有限样本逐记录路径相等；这正好界定了唯一剩余空间：Adam、裁剪、归一化、多步和有限样本。

## 可增强方向

FRRIE 中只需一个离线 factorized conditional-Q fixture：结构化 factorized arm、严格包含 generic relational critic 与错绑 cut，严格匹配数据、参数、optimizer、updates、FLOPs 和 memory。先比较 held-out target/source-gradient error，再比较一次共同 top-budget allocation。正结果只支持有限资源效率；cut/severed 同样获益则归因通用正则化；generic 等价或更优则关闭分支。
