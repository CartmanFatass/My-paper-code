# FRRIE 启发与增强

## 当前结论

关闭当前 24-root `FRRIE-RIDGEGATE-2Z-RSCF-R01` 结果对象，方向建议 `PARK`，而不是关闭
FRRIE 的全部科学可能性。没有生产运行，也没有 `PHY_TRUST` 对 `EDGE_FLEX` 的正、负或
等价极性。现有 V2 代码与测试只保留为 exact FP32、factual replay、matched-work、checkpoint
和 native seam 的结构证据。

## 沿用的合并启发

- SGSP 留下的是同一 `K0` chart 中 tight projection 与 strictly containing wide projection 的
  有限预算比较。两臂只在 projection/optimizer package 上不同；即使 tight 获胜，首先支持的
  也是 shrinkage、preconditioning 或 Adam path，而不是 graphon truth 或独立 relational
  mechanism。
- CCIC 的 typed-wedge、EGRCR 的 pair-aware conditional-Q/Rao--Blackwell、VQFP 的 exact
  allocation controller 都是 absorption/competence controls。它们限制可声称的机制，但旧方向
  的结果极性不转移到 FRRIE。
- 公共信息、初始化、tapes、更新数、environment work、参数量和评价机会必须匹配。generic
  comparator 不 competent 时属于 nonidentification，而不是 treatment 胜利。
- 当前 fixed-roster R01 不包含 join、leave、rejoin、replacement 或 churn，不能借结果外推到
  variable-membership MARL。

## 本轮新增数学 insight

### 1. 合法 IUT 不等于有决策能力

若只保留两个 held-out direct mean gates 与两个 `EDGE_FLEX` competence gates，正向结论是
intersection-union test：每个 component 使用 level `alpha=0.05` 的单侧检验，只有四个都拒绝
才通过，整体 size 仍不超过 `0.05`，不需要 56-tail Bonferroni。56 tails 只在保留完整联合置信
矩形、结果后选择 component，或同时开放 equality、wide-superiority、cut-insensitive 等多个
终局时需要。

这只解决合法性，不解决 power。令一次额外 distinct delivery 的材料性增益为

\[
\eta=0.65/6=13/120.
\]

在受保护的任意 bounded root-statistic 类中，端点 Bernoulli 子模型给出所有合法检验的
Neyman--Pearson 功效上界。24 roots 时：

| component | null margin | one-delivery alternative 下最大功效 |
| --- | ---: | ---: |
| held-out direct mean | `0.04` | `0.1323360180` |
| wide competence mean | `0.08` | `0.1302412162` |

同一精确随机化 binomial 上界表明，单 component 达到 80% power 至少需要 523 blocks
（direct）或 518 blocks（competence）。因此 523 只是任何四条件方案的必要下界，不是完整
设计。若要求四个 effect 都至少比 margin 高一个 `eta`，用单侧 Hoeffding 和 type-II union
bound 构造的保守充分数是 2043 blocks；它对应两 learned arms 约
`10,409,951,232` environment slots 和 `8.0894e15` conventional FLOPs。523、2043 及两者之间
的数字都不能在缺少 root variance、joint alternative 和 runtime law 时直接注册为预算。

### 2. Equivalence 不是缩小 multiplicity 就能修复

在 `P(X=1)=q>0.04`、其余为零的合法污染律下，24 个全零的概率趋近
`0.96^24=0.3754132467`。因此即使观察到全零，24 roots 也不能诚实认证
`|E[d_seen]|<=0.04`。未校正的单一 TOST 至少需要 74 roots 才让全零配置开始可判；旧
`0.05/56` 分配需要至少 172。两者都只是分辨率下界，不是 power 设计。

### 3. Majority/prevalence 不是 mean repair

把对象改成 `P(d_s(N)>0.04)>1/2` 时，24 roots 的 exact one-sided sign test 要求至少
17/24 successes。它可执行，但回答的是 root-wise prevalence，不是 expected native return：

- 51% 的 roots 取 `0.05`、49% 取 `-1` 时，majority 通过而 mean 为 `-0.4645`；
- 49% 的 roots 取 `1`、51% 取 `0` 时，majority 不通过而 mean 为 `0.49`。

因此 prevalence 不能保留或关闭当前 package mean-effect；只有在存在独立 utility 理由、
prevalence margin 和结果解释时，才可作为新对象注册。

### 4. Root 总体必须由实现直接生成

当前 V2 validator 会接受任意 24 个不同的 256-bit hex 字符串和任意非空 provenance，未直接
生成或观察“从 `2^256` root 总体有序、均匀、无放回抽取”的过程。没有直接 prospective root
generator 时，artifact 最多识别 literal fixed panel，不能承担 sampled-root population claim。
这属于 sampling-law 缺口，不是身份、哈希或审批问题。

### 5. Projection contact 不是廉价 pilot

`beta=0.60` 只证明 wide box 严格包含 tight box，不证明训练可达。相反，optimizer-algebraic
持续同号梯度在 512 个 Adam steps 中可累计约 `512*0.0003=0.1536` 位移，所以不能静态证明
`PHY_TRUST` 的 `[-0.15,0.15]` 永不接触；真实 RSCF/DGP reachable set 目前也没有形式证明。

若要从 sampled trajectories 选择 exact no-contact closure，仍须审计全部 `24*512` updates：
每次 clamp 前后比较 18 个 FP32 beta bytes，并逐 update 比较两臂完整 parameter 与 Adam bytes。
它最多节省约 1.08% final FLOPs 和 0.96% environment slots，几乎等同完整训练。24-root
no-contact 只描述这些路径；contact 只证明轨迹可能分叉，不证明 return efficacy。没有新冻结的
package-level estimand 时，两种观察都不值得启动生产。

## 可执行的下一步与重开条件

当前最小投资顺序是先做数学证明，失败即继续 `PARK`：

1. **压缩真实 root contrast 类。** 证明实际 paired contrasts 的 support、variance 或其他有限样本
   结构严格窄于 `[-1,1]`，并据此给出 level-valid 方法及在一-delivery alternative 下至少 80%
   的 prospective power。只做经验 pilot 后再选 bound 不合法。
2. **若第 1 步成功，再冻结完整对象。** 同时冻结 block count、joint alternative、停止规则、
   claim ceiling、wall/RSS/scratch/durable ceilings 和直接 uniform-without-replacement root
   generator；block 数不得由运行方便或现有 24-slot scaffold 决定。
3. **资源准入。** 每次 result-bearing launch、resume、retry 或 slice 前运行共享
   `admit-memory`，要求 physical 与 effective available memory 均至少 4 GiB，再执行方向
   preflight。资源通过不能覆盖 science blocker。
4. **另一条合法重开路线。** 若要研究 prevalence、median 或其他非 mean target，必须先给出其
   原生决策价值、margin、power law 和只解释该 estimand 的终局；不得把它称为 R01 repair。
5. **Exact-treatment closure 路线。** 只有对所有 reachable supported histories 证明 universal
   non-contact，才能不依赖 sampled-return inference 关闭 exact treatment。有限 roots 的
   no-contact observation 不足；contact 后继续也必须先有新的 package estimand。

在这些条件之前，不应补 production driver、结果 analyzer、native artifact retention 或扩大
blocks。特别禁止把删除 equivalence/cut 后的单侧结果继续解释成 relational-mechanism 证据。
