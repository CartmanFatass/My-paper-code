# FSBS 启发与增强

## Portfolio 结论

关闭同信息 carrier-access standalone 对象。只有 binding 改变合法 access、authorization、failure 或净 acquisition cost 时，才作为 CBSC 的 capability 轴继续。

## Insight 与数学支撑

在当前 normalized interface 中，AUTHENTIC 与 PREDICTIVE_INDEX 暴露相同 `hint=T`，且 initial learner/optimizer、controller、reward 与 RNG 相同。归纳得到

\[
O_t^A=O_t^Q,\;Z_0^A=Z_0^Q
\Rightarrow
a_t^A=a_t^Q,\;r_t^A=r_t^Q,\;Z_{t+1}^A=Z_{t+1}^Q.
\]

因此 exposure、checkpoint、selection 与 held-out return 路径相同；非零差首先说明 equality contract 被破坏。原 REASSOCIATED 定义若同时匹配 emitted hint，又要求 hint 与 truth 独立，会产生内部矛盾。修正匹配 strata 不能解除 AUTHENTIC/PREDICTIVE_INDEX containment。

## 可增强方向

CBSC 的最小 capability gate 是 `binding={AUTHENTIC, whole-valid-carrier REASSOCIATED}` × `access={OPEN, BINDING-GATED}`，匹配 pretreatment strata，排除 emitted hint、授权结果和回报。加入 capability-matched predictive index 与 raw optimum。只有 OPEN 无 binding 效应、GATED 有净 headroom，且能力匹配 index 不能复制时，binding 才具有 residual value；否则关闭。
