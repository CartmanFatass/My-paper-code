# CCIC 启发与增强

## Portfolio 结论

关闭 CCIC standalone。其有限宿主证明 covariance orientation 超出 scalar/spectrum/二阶摘要，但合法 arity-3 typed-wedge 精确恢复同一动作；剩余问题进入 FRRIE，作为“结构化表示是否提高有限资源效率”的 absorption control。

## Insight 与数学支撑

在冻结八源构造中，两臂具有相同 trace、posterior spectrum、`U1/R2`，却交换最优 sensing axis；低阶共同策略相对 oracle 有正 Bayes-risk gap。与此同时 typed-wedge 的符号统计精确复现 covariance oracle。

一般地，只要 covariance `C=f(H,M)` 是完整公共历史和物理律的可计算函数，并且 relational comparator 的函数类包含 `f`，则 `(H,C)` 相对 `H` 没有信息论增量。正条件互信息或 covariance entropy 也不自动产生固定效用下的 action value。

## 可增强方向

FRRIE 中应在一个统一 variable-`N` host 上比较结构化 relational prior 与严格包含的 generic learner，匹配原始信息、参数、更新、环境交互和 compute。主量是 held-out native regret 与 work-to-threshold，而非 covariance MSE。加入 typed-wedge compiler、raw classifier 与 reassociation cut。只有 structured arm 在 competent generic null 上保留 matched-work 优势，才能声称有限资源归纳偏置。
