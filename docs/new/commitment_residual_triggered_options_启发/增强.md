# CRTO 启发与增强

## Portfolio 结论

方向保留但 RECAST。放弃追逐已丢失的 update-1,000 动态状态；新问题是显式 commitment-origin residual 是否在有限预算下改善原生动作选择，而不是能否重建全部 residual 坐标。

## Insight 与数学支撑

若 raw packet 为 `X`、residual 为确定变换 `Z=T(X)`，则

\[
\sigma(Z)\subseteq\sigma(X),\qquad V^*_{RAW}\ge V^*_{RESIDUAL}.
\]

所以 residual 不增加信息或可达策略类；可检验的仅是有限样本、函数近似、数值条件或优化路径的归纳偏置。旧 `52→64→32→24` probe 要求重建全部 24 坐标，但 coordinate reconstruction 既非 option-action sufficiency 的必要条件，也非充分条件；训练 MSE 也不等于判定用 NMSE/sign gate。

现有 update-10,000 endpoint 是未观测，不是失败。probe 参数、Adam moments/step 和 cursor 未持久化；genesis replay 会定义新对象。

本轮又得到三个可复用的方法论 insight：

- 全体 K8 平均 regret 不能证明 comparator 有能力。若 `80%` 行是 KEEP-easy、`20%` 行的 replanning headroom 恰为 `0.02`，永远 KEEP 的策略平均 regret 仅为 `0.004`，却完全没学会重规划。因此 competence 必须在 `KEEP_MATERIAL` 和 `REPLAN_MATERIAL` 两层分别成立。
- 固定 counter-address 只提供可重现性与 stream isolation，不会自动产生 iid Normal、exchangeability 或 seed 超总体。八个地址的有效结论必须收缩为 exact finite census；用六个 all-slot hull `[min_s,max_s]` 决策，Student-t 只能作有条件的描述。
- SHORT 有 gap、LONG gap 闭合不足以证明“RAW 追上”；它也可由 TRUE 退化造成。`OPTIMIZATION_EXPOSURE_ONLY` 还必须要求每个 slot 的 RAW 绝对 regret 改善超过 `0.005`，TRUE 不得有超过 `0.005` 的退化，且 LONG 的三个 pair 全部落入 `[-0.005,0.005]`。

## 可增强方向

冻结一个 `3×2` common-history decision probe：`RAW / TRUE-RESIDUAL / CALIBRATED-DERANGEMENT` × short/long matched exposure。使用 common future tapes、真实 replan cost、held-out `K` cells 与 native action regret。RAW 必须先过 in-support competence。短预算 residual 胜、长预算 RAW 追平只支持优化曝光；derangement 同样有效说明是通用 preprocessing；RAW 等价或更优则关闭机制。

最小的下一步不是直接支付全部 `3×2×8` 计算，而是两个独立 development addresses 的 RAW-only pilot：只拟合 predictor、训练 RAW 到 2,048 updates，并在 64 条 K8 development tapes 上检查双 material-stratum support 与 `max mean regret<=0.01`。它只能判断可行性，不能改阈值、挑 seed 或代替最终八地址 confirmation。当前工程的硬 blocker 是将 all-horizon calibration residuals、首个 audit boundary、G16 branches 和 exact ledger 绑定到同一次 256-step tape traversal；在此之前保持 result fail-closed。
