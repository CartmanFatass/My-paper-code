# RISP 启发与增强

## Portfolio 结论

方向 RECAST 为 event-conditioned Bayesian recurrence，保持 REGISTERED。APFI 的 capacity-censored typed flow 只可作为未来宿主；当前 APFI 结果不转移。

## Insight 与数学支撑

当前真正的因果核是实际接收 ACK 后、下一 renewal 动作前更新私有快状态。现有 `G` 的 prior、duration 与 time 列为零，所以没有识别“renewal-indexed”。两 agent 条件独立、只共享参数，也更接近单智能体 POMDP/SMDP 的数据副本，而非协调。

对当前对称三状态转移，`P^k=(1/3)J+(15/16)^k(I-(1/3)J)`；`k` 只缩放置信度而不改变 belief 排序，不能产生 duration 导致相反动作的价值。一次 LAST-ACK-G 还可能覆盖强烈的较早 prior，因此不是一般 sufficient recurrence。

## 可增强方向

学习前比较 `FULL-BAYES-K / FULL-BAYES-K-ERASED / LAST-ACK-BAYES / LAST-ACK-G`，并以 unrestricted raw-history Bayes 为上界。构造末次 action/ACK/duration/current observation 相同、旧 prior 不同的 reachable twins，比较 next action 与 physical-time return。若 K-erased 等价，则无 renewal 边际；若 full Bayes action-sufficient，则 structured initialization 只能研究有限资源效率。未来 APFI host 必须先证明删失 posterior 非退化、低阶控制失败并跨越动作阈值。
