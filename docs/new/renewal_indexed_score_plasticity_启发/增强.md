# RISP 启发与增强

## 当前结论

RISP 已从初始化问题重铸为 event-conditioned Bayesian recurrence。`RISP-ECR-R01` 已完成并保留为精确存在定理：旧 ACK 与 completed-duration 顺序可以改变下一 renewal 的 Bayes 动作和价值。它不提供自然 prevalence、learnability 或 learned-successor 投资依据。

本轮方向建议是关闭 standalone RISP，而不是继续制造一个方便可算的 census。ECR 的 noncommutation 结论可以作为 SCDMP 等方向的 event-order/duration-memory control 输入，但不得转移 RISP 的结果 polarity。最终生命周期仍由 Root 决定。

## Insight 与数学支撑

当前真正的因果核是实际接收 ACK 后、下一 renewal 动作前更新私有快状态。现有 `G` 的 prior、duration 与 time 列为零，所以它没有识别一般的 renewal-indexed Bayes state。两 agent 条件独立、只共享参数，也更接近单智能体 POMDP/SMDP 的数据副本，而非协调。

对当前对称三状态转移，

\[
P_k=J/3+(15/16)^k(I-J/3).
\]

单独一次 prediction 是对非均匀 belief 的对称收缩，但 prediction 与 action-conditioned ACK update 不可交换。多次交错后，duration 的顺序可以改变 posterior 排序；因此不能再从单步对称性推出“duration 不会改变动作”。`LAST_ACK_G` 也会丢失较早 public outcomes，不能作为一般 sufficient recurrence。

### 完整但未采纳的 PC3 law

本轮构造了 witness-independent 候选 `PC3-IID-REFERENCE`：

\[
N=3,\qquad K_{1:4}\overset{iid}{\sim}U\{4,8,12\},\qquad
A_{1:3}\overset{iid}{\sim}U\{L,C,R\}.
\]

结合继承的 hidden transition 与 ACK law，完整 atom 为

\[
\mu=3^{-8}\prod_{i=1}^{3}P_{K_i}(X_{i-1},X_i)
\ell(Y_i\mid A_i,X_i).
\]

它严格归一化，并覆盖全部 17,496 个 public history/next-`k` cells；没有选择、排除或增权四条既有 witness。对任一 coarsened view `C`，最强 matched-information null 可精确定义为

\[
b_C(v)=
\frac{\sum_{h:V_C(h)=v}\mu(h)b_h}
     {\sum_{h:V_C(h)=v}\mu(h)}.
\]

但 PC3 未被采纳：uniform action 是人为 off-policy occupancy，而 action 会改变 ACK 信息，所以改变行为律不仅改变 history 权重，也会改变 coarsened Bayes null 本身。固定三次停止、IID duration、terminal opportunity、uniform next-`k` 和 materiality floors 同样只是便利约定。可归一化、可穷举不等于有独立决策价值。

### event、time 与 occupancy 分母

令 `g_C(h)` 为 full Bayes 相对 comparator `C` 的下一 hold 期望价值损失。至少要区分：

\[
R_C^{opp}=E_\mu[g_C(H)/K_{next}]
\]

与

\[
R_C^{time}=E_\mu[g_C(H)]/E_\mu[K_{next}].
\]

二者一般不相等，也都不同于 episode-level 或任意物理时刻的 population。prevalence、conditional Bayes null、regret 分母和 materiality threshold 必须属于同一个明确 occupancy；不能把 decision-count、physical-time 与 policy-induced population 混用。Tie histories 保留在共同分母中，并需单报 tie-only action differences，避免打印顺序伪造价值差异。

### InstSci 文献边界

本轮只读核查了 InstSci 正式库当前 190 PDF / 190 JSON / 190 Metadata v2 基线。库内没有直接的 Palm/renewal-reward、opportunity-sampling 或 stationary holding-time weighting 来源可为 RISP 选择数值总体律。

- `MARL-0621` 与 `MARL-0449` 支持区分 variable-duration decision epochs、macro decision count 与 elapsed micro-time。
- `MARL-0061` 支持 conditional coarsening 必须写在明确的 policy-induced occupancy 下，并说明粗粒度平均不保证保留细信息动作。
- `VS-0002` 支持按物理时间定义 continuous-time value。

这些文献约束“必须明确 measure”，但不提供 RISP 的 stopping、behavior、duration、opportunity、regret 或 materiality law。通用 Palm 引用即使补齐，也只能说明 measure 如何转换，不能替项目选择目标 occupancy。

## 可增强方向

已经完成且值得保留的增强，是用 `RAW-HISTORY-BAYES / FULL-BAYES-K / FULL-BAYES-K-ERASED / LAST-ACK-BAYES / LAST-ACK-G` 分解信息损失，并将 ECR 的 noncommutation witness 用作其他方向的单元控制。

不建议继续实现 PC3 或重跑 ECR。Standalone RISP 只有在下列任一条件满足时重开：

1. 一个目标 benchmark/deployment 独立给出完整 generative/utility law，包括 stopping、duration schedule、behavior occupancy、opportunity sampling、next-`k`、物理效用和成本校准 materiality；或
2. 对一个独立合理的 law class 证明 law-robust prevalence/regret 下界，并且该下界跨过独立成本门槛。

APFI 的 capacity-censored typed flow 仍只能作为未来 prospective host；必须先证明其 posterior 非退化、低阶控制失败并跨越 native action boundary，且 APFI 当前结果不转移。若把 ECR 输入 SCDMP，应只注册为“prediction/ACK update 非交换、duration order 可能相关”的控制事实，不能把四-history 正结果解释成 SCDMP efficacy。

## Claim ceiling

当前最大结论仍是：在固定三扇区 host 的四条冻结 histories 上，较早 public outcomes 与 completed-duration 顺序可改变下一 native Bayes action/value。它不是自然 occupancy prevalence、任意 `N/k`、有限资源 learnability、协作、variable population、UAV transfer、安全或部署证据。
