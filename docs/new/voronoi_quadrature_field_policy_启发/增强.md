# VQFP 启发与增强

## Portfolio 结论

进入过渡 PARK；保留并观察现有 operation 到终态，不再启动 standalone work。之后 VQFP 仅作为 FRRIE 的解析 competence/control，除非一个明确资源边界排除 exact generic allocation controller。

## Insight 与数学支撑

当前对象是一阶段、集中式、完全信息的可分整数资源分配，不是 dynamic-roster MARL。每行公开 `v_i,d_i,dbar,1/N`，因此 `m_i=v_i d_i`。可构造同信息 exact marginal heap：

\[
\Delta_i(k)=\frac{m_iv_i}{v_i+kh}-\frac{m_iv_i}{v_i+(k+1)h}.
\]

从 `k_i=0` 开始，重复 `Q` 次选择最大边际并递增该格，严格递减边际使该算法精确复现 top-Q oracle，复杂度 `O((N+Q)log N)`。因此 ORACLE 在当前访问律下是 competent generic controller，不是不可达信息上界。

均匀场时 `d_i=dbar=1`，treatment 对任意 θ 都退化为 `w_i∝v_i=m_i`，与 MASS 命令相同。`T-P` 的损失主要证明正确 measure-demand pairing 有用，不能证明 learned Voronoi relation。

## 可增强方向

先完成静态 access gate：若 full reduction/sort 和已知 endpoint 均允许，旧 K1 不再能支持 standalone 投资。只有在 prospective communication/latency/memory/compute contract 允许低维 amortized mapping、却排除逐边际求解时，才比较 oracle regret、rounds、latency 与 operations，并加入 `MASS-P` difference-in-differences 控制。正结果只能支持资源约束下的 amortized allocation efficiency，并归入 FRRIE。
