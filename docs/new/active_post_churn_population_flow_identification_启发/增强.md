# APFI 启发与增强

## Portfolio 结论

当前 standalone 方向关闭。CCF-R01 的公开四词语言可由一位 pair-XOR/DFA 精确识别，未建立“删失人口流”本身的识别价值。容量删失与 typed flow 的想法只保留为 RISP 的候选新宿主，不转移当前结果极性。

## Insight 与数学支撑

对公开序列集合 `L0={0011,1100}`、`L1={0110,1001}`，终端标签满足

\[
Z=X_1\oplus X_2.
\]

因此缓存前两事件的一位自动机已足够；后续累计 order-state 并非必要。若零 admission 的时钟不可见，则文档声明的公共四词语言本身不可恢复。当前 censoring-swap 又把 rejected/queued offers 定义为不影响可见状态与奖励的 nuisance，所以对象识别的是公开 order code，而不是隐藏流。

完整 order-state 被包含控制器吸收：`ORDER-STATE` 与 `PAIR-XOR/DFA` 应在四词×两动作上逐点同动作、同回报。任何 learned 优势最多是有限预算初始化/优化几何。

## 可增强方向

仅在新宿主同时满足以下条件时复用此启发：公共支持重叠、删失后 posterior 非退化、`LAST/COUNT/PAIR-XOR/typed-bag` 全部失败、posterior 跨越原生动作阈值，并且 competent containing recurrence 不能在相同工作量下吸收结构化初始化。最小 learned 比较应为同一 recurrence 内的 flow-start、匹配 sham-start 与 generic-start，并在 held-out capacity/censoring laws 上测 native regret。
