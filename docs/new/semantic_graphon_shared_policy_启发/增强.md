# SGSP 启发与增强

## Portfolio 结论

关闭 standalone graphon/RSCF 标签，把 SGSP 作为新方向 FRRIE 的 learned-treatment ancestry。旧结果不转移；新对象只研究严格 matched-work 的 relational inductive efficiency。

## Insight 与数学支撑

当前 RSCF 更接近公开三角色、计数依赖的 typed block kernel，而非严格图极限对象。实现先聚合 role sums/counts，再以 `K0_ab(n_b)` 计算；块内拓扑不可见。`EDGE-FLEX` 严格包含 `PHY-TRUST`，两臂主要差异是投影盒，所以任何优势首先是有限预算正则化、preconditioning 或 Adam path。

九格物理核中只有 `RELAY←WEST/EAST` 两格进入 mission transition，其余更多是策略先验。正确 center 胜错误 center 只说明错误 center 有害、center 会影响 action，不证明 narrow prior 胜 competent flexible learner。

## 可增强方向

FRRIE 必须选择一个单一 variable-`N` learned host。structured prior 与 strictly containing generic learner 接收相同关系和值，匹配参数、更新、交互、FLOPs 和 memory。加入 CCIC typed-wedge、EGRCR pair-aware Q、VQFP allocation compiler 与 relation-reassociation cut。主量是 held-out `N` native return/regret 和 work-to-threshold。generic competence 失败为 nonidentification；cut-insensitive gain 归入 optimizer geometry。
