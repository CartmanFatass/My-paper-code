This record is a durable role/workspace pointer only. The Scheduler is the
user-owned Desktop task that routes lifecycle and concrete resource conflicts
for same-level ephemeral Explorer and CPM owner tasks. It has no science,
code, technical acceptance, Git, runtime execution, semantic relay or sibling
preload authority. The native lifecycle/routing handle is the exact
`{threadId,hostId}` pair. When present, `ACTIVE_ASSIGNMENTS.md` is only an
optional restart locator; it is neither a registry nor an authority source.
Canonical artifact and continuity files are pointers, not proof of LLM
identity. Writes remain cooperative and exact-path scoped.
