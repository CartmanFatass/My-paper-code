# Shared architecture decisions

ADRs record durable shared architecture, harness, context, and control-plane choices.
They do not restate scientific decisions, technical acceptance, or portfolio allocation.
Those remain in their owner-authored canonical artifacts and may be linked by the index.

Each ADR uses TOML front matter. Status is one of `accepted`, `proposed`, or
`superseded`. Canonical sources are repository-relative paths. File-byte hashes
are never a validity gate.
