## 4. 最新 PPC：有进展，但它解决的是哪一层问题？

### 4.1 已经回答的内容

PPC 用一个小型循环学生学习近似规划教师的行为，部署时移除在线过滤和模拟。普通 BC 从 B01 就存在；WBC/O 改变训练误差的权重。其 NOTES 明确借鉴现有模仿学习和价值加权思路，没有把这些概念本身作为已确立的新颖性。

B02 回答的是一个预先固定的窄复现问题：新的训练/数据/256-context 面板区组里，WBC−BC 的完成量正号是否反复出现。该规则通过，但仍有 17 个损失世界，WBC−教师五块均负。不能用“论文贡献仍不足”撤销已经通过的规则。

B03 针对另一个问题：在固定存档数据上，权重与具体历史的对应是否有用，以及加权是否胜过新普通 BC。两配对 O−BC 平均为 **.060546875 个任务/context**，约为这两面板 BC 总完成量的 **0.531%**。O−BC 的平局世界为 237/256、243/256，损失世界为 4、2 个。总包数与交付数相同，强制发送和 unknown-gate 计数上升；这些分量需要保留，但不能仅按符号把它们全部解释为损害。

普通标签错误率较差而原生完成量稍高，说明普通模仿精度不足以独自选择方法。置乱同时改变与难度、来源、时间和优化的关系，故结果没有识别“真实决策后果”的因果机制。两配对共享 D，也不是两次独立的数据取得。

### 4.2 暂停前已选、尚未执行的 B04

暂停前，DM 在独立科学 Reviewer 建议后选定 B04：两个新数据/训练/评价区组，每块 O、BC 两个 fresh fit；共同 256-context 教师前缀，加各自 256-context 带标签 roll-in，最终与教师和 AF 一同评价。这样每种学生不再需要另一种学生来取得自己的训练数据。最新 owner 指令已取消继续启动的权限，保留设计与未运行代码供审阅。

### 5.2 一项研究通常怎样落地

1. Root 或 DM 读共享认识和方向记录，形成问题、普通参照、竞争解释、预测及值得购买的比较。
2. 到重大问题/解释/关闭或重开/确认等决策点时，完成所需 Pro 咨询；独立科学 Reviewer 重建证据并给纠偏建议。可复用覆盖相同问题和分支的既有意见，不要求每批重做。
3. DM 在 append-only NOTES 写前瞻与成本；确认另有 CLAIM。提出简短 L0，必要时委派 Implementer。
4. 对实际变更做适当测试和独立工程复核，提交并发布精确代码/输入；源版本、方向负责人、暂停及实际节点内存通过原生准入。
5. 使用 `hmasd_launch.py` 启动固定源快照，`hmasd_wait.py` 观察同一已接受操作。检查点、超时、进程退出均不能冒充科学结果或自动重启许可。
6. DM 完整读取原生终点、反例、学习变化、成本和技术异常；必要独立数值读取重建关键对比，冻结规则保持不变。
7. DM 自行发布 NOTES、紧凑 runs 证据及自己的 RESEARCH 条目/共享认识；Root 不是常规发布审批层。后继须有自己的科学理由，不自动增加 seeds 或调参救回原批次。

三个正式记录类型为 NOTES、runs、确认前 CLAIM；RESEARCH 是唯一当前索引。当前主分支方向目录、显式路径提交、单路径写者和必要证据保全已实施。完成的项目复盘归档，普通进度不另造快照。独立 App 会话不自动汇报/ACK/转发，内部有界助手和 Pro 保留各自流程。

### 5.3 当前科学标准的含义

- 使用胜任且信息匹配的普通主要参照；包级比较不直接证明组件因果。
- 正式经验学习主张至少三个独立训练 seed/臂；确认通常 3–5 个新 seed/臂和一个固定批次。这个最低数量不保证精度；单/双配对可探索，不能因此升级成确认。
- 评价世界、时间步与同一模型的多面板不增加独立训练 n。训练条件与评价面板同时变化，会限制反转归因。
- 保留全部结果，区分自身学习、候选增量、完整用途、主张范围和投资选择；不显著不等于等效，不利局部读数不自动否定大类方法。
- 代理误差、熵、恢复计数、参数更新或更精确的估计不替代完整原生任务后果。
- 数学模型、文献、小模型可以帮助形成猜想；没有一条现行规则要求先证明机制、找到阳性 toy 或穷尽所有替代解释才允许探索。

这些原则已有不少实际落实。当前问题不能只用“再强调严谨、再要求认真反思”解决；应检查它们如何影响选题和下一步分配。
