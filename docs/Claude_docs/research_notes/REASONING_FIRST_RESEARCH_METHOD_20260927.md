## 0. 一句话

先把创新主张说具体——新在哪、为什么重要、最接近的已有方法与最强简单替代怎样处理它、什么观察会削弱它、成本多少——经一次适用的独立质疑，然后直接决定：一次有限完整实验、一次针对性修订，或不投入。推理的作用是改变比较对象和投资选择，不是"先认证创新，再允许实验"。

- **特征、控制器、数据改变一律归基础设施、不能买 fit**：撤回按代码位置的分类。贡献按新增的知识与比较判断；有限学习、表示或数据方法可能是真研究，普通基线也可能值得训练；所有结果性运行仍计入五条资源上限，不能靠改称基础设施绕过。

## 2. 两版一致、保留为方法的内容

1. **分工**：DM 构造创新主张；现有 Scientific Reviewer 在独立上下文做一次适用的质疑（含必要的数学检查）；Pro 只在能补充独特知识或解决实质分歧时加入；然后 DM 直接决定。不是每个 batch 重走，不是四级签字。
2. **前瞻里的一段连贯论证**（写在现有 NOTES 的声明条目里，在建立或材料变更研究问题时，即宪章 §5 第 1 点的对象；复用已适用的论证）：目标任务中哪个有后果的问题未解决；最接近的已有方法与最强简单方案怎样处理它；我们改变了哪一条信息、决策、学习或协作关系；为什么预期有用；哪种观察会削弱这个理由；成本。并做一个反事实检查：**假设实验完全成功，我们能写出的贡献句是什么**——"换个 loss 分数更高""启发式更强""修好了评估路径"可以是有用结果，成为主创新还要说明新增了什么可复用的方法或认识。
3. **新颖性可暂定**："已有工作直接覆盖且没有新的问题或认识"与"新颖性尚未查明"是两回事，后者不取消探索价值。检索围绕最接近的原始工作和决定性差异，不以论文数量为条件；已知方法在新场景有效是迁移证据，只有说清额外困难、方法差异或新认识才形成新贡献主张；组合模块要解释组合带来的新作用。
4. **推理与实验各有出口**：比较对象／信息权限／数学定义的矛盾必须先修；效果大小、机制强弱、可学习性未知是实验可以回答的问题；新意或问题价值不足是当前不投入的理由，不必证明它永远无效。前两类不混成"未完全理解，继续闭合"。再做分析前先说它可能怎样改变选择；推理也计成本，0 fit 不是免费。
5. **读实验不默认寻找下一个修补点**：技术故障按直接证据修，不算机制失败也不趁机扩题；预期关系在目标条件下几乎不发生就降低它的价值，不为造阳性提高故障强度或换易赢指标；中间量改善而完整 J／服务／风险未改善就削弱通往任务价值的论证；与简单对照持平或收益被普通方法吸收，可保留工具和基线、结束该创新包的投入；单次有意义但不确定的信号，若独立复现会改变选择就值得付费；阴性后只剩"再训练久一点／换 seed／换权重"就不购买续跑。
6. **零 fit 的判别性测量**鼓励做，但每个要先写它可能改变哪个选择；"跑跑看"不做。
7. **组织**：五条是并发上限，不是必须填满的流水线；不为填槽创建 DM；已接受的工作按原身份收尾；方法变化先落在实际的一次选题或续投决定上，再改现有方法文字。

## 3. 不确定性怎么算（替代 2 × SD 门槛）

有合法配对的独立训练区组时，令 D_i = J(T_i) − J(C_i)，均值差的标准误估计为 s_D/√n，且 Var(D) = Var(T) + Var(C) − 2 Cov(T, C)；非配对设计用相应的两样本或分层不确定性。同一策略的 32 个评价世界不是 32 个训练区组。未知协方差、小 n 和选择曝光如实保留。是否投入由实际重要性、正确比较的差值变异、目标精度和总成本共同决定，不由某一臂的 seed SD 一刀切。

## 4. 创新候选从哪里来（待筛选，不预设为创新）

候选应来自本问题独有的结构，并明确它可能被普通规划、现有策略梯度方法或 option 方法吸收：
