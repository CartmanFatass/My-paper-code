# E1 — age input to the discriminators at fixed k (D0 versus D1, scenario 1)

Design written by Claude Code (Fable 5.1) on 2026-09-02 after the owner's E1 prediction was
recorded (plan §11). Governing texts: `../plans/FLEXIBLE_SKILL_DURATION_PLAN_20260902.md` §2
(concerns C1, C2), §5 (E1 row: "Return change small; label agreement rises with age input
(predict first)"), §11 (the prediction and the decision to keep E1 at fixed `k`);
`docs/research/specs/MARL_EMPIRICAL_EVIDENCE_SPEC.md` §4, §5.2, §11.4. Claim ceiling:
**B — EXPLORE.** Launch condition: after the throughput refactor's P3 has landed (re-frozen
fingerprint, new timing), so that both arms run on the same environment code; the launch commit's
sha is recorded in the manifests.

## 1. Question, claim ceiling, non-goals (spec §4.1)

Question: at fixed `k = 10` on scenario 1, does giving the team and individual discriminators the
normalised skill age as an input (D1) change, relative to the same learner without it (D0), the
stability of skill labels across training and the discriminators' accuracy on a frozen probe set,
and does it change the return?

Prediction on record (plan §11): owner — no material change in label agreement or probe accuracy;
reviewer — an accuracy gain concentrated on high-age probes, smaller than the gain D2 will show.

Non-goals: no D2 arm, no finite `c`, no corridor, no claim about which arm is better in return
(the return is reported as a counter with the E0 caveat), no seed-count claim beyond "direction
and obvious instability" (spec §5.2, three seeds).

## 2. Algorithm, environment, comparator (spec §4.2)

- Learner: HMASD base route at the launch commit. Both arms use `policy_interruption_mode = "d2"`
  with `interruption_cost_c = interruption_cost_c_Z = inf`, `skill_cap_k_max = team_cap_k_Z = 10`
  (the fair D0 of ADR 01). D0: `age_feature = "off"`. D1: `age_feature = "normalized"` (the
  discriminator input grows by one dimension: `a_Z / k_Z` for the team discriminator, `a_i / k_max`
  for the individual one; the coordinator and the low-level policy are unchanged).
- Environment: scenario 1, `n_uavs = 6`, `n_users = 50`, `episode_length = rollout_length = 500`,
  `num_envs` = 32 if the P3 timing allows one arm within 90 minutes at `R = 20`, else 16 (recorded).
- Rollout loop: the E0 runner `scripts/run_flexible_skill_duration_e0.py`, extended by the E1
  probe measurements of §3 (a new script `scripts/run_flexible_skill_duration_e1.py` that imports
  the E0 runner's loop rather than copying it).
- Seeds: 1, 2, 3 for both arms (six runs). Order: D0 seed 1, D1 seed 1, D0 seed 2, D1 seed 2, D0
  seed 3, D1 seed 3, so that a stop after any pair leaves matched seeds.
- Comparator: D0 versus D1 at the same seed; the two arms share the environment seeds and the
  learner seed, so rollout 1 is identical up to the first discriminator update (checked as in E0).

## 3. Measurements (spec §4.3, §4.4, §5.2)

Everything E0 records per rollout (transitions, episodes, optimizer steps per network, `M`,
returns, exposure lines, D0 metrics, evaluation every 5 rollouts with 8 deterministic episodes),
plus, after every rollout's update, on the frozen probe set
`temp/directions/flexible_skill_duration/probes/E0_probe_set_seed1.npz` (content digest
`1b983ea98260a6b498fb0a01fb66d245fb4af105eb5dca43a0042d712afbf51c`, 1,536 probes):

1. **Discriminator labels.** Team label `argmax` of the team discriminator on the probe's global
   state; individual label `argmax` of the individual discriminator on the probe's observation
   conditioned on the probe's recorded team skill. For D1 the age input is `(env_step mod 10) / 10`
   for both ages, because the probes were collected under `off` with `k = 10` where every agent's
   age equals the team age. Labels are stored per rollout as `[R, 1536]` and `[R, 1536, 6]`.
2. **Label agreement between adjacent checkpoints** (concern C2): fraction of probes whose team
   label at rollout `r` equals the label at `r - 1`; the same per agent for individual labels,
   averaged over agents. Reported per `r` and as the mean over `r >= R/2`.
3. **Probe accuracy** (concern C2): fraction of probes whose team label equals the recorded team
   skill, and whose individual label equals the recorded agent skill; overall and **split by age
   bucket** `{0-2, 3-6, 7-9}` of `env_step mod 10`. This split is the differentiating measurement
   for the prediction on record.
4. **Value-target drift** (concern C1): the coordinator's team value head and per-agent value heads
   evaluated on the probes at each rollout (denormalised); reported as the mean over probes of the
   absolute change between adjacent rollouts, and the variance across rollouts `r >= R/2`.
5. The D1 arm additionally records the age-feature share of the discriminator's first-layer weight
   norm (the norm of the age column over the norm of the whole input-projection matrix), per
   rollout, as a cheap indicator of whether the age input is used at all.

The probe set is read-only; nothing is added to it. The measurements are made by a second agent
instance synced from the learner (the E0 evaluation mechanism) so that the learner's RNG and
per-lane state are untouched.

## 4. Budget and stop rule

1. `R = 20` rollouts per run (twice E0, so that the `r >= R/2` window has ten checkpoints);
   `num_envs` per §2. Wall-clock estimate written before launch from the P3 timing.
2. Resource preflight inside the runner before every run, as in E0.
3. Stop rule per run: `R` rollouts, or the first non-finite loss or return (recorded as an
   instability observation). Instrumentation failure quarantines the run (spec §6.2): no
   interpretation, no resume, no salvage. A quarantined run's seed is re-run once from scratch
   under a new run name; if it fails again the seed is reported as not run.
4. Stop rule for the study: all six runs, or the owner's stop. Pairs completed are reported as such.

## 5. Reading the result (written before the data)

- The prediction on record is contradicted if the D1 minus D0 probe-accuracy gain in the `7-9`
  bucket exceeds the gain in the `0-2` bucket by more than the across-seed spread of either, in at
  least two of three seed pairs. It is supported if the gains are within the spread in every bucket.
- Label agreement: reported as D1 minus D0 per seed pair with the three-seed range; no threshold is
  fixed, the direction is the observation.
- Return: reported with the E0 caveat; a difference within the across-seed range of either arm is
  reported as "no difference observed at this budget".
- Any pattern not anticipated here is recorded as an observation for E2's design, not as a result.

## 7. Interpretation boundary (spec §4.7)

Bounded to scenario 1 with six UAVs and fifty users, fixed `k = 10`, one machine, three seeds,
`R = 20` rollouts, the frozen seed-1 probe set collected under `off`, and the measurements above.
It says whether the explicit age input changes label stability and probe accuracy at fixed `k`; it
says nothing about D2, finite `c`, the corridor, or which arm is better.
