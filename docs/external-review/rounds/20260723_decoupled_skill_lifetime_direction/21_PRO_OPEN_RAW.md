# 1. Evidence audit: what R42–R48 establish

## 1.1 R42 — valid scientific failure of a skill-logit residual

Repository fact:

R42 added a zero-output task-blind residual over the incumbent categorical skill
roster, focal position and active mask to the existing individual-skill logits.
It did not introduce a separate lifetime event or a separate renewal
probability. 


The implementation and fixed service anchor were valid. The treatment reduced
win performance relative to fixed refresh, with a paired interval
`[-0.17,-0.03]`. Its temporal-decoupling gate also failed: treatment
discordance was `0.10`, full synchronization remained `0.90`, and one
KEEP/SET marginal was zero. The registered result is
`VALID_FAIL_R42_IRR_SERVICE`. 



Binding scientific scope:

R42 closes direct incumbent-roster corrections to the existing categorical
skill logits under that complete-replacement action grain and credit path. It
does not test a separately defined latent transition, predictive segmentation,
continuous slow state or self-supervised lifetime process.


## 1.2 R43 — operationally invalid for mechanism inference

Repository fact:

R43 factorized each individual categorical action into an explicit
KEEP/RENEW factor and, only on RENEW, a conditional non-incumbent categorical
skill. It retained the source-global `k0=50` opportunity clock, source team
token, low policy and source discriminators.



The R43 fixed arm lost the registered positive source anchor. Its final
win/key0/key1 values were `0.52/0.54/0.81`, while the original source checkpoint
remained positive on both evaluation streams. The registered terminal was
`INVALID_R43_FIXED_ANCHOR_LOST`. 


Binding scientific scope:

R43 supplies diagnostic evidence that the proposed factorization, clock,
likelihood replay and gradient path were implementable. It supplies no valid
scientific evidence about whether the treatment succeeds or fails. Its
all-RENEW behavior is quarantined and cannot be used to retire renewal,
categorical skills or asynchronous lifetime.


## 1.3 R44 — valid failure of frozen-source `K=50` reward-credit renewal

Repository fact:

R44 froze the complete R41B source and reused R43’s explicit renewal
factorization and global `K=50` clock. The treatment’s only trainable behavioral

Binding scientific scope:

The initial analyzer defect was a contract mismatch over critic-gradient counts;

## 1.4 R45 — valid failure of the Alice–Bob natural-support Q/DR route

Binding scientific scope:

# 2. Plural Conjecture → Derivation → Counterexample → Correction pass

## Candidate A — C-ALPSW: agent-local predictive sparse-write slow state

### Conjecture

Each active lifecycle owns two states:

- a fast recurrent control state `h_i`;
- a slow predictive state `z_i`.

`h_i` may update on every active primitive transition. `z_i` remains exactly
unchanged until an endogenous agent-local latent transition writes a new value.
The transition model is learned only from generic observation dynamics and
membership masks, not from external reward or task semantics.

There is no categorical skill label and no high-level skill action.

### Derivation

G8’s single recurrent state already has sufficient theoretical freedom to carry
both fast and slow information. The admissible claim is therefore not greater
representational expressivity.

The possible benefit is an inductive-bias and credit factorization:

1. Fast primitive control no longer has to preserve all slowly varying
   predictive information in the same continuously overwritten state.

2. A piecewise-persistent slow state gives long-horizon information an explicit
   ownership and replay contract across updates, temporary absence and roster
   edits.

3. The writer can be trained from an environment-agnostic predictive
   description-length objective rather than the external-return renewal
   estimators that failed in R44–R46.

4. The primitive policy can learn whether the slow state is useful while reward
   gradients are prevented from redefining the writer’s segmentation.

5. An explicit slow state is intervention-accessible. A later causal audit can
   distinguish “predictable state exists” from “the policy naturally uses the
   state to improve behavior.”

### Strongest counterexample

An unrestricted recurrent policy can absorb the entire slow state into its
hidden state. Therefore C-ALPSW cannot claim that recurrence is incapable of the
behavior.

Further counterexamples are:

- always write: the predictor rewrites every step and calls the resulting
  one-step feature a skill;
- never write: a stable latent persists but never responds to genuine changes;
- membership-gap shortcut: temporary absence or join events determine apparent
  lifetime without learned process segmentation;
- nuisance segmentation: the writer tracks an easily predicted observation
  fluctuation that does not affect primitive behavior;
- latent-coordinate relabeling: raw coordinate accuracy appears poor despite
  identical behavior, or appears high only because labels were aligned post hoc.

### Correction

- Define the slow state through an online predictive compression objective with
  an explicit write cost.
- Treat oracle change-point labels as audit-only evidence, never as an input,
  reward or training target.
- Require exact always-write, never-write, age-only and membership-event-only
  nulls in the first derivation.
- Define a “skill” only after both natural persistence and causal action
  mediation are established.
- Keep G8 as the mandatory complete comparator.

### Disposition

Retain and select for the first action.

## Candidate B — C-ALH: explicit agent-local categorical hazard

### Conjecture

Each agent samples a Bernoulli termination or renewal hazard and, on renewal, a
new categorical skill. Hazards are independent across active lifecycles and
therefore produce different lifetimes.

### Derivation

This would directly expose a semi-Markov action factor and make lifetime
probabilities explicit. It could in principle assign different renewal times to
different agents.

### Strongest counterexample

A Bernoulli KEEP/RENEW factor evaluated at every active primitive step is
scientifically equivalent to choosing a shared opportunity period `k=1` and
then making the existing per-agent KEEP/RENEW decisions. Changing only the
opportunity frequency is a clock parameter change, not a structurally new
mechanism.

R43 already established the categorical KEEP/RENEW plus conditional-skill
factorization mechanically; R44 showed that a connected renewal actor can move
without transporting to useful timing; R45 showed that next-window renewal
value on the source was overwhelmingly common-mode.

A context-insensitive hazard can also produce nondegenerate lifetime
distributions without useful timing, as retained by
`CE-CONTEXT-INSENSITIVE-HAZARD`. 

### Correction

A future explicit hazard route would need a new causal source and a
scientifically new source of boundary supervision. Merely changing `K=50` to
another period, including one, is prohibited.

### Disposition

Park. Reactivate only if C-ALPSW establishes a valid predictive boundary object
but later evidence shows that task-directed explicit termination decisions are
necessary and can be studied without reviving R43–R45.

## Candidate C — C-ATS: continuously adaptive timescale recurrence

### Conjecture

Split each lifecycle’s state into fast and slow components and update the slow
component continuously:

    z_i,t+1 = (1 - alpha_i,t) z_i,t + alpha_i,t candidate_i,t

where `alpha_i,t` is learned from task-blind context.

### Derivation

This is simpler than a discrete write model and may suppress fast-state
interference while allowing each agent a different effective memory timescale.

### Strongest counterexample

There is no objective segment boundary. “Lifetime” must be recovered by an
arbitrary threshold on `alpha`, decay mass or autocorrelation. A continuous
leak can remain numerically persistent while having no discrete behavioral
meaning, and it can be folded directly into ordinary recurrent weights.

Any claimed lifetime would therefore depend on a post hoc threshold unless a
new estimand is supplied.

### Correction

C-ATS requires a threshold-free survival or causal persistence estimand before
it can support a variable-lifetime claim.

### Disposition

Do not schedule. Retain as a fallback representation family only if a later
derivation supplies a threshold-invariant lifetime definition.

## Candidate D — C-SEPM: set-equivariant persistent population memory

### Conjecture

Maintain an unordered set of persistent records whose creation, update and
deletion are permutation-equivariant. Active lifecycles read or own records,
allowing complementary information to persist across roster turnover.

### Derivation

This family could address the many-agent burden that individual recurrence may
not solve: complementary allocation among retained, temporarily absent and
newly joined members.

### Strongest counterexample

A recurrent team summary or ordinary set encoder may carry the same information
without learned persistent records. Fixed memory slots may silently reintroduce
identity. More importantly, this family changes both the individual-lifetime and
coordination axes at once, making attribution poor.

The accepted portfolio already records that team recurrence was sufficient for
the G2 global-bit handoff and that roster interventions in G3/G4 changed policy
without establishing competence. 


### Correction

First establish one individually owned lifetime object. Reactivate population
memory only when an identified complementary-allocation source demonstrates
that per-lifecycle state and TEAM_REC are insufficient.

### Disposition

Park as a live coordination direction, not iteration 1.

# 3. Selected scientific direction

## 3.1 Selection

Select C-ALPSW.

It is the smallest surviving family because it retains the validated G8
dynamic-roster policy and adds only one scientifically distinct object: a
lifecycle-owned predictive slow state with sparse endogenous transitions.

## 3.2 What it retains, deletes and adds

Retain:

- G8’s active-set, capacity-independent direct policy;
- lifecycle-owned fast recurrent state;
- anonymous membership handling;
- active masks;
- primitive action learning from external return;
- survivor continuity;
- the exact G8 comparator.

Delete or omit:

- shared global skill cycle `k`;
- categorical team skill `Z`;
- categorical individual skill labels;
- an autoregressive high-level skill coordinator;
- high-level reward PPO and high-level value heads;
- skill discriminators and discriminator-derived intrinsic rewards;
- a duration-action catalogue;
- reward-trained KEEP/RENEW decisions.

Add:

- one bounded continuous slow state per lifecycle;
- one task-blind latent transition model;
- one environment-agnostic predictive decoder/objective;
- one action adapter that lets the primitive policy consume the detached slow
  state;
- explicit lifetime, replay and intervention evidence for the slow state.

The legacy HMASD coordinator generates a team token followed by categorical
per-agent skills and owns fixed per-agent value heads indexed by configured
agent count. That is not the open-roster object selected here.



## 3.3 Why C-ALPSW is structurally new relative to R42–R48

C-ALPSW is not:

- a residual on categorical skill logits, unlike R42;
- a reward-trained categorical KEEP/RENEW action, unlike R43/R44;
- a change to the global check period;
- a next-`K` external-return renewal critic, unlike R44/R45;
- an action-Q sign estimator, unlike R45/R46;
- a frozen global spectral basis or skill-label occupancy score, unlike R47;
- a recurrent hidden-state reset at a categorical boundary, unlike R48.

Its latent transition is part of an environment-agnostic predictive state-space
model. It is not treated as a high-level task action.

## 3.4 Honest claim ceiling

Because ordinary recurrence can emulate finite persistent state, C-ALPSW may
eventually support only:

- an optimization or temporal-factorization advantage;
- more stable held-out transport;
- a causally used persistent representation;
- a cleaner individual-lifetime object.

It may not claim representational impossibility of G8 or ordinary recurrent
MARL.

# 4. Frozen scientific contract for C-ALPSW

## 4.1 State objects

For each lifecycle `i`:

    h_i,t  = fast lifecycle-owned recurrent control state
    z_i,t  = bounded slow predictive state
    age_i,t = active primitive steps since the last structural or learned write
    w_i,t  = latent write indicator on an active transition

`h` and `z` are distinct causal objects. Concatenating a larger ordinary hidden
state and naming part of it “skill” does not satisfy this contract.

## 4.2 Definition of skill

Before causal evidence, `z` is a candidate slow state.

It is called an individual skill only if all of the following later hold:

1. Natural persistence:
   `z` remains unchanged across more than one active primitive step on a
   nontrivial population of complete segments.

2. Endogenous change:
   writes are not determined solely by a fixed period, age, join/rejoin,
   temporary absence or padding layout.

3. Primitive action relevance:
   intervening on `z` while holding observation, fast state, active set,
   parameters and action RNG fixed changes the primitive action distribution or
   later trajectory.

4. Natural mediation:
   naturally written states mediate later behavior and held-out utility, rather
   than appearing only in forced branches.

5. Simpler-explanation resistance:
   the effect survives comparison with a capacity- and training-matched masked
   slow-state arm and with G8.

Predictive accuracy or persistence alone is not skill evidence.

## 4.3 Lifetime

A lifetime is measured in active primitive steps:

    lifetime = active steps from one write to the next write

The opening write may be:

- the structural initial write at a genuine join;
- an endogenous learned write during active execution.

The closing event may be:

- the next endogenous write;
- terminal leave, producing a right-censored segment;
- formal evaluation horizon, also right-censored.

Temporary absence does not advance age or terminate the segment.

Rollout cutoffs, optimizer updates, checkpoint boundaries and ordinary episode
chunking are not lifetime events.

## 4.4 Latent transition

At a genuine join:

    z_i,0 ~ q_join_phi(z | c_i,0)

This is a structural initialization. There is no Bernoulli write decision at the
join.

For an active existing lifecycle:

    w_i,t ~ Bernoulli(lambda_phi(c_i,t))

If `w_i,t = 1`:

    candidate_i,t ~ q_phi(z | c_i,t)
    z_i,t+ = candidate_i,t
    age_i,t+ = 0

If `w_i,t = 0`:

    z_i,t+ = z_i,t-
    age_i,t+ = age_i,t- + 1

The transition is evaluated only for that lifecycle’s active steps. It is not
driven by a shared high-level cycle.

## 4.5 Causal online context

The writer context may contain only:

- current local observation or a uniformly defined local observation embedding;
- `stopgrad(h_i,t)`;
- `stopgrad(z_i,t-)`;
- active-step age through a fixed task-independent encoding;
- anonymous membership-event type: genuine join, temporary leave, rejoin,
  terminal leave or none;
- an active-set permutation-invariant summary with no fixed identity slots;
- the executed primitive action when used only as a dynamics-conditioning
  variable.

It may not contain:

- lifecycle key or persistent identity as a feature;
- assigned role;
- task name;
- goal, target or named object;
- external reward;
- success or progress predicate;
- distance-to-goal or task phase;
- an oracle change-point or duration label;
- a future observation at decision time;
- global cycle phase `t mod k`.

Routing keys may exist only in the environment ledger and evidence provenance.

## 4.6 Environment-agnostic supervision

The writer and predictive model are trained only from a generic predictive
objective over raw or uniformly encoded observations, active masks and generic
membership transitions.

A scientific form is:

    J_pred =
        E[
          sum over active transitions
            -log p_eta(y_i,t+1 | z_i,t+, h_i,t, o_i,t, a_i,t, active-set summary)
          + beta * w_i,t
        ]
        + registered variational regularization

`y_i,t+1` may contain only the next generic observation representation and
generic membership mask/event representation.

External reward is excluded from `J_pred`.

Oracle segment or regime labels may be used only in an audit of a synthetic
derivation source. They may not train the writer, determine a write or enter the
policy.

## 4.7 Probability factorization

For the active set `A_t`, writer transitions are parallel and
permutation-equivariant:

    p_phi(w_t, candidate_t | H_t)
      =
      product over i in A_t of
        Bernoulli(w_i,t ; lambda_i,t)
        times
        q_phi(candidate_i,t | c_i,t) raised to w_i,t

The primitive action factor is separate:

    a_t ~ pi_theta(
              a |
              observations_t,
              fast_states_t,
              stopgrad(slow_states_t+),
              active_mask_t,
              active-set summary_t
          )

The complete causal factorization is:

    p(w_t, candidate_t, a_t | H_t)
      =
      p_phi(w_t, candidate_t | H_t)
      times
      pi_theta(a_t | H_t, stopgrad(z_t+))

There is no candidate density when `w=0`.

The structural join sample has its own `q_join` factor and no Bernoulli
renewal factor.

## 4.8 Gradient and credit authority

Writer/predictor authority:

- predictive and variational losses update only the slow-state writer,
  candidate encoder and predictive decoder;
- external reward and primitive PPO losses do not update those modules;
- any G8 representation consumed by the writer is stop-gradient at the writer
  boundary.

Primitive-policy authority:

- the primitive actor may learn an adapter from `stopgrad(z)` to action logits
  or policy features;
- actor and critic gradients do not pass into `z`, the write probability or the
  predictive decoder;
- the primitive policy continues to learn from the ordinary external MARL
  objective.

A collected transition’s predictive loss is assigned to the slow state that was
installed for that transition. Administrative update boundaries may truncate
backpropagation but do not terminate the scientific lifetime.

No lifetime reward, switch penalty, renewal bonus or external-return writer
advantage is permitted.

## 4.9 Future comparators and causal estimands

No formal comparison is authorized now, but the scientific comparator structure
is frozen.

Mechanism-matched null:

    ALPSW-DUM

It owns the same writer, predictor, slow state, parameter count, predictive
updates and RNG, but multiplies the slow-state contribution to the primitive
policy by zero.

Complete comparator:

    exact G8 direct recurrent policy

Ordinary recurrent MARL and G8 remain mandatory comparators but not universal
research-admission gates.

Future primary link estimand:

    G_link = E[U_ALPSW - U_ALPSW-DUM]

Future complete-algorithm estimand:

    V = E[U_ALPSW - U_G8]

Future mechanism evidence must include:

    I_z =
      expected primitive-action total variation under a same-state intervention
      on z with observation, h, active set and action RNG fixed

    C_write =
      same-snapshot CRN continuation contrast between a natural write and its
      forced no-write alternative, or a natural no-write and its forced write
      alternative

Natural write/no-write groups alone are selection-confounded and are not a
causal estimand, consistent with the retained forced-event lemma.



## 4.10 Invariances

The writer, predictive objective, action consumer and evidence must be invariant
or equivariant as appropriate to:

- permutation of active-member presentation order;
- arbitrary lifecycle-key relabeling;
- inactive padding and operational capacity;
- batching and environment packing;
- insertion of inactive time during temporary absence;
- rollout chunking and checkpoint boundaries;
- invertible relabeling of latent coordinates.

Raw latent-coordinate accuracy is not an admissible metric. Intervention and
prediction evidence must be invariant to a latent permutation, sign change or
other registered invertible reparameterization.

## 4.11 Runtime-variable membership semantics

Genuine join:

- allocate a fresh lifecycle;
- initialize `h=0`;
- perform one structural `q_join` slow-state sample;
- set age to zero;
- do not reuse a terminal lifecycle state.

Temporary leave:

- freeze `h`, `z`, age, writer RNG position and open segment;
- emit no write opportunity and no predictive transition while inactive.

Rejoin:

- restore the frozen lifecycle state;
- process the current observation before its next primitive action;
- allow an ordinary endogenous write if the restored/current predictive context
  warrants one;
- do not force a write merely because rejoin occurred.

Terminal leave:

- right-censor and close the current lifetime;
- delete `h`, `z`, age and pending predictive ownership after final evidence is
  recorded.

Other survivors:

- retain their own states exactly;
- may respond only through the anonymous active-set summary;
- are never globally reset by another lifecycle’s membership event.

These rules extend the accepted G8 ownership contract, under which temporary
absence freezes hidden state, rejoin restores it, and a genuine join begins with
zero recurrent state. 


## 4.12 Checkpoint and replay meaning

A future checkpoint must own:

- G8 policy and optimizer state;
- writer, candidate encoder, predictive decoder and adapter state;
- every lifecycle’s `h`, `z`, age and open-segment start;
- active masks, membership epochs and ledger routing;
- writer, candidate, primitive and environment RNG states;
- predictive normalizers and pending fragment statistics;
- collector, update and episode positions.

Reload must preserve:

- exact discrete write decisions, masks, membership and segment identities;
- exact RNG schedules and realized variates;
- registered numerical replay of write probabilities, candidate densities,
  prediction losses and primitive action probabilities;
- no write, close or reset caused by checkpointing itself.

A replay record must separately identify:

- structural join initialization;
- ordinary latent writes;
- persisted no-write transitions;
- primitive action likelihood;
- predictive evidence;
- segment ownership and censoring.

A malformed provenance record is operationally invalid, not negative scientific
evidence.

## 4.13 Exact immediate falsifier

C-ALPSW is rejected before implementation if the S1 derivation establishes any
one of the following:

1. No nonempty write-cost interval exists in which a nondegenerate sparse writer
   is optimal.

2. Always-write, never-write, age-only, membership-event-only or post-hoc
   segmentation matches the proposed online predictive objective.

3. The proposed boundary requires external reward, task fields, identity,
   oracle duration or future information.

4. The lifetime is not invariant under lifecycle relabeling, inactive padding
   or temporary-absence insertion.

5. The proposed mechanism is only a categorical R43-style KEEP/RENEW policy with
   a changed opportunity period.

6. A “skill” claim requires raw latent-label accuracy rather than causal action
   mediation.

This is the family’s iteration-1 falsifier. No empirical rescue is permitted if
one of these conditions is proven.
