6. Prohibited rescues and reactivation conditions
Prohibited rescues of this result

Do not:

add seeds or budget;

lower 0.78;

select a best checkpoint;

change the reward, observation, benchmark distribution, model, PPO, learning rate, or backend;

rerun on CUDA to seek a different scientific result;

reinterpret aborted attempts;

use G, K, I_TV, or C_total to bypass branch 3;

add intrinsic reward or task shaping;

add identity, roles, a skill catalogue, duration actions, a learned hazard, graph, team latent, communication module, or new credit objective;

rename the source or branch and repeat it.

These changes are explicitly prohibited by the frozen design and the project’s valid-negative rule.

Reactivation of Conjecture A — shared credit/optimization bottleneck

Reactivated by a separately registered observation showing that the same information and model class can represent successful behavior, while the frozen external-credit learner cannot obtain it. A causal credit replacement—not a coefficient sweep—would then become reviewable.

Reactivation of Conjecture B — base representation or policy insufficiency

Reactivated if one structurally stronger, information-matched MARL controller accesses this benchmark under a new claim. Merely widening the current network after seeing the result is not sufficient.

Reactivation of Conjecture C — useful EHC link masked by no-access

Requires an access-positive mechanism-matched source with:

positive G;

executable mark-to-action dependence;

natural KEEP and RENEW consequences;

held-out external transport;

no simpler capacity or information explanation.

Reactivation of Conjecture D — link-null or benchmark mismatch

Strengthened if an accessible source produces UCB(G)<=0.10, or if positive representation influence repeatedly fails natural consequential transport. It becomes broad retirement evidence only after structurally independent, identified counterexamples—not from this no-access source alone.

The present frozen benchmark–comparator pair itself is not reactivated. It remains permanently closed unless an actual provenance or operational defect is discovered; none is reported here.
