## Where the apparent non-uniqueness came from

Four different objects were collapsed into one demand for a fully code-ready
scientific contract:

1. **Algorithm/conjecture semantics.** These determine which mechanism,
   behavior and capability relation is being studied and must remain the
   research scope.
2. **Evidence-contract choices.** These make one later conclusion-bearing
   action interpretable and reproducible. They are frozen immediately before
   that action, not before derivation or counterexample construction.
3. **PM-owned engineering realization.** These determine how the declared
   object is represented and executed without changing its information or
   estimand. Non-uniqueness here is desirable implementation freedom.
4. **Premature theory ontology.** Exhaustive result trees and a requirement to
   pre-classify every future observation freeze an immature conjecture and turn
   local gates into research objectives. These should not be completed.

The `two reasonable implementations` criterion applies to the evidence-bearing
semantics of an authorized action. It does not require identical code structure,
tensor layout, seed values or every environment edge case before an algorithmic
derivation can proceed.

## Measurement issue that is actually algorithmic

The next question is not which roster probability, dtype, bootstrap count or
seed to choose. It is whether the current implication is valid:

```text
natural KEEP/RENEW use
+ lifetime diversity
+ commitment/logit intervention sensitivity
+ external value gain
=> event-held temporal commitment supported
```

Existing project reasoning supplies three direct counterexample families:

1. a random non-degenerate KEEP/RENEW policy can satisfy natural-use support
   without demand-related commitment;
2. exogenous opportunity spacing can create lifetime diversity without learned
   lifetime control; and
3. an uninformative latent with strong logit coupling can change actions or
   `I_TV` without stable, task-relevant sequence organization.

These counterexamples target the measurement implication, not EHC, hierarchy,
variable lifetime or the valid G0 result.
