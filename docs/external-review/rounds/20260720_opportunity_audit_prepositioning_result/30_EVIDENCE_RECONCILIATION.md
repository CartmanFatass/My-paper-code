## Exact interpretation of the result

The result identifies a task-local scheduling mechanism:

```text
predictable candidate windows
+ sparse owner opportunities
+ persistent primitive marks and long KEEP
-> useful pre-wave configuration
```

It does not identify:

```text
learned reusable skills
+ natural heterogeneous semantic lifetimes
+ later-on-earlier applied-prefix cooperation
-> a load-bearing hierarchy advantage
```

`G_H=1` shows that the realized sparse frontier contains enough authority when
full future information is available. The positive learned excess is instead
localized before waves, while both multi-owner-later excess and the aggregate
working-prefix direction are negative. The strongest supported reduction is
therefore scheduled persistent-mark control on this toy, not F1-specific team
composition.

## Reconciled plural causal portfolio

### K — Current benchmark is calendar-identifiability limited

Fixed candidate windows, visible physical time, a fixed four-step wave, a
two-step SHORT streak target and primitive-as-label semantics allow useful
pre-positioning without learned temporal abstraction. A time-only or
candidate-window finite-state null on held-out schedules would raise or lower
this explanation.

### D — Information-matched direct recurrence is sufficient

Primitive-time recurrence may supply all needed memory and adaptation without
an explicit skill object. It is already the mandatory access null, although
future comparisons must match its active-set communication and control
authority. Its strongest contradiction would be a load-bearing benchmark where
a learned-skill hierarchy provides material held-out value or sample-efficiency
advantage under matched information, communication, capacity and exposure.

### R — Persistent event abstraction has value without learned skills

An owner-local recurrent controller may benefit from commitments that persist
between sparse opportunities, independent of later-on-earlier prefix coupling.
On this toy it explains PREWAVE dominance and long KEEP. It merges into ordinary
controller state if a matched scheduled-mark controller is equivalent to direct
recurrence, and it remains short of skill evidence unless learned closed-loop
behaviors become natural and load-bearing.

### P — Applied-prefix value may exist only in another coordination regime

The current evidence weighs against P on Generic-SHORT but does not logically
disprove it for all tasks. It remains parked unless a non-calendar,
non-prepositionable task naturally requires multiple owners to make sequential
same-frontier assignments and a matched working-prefix treatment transports to
external utility.

### B — Learned executor may be a conditional downstream bottleneck

Fixed primitives show that the high/event path can express task-local useful
behavior but reveal nothing about why historical shared learned executors
failed. B is meaningful only after a benchmark establishes load-bearing
persistent abstraction; otherwise replacing the executor would stack an
unidentified mechanism onto a non-identifying task.

The Gemini continuous-mark idea is a possible implementation family within or
against R, not a separately established cause. K is a benchmark explanation,
not a production module.

## Candidate next evidence sources without ranking

### A — Benchmark-identifiability contract

Define a small task family with constructive feasibility, a labeled non-causal
hindsight ceiling, an absolute-time/candidate-window finite-state null and a
causal information-matched recurrent controller. Evaluate held-out schedule,
roster and duration shifts. Branches distinguish shortcut-identifiable,
ordinary-access, no-access and structurally unreachable tasks before any skill
learner is introduced.

### B — Reanalysis of the existing checkpoint under schedule information

Without retraining or changing the toy, evaluate time-only/calendar-only
predictability and held-out or permuted schedule behavior only if an exact
counterfactual can be constructed from the existing task contract. This may
strengthen or weaken K but cannot establish F1, learned skills or hierarchy
superiority and cannot rescue the completed toy line.

### C — Information-matched ordinary-control matrix on a qualifying task

Only after a task passes feasibility and ordinary access, compare direct
primitive recurrence with a same-information, same-communication,
same-capacity scheduled persistent-mark controller. This separates D from R;
it does not by itself establish learned skills.

### D — Conditional learned-executor necessity source

Only after persistent abstraction has external load-bearing value, replace one
low executor parameterization at a time while freezing the high/event spine and
retaining the direct null. Natural executable differentiation, nuisance
resistance, held-out utility and sample efficiency—not labels or intervention
effects—must carry the claim.
