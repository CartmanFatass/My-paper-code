### 5. Variable lifetime and learned-skill boundary
*   **Persistent marks**: Explicit environmental or active-set memory that survives physical step boundaries, allowing asynchronous context sharing across dynamic lifecycles.
*   **Supplied primitives**: Fixed, hardcoded low-level actuator sequences (like the executor in this toy) which serve as an execution crutch. They are *not* learned skills and cannot claim semantic discovery.
*   **Learned heterogeneous skills**: Discovered macroscopic behaviors whose lifetimes organically vary based on unpredictable environment shocks and task demands, completely decoupled from fixed duration catalogues or supplied rigid sequences.
