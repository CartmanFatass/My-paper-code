## Binding architecture portfolio

### F0 — retain and strengthen

`Active-Set Scheduled Recurrent MARL` is the ordinary-MARL reduction baseline.
It receives the same active-only packing, lifecycle table, survivor/rejoin
continuity, exogenous policy opportunities, skill-conditioned low actor,
duration-correct event return, checkpoint contract and replay ledger as F1.

Its learned member logits are conditionally independent given the same initial
active-set context. An applied prefix may change only a deterministic legality
mask, not learned scores on the common legal support.

### F1 — retain with corrections as the leading family

`Exchangeable Exogenous-Opportunity Event-Frontier Commitment Editor` is the
single leading skill-based hypothesis. It shares all correctness infrastructure
with F0 and differs only by a learned, applied-prefix-conditioned distribution
over concurrent commitment edits.

Its proposed novelty is therefore not variable `N`, ragged tensors, an event
ledger, `gamma^Delta`, survivor state or skill persistence. It is the claim that
earlier applied skill edits materially change later learned scores on the same
legal support and that this coupling yields cooperative value beyond F0.

### F2 — merge and retire as a separate name

The conditionally independent KEEP/SET part is F0. Learned termination hazard
belongs to the deferred point-process family. Keeping F2 would preserve a false
middle layer with no unique causal boundary.

### Learned point process — defer

Survival/intensity, integrated hazard, censoring and competing-risk likelihood
remain outside the first architecture. They become relevant only if a later
result identifies exogenous opportunity timing itself as the binding limit.

  rejoin continuity, learned event-time likelihood or HMASD skill cooperation.

  It is a synchronous-design warning, not a causal impossibility result.
- **Reject:** Hybrid Field-Slot or a sparse graph is the current default.
  Start from the smallest active-only permutation-compatible sum/count encoder.
- **Accept:** lifecycle ownership, exchangeability, replay and duration credit
  are shared correctness infrastructure, not F1 novelty.
- **Reject:** retained R53 artifacts support a no-training prefix audit. They do
  not contain the necessary final weights and per-decision contexts.
- **Accept:** identity-free recorded random event-frontier ordering can support
  exact teacher-forced AR; order probability is external and cancels in the PPO
  ratio.
