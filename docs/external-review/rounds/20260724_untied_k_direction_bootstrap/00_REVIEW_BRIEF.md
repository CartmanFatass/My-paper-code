## Why this round exists

Two things happen here at once, and they are deliberately separated in the
question.

**First, it registers this branch's conversation.** Conversations are bound one
per branch. The previous registration belonged to `aggressive` and is retired;
`untied-k` has had none. This is the first round in its dedicated conversation,
so the freshness fence it carries also fixes the branch identity for every later
round.

**Second, it asks the branch's opening scientific question.** `untied-k` exists
to explore unbinding the skill period `k`. That direction has not been chosen —
only named. Choosing it is a scientific decision, and scientific decisions are
now yours.

## What changed in the authority contract

The Project Manager previously held scientific reconciliation exclusively. That
has moved. The split now in force:

- **You own the science** — which mechanism is right, which route is excluded,
  whether a result closes, what the next scientific direction is.
- **The Fable orchestrator owns the code** — module shape, interfaces, task
  decomposition, implementation briefs. It never chooses the scientific route.

For the protected semantics that are simultaneously algorithm and code — reward,
probability factorization, gradients and detach, recurrent state, masks, clocks,
lifecycle ownership, RNG, replay, credit, checkpoint meaning — the split runs
through them: **you decide whether one changes; the orchestrator decides how.**

The corresponding amendments to `AGENTS.md` and the role charters are not yet
written. This round does not depend on them, and your answer does not authorize
them.

## Boundary of this round

You are asked for a scientific direction and its separating evidence. You are
not asked for, and must not supply:

- an implementation plan, file list, function signature, or task decomposition;
- authorization for any nonformal or formal compute;
- a workflow, role, or process change;
- a unique legal successor that forecloses the portfolio.

Read `docs/external-review/OPEN_REVIEW_PRINCIPLES.md` for how to explore inside
these constraints. The framing in the question is a hypothesis offered for you
to replace if it is wrong.
