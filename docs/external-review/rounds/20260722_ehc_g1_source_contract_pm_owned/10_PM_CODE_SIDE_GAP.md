## Frozen mechanism and outcome skeleton

The clarification must not reopen these choices:

- OR is the complete ordinary recurrent comparator.
- DUM and EHC have matched commitment capacity and optimizer exposure.
- EHC alone enables `primitive_logits = base_logits + W_z(m*z)`.
- `G = U_EHC - U_DUM` remains primary.
- Anonymous membership, survivor continuity, active masks, lifecycle ownership,
  and distinct physical/opportunity/event/segment clocks remain binding.
- Operational validity and source identifiability precede source access; source
  access precedes `G` and the K/`I_TV`/`C_total` battery.
- If no arm accesses G1, close only G1 without mechanism inference.
- With access, `LCB(G) > 0.10` plus the full battery supports the event-held
  link locally; integration remains separate.
- With access and `UCB(G) <= 0.10`, weaken or retire the link only within the
  matched accessible scope.
- With access and positive G but confident executable or natural-consequence
  failure, retain a representation-only or timing/selection explanation.
- Every other valid pattern is mixed or unresolved; no threshold, seed, or
  budget rescue follows.

## Executable source-family envelopes offered for Pro selection

These are non-authorizing feasibility envelopes, not PM scientific choices.

### Option A: clean-infrastructure temporal-duty source

Reuse only accepted anonymous membership, lifecycle, and snapshot
infrastructure from the clean access carrier. Define a new task whose
unpredictable online process evidence creates member-specific multi-step duties
and whose membership shocks change the optimal held commitment. The prior
clean task and reward cannot be reused unchanged because commitment was not
load-bearing there.

Engineering tradeoff: lowest implementation risk and clearest reuse boundary,
but external Pro must prevent the new duty from collapsing to an immediately
observable primitive-time shortcut.

### Option B: independent noncalendar multi-owner source

Define a new asynchronous service or allocation task with unpredictable load
onset, non-prepositionable multi-owner dependencies, heterogeneous duty
durations, membership churn, and held-out schedule/roster/duration shifts.

Engineering tradeoff: directly exposes long-lived member-specific
commitments, but has more scientific degrees of freedom and therefore requires
a more complete source definition.

### Option C: exact external-Pro alternative

External Pro may replace both envelopes with one fully specified independent
source that satisfies the frozen skeleton and makes persistent commitment
externally load-bearing.
