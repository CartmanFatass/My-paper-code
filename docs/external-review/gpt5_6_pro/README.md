# GPT-5.6 Pro Research Exchange

This directory stores the exact material exchanged with GPT-5.6 Pro. Each
consultation has one dated folder containing a review entry, the submitted
question/evidence, the raw response, and the controller's later disposition.
The preferred transfer is direct read access to the private GitHub repository;
legacy ZIP packages are not required for new consultations.

Web exchange is manual: Codex prepares and commits these files, the user gives
the review entry and commit to ChatGPT, and the returned answer is archived raw
before interpretation. Do not automate the ChatGPT website.

Do not summarize over a missing raw response. Git is the only version and
identity mechanism; no hashes or checksums are used.
