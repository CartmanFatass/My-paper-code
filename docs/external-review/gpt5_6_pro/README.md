# GPT-5.6 Pro Research Exchange

This directory stores the exact material exchanged with GPT-5.6 Pro. Each
consultation has one dated folder containing the submitted question, the
uploaded ZIP, the raw response, and the controller's later disposition.

Web exchange is manual: Codex prepares these files, the user uploads them to
ChatGPT, and the returned answer is archived raw before interpretation. Do not
automate the ChatGPT website.

Do not summarize over a missing raw response. Git is the only version and
identity mechanism; no hashes or checksums are used.
