# GPT-5.6 Pro Research Exchange

This directory stores the exact material exchanged with GPT-5.6 Pro. Each
consultation has one dated folder containing a review entry, the submitted
question/evidence, the raw response and mechanical intake.
The preferred transfer is direct read access to the GitHub repository;
legacy ZIP packages are not required for new consultations.

Current web transport is performed directly by Research Operations Manager under
`$hmasd-review-round` and `$browser:control-in-app-browser`, using the exact
conversation registered in `docs/external-review/REVIEWER_CONVERSATIONS.json`.
Research Operations Manager inspects for an accepted matching fence before any
submission, archives the completed raw exactly and resumes its local operations
loop without scientific interpretation. Do not create an Exchange task or a
separate transport task.

Do not summarize over a missing raw response. Git and the registered
round/commit/question fence define identity.
