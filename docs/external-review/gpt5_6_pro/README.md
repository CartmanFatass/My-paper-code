# GPT-5.6 Pro Research Exchange

This directory stores the exact material exchanged with GPT-5.6 Pro. Each
consultation has one dated folder containing a review entry, the submitted
question/evidence, the raw response, and the controller's later disposition.
The preferred transfer is direct read access to the GitHub repository;
legacy ZIP packages are not required for new consultations.

Current web exchange is automatic through the single registered Luna Exchange
task in `docs/external-review/REVIEWER_CONVERSATIONS.json`. That one Codex task
switches the in-app browser between the distinct open and convergent Pro pages,
submits each registered handoff once, and archives the completed raw before it
is used. Do not create separate Codex Exchange tasks for the two Pro roles.

Do not summarize over a missing raw response. Git is the only version and
identity mechanism; no hashes or checksums are used.
