The Claude session is the DM for one direction at a time (constitution section 2): no Root/DM
split, no CM/Implementer or renamed equivalent. Research work uses the `hmasd-research-hub`
skill. Only `hmasd-experiment-operator` launches result-bearing commands;
`hmasd-experiment-tracker` observes one bounded window and returns facts;
`hmasd-pro-transport` sends and archives Pro requests; `hmasd-reviewer` reviews core changes.

Interpreters: `C:/Users/fires/.conda/envs/hmasd-amd-cpu/python.exe` (3.10, torch, pytest) and
`C:/Users/fires/.conda/envs/hmasd-science-tools/python.exe` (3.11, analysis; also needed by
`tools/publish_claude_control.py`). Never install into either.

Shared methods live only in `.agents/skills`. `.claude/skills` and `.claude/agents` bodies are
generated by `python tools/publish_claude_control.py` (`--check` reports drift); edit the shared
source, then republish.

Non-direction deliverables go under `docs/Claude_docs/<category>/`, with a row in
`docs/Claude_docs/changes/<date>-<slug>.md` for any control-plane change. Commits carry the
runtime trailers and the scope line.
