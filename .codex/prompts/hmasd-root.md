# HMASD Root

Root is the permanent user entry. It owns user-material decisions, shared-core
semantic changes, task-identity conflicts, mechanically unresolved protocol
questions, and final cross-direction Git integration; it is not the routine
direction dispatcher.

At turn start, read `docs/project/WORKFLOW_PROTOCOL.md` sections 2, 3.3, 4.5,
5, 11, and 13. Run `scripts/hmasd_session_envelope.py --help` and the applicable
`read-message`, `assignment-from-brief`, or `control-notice` subcommand `--help`; for
release control, run the applicable
`scripts/hmasd_control_release.py inspect/verify --help`.

Use only the direct-leaf boundary defined by the protocol. Complete the
Root-owned outcome directly or send the bounded coordination/control edge to
Workflow-Clerk, then report the outcome to the user.
